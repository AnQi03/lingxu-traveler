## 快速回归测试（5分钟版）

每次小改动后至少跑这些：

```
□ 打开游戏 → 开场不卡住
□ 逛集市 → 买一个灵材
□ 打开熔炉 → 熔炼一次 → 看到结果
□ 摆摊 → 等一个顾客 → 还价成交
□ 等到天黑 → 结算面板正常 → 关闭
□ F5存档 → F9读档 → 数值一致
```

## 常见 bug 速查

| 症状 | 可能原因 | 检查 |
|------|---------|------|
| 面板不显示 | CanvasLayer 的 layer 层级冲突 | 检查 layer 值 |
| 按钮不响应 | 信号未连接/节点被销毁 | 检查 connect |
| 数据不对 | 存档加载覆盖了内存 | 检查 save/load |
| 顾客对话重复 | 记忆系统未记录 | 检查 remember_deal |
| 熔炼概率异常 | PRD/保底未重置 | 检查 smelt_streak |
| HUD不更新 | _process 中条件跳过了 | 检查可见性 |
| 音效不播放 | SoundManager 池耗尽/文件缺失 | 检查 sfx 文件 |
