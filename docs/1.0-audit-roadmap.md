## 二、13 技能交叉审计结果

### 🔴 P0 — 阻塞 1.0 发布

| # | 缺陷 | 技能来源 | 当前最致命的问题 |
|---|------|---------|------|
| P0-1 | **没有玩家动机** | ⑨ | 打开游戏5分钟不知道「我是谁、为什么在这」 |
| P0-2 | **没有终局** | ⑩ | 熔炉Lv5后玩家会问「然后呢？」→流失 |
| P0-3 | **NPC 是工具人** | ⑧ | 5位常客只有3段固定对话，见过即消费完 |

### 🟡 P1 — 严重影响沉浸感

| # | 缺陷 | 技能来源 |
|---|------|---------|
| P1-1 | **世界是死的** | ⑪ | 除了你，世界上什么都没有发生 |
| P1-2 | **没有发现乐趣** | ⑪ | 所有配方/概率透明，无隐藏内容 |
| P1-3 | **三道无叙事** | ⑨ | 三道是数值不是人格（参考 Disco Elysium） |
| P1-4 | **手感单薄** | ⑤ | Layer 1-2，缺粒子/震动/音效分层 |
| P1-5 | **灵石后期无处花** | ④ | 熔炉Lv5后灵石=废纸 |

### 🟢 P2 — 锦上添花

| # | 缺陷 | 技能来源 |
|---|------|---------|
| P2-1 | **批量操作缺失** | ⑦ | 集市不能批量买，熔炼不能重复上次 |
| P2-2 | **信息预览缺失** | ⑦ | 无 tooltip，无概率预览 |
| P2-3 | **概率无保底** | ⑥ | 连续销毁无保护（碎片部分修复） |
| P2-4 | **视觉身份为零** | ⑧ | 看不到 NPC 长什么样 |
| P2-5 | **音效层次不足** | ⑤ | 只有基础音效，无环境音/升品史诗音 |

## 三、1.0 改造路线图

### 阶段一：灵魂注入（P0 — 周1-2）

#### P0-1: 玩家身份 & 开场叙事

**改造文件**：`Main.gd`（开场）+ `PlayerData.gd`（主角数据）+ 新增 `Opening.gd`

```
实现：
- 游戏启动 → 3 屏开场叙事（像素+文字）
  屏1: 「灵墟边陲，三不管的集市。你在一个雨夜抵达。」
  屏2: 「管家说：少爷/小姐，老爷的债...」
  屏3: 「你握紧手里仅有的150灵石。从明天开始。」

- PlayerData 新增:
  var player_name: String = "安"  # 默认名
  var player_title: String = ""   # 称号（由三道/成就决定）
  var player_motivation: String = "还债"  # 动机文本

- 三道初始对话：
  商道>0时第一次议价→商道「说话」："这人的绸缎料子不错，出得起价"
  天道>0时第一次熔炼→天道「说话」："炉火跳了一下…这灵材在呼应你"
  人心>0时第一次常客回头→人心「说话」："他记得你。这是好事。"
```

**验收**：打开游戏→5分钟内知道「我是来灵墟还债/立足的」

---

#### P0-2: 一年评定终局

**改造文件**：`PlayerData.gd` + `DaySummary.gd` + 新增 `YearEnd.gd`

```
实现：
- 第120天（一年）自动触发「灵墟商会年度评定」
- 场景：比 DaySummary 更隆重的大面板

评定维度（满分12）：
  灵石总量 ≥1000 → +1 / ≥5000 → +2 / ≥10000 → +3
  熔炉等级 Lv3→+1 / Lv4→+2 / Lv5→+3
  常客数量 ≥3人→+1 / ≥5人→+2
  灵材图鉴 ≥10种→+1 / ≥20种→+2
  碎片收集 ≥20→+1 / ≥50→+2

评级：
  12分 → ⭐⭐⭐⭐⭐ 灵墟传奇
  9-11  → ⭐⭐⭐⭐ 杰出商贾
  6-8   → ⭐⭐⭐   稳健经营
  3-5   → ⭐⭐     还需历练
  0-2   → ⭐       初来乍到

- 三道倾向决定评分后的结局叙事文字
- 90天时管家来信预告：「少爷，三个月后商会评定…」
- 评定后可继续自由模式

进度条在 HUD/结算中可见：「离年度评定还有 XX 天」
```

**验收**：玩家在任何时候都知道「离评定还有X天」，第120天有仪式感评定

---

#### P0-3: NPC 对话池扩充 + 记忆

**改造文件**：`CustomerGenerator.gd`（新增对话系统）

```
实现：
- 每个常客对话池从 3 段 → 15 段
  好感度 0-2: 客套话（3句）
  好感度 3-5: 熟人话（3句）
  好感度 6-8: 朋友话（3句）
  好感度 9-10: 知己话（3句）
  特殊触发: 季节/天气/节日 各 1 句

- NPC 记忆系统：
  上次成交价 → 「上次那个价还算公道」
  上次被拒 → 「这次别再抬那么高了」
  上次被优惠 → 「上次你给的价很好，这次我多带了个朋友」
  连续光顾3天 → 「最近你摊子生意不错啊」

- NPC 到达时随机 70% 用记忆对话，30% 用随机池
```

**验收**：常客的对话不重复，且能感受到他们「记得」之前的交易

### 阶段二：世界注入（P1 — 周3-4）

#### P1-1: AI Director 灵墟之眼

**改造文件**：新增 `LingxuDirector.gd`（autoload）

```
实现：
- 每天触发 1 个事件（好事55% / 坏事45%）
- 监控玩家状态调整事件：
  灵石<100 → 提高好事概率
  连续3天无坏事 → 强制触发坏事
  每次熔炼销毁 → 降低后续坏事概率

事件池（初始20个）：
  🟢 好事：贵客到访（出价×1.5）、灵材降价、熔炉运势+
  🔴 坏事：小偷光顾、竞争对手压价、商会加税

- 事件在 DaySummary 之后触发
- 大部分事件提供玩家选项（不是被动接受）
```

**验收**：每天不只有你做的事，还有「灵墟发生的事」

---

#### P1-2: 三道人格化 + 故事

**改造文件**：`PlayerData.gd` + `CustomerGenerator.gd`

```
实现：
- 三道>10时，在关键场景自动「说话」
  商道：议价时给建议
  天道：熔炼时给提示
  人心：NPC对话时给洞察

- 三道之间偶尔「对话」（Disco Elysium式）
  「商道：抬价！这人不差钱。」
  「人心：别抬。他眼睛里有悲伤。」
  → 玩家选听谁的

- 每道>30时触发个人小故事
  商道30→「父亲教你的第一个生意经」
  天道30→「你第一次感受到灵材的'呼吸'」
  人心30→「石老私下对管家说：你这主人，心善」
```

**验收**：三道不仅是数值，玩家能感受到「我的商道/天道/人心在变化」

---

#### P1-3: 灵石消费出口扩充

**改造文件**：`PlayerData.gd` + `Furnace.gd` + `Market.gd`

```
新增消费：
1. 摊位拓展（灵墟商会的「铺面竞标」）
   Day30起可用灵石竞标更好的摊位位置
   好位置→更多客流量→更快赚钱

2. 灵墟情报（向商会购买市场预测）
   50灵石→明天热门灵材预告（必中）

3. 特殊熔炼辅料（提高特定属性概率）
   灵石买「引火石」→火系升品+10%
```

**验收**：熔炉Lv5后灵石仍有消费出口

---

#### P1-4: Juiciness 粒子 + 音效分层

**改造文件**：`Furnace.gd` + `StallScene.gd` + `SoundManager.gd`

```
实现：
- 升品(凡→灵): 10金星粒子向上飞 + 清脆叮声
- 升品(灵→宝): 30金粒子旋转 + 洪亮音效
- 升品(宝→仙): 100粒子爆炸 + 全屏金光 + 慢动作 + 史诗音效

- 成交：灵石粒子从面板飞向HUD（Layer 4）
- 碎片获得：紫色粒子 + 闪亮音

- 音效新增：环境音（白天集市喧闹/夜晚静谧）
```

**验收**：熔炼升品时有不亚于 Balatro 分数结算的满足感

### 阶段三：系统交互（P2 — 周5-6）

#### P2-1: 五行相生相克熔炼

**改造文件**：`Furnace.gd`

```
实现：
- 熔炉增加「双槽」模式（放两个灵材一起熔炼）
- 五行规则：
  同属性 +15%升品率
  相生 额外产出一个凡品
  相克 爆炸概率翻倍但成功=双属性灵品

- 隐藏配方（不写在文档里）：
  炎晶+寒魄 → 冰火双生灵品
  荧菇×3   → 月华宝品
```

**验收**：玩家能「发现」隐藏组合，有「卧槽」时刻

---

#### P2-2: QoL 批量 + 预览

**改造文件**：`Market.gd` + `Furnace.gd` + `Inventory.gd`

```
实现：
- Shift+点击集市灵材 → 弹出数量选择器
- 熔炉「重复上次策略」按钮
- 悬停灵材 → tooltip（品阶/五行/价格/上次熔炼结果）
- ESC 关闭当前面板
- F5 存档时 HUD 显示 「💾 已存档」
```

**验收**：操作步骤减少 30%+

## 五、不做的

以下调研中出现的功能，1.0 不做：

- NPC 像素立绘/行走图（资源不足，文字+emoji够用）
- NPC 日常行程表（工作量太大，AI Director事件替代）
- NPC 间派系关系网络（需要NPC数量基础，先做好5常客）
- 多结局分支（先做一个评定+叙事变体）
- 摊位布置/装饰系统（P2做摊位拓展就够了）
- 完全自由的NPC自主行为（技术复杂度高）
