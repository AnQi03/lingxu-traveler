# 议价机制调研 · 真实谈判心理 + 游戏案例

> 用于重新设计灵墟旅商的还价逻辑

---

## 一、真实讨价还价的心理机制

### 1. 锚定效应（Anchoring）
第一个报出的数字会"锚定"整个谈判范围。高手会报一个极端数字来拉偏对方心理预期。

**应用**：某些性格的顾客开局报价应明显低于合理价（锚定压价），玩家需要还价拉回来。

### 2. ZOPA（可协议区间）
```
卖家的底线 ←————————→ 买家的上限
          |—— ZOPA ——|
          
低于卖家底线 → 卖家不卖
高于买家上限 → 买家不买
在 ZOPA 内 → 可以成交
```

**应用**：顾客有 `min_accept`（愿意出的最低）和 `max_price`（心理上限）。玩家报价在这之间就能成交。

### 3. 让步递减（Concession Pattern）
真实谈判中，让步不是线性的——越到后面让步越小，释放"我没空间了"的信号：

```
第1轮让步：40%的差距 → "我可以退一步"
第2轮让步：25%的差距 → "我再让一点"
第3轮让步：10%的差距 → "这真的是最后了"
第4轮+：几乎不让了
```

**应用**：替代当前固定 50% 的线性让步。

### 4. 情绪信号
谈判中的愤怒、转身欲走、犹豫都是真实策略。一个好的还价系统应该让玩家通过观察这些信号来判断"是不是可以再压一轮"。

**应用**：情绪变化 + 回合剩余数给玩家判断空间。

## 二、游戏中的议价机制案例

### Recettear（露塞提娅：道具屋经营妙方）
- 顾客拿起商品放到柜台
- 玩家定一个百分比价格（如 130%）
- 顾客表情反应：开心→成交 / 犹豫→可能还价 / 生气→不买
- **亮点**：没有显式数字，纯靠读表情判断。简单但有效。
- **可借鉴**：情绪反应作为价格判断的核心线索

### Moonlighter
- 摆商品到货架，标价
- 顾客路过看到价格，头顶冒表情
- 不满意就放下走人
- **亮点**：通过大量顾客的集体反馈来发现"合理价"
- **可借鉴**：不同顾客对同一价格的接受度不同

### Kingdom Come: Deliverance
- 和商人对话时可选"讨价还价"
- 一个滑动指针在条形上游走
- 推太远→商人发怒→交易失败
- 口才技能越高，可推的范围越大
- **亮点**：风险/收益的张力——你想多赚就要冒险谈崩
- **可借鉴**：出价太低有风险，顾客可能直接走

## 三、当前灵墟议价系统的问题

| 问题 | 表现 |
|------|------|
| 让步线性 | 每次走 50%，机器人感 |
| 没有风险 | 出价低也不会激怒顾客 |
| 信号不足 | 玩家看不出"再压一轮会怎样" |
| 锚定缺失 | 所有顾客开局报价逻辑一样 |

## 四、改进方案

### 让步递减模式
```
第1轮让步：gap × 0.40  → 大步退让
第2轮让步：gap × 0.25  → 中等退让
第3轮让步：gap × 0.10  → 小步退让（释放"到底了"信号）
第4轮+：gap × 0.02   → 几乎不让
```

### 风险机制
- 玩家出价低于 `min_accept` 且有 30% 概率直接激怒→走人
- 越接近 `min_accept` 概率越低

### 性格差异化让步
| 性格 | 让步风格 | 回合数 |
|------|---------|--------|
| 爽直 | 第一轮就让大半 | 2-3轮 |
| 精明 | 每轮让得少但轮数多 | 4-5轮 |
| 急躁 | 让步快但耐心少 | 1-2轮 |
| 耐心 | 让得少但能聊很多轮 | 5-6轮 |
| 吝啬 | 几乎不让，极难谈 | 4轮 |
| 慷慨 | 让步大方 | 1-2轮 |
| 多疑 | 让步不规律 | 3-4轮 |
| 轻信 | 容易说服 | 2-3轮 |

### 信号增强
- 商道≥10：隐约感知顾客还剩几轮耐心
- 商道≥30：显示顾客心理价位区间
- 商道≥50：显示本轮让步后顾客可能的出价
