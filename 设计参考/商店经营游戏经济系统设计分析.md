# 商店经营游戏经济系统设计分析

> 聚焦 Recettear、Moonlighter、Potionomics、星露谷物语四款标杆作品的经济循环设计模式。
> 研究维度：买/卖定价平衡、顾客需求驱动、商店升级体系、循环满足感来源。

---

## 一、Recettear：露塞提娅～道具屋经营妙方

### 1.1 经济循环概貌

```
迷宫探索 → 带回物品 → 店铺定价售卖 → 赚钱 → 还债/升级/进货 → ...
              ↑                          ↓
         从NPC处进货 ──────────── 集市/批发商采购
```

游戏核心驱动力：**每周还款压力**。主角的父亲欠下巨额债务，女儿必须在固定期限内还清，否则 Game Over。这个「倒计时债务」是整个经济系统的锚点。

### 1.2 买入/卖出定价平衡

| 定价维度 | Recettear 做法 |
|----------|---------------|
| **进货价** | 迷宫免费获得物品（体力成本）；商人公会/集市以固定批发价进货；特殊NPC有浮动报价 |
| **卖出价** | 玩家自由设定（基准价的 70%~200%+），无系统建议价 |
| **定价反馈** | 顾客表情实时反应：😊开心（接受）/ 😐犹豫（可能还价）/ 😡生气（直接走） |
| **价格歧视** | 不同顾客类型有不同心理价位区间 |

**顾客类型 × 价格接受度矩阵**：

| 顾客类型 | 接受范围 | 行为特征 | 设计意图 |
|---------|---------|---------|---------|
| 小女孩 | 100-130% | 钱少但容易成交，不会还价 | 安全交易对象 |
| 大妈 | 70-100% | 爱砍价，会主动还价 | 教会玩家「有人会嫌贵」 |
| 富婆 | 130-200% | 不在乎钱，高价也买 | 暴利窗口 |
| 男人 | 100-130% | 中规中矩 | 基准参考线 |
| 精灵/特殊种族 | 110-150% | 偏好特定品类（武器/饰品） | 引入「偏好溢价」 |

**核心设计智慧**：
- Recettear 的定价本质是 **「读表情博弈」**，不是算数。
- 没有显式数字讨价还价——玩家需要观察顾客拿起商品后的微表情来判断「这价格能不能加」。
- 同一物品对不同顾客能卖出不同价格，鼓励玩家记住老顾客的面孔和偏好。

### 1.3 顾客需求系统

| 需求机制 | 设计 |
|---------|------|
| **顾客生成** | 随机进门，但受店铺等级、装饰、位置影响客流量 |
| **需求类型** | 确定性需求（NPC点名要某物）+ 浏览型需求（进店随机拿起货架商品） |
| **稀缺信号** | 顾客自言自语「好想要XX」→提示玩家去特定迷宫层数刷 |
| **时间压力** | 每天有限营业时间，顾客排队等待——不成交就流失 |

**最精彩的设计**：顾客会「逛店」——走进来在货架前徘徊，拿起一件放下又拿起另一件。玩家可以主动走到顾客面前按确认键「推销」，也可以选择不理（比如知道他买不起）。这让守店从「等对话框弹出来」变成「观察店内动态」。

### 1.4 商店升级体系

```
店铺升级维度：
├─ 店铺规模（Lv.1 小摊 → Lv.5 豪华店）
│   ├─ 更大空间 → 更多货架 → 更多同时陈列商品
│   ├─ 更豪华装修 → 更高客流量 + 更富顾客出现率
│   └─ 解锁新功能：自动售货机、背景音乐、店员制服
├─ 货架/陈列柜
│   ├─ 不同货架类型（普通柜、玻璃柜、展示台）
│   └─ 影响商品曝光度 → 顾客拿起概率
├─ 装饰/氛围
│   ├─ 地毯、壁纸、植物、吊灯
│   └─ 影响顾客停留时间和购买意愿
└─ 店铺名声（不可见数值）
    └─ 高名声 → 更多特殊顾客 + 进货渠道解锁
```

关键设计：**升级不只是「卖得更贵」，而是改变顾客构成和店内行为**。豪华店里走进来的富婆比例明显更高，这让升级带来的回报是「质的改变」而非单纯的「数字+10%」。

### 1.5 循环满足感来源

| 满足感 | 实现方式 |
|--------|---------|
| **生存压力** | 每周还款倒计时 → 每次摆摊都有紧迫感 |
| **价格发现** | 猜价→看表情→微调→成交，「猜中了」的快感 |
| **客户关系** | 记住某顾客的偏好，他下次来专门为他留货 |
| **空间成长** | 从寒酸小店到豪华商铺，视觉效果巨变 |
| **迷宫战斗的反哺** | 刷迷宫→得到稀有品→回店高价卖出，两套循环互相增强 |

**最核心的魔力**：Recettear 是罕见的「两个游戏合一」——迷宫 ARPG + 商店模拟经营，且两者不是割裂的。迷宫产出的战利品直接成为商店的商品，商店赚的钱用来买更好的装备闯更深的迷宫。**「冒险→获得→售卖→再投资冒险」的双循环互相提供动力，这才是它持久上瘾的根源。**

## 二、Moonlighter（夜勤人）

### 2.1 经济循环概貌

```
白天：经营武器/道具店，定价售卖
夜晚：进入地下城刷怪获取战利品
循环：地下城得货 → 回店定价卖 → 赚钱 → 升级装备/店铺 → 更深地下城
```

Moonlighter 是 Recettear 的精神续作，同样采用「地下城→商店」双循环，但在商店经营部分做了重大简化，在地下城部分做了大幅强化。

### 2.2 买入/卖出定价平衡

| 定价维度 | Moonlighter 做法 |
|----------|-----------------|
| **物品获取** | 纯地下城掉落（无进货系统），每一件商品都是「亲手打回来的」 |
| **定价机制** | **完全自主定价**，无建议价，无基准价提示 |
| **反馈方式** | 顾客看价格后的四档反应 |
| **价格发现** | 通过大量顾客的集体反馈来「试探」合理价位 |
| **需求波动** | 物品热度会变化——某物品突然流行→涨价窗口 |

**顾客反应四档**：

| 反应 | 表情 | 含义 | 玩家应做什么 |
|------|------|------|------------|
| 😍 狂喜 | 眼睛发光，秒买 | 定价远低于顾客心理价位 | 大幅提价 |
| 🙂 满意 | 点头，正常购买 | 在合理区间内 | 可微涨试探 |
| 😐 犹豫 | 皱眉，放下又拿起 | 略高于心理价位 | 下次降一点 |
| 😡 愤怒 | 扔下就走 | 远超承受范围 | 立刻大幅降价 |

**Moonlighter 独特的「价格发现」乐趣**：

与 Recettear 不同，Moonlighter 没有任何 NPC 会告诉你「这个该卖多少钱」。每件新物品的合理价格完全靠玩家自己摸索：
- 第一天标价 100 → 😡 → 降到 50 → 😐 → 降到 30 → 🙂
- 第二天标价 35 → 🙂 → 微调到 40 → 😐 → 调回 35
- 第四天发现这件物品突然「流行」了 → 45 → 😍！

这个过程让玩家感觉自己像真正的商人——**不是系统告诉你的数字，而是你通过观察和试错学到的市场知识**。

### 2.3 顾客需求系统

| 需求机制 | 设计 |
|---------|------|
| **顾客生成** | 按店铺等级 + 城镇声望决定数量和质量 |
| **热门需求** | 每日有「热门物品」清单——标注今天哪些物品需求高，卖价可翻倍 |
| **小偷** | 偶尔进店偷窃，玩家需要亲手抓住（动作玩法混入经营） |
| **特殊顾客** | 收藏家、贵族等特殊 NPC 出价远高于普通人 |

**热门清单机制**：

这是 Moonlighter 最具特色的需求设计。每天商店开门前，柜台上会出现一份「今日热门」，列出 2-3 种当前需求旺盛的物品。这些物品当天可以卖到 1.5-2 倍价格，但只持续到今天。

```
热门清单的经济效果：
├─ 创造「每日目标」——今天要下去打XX材料！
├─ 解决库存积压——原本卖不掉的物品突然变抢手
├─ 引导探索——热门物品通常来自特定地下城层数
└─ 周期性波动——同一种物品不会每天热门，避免刷单一副本
```

### 2.4 商店升级体系

```
店铺升级维度：
├─ 店铺规模（Lv.1-4）
│   ├─ 更多货架位 → 同时展示更多品类
│   ├─ 更大的店内空间 → 顾客停留更长
│   └─ 更富的顾客出现率提升
├─ 收银台升级
│   └─ 给小费概率提升，顾客排队效率提升
├─ 床铺升级
│   └─ 地下城死亡后保留更多物品
├─ 特殊功能
│   ├─ 愿望清单（顾客提前预定物品，到期高价收购）
│   ├─ 售货机（自动销售低价物品，释放货架）
│   └─ 镜子（提升顾客购买意愿）
└─ 城镇投资
    ├─ 投资铁匠铺 → 解锁更好装备
    ├─ 投资药水店 → 解锁更强药水
    └─ 投资银行 → 解锁存钱功能
```

**关键设计**：Moonlighter 的商店升级和地下城装备升级使用**同一货币**。这意味着每一笔收入都要在「让店铺赚更多」和「让自己打更深」之间做选择——经典的 trade-off 设计。

### 2.5 循环满足感来源

| 满足感 | 实现方式 |
|--------|---------|
| **价格发现** | 「这个新材料到底值多少钱？」→试探→找到最优价→成就感 |
| **双循环 synergy** | 打到的物品在店里卖出去的满足感远超「卖给系统商店」 |
| **热门追逐** | 看到清单上需要某物→下本去打→高价卖出，完整的动机链 |
| **空间可视化** | 亲眼看到货架上的商品被顾客一个个拿走，现金叮叮当当进账 |
| **债务驱动** | 投资城镇商店是昂贵的长期目标，驱动持续经营 |

**Moonlighter 与 Recettear 的关键差异**：

| 维度 | Recettear | Moonlighter |
|------|-----------|-------------|
| 定价方式 | 有基准价，玩家调百分比 | 完全自主，零提示 |
| 反馈粒度 | 表情连续变化 | 四档离散反应 |
| 需求驱动 | 还债倒计时 | 热门清单 + 城镇投资 |
| 战斗比重 | 轻（简单的 ARPG） | 重（以撒式地牢） |
| 叙事压力 | 强（父亲债务+角色故事） | 弱（设定驱动） |

## 三、Potionomics（魔药经济学）

### 3.1 经济循环概貌

```
采集/购买原料 → 酿造药水 → 定价销售 → 赚钱 → 升级设备/旅行/参加竞赛 → ...
     ↑                                                              ↓
升级好感度（与NPC社交）←── 赠送药水/聊天/约会 ←────────────────── 解锁新配方/折扣
```

Potionomics 是近年最创新的商店经营游戏之一，它在传统「进货→加工→卖」循环之上叠加了**卡牌对战式议价**和**深度 NPC 社交系统**。

### 3.2 买入/卖出定价平衡

| 定价维度 | Potionomics 做法 |
|----------|-----------------|
| **原料获取** | 从供应商购买（固定价格但可随好感度打折）+ 野外采集 |
| **药水定价** | 有「建议售价」标签，但实际售价由**议价卡牌战**决定 |
| **议价机制** | 独特的卡牌对战系统——打出手牌影响顾客耐心和最终价格 |
| **价格区间** | 每瓶药水有基础价值和品质加成，但最终售价完全取决于议价表现 |

**Potionomics 的卡牌议价系统（核心创新）**：

```
议价过程：
1. 顾客给出初始报价（通常低于建议价）
2. 玩家从手牌中选择策略卡：
   ├─ 抬价卡（提高售价但消耗顾客耐心）
   ├─ 安抚卡（恢复顾客耐心但不改变价格）
   ├─ 施压卡（大幅抬价但消耗更多耐心）
   ├─ 利益卡（展示药水附加价值，温和抬价）
   └─ 特殊卡（根据玩家技能/装备解锁）
3. 每张牌消耗「兴趣值」（顾客耐心），归零则谈崩
4. 可选在任意时点成交——接受当前价格或继续博弈

顾客耐心条 = 你能打多少张牌 = 能提价多少
风险 = 打太激进了耐心耗尽 → 交易失败
收益 = 打出完美 combo → 原价 100 的药水卖出 250
```

这和 Recettear / Moonlighter 截然不同——定价不是滑块或数字，而是一个有策略深度的卡牌小游戏。**每张牌的选择都让玩家感觉「我在使用谈判技巧」，而不是「我在猜数字」。**

### 3.3 顾客需求系统

| 需求机制 | 设计 |
|---------|------|
| **顾客类型** | 冒险者（要战斗药水）、贵族（要高颜值药水）、学者（要稀有配方）、平民（要便宜实用） |
| **需求偏好** | 每类顾客对药水的「品质」「颜值」「稀有度」「价格」有不同权重 |
| **竞赛系统** | 定期举办魔药竞赛，提交特定类型药水，名次越高奖金越多 |
| **季节性需求** | 不同季节/活动期间某些药水需求暴增 |

**Potionomics 最独特的需求设计——NPC 社交驱动需求**：

```
社交关系影响经济：

好感度 Lv.1 → 陌生商人：正常报价，无折扣
好感度 Lv.3 → 熟人：原料 9 折，偶尔透露内幕消息（下周什么药水涨价）
好感度 Lv.5 → 好友：原料 8 折，定期赠送稀有材料
好感度 Lv.7 → 挚友/恋人：独家配方解锁，竞赛评委偏袒

社交成本：需要消耗时间和资源（送药水、约会、聊天）
社交收益：降低进货成本 + 市场情报 + 独家配方
```

这意味着 NPC 不只是「交易点」，而是需要培养的**战略资源**。玩家面临「今天花时间和某 NPC 约会套近乎」vs「今天多酿几瓶药水卖钱」的永恒抉择——这正是模拟经营游戏最宝贵的 **action economy** 张力。

### 3.4 商店升级体系

```
升级维度：
├─ 酿造设备
│   ├─ 坩埚等级 → 一次能酿更多瓶
│   ├─ 发酵桶 → 提升药水品质
│   └─ 蒸馏器 → 解锁新酿造工艺
├─ 店铺装修
│   ├─ 展示柜 → 提升顾客兴趣值（议价时耐心更多）
│   ├─ 氛围装饰 → 吸引特定类型顾客
│   └─ 招牌 → 提升客流量
├─ 技能树
│   ├─ 议价技能（更多强力卡牌）
│   ├─ 酿造技能（更高效生产）
│   └─ 社交技能（好感度获取加速）
└─ 旅行/探索
    └─ 去不同地区获取稀有原料（需花费游戏天数和金钱）
```

**关键设计**：Potionomics 的升级和星露谷/Recettear 最大的不同在于——**时间是最稀缺的资源**。每一天被切分为上午/下午/晚上三个时段，每个时段只能做一件事：
- 上午酿药水 vs 上午逛街买原料 vs 上午找NPC聊天
- 下午开店 vs 下午去野外采集 vs 下午参加竞赛
- 晚上社交 vs 晚上研究配方 vs 晚上休息（回状态）

这让升级决策带有强烈的机会成本色彩：「升级坩埚可以一次酿更多药水，但升级社交技能让我能从 NPC 那拿到更便宜的原料——哪个先？」

### 3.5 循环满足感来源

| 满足感 | 实现方式 |
|--------|---------|
| **卡牌议价策略感** | 手牌管理 + 风险/收益平衡 → 每次议价都是小游戏 |
| **NPC 关系深度** | 不只是买东西，是交朋友、甚至谈恋爱 → 情感投资 |
| **竞赛高潮** | 周期性竞赛提供「憋大招→炫技→排名」的大满足 |
| **时间管理张力** | 每天三段，总有「时间不够用」的甜蜜焦虑 |
| **配方发现** | 新配方不是买到的，是通过实验试出来的 → 探索乐趣 |
| **药水颜值** | 每瓶药水的外观可定制（瓶型/颜色/标签）→ 个人表达 |

**Potionomics 对灵墟旅商最大的启示**：

Potionomics 证明了「经营游戏 + 卡牌战斗」的杂交是完全可行的，而且能同时抓住两类玩家的心——喜欢策略的享受议价 combo，喜欢模拟的享受开店和社交。灵墟的「察言观色议价」系统可以借鉴其「多策略卡片」的设计思路：不是只有一个「出价」维度，而是有抬价、让利、施压、捧场等多张牌可以打。

## 四、星露谷物语（Stardew Valley）

### 4.1 经济循环概貌

```
种地/养殖 → 收获产物 → 加工增值 → 售卖 → 赚钱 → 升级工具/建筑 → 种更多/更好 → ...
   ↑                                     ↓
采集/钓鱼/挖矿 ←── 季节轮替 ←── 加工品囤货（果酒/奶酪等发酵品需时间）←── 解锁温室等
```

星露谷虽然严格来说不是「商店经营」游戏（玩家扮演农场主而非店主），但它的经济系统对商店经营类游戏有极为重要的参考价值——尤其是**加工增值链**、**季节周期**和**「再来一天」循环**。

### 4.2 买入/卖出定价平衡

| 定价维度 | 星露谷做法 |
|----------|-----------|
| **种子/原料买入** | Pierre 杂货店 / Joja 超市（固定价格，个别季节性波动） |
| **动物买入** | Marnie 牧场（小鸡、牛、羊、猪、兔）→ 持续产出 |
| **产物卖出** | 直接扔进出货箱（夜间自动结算）+ 或当场卖给药水店/铁匠铺 |
| **价格决定因素** | 基础价 × 品质系数 × 专精技能系数 |
| **无议价** | 星露谷完全没有讨价还价——价格是固定的，玩家的主动权在「卖什么和什么时候卖」 |

**星露谷增值链（核心经济引擎）**：

```
原料 → 加工品 → 价格倍增

草莓 (120g) → 草莓果酒 (360g, 3x)
南瓜 (320g) → 南瓜汁 (690g, 2.15x)
上古水果 (550g) → 上古果酒 (1650g, 3x) → 地窖陈年 (伊ridium品质 ×2 = 3300g)
牛奶 (125g) → 奶酪 (200g, 1.6x)
鸡蛋 (50g) → 蛋黄酱 (190g, 3.8x)
松露 (625g) → 松露油 (1065g, 1.7x)

品质加成：金星品质 ×1.5
专精技能：工匠技能 ×1.4（所有加工品）
最终倍率示例：金星上古果酒 = 1650 × 1.5 × 1.4 = 3465g（基础水果的 6.3 倍！）
```

星露谷的定价哲学是：**原材料不值钱，加工品才值钱。加工需要时间成本（酿酒要7天、腌菜要3天、奶酪要3小时），这就是「时间=金钱」的核心体现。**

### 4.3 顾客需求系统

星露谷没有「顾客」概念（出货箱自动收购），但它有隐形的「需求系统」：

| 需求机制 | 设计 |
|---------|------|
| **社区中心收集包** | NPC们集体需要特定物品组合，提交后解锁新功能/区域 |
| **NPC任务** | 随机出现在公告栏，点名要某种作物/鱼/矿物 → 3倍价格收购 |
| **特殊订单** | Pierre 的「大订单」（一次性大量采购） |
| **节日** | 秋收节的农产展览会，提交高品质作物比赛 |
| **送礼** | 每个 NPC 有喜好/厌恶列表，2次/周，生日8倍好感 |

**隐形的「市场」设计**：

星露谷没有明面上的市场波动，但通过以下机制创造了类似效果：

```
    不同季节目不同产物 → 玩家必须轮作 → 自然形成供应周期
    + 
    社区中心收集包 → 特定时间点对特定物品需求暴增
    +
    冬季无法种植 → 秋季必须囤积足够多的加工品过冬 → 资金管理压力
    =
    虽然没有「顾客议价」，但玩家始终在思考「现在种什么最划算？」
```

### 4.4 农场升级体系

星露谷的升级体系是经营游戏中最经典的渐进式设计之一：

```
工具升级（铜→铁→金→铱，每次需钱+材料+2天等待）：
├─ 锄头升级 → 一次锄更多格（1→3→5→9）
├─ 水壶升级 → 一次浇更多格
├─ 斧头升级 → 砍高级树
├─ 镐子升级 → 打更硬的矿
└─ 鱼竿升级 → 钓更稀有的鱼

建筑/设施：
├─ 鸡舍 → 牛棚 → 养猪场 → 兔舍（渐进解锁）
├─ 马厩 → 解锁快速移动
├─ 温室 → 冬季也能种植（游戏变革性解锁）
├─ 地窖 → 陈年加工品提升品质
└─ 祝尼魔小屋 → 自动收割

技能专精：
├─ 耕种5级 → 专精分支（工匠/农场主）
├─ 采矿5级 → 专精分支（矿工/地质学家）
├─ 10级满级 → 终极专精技能
```

**星露谷升级设计的精髓：**

| 原则 | 实现 |
|------|------|
| **每次升级都有「可见的」差异** | 铜水壶浇1格，铁水壶浇3格——一眼就能看出「我变强了」 |
| **升级解锁新内容，不只是+10%** | 铁镐能打冰冻晶石 → 解锁矿洞40层以下 → 新怪物/新矿物 |
| **升级需要时间等待** | 工具交给铁匠升级要等2天 → 你被迫在那2天里做别的事 |
| **永远差一点** | 「还差 500g 升级喷壶 → 明天第一件事去钓鱼赚钱」 |

### 4.5 循环满足感来源

| 满足感 | 实现方式 |
|--------|---------|
| **「再来一天」** | 每天结算时「今天赚了XXX」+「明天什么作物成熟」→ 永远有明天的目标 |
| **季节性新鲜感** | 28天/季 × 4季，每季专属作物/鱼/采集物/节日 → 不会腻 |
| **加工增值验证** | 原始草莓卖120g，酿成酒后卖360g → 「我的决策产生了价值」 |
| **社区中心进度** | 一组收集包需要多种物品，慢慢凑齐→解锁新功能→巨大的成就感 |
| **永远差一点的张力** | 距离下一次升级总差一点点钱/材料 → 明天第一件事就很明确 |
| **从零到繁荣的视觉叙事** | 第一天的荒地 vs 第三年的自动化农场 + 满级工具 → 史诗级满足 |

**星露谷的终极秘密——「为什么玩家停不下来」**：

```
每天结束时有三个心理锚点同时作用：

1. 收获感：今天XXX作物收了，卖了XXX金币，升了XXX技能
2. 悬而未决：温室还差3个材料、还差2000g升级斧头、后天是某NPC生日
3. 明天预告：天气预报说明天下雨不用浇水→可以全天挖矿→准备带什么食物

→ 三个锚点让玩家脑子里自动生成了「明天第一件事做什么」
→ 点了「睡觉」按钮，第二天早上6：00，收音机播天气预报
→ 又是新的一天，又是新的期待
```

**对灵墟旅商最大的启示**：结算面板不能只是「今天赚了多少灵石」的财务报告，而应该是**制造「明天期待」的引擎**——预告明天什么灵材会涨价、哪个 NPC 会来、熔炉冷却还有多久。

## 五、四款游戏横向对比总结

### 5.1 定价机制谱系

```
纯固定价 ←─────────────────────────→ 纯自由定价

星露谷     Potionomics      Recettear        Moonlighter
（完全固定）（卡牌议价范围）  （%基准百分比）  （完全自主零提示）
   │              │               │                │
   │              │               │                │
玩家主动权     策略感最强      有参照系       试错发现乐趣
在「卖什么」   在「怎么谈」    在「看人下菜」 在「猜这个值多少」
```

### 5.2 需求驱动机制

| 游戏 | 核心需求驱动 | 特点 |
|------|------------|------|
| **Recettear** | 每周还债倒计时 + 顾客偏好 | 生存压力驱动，短周期紧迫感 |
| **Moonlighter** | 每日热门清单 + 城镇投资 | 每日目标驱动，有明确方向感 |
| **Potionomics** | 竞赛周期 + NPC社交需求 | 竞赛是中期高潮，社交是长期动力 |
| **星露谷** | 社区中心 + NPC任务 + 季节 | 长期目标 + 日常小目标并行 |

### 5.3 商店/农场升级设计

| 游戏 | 升级维度数量 | 最亮眼的设计 |
|------|------------|-------------|
| **Recettear** | 店铺规模、货架、装饰、名声 | 装修改变顾客构成（不是数值+10%） |
| **Moonlighter** | 店铺、收银台、特殊功能、城镇投资 | 同一货币用于店铺和战斗装备，强制 trade-off |
| **Potionomics** | 酿造设备、店铺、技能树、旅行 | 时间是最稀缺资源，三段式日常制造机会成本 |
| **星露谷** | 工具、建筑、技能专精 | 每次升级有「可见差异」+ 解锁新内容 |

### 5.4 循环满足感公式

```
卓越的商店经营游戏 = 以下至少三者的组合：

① 有意义的决策
   Recettear: 看人下菜定价    Moonlighter: 试探最优价
   Potionomics: 卡牌议价策略  星露谷: 种什么/加工什么/囤什么

② 可见的成长
   Recettear: 店铺从寒酸到豪华  Moonlighter: 货架从空空到满满
   Potionomics: 药水从凡品到传奇 星露谷: 农场从荒地到自动化帝国

③ 不确定性和惊喜
   Recettear: 迷宫掉什么不可预测   Moonlighter: 热门清单每天变
   Potionomics: 议价能抬多高取决于抽牌  星露谷: 矿洞遇到什么、鱼钓到什么

④ 节奏和时间压力
   Recettear: 每周还款日   Moonlighter: 热门物品仅限今天
   Potionomics: 竞赛倒计时  星露谷: 季节更替、作物28天过期

⑤ 关系和世界
   Recettear: 记住老顾客偏好   Moonlighter: 投资城镇商店改变世界
   Potionomics: 深度 NPC 社交+恋爱  星露谷: 12个可婚 NPC + 全村的记忆
```

### 5.5 对灵墟旅商的核心启示

| 维度 | 可借鉴的设计 | 来源游戏 |
|------|------------|---------|
| **议价深度** | 多策略卡牌议价（抬价/让利/施压/捧场）→替换纯滑块 | Potionomics |
| **顾客反馈** | 表情+口头线索→替换纯文字提示 | Recettear |
| **每日目标** | 「明日预告」+热门灵材清单→制造期待 | Moonlighter + 星露谷 |
| **增值链** | 多级加工路径（熔炼+切片+炼丹+附魔）→时间=金钱 | 星露谷 |
| **商店升级** | 升级改变顾客构成和店内行为→不只是数值 | Recettear |
| **NPC关系** | 好感度→折扣+情报+独家渠道→战略性社交 | Potionomics + 星露谷 |
| **周期性高潮** | 拍卖会/竞赛/灵潮日→中期多巴胺脉冲 | Potionomics + 星露谷 |
| **时间管理张力** | 三段式每日（早市/日间/夜市）+灵识限制 | Potionomics + 星露谷 |
| **「再来一天」** | 结算面板=明天期待生成器，不只是财务报告 | 星露谷 |

## 六、总结

这四款游戏在经济系统设计上各有所长，但它们共享一个核心哲学：

> **经营游戏的本质不是「让数字变大」，而是让玩家在每一个决策点上感受到「这是我的选择，而且这个选择产生了结果」。**

- Recettear 让每一次定价都变成「读人的博弈」
- Moonlighter 让每一次定价都变成「市场试探实验」
- Potionomics 让每一次定价都变成「策略卡牌对决」
- 星露谷让每一天都变成「我今天要做什么」的期待

灵墟旅商要做的，是把这些游戏中「让玩家感觉自己在做有意义决策」的设计智慧，嫁接到修真世界的摆摊讨价还价场景中去。
