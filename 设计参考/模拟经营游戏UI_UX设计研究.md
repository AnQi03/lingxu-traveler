# 模拟经营类游戏 UI/UX 设计研究报告

> 研究对象：Stardew Valley（星露谷物语）、RimWorld（环世界）、Factorio（异星工厂）
> 输出语言：中文

---

## 一、信息架构 (Information Architecture)

### 1.1 信息层级原则

模拟经营游戏通常包含海量数据——资源、角色状态、建筑、科技树、事件等。
信息架构的核心是**分层递进**，遵循"概览 → 详情"的认知模式：

- **第一层（HUD 概览层）**
  最重要的即时信息——核心资源（金币/食物/电力）、时间/日期、警报/通知图标。
  始终可见，不遮挡游戏画面。信息量控制在 5±2 项以内。

- **第二层（侧边栏/快捷面板）**
  常用功能入口——建造菜单、库存、角色列表。一键呼出，一键关闭。

- **第三层（全屏面板）**
  深度交互——科技树、统计图表、设置。有明确进入/退出动效，完全占据视野。

### 1.2 各游戏的信息架构对比

**Stardew Valley（星露谷物语）**

- HUD 层：左下角金币、右上角时钟+日期+季节、左侧体力条（当前/最大）、生命条。极简，仅 4 项核心指标，信息密度极低。
- 面板层：按 Tab 打开暂停式菜单，分类标签（背包、技能、社交、地图、制作、收集品、选项）。每个标签页信息密度低，使用大图标 + 简短文字降低认知负荷。
- 设计哲学：模拟"翻实体笔记本"的体验，亲切自然。菜单打开时游戏暂停，给玩家充分思考时间。

**RimWorld（环世界）**

- HUD 层：底部资源条（食物、药品、材料、心情等可自定义项）+ 时间流速控制（暂停/1x/2x/3x）+ 右侧通知区。
- 面板层：底部按钮区（工作、日程、研究、势力、世界等）+ 选中物体后弹出底部信息卡。详情面板就地展开，不遮挡整体视野。
- 设计哲学：高度模块化，玩家可自定义底部资源条的显示项。信息架构服务于"故事生成器"的核心体验。

**Factorio（异星工厂）**

- HUD 层：底部快捷栏（物品栏 + 工具带，1-10 + Shift 键可达 20 槽位）+ 右下角小地图（雷达覆盖范围、玩家位置）。
- 面板层：选中实体后右侧弹出详情面板（输入/输出/状态/电路网络）。全屏面板：科技树（树状+队列）、生产统计（按时间粒度的产量/消耗图表）、物流网络、蓝图库。
- 设计哲学：技术支持导向——一切为"生产效率优化"服务。信息架构极度扁平化，任一面板都可从工具栏一键直达。

### 1.3 通用设计规律

| 设计要素 | 最佳实践 |
|---------|---------|
| 信息密度 | HUD 层 ≤7±2 项（Miller 定律）；详情面板可更密集 |
| 视觉流向 | 左上→右下（资源栏左上，通知右下，符合 F 型阅读模式） |
| 上下文保持 | 面板打开时不完全遮挡游戏画面，或使用半透明背景 |
| 一致性 | 同类信息始终在同一位置、同一颜色、同一交互方式 |
| 渐进式披露 | 默认只显示核心数据，点击/悬停展开详细信息 |
| 最少点击 | 任何功能不超过 3 次点击/按键到达（三击原则） |

## 二、HUD（抬头显示器）设计

### 2.1 HUD 组成要素

模拟经营游戏的 HUD 通常包含以下模块：

**1. 资源指示器（Resource Indicators）**
- 图标 + 数值 + 趋势箭头（↑/↓）
- 常用格式：金币（金色圆形图标）、食物（苹果/麦穗）、电力（闪电符号）
- 关键细节：数值变化时配合微量动画（数字跳动、颜色闪烁），让玩家感知变化趋势

**2. 时间/日期显示（Time & Date）**
- 游戏内时钟/日历，模拟经营游戏的灵魂系统
- Stardew Valley：右上角钟表 + 日期 + 季节（28天/季，春夏秋冬循环）
- RimWorld：年月日 + 时分，时间流速可调（暂停/1x/2x/3x）
- Factorio：纯游戏刻(tick)，无昼夜概念但有进化因子显示

**3. 小地图（Minimap / Radar）**
- Factorio：雷达覆盖区域 + 玩家位置 + 火车实时位置
- RimWorld：无小地图（依靠双指缩放 + 滚轮全景浏览）

**4. 快捷操作栏（Action Bar / Toolbelt）**
- 常用工具/建筑/物品的一键选择
- Factorio：底部 2-4 行工具带，数字键 1-0 + Shift+1-0 可达 20 个快捷物品
- RimWorld：底部建筑师分类图标，每个分类下有子项网格

**5. 通知/警报区（Alert Area）**
- 详见第四部分通知系统分析

### 2.2 HUD 布局模式对比

| 布局模式 | 代表游戏 | 布局特点 | 优点 | 缺点 |
|---------|---------|---------|------|------|
| 底部横条式 | Factorio, RimWorld | 所有 HUD 集中底部一横条 | 最大化游戏视野 | 底部信息可能拥挤 |
| 角落分散式 | Stardew Valley | 左上生命体力，右上时钟，左下金币 | 各信息有独立空间领域 | 眼球移动距离大 |
| 顶栏+底栏式 | Cities: Skylines | 顶部资源概览，底部建造面板 | 层级清晰，功能分区明确 | 占上下两条屏幕空间 |
| 极简角落式 | Don't Starve | 仅右上角三维（生命/饥饿/理智） | 极致沉浸感 | 信息过少，需频繁切菜单 |

### 2.3 HUD 响应式设计要点

- **分辨率适配**：使用锚点系统（anchor points）确保 UI 在 16:9 / 21:9 / 4:3 下都不变形、不错位。
- **UI 缩放**：UI 尺寸应可独立调节（许多玩家在大屏幕/小屏幕/Switch 之间切换）。
- **手柄/触屏适配**：模拟经营游戏越来越多移植到 Switch/移动端，需考虑摇杆导航 + 大触控按钮（最小触控区域 44×44pt，符合 Apple HIG / Material Design 标准）。

### 2.4 HUD 动效设计

- **数值变化动画**：资源增减时数字缓动（ease-out，约 300ms），让玩家感知变化幅度。
- **警报动画**：紧急状态使用脉冲/闪烁（低频率，约 1Hz），避免高频闪烁导致不适。
- **面板进出**：滑入/滑出 200-300ms，方向性明确（从哪个按钮呼出就向哪收回）。

## 三、面板设计 (Panel Design)

### 3.1 面板类型分类

**A. 数据面板（Data Panel）**
- 科技树、统计图表、生产报表
- Factorio 的"生产"面板为标杆设计：
  - 可选择时间范围（1分钟 / 10分钟 / 1小时 / 10小时 / 50小时 / 全部）
  - 按物品分类的柱状图（产量 vs 消耗量并列显示）
  - 一眼看出生产瓶颈在哪里（哪项消耗>产量）
  - 支持搜索和排序

**B. 交互面板（Interaction Panel）**
- 建造菜单、制作菜单、交易界面
- RimWorld 的"建筑师"菜单：
  - 左侧分类图标列（结构、家具、电力、生产、防御、温度……）
  - 右侧子项网格显示该分类下的所有可建造物
  - 分类图标高度可视化（墙壁用砖块图标、家具用椅子图标），几乎免文字阅读

**C. 详情面板（Detail / Inspector Panel）**
- 选中单个实体后显示其属性
- 三款游戏都使用"选中 → 弹出底部或右侧面板"的交互模式
- Factorio 的组装机详情面板设计极为精良：
  - 当前配方名称和图标
  - 模块插槽（速度/产能/效率模块，最多4个）
  - 输入库存和输出库存（各物品的实时数量）
  - 当前生产进度条（百分比 + 视觉填充）
  - 状态指示灯：工作中(绿) / 缺料(黄) / 输出满(黄) / 缺电(红)
  - 电路网络连接状态

**D. 管理面板（Management Panel）**
- RimWorld 的工作优先级表是模拟经营类数据密集表格设计的典范：
  - 网格状布局，X 轴为殖民者头像+名称，Y 轴为工作类型
  - 数字 1-4 表示优先级（1=最高，4=最低，空白=不从事）
  - 用勾/叉图标 + 灰度文字表示该殖民者是否具备该技能
  - 支持批量操作（按住 Shift 调整整列优先级）

### 3.2 面板设计核心原则

| 原则 | 说明 | 反例 |
|------|------|------|
| 分组与留白 | 用分割线、间距和卡片式布局将相关信息聚类 | 信息挤在一起，无视觉分组 |
| 标签页 vs 滚动 | 信息超过一屏时优先用标签页（减少滚动疲劳） | 一个面板内无限滚动 |
| 非模态优先 | 尽量使用非模态面板（不阻塞游戏交互） | 弹出模态框打断玩家操作 |
| 面板动画 | 滑入/滑出 200-300ms，提供空间导航线索 | 面板突然出现/消失 |
| 面包屑导航 | 深层嵌套面板显示层级路径，可点击跳回 | 迷路后只能逐层返回 |
| 搜索/过滤 | 物品/建筑数量多时提供搜索栏 | 只能靠翻页/滚动查找 |

### 3.3 面板动画细节

- **方向性**：从右侧滑入的面板，也从右侧滑出。从底部弹出的面板，也向底部收回。
- **缓动函数**：推荐 ease-out（进入时快出慢停）和 ease-in（退出时慢起快走）。
- **遮罩层**：模态面板配合半透明黑色遮罩（透明度约 40-60%），非模态面板不加遮罩。
- **焦点锁定**：模态面板打开时，键盘/鼠标焦点锁定在面板内，Tab 键在面板控件间循环。

## 四、通知系统 (Notification System)

### 4.1 通知分级机制

模拟经营游戏的复杂系统会产生大量事件，通知系统的设计必须考虑**分级机制**：

| 优先级 | 类型 | 视觉表现 | 听觉表现 | 交互行为 | 示例 |
|--------|------|---------|---------|---------|------|
| P0 紧急 | 生存威胁 | 全屏红色闪烁边框 + 居中大图标 | 尖锐警报音效（持续循环） | 强制暂停游戏 | 殖民者濒死、基地被大规模袭击 |
| P1 重要 | 负面事件 | 右侧弹出卡片 + 红色/橙色图标 | 单次警示音 | 可配置是否暂停 | 火灾、停电、疯狂动物入侵 |
| P2 提示 | 状态变化 | 顶部浮动文字 / 右下角小图标 | 轻提示音（可选） | 不暂停，5-8秒自动消失 | 技能升级、研究完成、建筑竣工 |
| P3 信息 | 常规通知 | 仅写入通知日志，不弹出 | 无声 | 完全不打断玩家 | 作物成熟、物品制作完成 |

### 4.2 各游戏通知系统分析

**RimWorld（通知系统设计最成熟）**

右侧信件/通知面板：
- 按时间倒序排列，最近的在最上面
- 彩色信封图标区分严重程度：
  - 🔴 红色信封：致命威胁（袭击、火灾、猎杀人类动物）
  - 🟡 黄色信封：负面事件（瘟疫、心情崩溃、食物中毒）
  - 🔵 蓝色信封：中性通知（商队到达、访客、旅行者）
  - 🟢 绿色信封：正面事件（婚礼、新成员加入、灵感迸发）
- 右键可消除通知，左键点击跳转到事件发生位置
- 设置中可配置：哪类事件自动暂停游戏
- 历史通知可回溯查看（不因消除而丢失）
- 音效差异化：威胁音效尖锐紧迫，好消息轻快柔和

**Factorio**

- 右下角弹出通知条："科技研究完成"、"建筑被摧毁"、"炮塔已接敌"
- 右下角警报图标（持续显示）：炮塔弹药不足、建筑严重受损
- 地图上闪烁图标标记被攻击/被摧毁位置
- 可配置的警报音效（玩家可选择语音提示或纯音效）
- 科技研究完成有独特"叮"声 + 屏幕中央短暂弹出动画（约 1.5 秒）

**Stardew Valley**

- 左上角弹出浮动文字："获得 xxx"、"技能升级至 Lv.N"
- 早晨起床时检查邮箱——一种异步叙事式通知
- 极简设计，因为游戏本身系统复杂度相对较低
- 通知量少，不需要复杂的过滤/聚合机制

### 4.3 通知设计最佳实践

- **可打断性控制**：让玩家选择哪些事件会暂停游戏（降低挫败感）。
- **批量聚合**：短时间内同类重复通知应合并显示。例如："收获：小麦 ×50、玉米 ×32、番茄 ×18"合并为一条，而非弹出 100 条独立通知。
- **空间分区**：不同类别通知固定在屏幕不同位置——伤害/威胁→顶部中央，获得物品→左侧，系统通知→右下角。
- **历史日志**：始终可访问完整的通知历史，不依赖即时阅读。RimWorld 的做法值得借鉴。
- **音效层次化**：P0 有独特紧急音效（尖锐、高频、循环），P3 仅视觉提示无音效。
- **通知冷却**：同一类型通知的最短间隔（如不低于 3 秒），防止通知风暴。

## 五、Tooltip 设计 (Tooltip Design)

### 5.1 Tooltip 层级体系

Tooltip 在模拟经营游戏中承载了极其重要的教学和辅助决策功能：

**一级 Tooltip（快速悬停，延迟 < 0.3 秒）**
- 物品/建筑名称 + 一行简短描述
- 示例：鼠标悬停木材 → 弹出 "木材 | 基础建筑材料，可用于建造和燃料"
- 背景半透明深色，白色文字，圆角矩形

**二级 Tooltip（持续悬停，延迟 ≈ 0.5 秒）**
- 详细属性、数值、状态、比较信息
- RimWorld 悬停殖民者 → 显示心情、健康、技能等级、当前活动等详细数据
- Factorio 悬停组装机 → 显示当前配方、生产速度、模块加成、电力消耗
- 宽度通常 250-350px，适配不同信息量

**三级 Tooltip（按 Shift/Alt 或点击触发）**
- 深层关联信息：相关物品链接、配方溯源（向上追溯原材料 + 向下查看用途）
- Factorio：Alt 键开启"详细模式"——所有容器/机器叠加显示其内容物图标，传送带上显示物品图标，这是 UI 信息密度的经典切换设计

### 5.2 Tooltip 设计原则

| 原则 | 说明 |
|------|------|
| 延迟可配置 | 新手需要更长展示时间（0.5s），老手可能需要更短（0.1s）甚至关闭 |
| 不遮挡目标 | Tooltip 根据屏幕边缘动态调整方向（上/下/左/右自适应弹出） |
| 富文本支持 | 图标嵌入文本中（如 "消耗 🪵×5 🔩×2"），比纯文字直观得多 |
| 交互式 Tooltip | 部分游戏允许在 Tooltip 内进行简单操作（如 RimWorld 中右键分配任务） |
| 长按 = 右键详情 | 移动端/手柄无法悬停，用长按（≥500ms）或按下右摇杆代替 |
| 比较信息 | Tooltip 内显示当前装备/物品与已装备的对比（↑ 提升 / ↓ 下降 / → 持平） |

### 5.3 Factorio 的 Alt 模式：经典设计案例

Factorio 的 Alt 键是 UI 设计的经典案例——一键切换"美术沉浸模式"和"信息叠加模式"：

- **Alt 关闭（沉浸模式）**：看到的是纯美术画面——工厂建筑、传送带动画、环境景观。适合欣赏自己的工厂布局。
- **Alt 开启（信息模式）**：所有机器上叠加图标（产品图标、配方图标），箱子显示内容物缩略图，传送带上显示正在运输的物品图标，物流机器人显示携带的货物。
- **设计启发**：两种模式服务于不同的认知任务——"我的工厂好看吗？" vs "我的工厂哪里效率低？"。这一设计也是 Factorio 被广泛认为 UI/UX 最优秀的重要原因之一。

## 六、菜单导航 (Menu Navigation)

### 6.1 菜单层级设计

模拟经营游戏的菜单导航遵循**广度优先**原则——让玩家以最少点击到达目标：

**平铺式**（Stardew Valley）
- 标签页平铺，各页之间完全正交，无层级嵌套
- 深度 ≤ 2 层（标签页 → 子项）
- 适合系统数量较少（< 10 个子系统）的游戏

**树状面板**（RimWorld / Factorio）
- 底部按钮 → 分类面板 → 子项网格
- RimWorld 建造路径：建筑师按钮 → "家具"分类 → 椅子/桌子/床/灯具……
- Factorio 制造路径：背包 → "生产"标签 → "物流"子标签 → 传送带/分拣器/地下带……

**径向菜单**（部分主机版模拟经营游戏）
- 按住肩键/扳机键呼出环形菜单，摇杆选择方向
- 适合手柄操作，减少方向键逐格导航次数
- 菜单项建议限制在 4-8 个方向（与人类方向感知匹配）

### 6.2 导航辅助设计清单

| 辅助功能 | 说明 | 代表实现 |
|---------|------|---------|
| 键盘快捷键 | 高频面板绑定字母键，老手可纯键盘操作 | Factorio: E=背包, T=科技, B=蓝图, G=连线 |
| 搜索/过滤栏 | 物品/建筑数量多时搜索远快于翻页 | Factorio 物品栏搜索、RimWorld 库存过滤 |
| 收藏/常用固定 | 自定义快捷栏或固定常用建造项 | Factorio 工具带自定义, RimWorld 建造收藏 |
| 面包屑导航 | 深层面板顶部显示层级路径 | "设置 → 音频 → 音量 → 音乐音量" 可点击跳回 |
| 最近使用优先 | 建造菜单优先显示最近/最常用的物品 | Factorio 快捷栏最近使用自动排序 |
| 返回手势/按键 | 统一的返回操作 | Esc / Backspace / 鼠标侧键 / 手柄 B 键 |

### 6.3 导航效率原则

- **三击原则**：任何功能应在 3 次交互内到达（点击 + 点击 + 点击，或 按键 + 点击 + 点击）。
- **统一返回**：所有面板使用同一个返回键（Esc 或手柄 B），形成肌肉记忆。
- **面板不堆叠**：打开新面板时自动关闭同级旧面板（或限制同时打开的面板数 ≤ 2）。
- **快速关闭**：点击面板外的游戏区域关闭面板（"点击空白处关闭"），比找关闭按钮快得多。

## 七、颜色编码系统 (Color Coding)

### 7.1 语义颜色体系

模拟经营游戏通过一致的颜色语言来传达状态，减少文字依赖：

| 颜色 | 语义 | 典型使用场景 |
|------|------|------------|
| 🟢 绿色 | 正常 / 充足 / 正向 / 成功 | 满血、资源充足 (>60%)、心情好、工作效率高、建造位置合法 |
| 🟡 黄色 | 警告 / 不足 / 需要注意 | 资源偏低 (20-60%)、轻微伤害、需关注、输出已满、建设位置受限 |
| 🔴 红色 | 危险 / 严重 / 紧急 / 错误 | 濒死 (<20%)、资源枯竭、被攻击、火灾、建造位置非法 |
| 🔵 蓝色 | 信息 / 科技 / 魔法 / 中立 | 研究进度、法力值、科技项、中立事件、信息提示 |
| ⚪ 灰色 | 禁用 / 不可用 / 空白 / 未解锁 | 技能锁定、条件不满足、空槽位、冷却中 |
| 🟣 紫色 | 稀有 / 特殊 / 高级 / 灵异 | 史诗物品、Boss事件、灵异现象、最终科技 |
| 🟠 橙色 | 强调 / 可交互 / 选中 | 新建造物预览、可点击按钮、当前选中高亮 |

### 7.2 各游戏颜色运用深度分析

**RimWorld 心情颜色系统**

殖民者心情以连续颜色渐变表示：深红（极度崩溃）→ 橙红 → 橙黄 → 浅黄 → 浅绿 → 深绿（极度快乐）。这个设计让玩家无需阅读详细数据，一眼扫过所有殖民者头像就能判断整体士气状况。颜色配合数值（0-100）双重编码。

**Factorio 设备状态指示灯**

组装机、化工厂、研究中心等生产设备上有物理指示灯：
- 🟢 绿灯常亮：正常工作中
- 🟡 黄灯闪烁：输出已满（需要清空产出）或原料不足（需要补充输入）
- 🔴 红灯常亮：完全停止——缺电、缺配方、或输出阻塞导致产线停摆
- 关键设计：这些灯在玩家缩小画面（远距离视角）时仍然可见，实现"远距离状态感知"——站在远处扫一眼就能发现哪个产线出了问题。

**Stardew Valley 体力条**

体力条使用颜色渐变：绿色（>60%）→ 黄色（30-60%）→ 红色（<30%）→ 红色闪烁（<10%）。配合角色动画变化——体力低时走路速度变慢、动作变迟缓，形成"视觉颜色 + 角色动画"的多模态反馈。

### 7.3 色盲/视障无障碍设计

模拟经营游戏重度依赖颜色传达信息，无障碍设计至关重要：

- **不要仅用颜色传达信息**：颜色 + 图标形状 + 文字标签三重编码。例如警报不仅是红色边框，还有 ⚠ 图标 + "危险"文字。
- **Factorio 的色盲模式**：自 0.17 版本起内置色盲模式，提供红/绿色盲和蓝/黄色盲两套调色方案。电路线的红/绿在色盲模式下变为蓝/橙。
- **RimWorld 的通知信封**：除颜色外，信封图标形状也不同——红色信封有火焰装饰、蓝色有问号、绿色有笑脸。
- **颜色对比度**：文字与背景至少满足 WCAG AA 标准（对比度 ≥ 4.5:1），关键信息满足 AAA（≥ 7:1）。
- **图案/纹理叠加**：在颜色区分的基础上叠加斜线纹理、点状图案等，辅助区分不同颜色区域。

## 八、跨游戏通用 UI/UX 模式总结

### 8.1 空间一致性
- 同一功能入口始终在同一屏幕位置，不随游戏状态变化而移动
- 面板呼出/关闭有方向性动画（滑入方向 = 关闭时滑出方向）
- 选中物体后的详情面板位置固定（一般是底部或右侧）

### 8.2 即时反馈
- 所有操作有视觉反馈：按钮按下状态变化、建造预览网格（绿色=可建造 / 红色=不可建造 / 蓝色=已规划）、物品拖拽高亮边缘
- 数值变化有过渡动画（ease-out, ~300ms），不直接跳变
- 长时间操作有进度条（研究、建造、制作）

### 8.3 信息可配置性
- 允许玩家自定义 HUD 显示内容（RimWorld 底部资源条可增减项目）
- 允许关闭/调整通知类型和优先级
- 允许独立调整 UI 整体缩放比例

### 8.4 渐进式复杂度
- 新手引导期间 UI 功能逐步解锁——开始只显示核心 HUD，随教程推进逐步开放新面板
- 复杂功能默认折叠或隐藏，但高级玩家可随时展开（Factorio 电路网络新手不可见但始终可用）
- "简单模式"和"高级模式"的切换（如 Factorio Alt 键）

### 8.5 多模态反馈
- 关键事件：视觉 + 音效 + 可能的振动（手柄）三重确认
- UI 音效本身具有信息性：资源增加→清脆短促音，资源减少/损失→低沉音
- 环境音效配合 UI 信息：警报声 + 红光闪烁 + 屏幕轻微震动 = 最高级威胁事件

|---------|------------|-----------|
| HUD 极简设计 | Stardew Valley | 核心指标 ≤ 5 项，信息绝不超载；钟表+金币+体力就是一切 |

## 十、对中小型模拟经营游戏的实践建议

1. **从简开始，迭代添加**
   先实现核心 HUD（3-5 个核心指标）+ 一个主面板。随开发迭代逐步丰富面板体系。每次添加新面板时，自问："这个信息能否放入已有面板的 Tooltip？"

2. **Tooltip 先行于独立帮助系统**
   在实现复杂的独立教程/帮助系统之前，先把一切教学信息放进 Tooltip。Tooltip 是模拟经营游戏最重要的教学工具，成本低、不打断体验。

3. **通知分级架构尽早确定**
   通知系统的分级机制（P0-P3）影响底层事件系统的事件类型定义和派发逻辑，后期重构成本极高。建议在项目前期就定好分级标准和事件基类。

4. **建立语义颜色表并严格执行**
   从项目 Day 1 就建立语义颜色表，所有 UI 组件和游戏内反馈共用同一颜色编码规则。例如"绿色永远表示正常/正面"，避免一个面板里绿色表示"正常"，另一个面板里绿色表示"有毒"。

5. **设计"信息叠加层"切换键**
   考虑是否需要类似 Factorio Alt 键的机制，让玩家在"沉浸画面"和"数据画面"之间自由切换。这在模拟经营游戏中价值极高。

6. **参考 Factorio 的 UI/UX 哲学**
   Factorio 的 UI/UX 在模拟经营品类中被开发者社区广泛认为是最优秀的。其 Wube Software 团队在 UI 上的投入（色盲模式、Alt 切换、可配置快捷键、生产统计图表）值得反复研究测试。

7. **早期测试色盲可用性**
   在原型阶段就用色盲模拟工具（如浏览器 DevTools 的 vision deficiency 模拟，或 Godot 的颜色校正）测试 UI，而不是临近发布才补救。

8. **为手柄/触屏预留架构空间**
   即使首发仅 PC 键鼠，也应在 UI 导航架构中预留手柄焦点导航和触屏 hit area 的扩展能力——模拟经营游戏移植到 Switch/Steam Deck/移动端的比例远高于其他品类。
