## 核心设计原则（跨文档提炼）

### 1. 心流通道（Flow Channel）
- **坡度**：前期缓（学习）、中期陡（成长）、后期平（精通）
- **波动**：高峰后给低潮期，防止疲劳
- **宽度**：提供多路径（摆摊/熔炼/社交），不同玩家找到自己的节奏

### 2. 脚手架设计模式
```
引入 → 练习 → 测试 → 掌握 → 颠覆
Day1    Day1-3  Day3-5  Day5-7  Day8+
```

### 3. 定价博弈三要素（来自Recettear+Moonlighter+Potionomics）
- **信息不对称**：顾客不知道你的成本，你不知道顾客的上限
- **性格驱动**：不同性格的顾客有不同出价策略
- **谈判机制**：让步递减 + 情绪反馈 + 偶尔惊喜

### 4. 经济循环健康检查
```
买入 → 加工/熔炼 → 卖出 → 升级 → 买入更贵的
钱 ↑                                    ↓
└──── 必须有利润空间 ─────────────────┘
```

### 5. 多巴胺时间结构（Hook模型）
| 频率 | 锚点 | 当前实现 |
|------|------|---------|
| 秒 | 操作反馈音效/动画 | 部分 |
| 分 | 议价成功/熔炼闪光 | ✅ |
| 时 | 昼夜切换/顾客到访 | ✅ |
| 日 | DaySummary/管家来信 | ✅ |
| 周(10天) | 集市大日 | ✅ |
| 季(30天) | 季节轮换 | ✅ |
| 长期 | 熔炉升级/解锁 | ✅ |

### 6. 五层关系模型
```
数值层 → 触发层 → 叙事层 → 上下文层 → 生态层
好感度   事件条件   剧情文本   日程/位置   NPC间互动
```

### 7. 三级信息架构（UI）
```
L1 HUD — 灵石/灵识/时间/快捷键（始终可见）
L2 快捷面板 — 集市/熔炉/背包/摆摊（按键弹出）
L3 深度面板 — 议价详页/熔炉升级/结算（全屏沉浸）
```

## 灵墟旅商特定设计准则

1. **所有设定定稿后才写代码** — 设计修改+剧情融合+同次commit
2. **玩家视角验证** — 每项设计走一遍"玩家第一人称体验"
3. **不接受"因为设定如此"** — 必须有底层机制支撑
4. **经济闭环** — 任何系统必须能自圆其说（灵力哪来的？为什么涨价？）
5. **节奏感** — 不能连续高强度（议价后要有"喘息"时间）
6. **修仙味** — 数值涨了要有叙事包装（不是"+10好感"，是"石老捻须笑了"）
