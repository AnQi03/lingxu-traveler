# 星露谷物语 · 设计分析与借鉴

> 调研用于灵墟旅商的设计参考，聚焦可借鉴的系统与机制。

---

## 一、时间系统

### 星露谷设计
| 参数 | 值 |
|------|-----|
| 一天 | 6:00 AM → 2:00 AM（20小时） |
| 现实时间 | 约13分钟/天（不暂停时约7秒/10分钟） |
| 季节 | 28天/季，4季/年 |
| 暂停规则 | 菜单、对话、商店、钓鱼mini-game时暂停 |

### 灵墟旅商可借鉴

**1. 时间暂停的粒度区分**

星露谷的做法不是"全停或全不停"，而是区分场景：

| 场景 | 星露谷 | 灵墟当前 | 建议 |
|------|--------|---------|------|
| 管理面板（背包/熔炉/集市） | 暂停 | 暂停 ✅ | 保持 |
| 核心玩法（摆摊/议价） | 不暂停（钓鱼mini-game） | 流动 ✅ | 保持 |
| NPC对话/剧情 | 暂停 | 未实现 | 暂停 |
| 过场结算 | 自然过渡 | 暂停+10秒面板 | OK |

**2. 午夜强制结算**

星露谷凌晨2:00强制晕倒 → 扣钱 → 第二天。灵墟可以借鉴：
- 晚上20:00后不能摆摊，但可以继续做熔炼/整理背包
- 凌晨24:00强制进入结算（不管玩家在哪）

**3. 跳过等待**

星露谷可以"睡觉"直接跳到第二天。灵墟可以：结算面板上加一个"立即进入第二天"按钮（或按任意键加速）。

## 二、能量系统（星露谷的核心"有限性"）

### 星露谷设计
- 每天有固定能量条（初始270，上限508）
- 每个动作消耗能量（浇水-2，挖矿-3，砍树-2...）
- 能量耗尽 → 移动缓慢 → 强行干到晕倒 → 扣10%钱
- 吃东西/泡温泉恢复能量
- 升级技能减少消耗

### 这是星露谷最核心的设计——"每天能做有限的事"

如果不限制，玩家会种无限多的地 → 游戏失去节奏。能量系统强迫玩家做取舍。

### 灵墟旅商可借鉴

灵墟的核心限制不是体力，而是：

| 当前已有的限制 | 可加强的方向 |
|-------------|------------|
| 每日熔炼上限5次 | ✅ 已有 |
| 每日顾客上限10人 | ✅ 已有 |
| 资金有限（初始100灵石） | ✅ 自然形成 |
| **缺少感知层** | 玩家没有"今天我累了"的感觉 |

**建议：加一个"精力值"（精→气→神转化）**

不叫体力，叫**"灵识"**（修真感）：

```
灵识 = 100（上限随修为增长）
├─ 熔炼一次 -15灵识
├─ 议价一次 -5灵识（察言观色费神）
├─ 赶路/探索 -10灵识
├─ 灵识耗尽 → 当天无法再做"费神"操作（只能看背包/走路）
├─ 喝茶/打坐/丹药 → 恢复灵识
└─ 睡眠 → 完全恢复
```

这和星露谷的能量系统异曲同工：**硬限制每天的"高价值行动"次数**。

## 三、商店营业时间

### 星露谷设计
每个商店有不同的营业时间：

| 商店 | 营业时间 | 休息日 |
|------|---------|--------|
| Pierre杂货 | 9:00-17:00 | 周三 |
| Clint铁匠 | 9:00-16:00 | 周五（社区中心后） |
| Robin木匠 | 9:00-17:00 | 周二 |
| Marnie牧场 | 9:00-16:00 | 周一周二 |
| Willy渔店 | 9:00-17:00 | 周六 |

玩家必须**记住NPC作息**，错过就要等明天，形成自然的时间管理压力。

### 灵墟旅商可借鉴

**灵墟集市不必24小时营业**：

```
灵墟摊位时间表（建议）
├─ 早晨市集 (5:00-9:00) — 批发价灵材，大宗交易
├─ 日间市集 (9:00-17:00) — 常规价格，摆摊时间
├─ 夜市 (18:00-20:00) — 特殊/稀有灵材，高价
└─ 暗市 (22:00-2:00) — 非法灵材，高风险高回报

不同宗门/商贩的出现时段不同
```

这会自然形成玩家的时间管理决策："今天是早上去批发灵材，还是留着精力晚上去暗市？"

## 四、品质系统 & 加工增值

### 星露谷设计

```
原材料 → 加工品 → 价格倍增

水果 (100g) → 果酒 (300g, 3x)
蔬菜 (100g) → 腌菜 (250g, 2.5x)
牛奶 (125g) → 奶酪 (200g, 1.6x)
鸡蛋 (50g) → 蛋黄酱 (190g, 3.8x)

品质加成：金星品质再 ×1.5
专精技能加成：工匠技能 ×1.4
```

核心设计：**加工要时间但大幅增值**，玩家面临"直接卖还是加工后再卖"的决策。

### 灵墟旅商可借鉴

灵墟已经有了类似的体系（灵材→熔炼→升品），但缺少**中间加工**：

```
灵墟增值链（建议扩展）
├─ 凡品灵材 (10灵石) → 直接卖 ✓
├─ 凡品灵材 → 熔炼 → 灵品 (50灵石) ✓ 已有
├─ 凡品灵材 → 切片加工 → 灵材片 (15灵石, 加工时间短)
├─ 多灵材 → 炼丹 → 丹药 (100灵石, 需要配方+时间)
├─ 灵品灵材 → 附魔 → 附魔灵材 (200灵石, 需要特殊工具)
└─ 废料 → 回收 → 灵砂 (3灵石, 无成本但量少)
```

这样玩家不只是"买→卖"或"买→熔炼→卖"，而是有**多条加工路径**：
- 快速变现（直接卖/切片）
- 赌升品（熔炼）
- 慢但稳（炼丹，需要配方但成功率100%）
- 高风险高回报（附魔）

## 五、社交系统（NPC好感度）

### 星露谷设计

| 机制 | 细节 |
|------|------|
| 送礼 | 2次/周/NPC，生日8x效果 |
| 好感等级 | 0→2→4→6→8→10心 |
| 心事件 | 每2心触发一段剧情 |
| 好感衰减 | 每天-2（忽略时）；达到满心后不衰减 |
| 解锁 | 食谱、礼物、剧情、可结婚 |

### 灵墟旅商可借鉴

灵墟已经有商道/天道/人心三道系统，但**缺少个体NPC层面的好感系统**：

```
灵墟顾客好感度（建议）
├─ 回头客：摆摊时概率遇到老顾客
├─ 老顾客好感度影响：
│   ├─ 议价容差更大（不会轻易走掉）
│   ├─ 特殊需求（告诉你他想要什么）
│   └─ 介绍新顾客（口碑传播）
├─ 好感获取：
│   ├─ 成交愉快 +2
│   ├─ 给折扣 +3
│   ├─ 送小礼物 +5（1次/天限制）
│   └─ 骗了对方 -5（出价太高被拒绝）
├─ 好感等级解锁：
│   ├─ 3级：告诉你灵材来源（你可以去进货）
│   ├─ 5级：透露市场情报（某灵材即将涨价）
│   └─ 7级：介绍你去特殊渠道（暗市/拍卖会）
└─ 忽略惩罚：
    └─ 太久不接待（3天+）好感缓慢下降
```

这和星露谷的做法一致：**NPC不是纯交易点，而是有记忆、会成长的关系**。

## 六、"再来一天"循环 — 星露谷最核心的魔力

### 设计精髓

1. **每天结束时有"收获感"屏幕** — 卖了多少、升级了什么、和谁说话了
2. **明天总有一个明确目标** — 节日明天、某作物成熟、铁匠明天开门
3. **永远有"还差一点"的感觉** — 还差一块钱升级工具 → 明天第一件事就是去挖矿
4. **惩罚温和** — 晕倒只扣10%钱，不会丢失进度

### 灵墟旅商可借鉴

灵墟当前的"结算面板"已经有了雏形（显示收入+库存），但缺少"明天预告"：

```
结算面板增强版
├─ 📊 今日营收：XXX灵石
├─ 📦 库存变化：进X出Y
├─ 🎯 明日预告：
│   ├─ "明天是XX宗门的集市日"（部分灵材打折）
│   ├─ "明早有XX顾客会来"（预约系统）
│   └─ "你的熔炉冷却好了"（提醒）
└─ 💡 小目标提示："还差XX灵石就能升级熔炉了"
    （参考星露谷的"还差一块钱"心理）
```

**关键是让玩家睡前有一个"明天第一件事做什么"的念头**。

## 七、季节/周期系统

### 星露谷设计

| 季节 | 28天 | 特点 |
|------|------|------|
| 春 | 1-28 | 基础作物、复活节 |
| 夏 | 1-28 | 高价值作物、月光水母节 |
| 秋 | 1-28 | 南瓜、丰收节、万灵节 |
| 冬 | 1-28 | 无种植、夜市、冰雪节 |

每个季节有专属：作物、鱼、采集物、节日、NPC生日。

### 灵墟旅商可借鉴

灵墟目前没有明确的时间周期概念。可以引入：

```
灵墟历法（建议）
├─ 灵潮月（春） — 灵材丰产月，进货价低
│   ├─ 第1周：草木灵材多
│   ├─ 第2周：兽类灵材多
│   ├─ 第3周：矿类灵材多
│   └─ 第4周：灵潮高峰 → 所有灵材便宜但顾客少（大家都在囤货）
├─ 静修月（冬） — 灵材枯竭，但NPC有时间聊天
│   └─ 摆摊收入低，适合做熔炼/社交/探索
└─ 特殊日期：
    ├─ 宗门交易日（每10天一次）— 大宗折扣
    ├─ 灵材拍卖日（每月2次）— 稀有灵材
    └─ 灵潮日（季节转换）— 特殊事件
```

**季节创造FOMO和长期规划**，让玩家不只过一天是一天，而是考虑"这个月我要囤什么？"

## 八、工具升级系统

### 星露谷设计

```
工具线性升级：
初始 → 铜 (2000g + 5铜锭) → 铁 (5000g + 5铁锭) → 金 (10000g + 5金锭) → 铱 (25000g + 5铱锭)

每次升级：效率提升 + 可操作更高等级的障碍物
升级需要：钱 + 材料 + 等待时间（2天）
```

### 灵墟旅商可借鉴

熔炉升级：

```
熔炉升级线（建议匹配现有仙品体系）
├─ 粗制熔炉（初始）→ 熔炼凡→灵概率35%
├─ 铁铸熔炉（500灵石）→ 凡→灵概率50%，解锁切片功能
├─ 灵纹熔炉（2000灵石 + 特殊材料）→ 凡→灵概率65%，灵→宝概率30%
├─ 宝光熔炉（5000灵石 + 稀有材料）→ 凡→灵概率80%，灵→宝概率45%
└─ 仙品熔炉（15000灵石 + 剧情解锁）→ 解锁宝→仙可能

升级需要"时间"——熔炉不能在工作时升级
```

## 九、社区中心 vs 宗门声望

### 星露谷设计

社区中心有6组收集包，每组需要多种物品。完成整组解锁新区域/功能：
- 工艺室 → 修复矿车（快速去矿洞）
- 储藏室 → 修复温室
- 鱼缸 → 移除矿井闪光巨石
- ...

### 灵墟旅商可借鉴

不是"社区中心"，而是**"宗门贡献"**：

```
宗门贡献里程碑
├─ 寒渊宗声望 Lv.1 → 冰属性灵材进货渠道
├─ 寒渊宗声望 Lv.3 → 冰属性熔炼成功率+5%
├─ 寒渊宗声望 Lv.5 → 解锁寒冰洞窟（特殊进货点）
└─ 寒渊宗声望 Lv.7 → 独有灵材"冰晶髓"

声望获取：完成宗门委托（交付指定灵材）
```

这不只是数值，而是**解锁新内容**——和星露谷社区中心一样的感觉。

## 十、设计哲学总结：星露谷为什么上瘾？

| 设计原则 | 星露谷做法 | 灵墟可借鉴 |
|---------|-----------|----------|
| **有限性** | 每天能量有限，必须取舍 | 灵识系统 + 熔炼次数 + 顾客上限 |
| **每日结算** | 睡前看收获，明天有目标 | 结算面板 + 明日预告 |
| **多路径并行** | 种地/钓鱼/挖矿/社交/采集 | 摆摊/熔炼/进货/社交/探索 |
| **渐进解锁** | 社区中心→工具升级→新区域 | 宗门声望→熔炉升级→新渠道 |
| **周期变化** | 四季轮转，专属内容 | 灵潮/静修周期，特殊日期 |
| **温和惩罚** | 晕倒扣10%，不会坏档 | 灵识耗尽停一天，不丢灵石 |
| **永远差一点** | "还差500g升级喷壶" | "还差200灵石升级熔炉" |
| **NPC有记忆** | 好感度衰减，专属剧情 | 回头客好感，口碑传播 |

## 对灵墟旅商的优先级建议

按可实现性和影响排序：

| 优先级 | 系统 | 理由 |
|--------|------|------|
| 🔴 1 | **结算面板增强**（明日预告+小目标） | 最低成本，最大"再来一天"效果 |
| 🔴 2 | **灵识系统**（限制每天行动数） | 给游戏节奏感，避免无限刷 |
| 🟡 3 | **顾客好感度**（回头客+口碑） | 增加摆摊深度，NPC有记忆 |
| 🟡 4 | **熔炉升级线** | 已有熔炼系统，升级是自然延伸 |
| 🟢 5 | **灵墟历法**（周期+节日） | 需要更多基础系统，可后期加入 |
| 🟢 6 | **多加工路径**（切片/炼丹/附魔） | 设计量大，适合中期扩展 |
