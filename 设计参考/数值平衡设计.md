# 灵墟旅商 · 数值平衡设计

> 基于难度曲线理论、成长曲线模型、经济循环分析

---

## 一、设计理论

### 1. 最优难度曲线（Sigmoid / S曲线）

```
成长速度
  ↑          ┌────────── 终局（平缓）
  │        ╱
  │      ╱  中期（陡坡—成长最快）
  │    ╱
  │  ╱  前期（缓坡—学习期）
  └────────────────────→ 游戏时间
```

- 新手期：坡缓，让玩家有时间学习
- 成长期：坡陡，快速解锁新内容
- 终局期：坡平，追求极致和完成度

### 2. 数值设计三原则

| 原则 | 说明 | 错误做法 |
|------|------|---------|
| **可见性** | 玩家能感受到数字变化的影响 | 数字涨了但体验不变 |
| **可达性** | 下一个目标在合理时间内可达 | 需要肝几十小时才升一级 |
| **反馈性** | 每次投入都有对应的回报感 | 花500灵石升级后感觉没用 |

### 3. 投入回报比（ROI）

```
合理ROI = 投入时间 ∝ 获得回报

当前问题：
  赚200灵石 → 需要4-10天 ≈ 1.5-4小时 → 太慢了！
```

## 二、当前数值诊断

### 早期经济（Day 1-7）

| 参数 | 当前值 | 问题 |
|------|--------|------|
| 初始灵石 | 100 | 买10-30个灵材，做5-15单生意 |
| 顾客数 | 1-2个/天 | OK但利润低 |
| 日均利润 | 10-30灵石 | 200灵石升级要7-20天 |
| 现实时间 | 24分钟/天 | 7天=近3小时才第一次升级 |

**结论：早期太长——玩家在3小时内看不到任何系统解锁。**

### 中期（Day 8-30）

| 参数 | 当前值 | 问题 |
|------|--------|------|
| 日均利润 | 40-80灵石 | 800升级需要10-20天 |
| 熔炉Lv.2→Lv.3 | 800灵石 | 又是10-20天 |
| 新增内容 | 无 | 中期完全空白 |

**结论：中期真空——Day8到Day30之间没有任何新东西。**

### 熔炼概率

| 品阶 | Lv.1概率 | Lv.2 | Lv.3 |
|------|---------|------|------|
| 凡→灵 | 35% | 50% | 65% |
| 灵→宝 | 20% | 25% | 35% |
| 宝→仙 | 0.7% | 1.0% | 3.0% |

当前凡→灵在Lv.1只有35%→新手熔炼经常降品甚至报废，挫败感强。

### 灵识消耗

| 操作 | 消耗 | 每日可用次数 |
|------|------|------------|
| 熔炼 | 15 | 6次（上限5次） |
| 议价 | 5 | 20次（上限10个顾客） |

灵识100对于当前限制来说太多——玩家感受不到"有限性"。

## 三、修改方案

### 经济节奏

```
新手期（Day 1-7）：  日均利润 40-60灵石  → 3-5天攒够200升级
成长期（Day 8-21）： 日均利润 80-120灵石 → 4-7天攒够800升级
熟练期（Day 22-60）：日均利润 150-250灵石
终局期（Day 60+）：  日均利润 300+灵石
```

### 具体调整

| 参数 | 旧值 | 新值 | 理由 |
|------|------|------|------|
| 初始灵石 | 100 | 150 | 给新手多几次试错 |
| 熔炉Lv.2成本 | 200 | 180 | 加快第一次升级 |
| 熔炉Lv.3成本 | 800 | 600 | 减少中期等待 |
| 熔炉Lv.4成本 | 3000 | 2000 | |
| 熔炉Lv.5成本 | 15000 | 8000 | |
| 灵识初始 | 100 | 80 | 让"有限性"更早感知 |
| 熔炼灵识消耗 | 15 | 10 | 可熔8次(上限5次) |
| 议价灵识消耗 | 5 | 3 | 可议价26次(上限10) |
| 凡→灵 Lv.1 | 35% | 40% | 新手期降低挫败感 |
| 凡→灵 Lv.2 | 50% | 55% | |
| 灵→宝 Lv.1 | 20% | 22% | |
| 灵→宝 Lv.2 | 25% | 28% | |

### 成长曲线效果

```
Day 1-3：  学习摆摊+熔炼，赚到第一桶金(~180灵石)
Day 4-5：  第一次升级熔炉(Lv.1→Lv.2)
Day 8-12： 第二次升级(Lv.2→Lv.3)，商道/天道开始积累
Day 14：   管家来信提醒拍卖会
Day 15-20：第三次升级(Lv.3→Lv.4)，常客关系深化
Day 30：   第一季结束，世界反馈更新
Day 60+：  终局内容
```
