# 灵墟旅商 · 次要NPC人物志

> 灵墟不只有名震四方的大人物。
> 更多的是那些每天在集市上讨生活的普通人——他们可能一辈子都不会改变灵墟的走向，
> 但他们的存在，让灵墟不再是一座空城。

---

## 设计原则

1. **有特征，但不一定有故事**——每个NPC至少有1-2个让人记住的个人特质（口头禅、小动作、怪癖），但不一定需要完整的背景故事
2. **有重复出现的理由**——每个NPC都有自己常来的原因，不只是"系统刷出来的顾客"
3. **不触发大型剧情事件**——他们就是日常的一部分，不会突然跳出来给你一个主线任务
4. **少数NPC可以成长为"老顾客"**——如果玩家多次与之交易，他们会从"随机路人"升级为"熟面孔"

# 一、中央荒原 · 常驻NPC

## C01 · 老烟杆

> "来株赤炎草——要叶脉泛金的那种。别拿隔夜货糊弄我，我抽了一辈子烟，闻得出来。"

| 项目 | 内容 |
|------|------|
| **称呼** | 老烟杆（因为他永远叼着一根烟杆——烟杆比他的命还长） |
| **年龄** | 六十出头 |
| **身份** | 散修，练气巅峰 |
| **外貌** | 干瘦、黝黑，手指被烟熏得蜡黄。穿一件补丁摞补丁的道袍，但洗得很干净 |
| **特征** | 他买灵草不是为了炼丹——他是拿来当烟丝抽的。他抽了一辈子灵草烟，对灵草的品相有独特的判断标准（和炼丹师的完全不一样）。他会掰碎一片灵草放烟杆里，点上火，深吸一口——"嗯，这批行。"或者"呸，这什么玩意儿。" |
| **常买什么** | 赤炎草（火系，味道最烈）、翠灵木的嫩叶（带着清香）、极地苔（味道怪但上头） |
| **出现频率** | 每2-3天来一次，雷打不动 |
| **为什么记得住他** | 他是唯一一个用"抽"的方式来验收灵草的顾客。而且他每次来都会给你一两条"灵墟老话"——"我年轻时走过炎狱域那边的火山口，那儿的灰灵壤才是真好货，现在的都是假的。" |

### 老烟杆的"灵墟老话"（随机说一条）

- "玄冰域那边的人啊，脸上冷，心里也冷。但他们的货是真的好——人冷货不冷。"
- "我年轻的时候，一件宝品能换半条街。现在？宝品满地跑，灵石不经花。"
- "那棵世界树——我远远看过一眼。那时候它还茂盛着呢。现在听说不行了？唉，什么东西都扛不住时间。"
- "暗市？我没去过。但我听说过——那下面有东西。不是货，是别的东西。说不好。"（说完接着抽烟，不肯多说了）

## C02 · 碎嘴阿婆

> "小伙子，你这赤炎草比昨天贵了两块灵石！别以为老婆子我不识数！"

| 项目 | 内容 |
|------|------|
| **称呼** | 碎嘴阿婆（没人知道她叫什么，整条街的人都这么叫她） |
| **年龄** | 七十余岁 |
| **身份** | 凡人——灵墟为数不多的纯凡人居民 |
| **外貌** | 矮小、驼背，花白的头发梳得一丝不苟。穿着中央荒原最常见的粗布衣裳。手里永远挎着一个竹篮子 |
| **特征** | 她几乎什么都买，但每样只买一点点——两根灵草、三片叶子、一小把矿石碎末。她的竹篮子里永远装着一些稀奇古怪的东西：一块石头、半截木雕、一片干枯的树叶。她每天都在集市上转悠，和每一个摊主聊天。她记得每一个摊主的价格变动——"你昨天卖85，今天怎么卖90了？" |
| **常买什么** | 什么都买一点点——但她特别喜欢买"别人不要的边角料"（断掉的灵草、碎裂的矿石） |
| **出现频率** | 几乎每天都来 |
| **为什么记得住她** | 她是中央荒原的"活历史"——她在这里住了七十年，见证了灵墟三代人的变迁。如果你愿意和她聊，她会告诉你：你摆摊的那个位置，三十年前是一个炼药师的小铺子——"那个炼药师后来去了苍木域，再也没回来。" |

### 碎嘴阿婆的"街坊新闻"（随机说一条）

- "北街那个做豆腐的老王头，他儿子前两天回来了——说是从金戈域那边回来的。带了好多稀奇古怪的铁疙瘩。"
- "听说天道商会最近换了一批账房先生——全都是生面孔。以前那个老账房呢？没人知道。"
- "昨晚城西那边有动静。不是风声，是比风声更低沉的那种声音。我活了七十年，只听过两次这种声音——一次是三百年前，一次是昨晚。"（如果玩家追问，她会摆摆手——"我老太婆瞎说的，别当真。"）

## C03 · 闷葫芦

> "……这个。"
> （指着你要价最高的那件灵材，从怀里摸出一个磨得发亮的钱袋，开始一枚一枚地数灵石。）

| 项目 | 内容 |
|------|------|
| **称呼** | 闷葫芦（因为他几乎不说话——一次交易能说三句话算话多了） |
| **年龄** | 四十岁上下 |
| **身份** | 散修，筑基初期 |
| **外貌** | 中等身材、面容普通到毫无特征。穿灰褐色短褐，不佩戴任何法器或饰品。他是那种你见过十次也记不住长相的人 |
| **特征** | 他从来不说自己要什么。他会站在摊位前扫视一圈，然后指向某件灵材——不开口。如果你把货拿给他，他会接过来仔细看一遍（看叶脉、闻味道、掂分量——和品阶鉴微的流程一模一样），然后点头或摇头。点头——开始数钱。摇头——转身走人。整个过程不超过二十秒 |
| **常买什么** | 中高档灵材——他的眼光很毒，从不买次品，也从不为次品付高价 |
| **出现频率** | 每周1-2次 |
| **为什么记得住他** | 他的沉默太特别了——你在灵墟几乎找不到第二个这样交易的人。而且他的眼光是真的好——他挑走的货，往往是最值钱的那几件。如果你留意到他的选择，你会开始注意到一些你以前没注意到的细节 |

### 闷葫芦的特殊设定

闷葫芦不是普通散修。他的真实身份是**铸魂殿的外派采购员**——但不是钱通那种正式的采购员。他是铁山派出来"微服私访"的探子，专门在各域集市上寻找被低估的好货。他从来不亮明身份，因为一旦亮明了身份，卖家就会抬价。

这个设定**玩家不会在正常游戏中发现**——但如果玩家的商道值够高（≥60）且多次注意到闷葫芦的眼光奇准，宁秩会在某天突然产生一个念头："这个人……不像是普通散修。"

## C04 · 急脚张三

> "快快快快——有没有现成的寒露草？三株！马上！我师父的炉子还开着呢！"

| 项目 | 内容 |
|------|------|
| **称呼** | 急脚张三（因为他永远在跑——不是走路，是小跑） |
| **年龄** | 二十出头 |
| **身份** | 炼药师学徒，练气中期 |
| **外貌** | 瘦高、长腿，穿着一件沾满药渍的短衫。头发总是乱糟糟的——因为每次出门都是放下手里的活就跑出来的 |
| **特征** | 他永远是急匆匆的——跑到摊位前，气还没喘匀就开始说需求。他的师父是个脾气暴躁的老炼药师，每次炼丹缺了哪味材料就派张三出来现买。张三在灵墟各大集市之间跑来跑去，对每个摊位的库存比摊主自己还清楚 |
| **常买什么** | 炼制丹药的常用灵草——寒露草、赤炎草、翠灵木的嫩芽等。每次量不大（3-5株），但频率很高 |
| **出现频率** | 每1-2天来一次 |
| **为什么记得住他** | 他的"急"太有辨识度了。而且——如果你在他最急的时候救过他的急（刚好有他要的货），他会记住你。以后他师父要采购大批材料时，他会第一个推荐你的摊位。 |

### 急脚张三的"师父秘闻"（可说可不说）

如果玩家和急脚张三比较熟了（交易≥5次），他会在等货的时候多聊两句：
- "我师父说——灵墟的灵草一年不如一年了。他年轻时候炼的清心丹，一株寒露草能顶现在两株的药力。"
- "上个月师父接了一个奇怪的订单——有人要炼制一种他从来没听说过的丹药。配方上有一味材料连师父都不认识。那东西……闻起来不像灵墟的东西。"

## C05 · 冷面客

> （不说话，不指货，只是站在摊位前目光扫过所有商品。
> 然后从袖中抽出一张纸条，上面写着所需物品的名称和数量。）

| 项目 | 内容 |
|------|------|
| **称呼** | 冷面客（摊主们私下都这么叫他——没人知道他的身份） |
| **年龄** | 看起来三十余岁（但修士的实际年龄很难判断） |
| **修为** | 看不出来——他收敛了所有气息 |
| **外貌** | 穿深色带兜帽的外袍，大部分时候看不清面容。身形挺拔、站姿端正。不说话、不笑、不做出任何多余的动作 |
| **特征** | 他用纸条交易。每次来都递一张纸条——上面用工整的小楷写着所需灵材、数量和可以接受的最高价。如果你能给，他就放下灵石、取走货物，在纸条背面盖一个小章（表示"已付清"），然后离开。全过程不会超过一分钟 |
| **常买什么** | 不定——有时是稀有的高阶灵材，有时是最基础的凡品。看不出规律 |
| **出现频率** | 不固定——有时一周来两次，有时一个月不来一次 |
| **为什么记得住他** | 他的交易方式太正式了——像在完成某种公务。而且他盖的那个小章——上面刻的不是名字，是一个图案：**一条简笔的鱼** |

### 冷面客的真实身份

冷面客是**沧溟宫的外派采购员**。他盖的那个鱼形小章，是沧溟宫外勤人员的身份标记——灵墟很少有人认得这个标记，但认得的人都不敢惹。他采购的灵材全部用于沧溟宫内部——因为深海域不产出某些陆上灵材，沧溟宫需要定期从各域采购。

这个设定玩家可以**通过鉴微+调查发现**——如果玩家在某次交易后仔细观察那张纸条的纸质，会发现纸的纤维中含有极细的银色丝线。这种纸只有深海域有产。

# 二、玄冰域 · 常驻NPC

## H01 · 哆嗦老王

> "快快快快……快拿货，我要回去了。这鬼地方太暖和了，我受不了。"

| 项目 | 内容 |
|------|------|
| **称呼** | 哆嗦老王（因为他永远在打哆嗦——不是冷的，是他习惯性的动作） |
| **年龄** | 五十余岁 |
| **身份** | 玄冰域散修，筑基初期 |
| **外貌** | 裹着厚厚的兽皮大氅，即使在中央荒原最暖和的日子里也不脱。脸色苍白，嘴唇微微发紫——长年在玄冰域生活的人的特征 |
| **特征** | 他是从玄冰域到中央荒原做买卖的中间商。每次来他都抱怨"太暖和了受不了"，然后匆匆忙忙交货拿钱走人。但他带来的玄冰域特产——寒铁、冰晶矿——成色总是很好。他有一套自己的"玄冰域标准"：灵材在玄冰域保存得当的话，灵气流失比别处慢得多。所以他总能卖个好价钱 |
| **常卖什么** | 玄冰域的基础灵材——寒露草、冰晶矿、寒铁 |
| **为什么记得住他** | 他的"冷"字招牌——每次看到他裹着大氅瑟瑟发抖的样子，你就会知道玄冰域的货来了。而且他偶尔会透露一点玄冰域的内部消息——"最近雪下得太大了，矿道封了好几处。过段时间寒铁可能要涨价。" |

| 项目 | 内容 |
|------|------|
| **称呼** | 寒渊宗的采购弟子（没有固定名字——每次来的人可能不同） |
| **年龄** | 二十到四十不等 |

# 三、其他板块 · 偶遇NPC

## R01 · 赤脚老六（炎狱域）

> "哎呀呀呀——烫烫烫——这鬼地方的地皮怎么这么烫！"

| 项目 | 内容 |
|------|------|
| **称呼** | 赤脚老六（他永远赤着脚——不是因为他穷得买不起鞋，是他修炼的功法必须脚底接触地面） |
| **外貌** | 赤脚、皮肤黝黑发亮、满身灰尘。穿一条破烂的短裤，上身赤膊。走在炎狱域的火山岩上像走平地一样自在 |
| **特征** | 他是炎狱域的信息枢纽——不是因为他地位高，而是因为他整天光着脚在炎狱域各处跑来跑去。哪个矿洞出了新货、哪个熔炉出了好铁、哪个宗门来了大人物——他知道的速度比马三还快 |
| **为什么记得住他** | 他是唯一一个你远远看到就能认出来的人——因为所有人都穿着鞋，只有他没穿。而且他有个习惯：说话的时候会用脚趾头在地上画画。如果你看他的"画"，会发现他画的都是些奇怪的符号——他自己都不知道那是什么意思，就是脚趾头自己在动 |

## R02 · 药篓子（苍木域）

> "这个、这个、还有这个——你看这三株，它们其实是一家的。你把它们分开卖，就没有灵性了。"

| 项目 | 内容 |
|------|------|
| **称呼** | 药篓子（因为他永远背着一个和他身形差不多大的竹药篓） |
| **外貌** | 看上去八十岁的苍木域老农——但实际年龄可能翻一倍。满脸皱纹，手指因常年接触灵植而染成了绿色 |
| **特征** | 他是万木灵宗外围的灵植农——不是正式弟子，但帮宗门照料一部分灵田。他对灵草有一种奇特的"共情力"——他能感知到灵草是不是"不开心"。他卖灵草的时候会仔细询问买主："你是要炼丹？还是入药？还是当装饰？"——因为他觉得灵草应该去最适合它的地方 |
| **为什么记得住他** | 他卖灵草的方式太特别了——他不讲价钱，讲"缘分"。有时候他看一个散修顺眼，会把一株价值不菲的灵草半卖半送地给出去。有时候他看到一个大商会的采购员，会直接把药篓子背上就走——"你们的灵草会用在不该用的地方。不卖。" |

## R03 · 石墩（金戈域）

> "你这批金灵砂，筛过没有？没筛过我不要。筛过了？——拿出来我看看。"

| 项目 | 内容 |
|------|------|
| **称呼** | 石墩（又矮又壮，像一块石头蹲在那里） |
| **外貌** | 身高不到一米六，宽度和高度差不多。脑袋大脖子粗，双手像两块铁板 |

| **为什么记得住他** | 验收矿石的时候他会敲半天，然后给你一个评价："这声儿——好矿。"或者"这声儿——废石。"和他做生意你永远不会被坑——因为他从不收次品，也从不把好矿当次品压价。 |

## R04 · 海螺婆婆（深海域）

> （她不说话——她递过来一个海螺，放在耳边可以听到里面传出的声音。）

| 项目 | 内容 |
|------|------|
| **称呼** | 海螺婆婆（因为她永远随身带着一个巴掌大的海螺） |
| **外貌** | 极老——满脸的皱纹像海床上的沟壑。穿深蓝色的粗布衣裳，赤脚站在沙滩上。她的眼睛是灰白色的——看不见的 |
| **特征** | 她是深海域少有的、会主动和外人接触的人。她不说话——她似乎不会说话。但她把想说的话录在了海螺里。她递给你的海螺，每只里只有一段话——有的是一句报价，有的是一段海浪声，有的是她年轻时候唱的歌。想要她卖给你的货？把灵石放在沙滩上，她听到了灵石落地的声音，就会把货放在你脚边。她不会骗你——她也知道你骗不了她 |
| **为什么记得住她** | 她用海螺"说话"的方式太独特了。而且她卖的东西——深海域独有的贝壳、珊瑚化石、被海浪打磨了千年的"海石"——品质无可挑剔。如果你想买深海域的特产又不想经过沧溟宫的官方渠道，海螺婆婆是唯一的选择。 |

# 四、特殊出现NPC

## S01 · 来踢馆的同行

> "听说你眼力很毒？巧了，我也是。来比比？"

| 项目 | 内容 |
|------|------|
| **触发条件** | 玩家的品阶鉴微名声传开后（商道≥30），每10-15天有概率触发——一个同行摊主来"切磋" |
| **特征** | 他（或她）会拿一件灵材到你的摊位前——"你看看这件什么品阶，什么价。"如果你说对了，他点头走人。如果说错了，他会嘿嘿一笑——"看来你的眼力也就那样。" |
| **为什么记得住他** | 他不一定是恶意的——有些同行是真的想切磋眼力。如果你连续三次都说对了，他以后可能会变成你的"朋友摊主"——两家摊位之间互相推荐客户："你要的货我没有——隔壁那个宁掌柜有，去他那儿看看。" |

## S02 · 神秘大能（极低概率）

> （一个穿着朴素的老人站在摊位前，看了很久。然后指着一件最便宜的凡品灵材——"这个，我要了。"）
> （他放下灵石，取走灵材，转身离开。你注意到他放下的灵石——是一枚上品灵石。而那件凡品灵材只要10灵石。）

| 项目 | 内容 |
|------|------|
| **触发条件** | 商道≥60，极低概率触发（约每30天1次） |
| **外貌** | 一个看起来极其普通的老人——但任何仔细看他的人，都会发现"看不清他的脸"。不是他挡着脸，是你看过去的时候，注意力会自动滑开 |
| **发生了什么** | 他用上品灵石买了一株凡品灵草，然后消失在人群中。你多了一枚上品灵石——但你总觉得他给的不是灵石，而是别的什么东西。那天晚上，宁秩会做一个模糊的梦——一个老人站在灵墟的边缘，回头看了他一眼。梦醒了。窗外的月亮还是那个月亮。 |
| **为什么记得住他** | 这件事没有后续、没有支线任务、没有隐藏奖励。它只是发生了。你甚至不确定是不是真的发生过——但那枚上品灵石就躺你的钱袋里，实实在在的。 |

## S03 · 拾荒小孩

> （一个瘦小的身影在收摊后的集市上翻找着什么。他看起来不到十岁，赤着脚，穿着一件大人的破衣裳。）

| 项目 | 内容 |
|------|------|
| **触发条件** | 玩家收摊时如果摊位上有不要的边角料/废品，有一定概率看到他 |
| **怎么做** | 你可以赶走他、可以无视他、也可以——把今天卖剩下的几株品相不太好的灵草递给他。如果你给了他，他不会说谢谢，但第二天你的摊位前会多一朵不知道从哪里来的野花。以后每次你收摊时给他东西，他第二天都会放一朵花在你摊位上。有时候是一株他捡到的灵草，有时候是一块漂亮的石头。他在用自己的方式还你。 |
| **为什么记得住他** | 他没有什么故事线——他不会成为你的随从，不会给你任务，不会触发任何剧情事件。但他每次出现都会让你觉得：这个世界不只是灵石和品阶。 |
