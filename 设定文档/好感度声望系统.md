# 好感度与声望系统设定

> 核心：三个隐性维度（商道/天道/人心）作为玩家的内在轨迹可视化呈现。不是数值游戏，但玩家的每一次选择都在书写自己的商途。

---

## 一、总览

### 三道架构

灵墟旅商的声望系统由**三个独立维度**构成。它们不直接显示数值，但世界会通过 NPC 的态度、可触发的交易、解锁的内容来告诉你"你走的是什么路"。

| 维度 | 积累方式 | 影响范围 | 对立面 |
|------|---------|---------|--------|
| **商道** | 经营行为的总和 | 交易价格、市场准入、商队报价 | —（低商道≠坏，只是不同路线） |
| **天道** | 天道熔炼的频率和结果 | 熔炼成功率、天道事件触发 | — |
| **人心** | 对待他人的方式 | NPC态度、盟友、关键选择 | — |

> 这三个维度相互独立，但会共同影响世界对你的整体认知。一个商道高、人心高、天道也高的人，和一个商道低、人心低、天道也低的人，面对的是完全不同的灵墟。

## 二、商道（经营之道）

### 商道层级的命名体系

| 商道值范围 | 称号 | 解锁内容 |
|-----------|------|---------|
| 0-20 | 无名小贩 | 基础摆摊 |
| 21-40 | 小有名气 | 可参与低级拍卖会、可租用仓库 |
| 41-60 | 一方商贾 | 可参与中级拍卖会、可雇用初级商队 |
| 61-80 | 商道名家 | 可参与高级拍卖会、部分宗门开放合作 |
| 81-90 | 富甲一方 | 可主办拍卖会、传送阵使用权 |
| 91-100 | 商道大能 | 天道商会主动合作、商路报价最低折扣 |

### 商道值变化表

| 行为 | 商道变化 | 说明 |
|------|---------|------|
| 完成一笔小交易（<100灵石） | +0 | 这种小单不算数 |
| 完成一笔中等交易（100-1000灵石） | +1 | 正经做了一单生意 |
| 完成一笔大额交易（>1000灵石） | +2 | 有分量的交易 |
| 预约订单按时交货 | +1 | 守信经营 |
| 预约订单提前交货 | +2 | 让顾客惊喜 |
| 预约订单延期 | -1~3 | 视延期程度 |
| 预约订单失约 | -5 | 严重失信 |
| 大额交易成交（单笔利润超5000灵石） | +3 | 真正的大单 |
| 参加拍卖会 | +1 | 参与正规市场活动 |
| 成功举办小型拍卖会 | +5 | 组织力证明 |
| 成功举办大型拍卖会 | +10 | 影响力证明 |
| 在暗市交易（戴面具） | -1~3 | 视交易额 |
| 在暗市交易（不戴面具） | -3~8 | 更严重 |
| 发布暗杀令 | -15 | 大幅下降 |
| 被查出暗市交易 | -10 | 正道宗门知道了 |

| 与正道宗门达成长期合作 | +5 | 正面背书 |
| 商路货物被劫 | -1 | 损失货值和面子 |

> 商道值**每日自然衰减**（除非持续经营）：长期不交易，每天-1。

### 商道值的影响

| 商道值区间 | NPC对你的称呼 | 市场反馈 |
|-----------|-------------|---------|
| 0-20 | "那个新来的" | 爱理不理、压价凶 |
| 21-40 | "宁家小子" | 正常交易 |
| 41-60 | "宁老板" | 主动议价空间更大 |
| 61-80 | "宁掌柜" | 宗门采购愿意谈长期单 |
| 81-90 | "宁会长" | 市场参考价对你更透明 |
| 91-100 | "宁大先生" | 走到哪都有人打招呼 |

## 三、天道（熔炼之道）

> 天道不是靠次数堆出来的——那叫熟练工，不叫天道感悟。真正的突破来自**关键节点的质变**，而不是日常操作的累加。

### 天道层级的重新设计

| 天道值范围 | 称号 | 主要解锁 |
|-----------|------|---------|
| 0-10 | 门外汉 | 只能2件熔炼，无任何提示 |
| 11-25 | 初窥门径 | 可以3件熔炼，极偶尔出现模糊感知 |
| 26-45 | 略通一二 | 可以4件熔炼，偶尔出现五行相性模糊提示 |
| 46-65 | 熔炼行家 | 固定获得五行相性提示（不模糊了） |
| 66-80 | 融会贯通 | 可以5件熔炼，小概率看到"可能的异变方向" |
| 81-92 | 天道感应 | 升品概率大幅提升，解锁"天道回响"（极低概率事件） |
| 93-100 | 炉火纯青 | 全部融会贯通，每次熔炼有极低概率触发额外感悟 |

### 天道增长机制——不是靠次数，是靠"感悟"

**基础规则**：普通熔炼（无论结果）不再直接加天道值。

天道值的增长来源改为：

| 获取方式 | 天道增长 | 说明 |
|---------|---------|------|
| **首次升品成功** | +8 | 第一次体会到"原来可以这样" |
| **首次异变** | +5 | 打开了新的认知 |
| **首次发现相生组合** | +3 | 系统记录你第一次发现"火+木→相生" |
| **发现新的相生/相克组合** | +1~2 | 每次发现新组合（不重复） |
| **触发"天道回响"** | +10 | 极低概率的大事件 |
| **阅读熔炼古籍/传承** | +3~8 | 剧情事件/奇遇 |
| **完成熔炼相关剧情任务** | +5~15 | 一次性事件 |
| **连续熔炼10次无任何质变** | +1 | 唯一的"保底"机制——说明你一直在坚持 |

**不增长的情况**：
- 重复熔炼相同组合 → 不加天道（你已经知道这个组合了）
- 熔炼失败/报废 → 不加天道（失败本身不是感悟）
- 日常批量熔炼 → 不加天道（流水线操作不会让人悟道）

### 熔炼基础概率表

| 投入件数 | 升品概率 | 异变概率 | 原样概率 | 降品概率 | 报废概率 |
|---------|---------|---------|---------|---------|---------|
| 2件 | 1% | 5% | 40% | 44% | 10% |
| 3件 | 3% | 10% | 35% | 37% | 15% |
| 4件 | 5% | 15% | 25% | 30% | 25% |
| 5件 | 8% | 20% | 20% | 22% | 30% |

> 投入越多，升品和异变的概率越高，但降品和报废的风险也越大——这就是玩家的核心抉择。

### 天道值对概率的修正

天道值不直接加概率百分比，而是提供"偏移修正"：

| 天道值区间 | 升品偏移 | 报废偏移 | 解锁效果 |
|-----------|---------|---------|---------|
| 0-10 | 0% | 0% | 无 |
| 11-25 | +0.5% | -1% | 偶尔出现模糊感知（"这两件……似乎有点联系？"） |
| 26-45 | +1% | -2% | 熔炼前看到五行相性模糊提示（"火+？——感觉不太对劲"） |
| 46-65 | +2% | -3% | 固定看到五行相性提示（"火+水——相克，风险极大"） |
| 66-80 | +3% | -4% | 小概率看到"可能的异变方向"（"如果成了，可能出防御类的"） |
| 81-92 | +4% | -5% | 解锁"天道回响"——熔炼时有极低概率触发额外产出的幻象指引 |
| 93-100 | +5% | -6% | 每次熔炼极低概率获得额外感悟（可转化为天道经验） |

### 五行相性系统

天道熔炼的核心策略——不是随便丢几件进去赌，而是**选择合适的组合**。

| 组合关系 | 效果 | 举例 |
|---------|------|------|
| **相生（2件）** | 升品概率×1.5，异变概率×1.2 | 木+火→木生火 |
| **相生（3件以上）** | 升品概率×2，异变概率×1.5 | 木+火+土→木生火，火生土 |
| **相克** | 降品概率×1.5，报废概率×1.5 | 水+火→水火不容 |
| **中立** | 无修正 | 金+木→金克木但木耗金，互相抵消 |
| **五行齐全（5件各一）** | 特殊规则：必出异变，但异变方向完全随机 | 五件五行各一的灵材投入→必然发生点什么，但不知道是什么 |
| **任意五件（不限品阶/不限五行）** | 极低概率直升仙品（约0.1%），其他情况按对应规则结算 | 乱丢五件进去，赌一个传说——但大概率还是按各自的五行相性各自计算 |

### 关于"相同品阶"的修正

> 天道熔炼的核心前提是**同品阶物品才能熔炼**——这是底层规则，不是额外加成。

但这里有一个更微妙的设计：**品阶越接近，熔炼结果越稳定**。

| 投入物品的品阶一致度 | 效果 |
|--------------------|------|
| 全部同一品阶（标准情况） | 按基础概率表正常结算 |
| 混入低一品阶物品 | 升品概率×0.8，降品概率×1.2（"杂质拖累了整体品质"） |
| 混入高一品阶物品 | 升品概率×1.2，但报废概率×1.3（"高品阶灵材不稳定，可能引发冲突"） |
| 混入跨两阶物品 | 极高概率降品或报废（"这根本不是一个层次的东西"） |

五行的生克关系：

```
木 → 火 → 土 → 金 → 水 → 木（循环相生）
木 ← 火 ← 土 ← 金 ← 水 ← 木（隔位相克）
```

### 熔炼的门槛机制

为了进一步控制节奏，增加以下设计：

1. **熔炼没有"批量模式"**：每次熔炼需要玩家亲自操作，不能一键熔100次
2. **单日熔炼次数限制**：每天最多熔炼5次（游戏内时间）。超过后熔炼界面提示"今日心神已疲，不宜再炼"
3. **同组合递减**：连续熔炼相同五行组合时，从第3次开始升品概率逐次降低（叠加递减），换组合后重置
4. **高品阶解锁**：灵品及以上品阶的熔炼，需要达到一定的天道值才能尝试

| 可熔炼品阶 | 需要天道值 |
|-----------|----------|
| 凡品 | 0（开局可用） |
| 灵品 | 10 |
| 宝品 | 30 |
| 仙品 | 60（同时需要特殊触发条件） |

### 天道值的衰减

天道值**不会自然衰减**——你一旦获得了感悟就永远记住了。但如果**连续10个游戏日不碰熔炼**，会触发一次"手生"判定：天道值临时下降5%，熔炼一次后恢复。这不是永久损失，只是说明需要热手。

### 综合节奏预估

假设玩家平均每2个游戏日熔炼一次，合理操作（逐渐发现相生组合、偶尔触发质变）：

| 里程碑 | 预估游戏天数 | 说明 |
|--------|------------|------|
| 从0到10（首次升品） | 5-10天 | 看运气，有些人第一天就升品了 |
| 从10到25 | 10-20天 | 需要积累几个相生组合 |
| 从25到45 | 20-30天 | 开始稳定输出，偶尔出好东西 |
| 从45到65 | 30-50天 | 开始能感知相性了，熔炼效率提高 |
| 从65到80 | 50-80天 | 瓶颈期，需要靠事件突破 |
| 从80到92 | 80-120天 | 大瓶颈，需要触发"天道回响"这类大事件 |
| 从92到100 | 看缘 | 全游戏可能只有几个人能达到的层次 |

> 最终结论：一个正常玩的玩家，**100个游戏日左右能达到天道值60-70**，到顶（90+）需要**机缘 + 时间 + 持续探索**。

## 四、人心（处世之道）

### 人心层级

| 人心值范围 | 称号 | 效果 |
|-----------|------|------|
| 0-20 | 生面孔 | NPC态度中立 |
| 21-40 | 脸熟 | NPC愿意多聊两句 |
| 41-60 | 靠得住 | NPC愿意赊账、分享信息 |
| 61-80 | 值得信赖 | NPC主动提供帮助、关键信息 |
| 81-90 | 以命相交 | 关键时刻有人替你出头 |
| 91-100 | 人心所向 | 一呼百应、危机时有贵人相助 |

### 人心值变化表

| 行为 | 人心变化 | 说明 |
|------|---------|------|
| 主动帮助NPC | +5~15 | 视难度而定 |
| 善待弱者/给优惠 | +3~8 | 老顾客长期积累 |
| 在议价中让利 | +2~5 | 让对方感受到诚意 |
| 诚信经营 | +1~3（累积） | 不是一次性的 |
| 完成委托任务 | +5~10 | 对特定NPC |
| 在暗市交易被发现 | -5~15 | 正道势力寒心 |
| 拒绝求助 | -3~10 | 视对方身份 |
| 欺诈顾客 | -10~20 | 被发现的话 |
| 在拍卖会上与人为善 | +3 | 礼让/不恶意竞价 |
| 专横霸道 | -5~15 | 累积行为 |

### 人心的独特机制

人心不像商道那样有"市场影响"，它影响的是**关键时刻**：

- **低人心**：遇到麻烦没人帮忙，商路被劫没人通风报信，宗门冲突没人调解
- **高人心**：危机时有贵人相助、重要信息会有人主动告诉你、暗市被查可能有人帮你打掩护

人心值在**游戏前期积累缓慢**，但在中后期可能成为救命稻草。

## 五、三道交汇：势力好感度

除了三个隐性维度，还有**势力好感度**系统——这是显性的，玩家可以直接看到。

### 好感度层级

| 好感度 | 效果 |
|--------|------|
| 敌对（-50以下） | 拒绝交易，升级为冲突 |
| 冷淡（-20~-1） | 交易价格上浮20%，不提供任何帮助 |
| 中立（0-20） | 基础交易，无加成 |
| 友好（21-50） | 交易价格下浮10%，开放普通合作 |
| 信任（51-80） | 交易价格下浮20%，开放专属商路/独家货源 |
| 同盟（81-100） | 交易价格下浮30%，共享情报，危机时出兵相助 |

### 好感度变化因素

| 行为 | 对所有正道宗门 | 对特定宗门 |
|------|--------------|-----------|
| 商道值高 | +（缓慢积累） | — |
| 主动提供帮助 | — | +10~20 |
| 完成宗门委托 | — | +15~30 |
| 在暗市交易（被发现） | -10~20 | -5~15 |
| 发布/接暗杀令（被发现） | -30 | -20~40 |
| 举办拍卖会邀请宗门 | — | +10 |
| 拒绝宗门合作请求 | — | -10~20 |

### 势力列表及其立场

| 势力 | 立场 | 特别在意 |
|------|------|---------|
| 五大正道宗门 | 正道 | 商道值、暗市行为 |
| 天道商会 | 中立偏正 | 商道值、交易额 |
| 万宝楼 | 绝对中立 | 只看灵石 |
| 散修联盟 | 中立 | 人心值 |
| 暗市势力 | 暗面 | 暗市交易额、反正道行为 |
| 暗杀公会 | 暗面 | 暗杀令发布数量 |

> 对暗市势力和暗杀公会来说，"好感度"的逻辑是反的——你在暗市交易越多、发布暗杀令越多，他们越喜欢你。但正道宗门就会越讨厌你。

## 六、三道交汇的影响总结

| 数值\\影响 | 交易价格 | 市场准入 | NPC态度 | 特殊事件 | 结局分支 |
|-----------|---------|---------|---------|---------|---------|
| **商道（高）** | 更好 | 更开放 | 尊重 | 商会合作 | 商道结局 |
| **商道（低）** | 更差 | 受限 | 轻视 | 暗市青睐 | 堕落结局 |
| **天道（高）** | 无直接影响 | 无 | 敬畏（传闻） | 熔炼奇遇 | 天道结局 |
| **天道（低）** | 无直接影响 | 无 | 无 | 无 | 平庸结局 |
| **人心（高）** | 老顾客优惠 | 无 | 亲近 | 贵人相助 | 人心结局 |
| **人心（低）** | 无 | 无 | 疏远 | 无人相助 | 孤独结局 |

> **结局不是由单一维度决定的，而是三道的综合走向**。一个商道高+天道高+人心高的人，和一个人心高但商道低的人，走的是完全不同的路。

## 七、次级资源回流表

> 好感度、声望、商路这些次级资源**不是独立的进度条**——每个次级资源的增长都应该有明确的、可量化的回流到核心资源（灵材/灵石）的路径。以下表格定义每条回流路径。

### 7.1 好感度→灵材获取效率

| 好感等级 | 解锁效果 | 回流到核心资源的方式 |
|---------|---------|-------------------|
| 中立 | 基础交易，无加成 | — |
| 友好 | 交易价格-10%；开放**非垄断灵材**的采购权 | 买更便宜→灵材成本↓→利润空间↑ |
| 信任 | 交易价格-20%；开放**专属灵材**采购权；NPC主动提供"近期好货"情报 | 独家货源→差异化灵材→议价优势↑；情报→低价买入被低估的灵材 |
| 同盟 | 交易价格-30%；NPC偶尔赠送灵材（每月1-2件随机灵品）；危机时NPC**优先调货**给玩家 | 免费灵材→零成本核心资源；优先调货→灵材短缺期不受影响 |

### 7.2 声望层级→商道感知力

| 声望等级 | 称号 | 解锁效果 | 回流到核心资源的方式 |
|---------|------|---------|-------------------|
| 0-20 | 无名小贩 | 基础交易 | — |
| 21-40 | 小有名气 | 能看到市场参考价±10%内波动 | 更精准的定价→灵材利润↑ |
| 41-60 | 一方商贾 | 能看到±20%波动；进货时小概率自动触发"品阶鉴微"判定 | 自动捡漏→低价获取高价值灵材 |
| 61-80 | 商道名家 | 能看到±30%波动；进货时中等概率自动触发判定 | 稳定捡漏→灵材获取成本↓ |
| 81-90 | 富甲一方 | 能看到全线价格；高概率自动触发判定 | 近乎完美的灵材价值判断 |
| 91-100 | 商道大能 | 能看到隐形成本（运输损耗、存贮风险等） | 全成本透明的经营决策 |

### 7.3 人心→情报网络

| 人心等级 | 解锁效果 | 回流到核心资源的方式 |
|---------|---------|-------------------|
| 0-20 | 生面孔 | NPC不会主动提供任何额外信息 | — |
| 21-40 | 脸熟 | NPC愿意多聊两句——偶尔透露某个灵材的产地消息 | 获得灵材产地线索→降低采购搜寻成本 |
| 41-60 | 靠得住 | NPC愿意赊账；**暗市情报**（哪批好货要到了） | 赊账→灵石周转效率↑；情报→优先采购稀缺灵材 |
| 61-80 | 值得信赖 | NPC主动提供**关键情报**（商路安全变化、宗门采购动向） | 预警信息→避免灵材损失；动向信息→提前囤货 |
| 81-90 | 以命相交 | NPC在玩家遇到困难时主动**调货/借钱/担保** | 危机时的灵材/灵石保底——次级回流的"最后防线" |
| 91-100 | 人心所向 | NPC上下游都愿意给玩家**最优先的供货权和最低价** | 全供应链优化→灵材成本最低，利润最高 |

### 7.4 回流效率公式

> 每个次级资源的"回流效率"不是简单的加法——它是**阶梯式的**。只有达到特定阈值才会解锁下一级的回流效果。

**好感度回流效率（举例）**：
```
中立（0-20） → 0%灵材成本优化
友好（21-50） → 10%灵材成本优化
信任（51-80） → 20%灵材成本优化 + 2条/月情报线索
同盟（81-100） → 30%灵材成本优化 + 4条/月情报线索 + 1件/月免费灵品
```

**商道回流效率**：
```
商道<15  → 偶尔捡漏（±10%精度）→ 等效灵材成本-2%
商道15-35 → 稳定捡漏（±20%精度）→ 等效灵材成本-8%
商道35-55 → 精通级（±30%精度）→ 等效灵材成本-15%
商道55+   → 大师级（±50%精度）→ 等效灵材成本-25%
```

> **设计原则**：不要把回流做成"XX点好感度→YY%折扣"这种纯数值。回流应该以**解锁行为/能力**的方式呈现，让玩家清楚地感知到"因为我和这个人关系好，所以我拿到了别人拿不到的货"。
