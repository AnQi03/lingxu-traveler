# 体验优化方案二：移动速度、初期玩法、库存管理

---

## 一、移动速度优化

### 现状
玩家从摊位走到集市需要几秒，来回多次后会产生倦怠感。

### 修改方案

**方案：场景内轻快步 + 场景间快速旅行**

1. **场景内增加"快走"模式**
   - 按Shift或右键点击远处位置——宁秩小跑过去，速度约1.8倍
   - 不消耗任何资源——纯节奏优化，不是功能解锁
   - 仅限于已经探索过的场景（第一次到达某个场景时自动以常速行走，让玩家看到环境细节）

2. **场景间增加"快速标记"**
   - 玩家去过一次的地方，在地图上标记为"已探索"
   - 再次前往时，直接在场景切换界面选择目标地点，跳过走路动画
   - 弹出黑屏过渡文字："沿着熟悉的路，你很快到达了xx。"
   - 这个功能不消耗灵石、不需要解锁——只要你去过一次，第二次就可以"快行"

3. **常去地点优先排列**
   - 玩家的摊位、最近的仓库、常去的集市——在切换列表中排在前面
   - UI记住最近访问的3个地点

**效果**：第一次去新地方走一遍看风景，第二次开始直接快行。解决中后期来回跑的疲劳感。

### 代步工具

随着游戏进展，玩家可以解锁不同的代步工具，进一步提升跑图效率：

| 代步工具 | 解锁条件 | 费用 | 效果 |
|---------|---------|------|------|
| 快步走 | 开局可用 | 免费 | 场景内移动速度×1.8（按Shift），相当于小跑 |
| 老马一匹 | 商道≥15 或 累计利润≥1000灵石 | 一次性购买500灵石 | 场景内移动速度×3。NPC会多看玩家一眼——"有马了？混得不错啊。" |
| 行商步辇 | 商道≥40 且 拥有至少2个板块进货渠道 | 一次性购买3000灵石 | 场景内移动速度×5。解锁"乘车"按钮——点击后画面显示宁秩坐在步辇上翻看账本的过场 |
| 小型传送令牌 | 与天道商会关系≥友好 或 参加过至少3次拍卖会 | 一次性购买8000灵石 | 在已激活传送阵的城市之间瞬间传送。激活传送阵需要首次亲自到达 |

**设计意图**：
- 代步工具不光是速度提升——它们也是玩家成长的标志
- 老马→步辇→传送令牌，每一次升级都让玩家感受到"我真的变有钱了"
- 传送令牌后期大幅减少重复跑路时间

## 二、初期灵石获取途径优化

### 现状
前两周只有"进货→摆摊→卖货"一条收入线，略显单调。

### 修改方案

**增加三种低门槛的初期收入方式，不依赖修为、不依赖本金、不影响核心经营循环：**

**1. 帮NPC跑腿（第2天解锁）**

老赵偶尔会顺口问一句："我要去城东取个东西，懒得跑一趟——你帮我带过来，给你10灵石跑腿费。"

| 项目 | 内容 |
|------|------|
| 触发方式 | 老赵/其他熟客对话中自然出现，非强制任务 |
| 耗时 | 不需要额外操作，下次切换场景时自动完成 |
| 收益 | 10-30灵石 |
| 额外效果 | 小幅提升与委托NPC的好感度 |
| 限制 | 每天最多触发1次，不影响正常经营 |

**设计意图**：不是"支线任务系统"——就是一个NPC顺口说的一句话，你点了就做了。给玩家"顺便赚点外快"的感觉，而不是"我得去做另一个任务"。

**2. 废品回收（第1天解锁）**

中央荒原集市角落有一个收购旧货的NPC——刘老头。他收所有玩家用不上的东西。

- 路边捡到的破损法器碎片→5灵石
- 卖不出去的凡品灵材（快过期的那种）→3-5灵石
- 随从外出时偶尔带回的"不值钱的小玩意儿"→10-20灵石

| 项目 | 内容 |
|------|------|
| 触发方式 | 集市角落有一个NPC，始终存在，不需要触发事件 |
| 用途 | 玩家清库存的出口——不用等顾客来买那些卖不掉的货 |
| 价格 | 市场价的20-30%（远低于正常售价，但总比烂在手里强） |
| 设计意图 | 给玩家一个"止损"的选项。仓库里的烂货有人收，就不用看着它们过期货架 |

**3. 情报倒卖（第3天左右解锁，与暗市挂钩）**

玩家去过暗市后，有时会听到一些"坊间传闻"——比如"最近有人在大量收购赤炎草"。

玩家可以把这条信息转卖给集市上的其他商人：

| 项目 | 内容 |
|------|------|
| 触发方式 | 从暗市的旧货摊/窃窃私语的NPC那里听到信息后 |
| 收益 | 每条信息30-80灵石，视价值而定 |
| 限制 | 每条信息只能卖一次；信息来源需要玩家自己去发现 |
| 设计意图 | 让暗市"穷人专柜"的信息类商品有明确的变现路径——你买了旧地图可以用，买了坊间情报也可以转卖 |

## 三、库存管理优化

### 现状
手动一个个拖放归类，前期东西少还好，中期货多起来会累。

### 修改方案

**1. 一键自动归类（从第一天就可用）**

仓库界面右下角有一个"整理"按钮，点击后自动执行：

- 按品阶排序（凡→灵→宝→仙）
- 同品阶内按五行排序（木→火→土→金→水）
- 即将过期的灵材自动排在最前面（红色标记）
- 同类型的可堆叠物品自动合并

> 不需要拖拽、不需要手动分类。点一下就好。

**2. 智能堆叠**

| 类型 | 堆叠上限 | 说明 |
|------|---------|------|
| 凡品灵草 | 99 | 最基础的，量大 |
| 灵品灵材 | 50 | 中档货，堆叠上限适中 |
| 宝品灵材 | 10 | 高价值，堆叠上限低 |
| 仙品灵材 | 1 | 传说级，不堆叠 |
| 成品丹药 | 30 | — |
| 矿石 | 99 | — |
| 异变产物 | 5 | 不稳定，不能大量堆叠 |

**视觉反馈**：堆叠的物品在图标右上角显示数量（小号数字），接近保质期时数字变为黄色，过期变红色。

**3. 快速搜索/筛选**

仓库界面提供三个维度的筛选下拉菜单：

| 维度 | 选项 |
|------|------|
| 品阶 | 全部 / 凡品 / 灵品 / 宝品 / 仙品 |
| 品类 | 全部 / 灵草 / 矿石 / 灵兽材料 / 灵木 / 水类 / 成品 / 异变 |
| 状态 | 全部 / 正常 / 即将过期（7天内）/ 已过期 |

玩家也可以直接输入名称搜索（文本输入框）。

> 即使不用筛选，默认按"即将过期优先"排列，玩家扫一眼就知道哪些货要先处理。

**4. 库存数量预警**

管家会在以下情况主动发玉简消息：

- 某类灵材库存超过50件："少爷，您的赤炎草堆得有点多了——再不出手怕要烂在库里"
- 某类灵材库存为0且近期有顾客问过："少爷，这几天有好几个人来问寒露草，要不要进一批？"
- 某件高价值物品即将过期："少爷，您那块灵木心再放三天就过期了——要赶紧出手吗？"

> 管家不只是"你知道的这个消息功能"，他还是玩家库存管理的隐性助手。不需要玩家自己去检查每个数字。
