# 游戏体量分层

> 所有内容分为三层：MVP（最小可玩产品）→ 正式版 → 拓展内容。做不完的往后挪，但有完整路径规划。

---

## 一、分层原则

| 层级 | 目标 | 玩家体验时长 | 对应设定文档覆盖范围 |
|------|------|------------|-------------------|
| **MVP** | 验证核心玩法是否有趣，让玩家愿意玩超过1小时 | 约1-2小时（游戏内约1-2周） | 经营框架 + 新手引导 + 第一次熔炼 |
| **正式版** | 完整的一周目体验，包含主线剧情和全系统循环 | 约60-80小时（游戏内约2年） | 全部30份设定文档的核心内容 |
| **拓展内容** | 二周目新体验、隐藏结局、深挖世界观 | 约20-40小时额外内容 | 灵墟归途路线、大型事件深化、DLC候选 |

---

## 二、MVP 最小可玩产品

> MVP的目标不是"展示完整游戏"，是"让玩家在1小时内经历一个完整的经营小循环，并愿意继续玩下去"。

### 包含的系统

| 系统 | MVP版本 | 说明 |
|------|---------|------|
| **摆摊经营** | ✅ 完整版 | 进货→摆摊→议价→交易的核心循环必须完整，不能砍 |
| **NPC系统** | ✅ 基础版 | 老赵作为唯一固定NPC，加2-3个随机生成的散修顾客。NPC有简单的性格差异（爽直/精明/急躁） |
| **管家系统** | ✅ 基础版 | 玉简激活、管家基础消息（月度简报不包含）、管家引导建议 |
| **时间与过夜** | ✅ 完整版 | 白天经营→傍晚收摊→过夜结算的完整循环 |
| **天道熔炼** | ✅ 核心版 | 第一次天道熔炼事件（产出玉简）。后续普通熔炼可用但无五行相性提示 |
| **暗市** | ⚠️ 精简版 | 第一次进入暗市的事件完整保留。暗市只开放旧货摊+一个普通摊位 |
| **商会等级** | ❌ 跳过 | 只需要"小摊→铺面"两个阶段，不涉及等级系统 |
| **随从系统** | ❌ 跳过 | MVP不需要随从 |
| **商路系统** | ❌ 跳过 | MVP不需要跨域贸易 |
| **拍卖会** | ❌ 跳过 | MVP不需要拍卖会 |
| **宗门关系** | ❌ 跳过 | MVP不需要宗门 |
| **大型事件** | ❌ 跳过 | MVP不触发任何大事件 |
| **湮灭线索** | ❌ 跳过 | MVP不涉及主线秘密 |

### MVP的剧情线

```
第1天：开场→进货→摆摊→第一笔交易→搭熔炉→过夜
第2天：老赵再次出现→第二笔交易→自由经营
第3-5天：积累灵石→触发暗市掮客→进入暗市→购买旧货
第5-7天：收集3件灵材→第一次熔炼→玉简激活→管家出现→管家第一条建议
第7-14天：自由经营→赚到100灵石→管家认可→租铺面→"从小摊到铺面"
```

**MVP终点**：玩家租下第一个铺面。此时玩家大约玩了1-1.5小时，经历了"亏→赚→积累→质变"的完整曲线。

### MVP不包含但需要预留接口的内容

以下内容在MVP中不实现，但数据结构需要预留，避免正式版开发时返工：

- 随从的数据结构（名字、属性、忠诚度、任务状态）
- 商路的数据结构（出发地、目的地、在途货物、预计到达时间）
- 宗门好感度的数据结构（宗门名称、好感度数值、已触发事件列表）
- 大型事件的触发状态标记
- 湮灭线索的收集状态
- 二周目标记

## 三、正式版（完整一周目）

> 正式版包含30份设定文档的全部核心内容。玩家可以在60-80小时内完成一周目，体验完整的经营循环和主线剧情。

### 正式版新增内容

| 类别 | 新增内容 | 对应设定文档 |
|------|---------|------------|
| **经营扩张** | 商会9级体系、分店系统、商会联盟、令牌系统 | 商会系统.md |
| **商路系统** | 五大板块商路路线、运费模型、风险对冲、运输保险 | 商路系统设定.md |
| **拍卖会** | 参与拍卖会、主办拍卖会、竞拍系统 | 拍卖会系统草案.md |
| **暗市深化** | 守夜人系统、黑门线索、暗市风暴事件 | 暗市系统设定.md |
| **随从系统** | 招募、培养、忠诚度、派驻分店 | 随从雇员系统.md |
| **宗门关系** | 五大宗门好感度体系、宗门合作、初代秘密 | 五大宗门人物志.md |
| **管家深化** | 百科全书、预警系统、商途日志 | 管家系统草案.md |
| **大型事件** | 世界树之殇、天机子隐退、宁家之难、五方盟重聚等 | 剧情框架与多结局.md |
| **五域引路人** | 六大引路人的专属剧情 | 五域引路人.md |
| **经济系统** | 灵潮周期、灵材保质期、动态物价、货币兑换 | 多个文档 |
| **交互系统** | 完整的议价UI、熔炼交互、拍卖会场景、暗市场景 | 交互系统设计.md |

### 正式版的主线流程

```
第一章（第1-3个月，现实≈15小时）：荒野求生
  - 7个事件（开幕→第一笔交易→预约→暗市→熔炼→月底结算）
  - 核心体验：学会怎么玩

第二章（第3-9个月，现实≈30小时）：站稳脚跟
  - 8个事件（老顾客→随从→拍卖会→宁家来人→灵力暴动→宗门接触→暗市代价→新板块）
  - 核心体验：开始接触到世界的深度

第三章（第9-18个月，现实≈40小时）：风口浪尖
  - 8个大型事件（世界树之殇、商会竞争、天机子隐退、宁家之难、暗市风暴等）
  - 核心体验：你的选择开始影响世界

终章（第18-24个月，现实≈10小时）：结局
  - 根据三条暗线的走向触发对应结局（8种主线结局）
```

### 正式版不包含的内容

- 天裂遗迹探险（留作拓展）
- 灵墟之外的世界（留作拓展）
- 商会战争深度扩展（留作拓展）
- 引路人专属剧情包（留作拓展或免费更新）

## 四、拓展内容

> 以下内容不在正式版的发布范围内。可以在正式版发售后以免费更新或DLC的形式逐步推出。

### 高优先拓展（建议免费更新）

| 内容 | 体量 | 说明 |
|------|------|------|
| **引路人剧情包** | 6个小型剧情任务，每个约30分钟 | 老赵、冰崖、赤炼、云叶、金锋、海瑶各自的专属剧情线。这些角色的背景故事已经写好了（五域引路人.md），只需要开发任务系统就可以直接使用 |
| **第二次灵气暴动** | 一个大型事件 | 世界树之殇结束后，另一个板块可能出现类似的灵气异常。玩家可以选择调查或无视。这个事件可以作为"天裂遗迹"DLC的前置剧情 |
| **商会等级上限突破** | 新增2个商会等级 | 正式版商会最高9级，拓展版可以增加到11级（"灵墟传说"和"跨域霸主"），在正式版发售后持续更新的内容 |

### 中优先拓展（付费DLC候选）

| 内容 | 体量 | 定价参考 | 说明 |
|------|------|---------|------|
| **天裂遗迹探险** | 中等，约5-8小时新内容 | 30-40元 | 新增探险玩法。玩家组建探险队，进入天裂遗迹收集域外材料。新地图、新材料、新NPC、新事件链。与本体经营玩法互补——探险获得的高价值材料可以在本体经营中出售或熔炼 |
| **商会战争** | 大型，约10-15小时新内容 | 50-60元 | 本体商会竞争事件的深化版。玩家商道达到巅峰后，可以选择与天道商会全面对抗、或与暗市势力结盟、或建立自己的商业联盟。新增商会外交系统、价格战争系统、商会间谍系统 |

### 低优先拓展（2C或3C更新）

| 内容 | 体量 | 说明 |
|------|------|------|
| **灵墟之外** | 剧情扩展 | 灵墟归途结局的后续——光柱送出去之后发生了什么？这个DLC讲述灵墟之外另一个世界的故事，但需要玩家先完成灵墟归途路线才能解锁，受众面较小 |
| **新游戏+ 增强** | 系统更新 | 增加更多二周目继承内容、二周目专属事件、二周目难度调整选项 |

## 五、开发顺序建议

```
第一阶段：MVP（3-4个月开发）
  ├── 核心经营循环（进货/摆摊/议价/交易）
  ├── 新手引导流程（第1-7天）
  ├── 第一次天道熔炼事件
  ├── 管家系统（基础版）
  ├── 暗市（精简版）
  └── 铺面升级

第二阶段：正式版基础（6-8个月开发）
  ├── 商路系统
  ├── 拍卖会系统
  ├── 随从系统
  ├── 宗门关系系统
  ├── 暗市深化
  ├── 商会等级体系
  └── 五大板块地图

第三阶段：正式版剧情（4-6个月开发）
  ├── 23个剧情事件实现
  ├── 五域引路人剧情
  ├── 8种主线结局
  ├── 灵潮周期系统
  ├── 经济系统完整版
  └── 二周目系统

第四阶段：上线后更新
  ├── 免费更新：引路人剧情包
  ├── DLC1：天裂遗迹探险
  ├── DLC2：商会战争
  └── 长期维护与优化
```
