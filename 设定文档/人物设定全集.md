# 一、主角团

## 01 · 宁秩

> 灵墟是一个看修为的世界。
> 他什么都没有——除了一个没人理解的杂灵根，和一种他自己都说不清的"感觉"。

| 项目 | 内容 |
|------|------|
| **全名** | 宁秩 |
| **年龄** | 十八岁（游戏开始时） |
| **修为** | 无——灵根驳杂（五行杂灵根），修炼无望 |
| **外貌** | 身形偏瘦，面容清秀但带着一丝常年熬夜的疲惫。手掌有老茧——不是在修炼中磨出来的，是在算盘和灵材上磨出来的。衣着朴素，看不出是一个商人家族的子弟 |
| **性格** | 表面平静，内里倔强。他不是一个容易激动的人——但他决定了的事，不会回头。他离开宁家时没有哭、没有回头——只是背着一个小包袱走出了山谷。他有商人的精打细算，但没有商人的世故圆滑。他有凡人的自知之明，但又不甘心一辈子做个普通人 |
| **核心能力** | **天道熔炼**：杂灵根让他能感知灵材之间的五行共鸣——别人做不到。<br>**品阶鉴微**：杂灵根让他对各种灵材的品阶判断比普通人敏锐得多。<br>**五感同频**：他是灵墟唯一一个能同时感知五块碎片频率的人——虽然他自己一开始不知道这个能力意味着什么 |
| **核心缺陷** | 零修为——不能战斗、不能修炼、不能使用大多数法器。在灵墟这个武力至上的世界里，他就是一条在鲨鱼池里游泳的鱼 |
| **和老管家的关系** | 宁秩对老管家的信任是无条件的。老管家是他在宁家唯一感到温暖的人，也是唯一一个支持他离开的人。他不确定老管家是不是真的只是一个"老奴"，但他知道——如果全世界都背叛了他，老管家不会 |
| **和父亲的关系** | 复杂。宁秩恨过父亲——不是因为父亲对他不好，而是因为父亲对他"太好了"——好到他觉得自己是个废人。离家出走后他才慢慢明白，父亲不是不爱他，是不会爱他 |
| **角色定位** | 玩家化身——玩家通过宁秩的眼睛看灵墟、用宁秩的手讨价还价、借宁秩的杂灵根感知世界 |

### 宁秩知道的事（游戏开始时）

- 灵墟五大板块的基本地理
- 基础灵材的名称和大致用途（但不精）
- 宁家商会的运作模式（从小耳濡目染）
- 自己修炼无望（被无数人告诉过）

### 宁秩不知道的事（游戏开始时）

- 天道熔炼为什么会发生
- 为什么只有他能做这件事
- 灵墟的真实历史（天裂之战以前的事几乎一片空白）
- 父亲的铁盒子里有什么
- 老管家到底是谁

## 02 · 老管家

> 他叫宁秩"少爷"。但他做的事，比一个仆人多得多。

| 项目 | 内容 |
|------|------|
| **称呼** | 老管家（宁秩叫他"管家"或"您"——他从来没有叫过他的名字，甚至不知道自己该不该知道管家的全名） |
| **年龄** | 六十余岁 |
| **修为** | 练气后期——他年轻时修炼过，但天赋平庸，修为常年停滞 |
| **外貌** | 中等身材，微微佝偻。常年穿深灰色的布袍，袖口总是挽起来——因为他习惯一边干活一边和宁秩说话。面容平凡到让人转身就忘——这也许是他最大的优势 |
| **性格** | 温和、周到、话不多但每一句都有分量。他是那种"你永远不会注意到他在做什么，但你需要的时候他永远在"的人。他有极高的情商——知道什么该说、什么不该说、什么时候该说、什么时候不该说 |
| **在宁家的位置** | 明面上是宁家的老仆，负责后院杂务。但实际上他在宁家已经干了四十年，从宁秩的祖父那一代就开始侍奉。他知道宁家所有人的秘密——包括宁远山的铁盒子、宁秩的母亲离家出走的真相、还有那条玄冰域商路特许权背后的交易 |
| **为什么对宁秩这么好** | 老管家从未解释过。他只是说："少爷是个好孩子。"——但宁秩隐约觉得，管家对他的好不只是因为"他是个好孩子"。老管家似乎知道一些关于宁秩的事，比他告诉宁秩的多得多 |
| **和宁秩的通信方式** | 通过那枚宁秩熔出的宝品玉简。玉简不需要灵力——它通过触碰记忆来工作。老管家手上的普通玉简在被宁秩的玉简"唤醒"后，变成了一个不需要灵力就能使用的传讯器。老管家把这个现象归结为"少爷做的东西不一般"——但他心里知道，事情没有这么简单 |
| **角色定位** | 远程导师、情感锚点、帮助系统。老管家是玩家在游戏中问问题的地方——不是"怎么操作"，而是"我该怎么做" |

### 老管家知道的事（但不会主动说）

- 灵墟的一些老传言（他年轻时侍奉过的那位游方修士说的那些话——"灵气终有一日会燃尽""碎片在找一个人"）
- 宁秩的母亲去了哪里（他可能是宁家唯一知道真相的人）
- 宁远山铁盒子里大概有什么（他见过铁盒子被拿出来的那晚）
- 宁秩的杂灵根可能不只是"修炼无望"——他年轻时听说过类似的情况，但那些人的结局都不太好

### 老管家不知道的事

- 天道熔炼的本质（没有人知道）
- 碎片为什么会远离（他知道碎片存在，但不知道它们在远离）
- 宁秩最终会面对什么（他只能祈祷宁秩能扛住）

### 专属剧情

老管家在游戏的每个关键阶段都会发来消息——他不是"任务发布者"，他是"一个在远方关心宁秩的人"。

| 时间 | 消息内容 | 意义 |
|------|---------|------|
| 第1天·抵达后 | (无——此时玉简未激活) | 宁秩一个人 |
| 第一次熔炼后 | "少爷……您刚才说，这是您自己熔出来的？……老奴活了这么多年，从未听说过。" | 管家意识到宁秩不是普通人 |
| 第30天·月底 | 月度简报 + "第一个月能做成这样，已经不错了。" | 初步认可 |
| 第3个月·第一个老顾客事件后 | "老奴听说你有了回头客。做生意最难的就是这一步。" | 阶段性认可 |
| 暗市被发现后 | "少爷……老奴听说了一些闲话。老奴不会多问。" | 提醒但不干预 |
| 第9个月·天道值达标 | "少爷，您终于感觉到了。" | 他知道宁秩迟早会发现 |
| 第12个月·宁家之难前 | "少爷……如果家里出了什么事，您不用顾虑老奴。" | 暗示宁家要出事 |
| 第18个月·最终抉择前夕 | "少爷，老奴活了这么多年，一直在想一个问题——如果一个人知道自己只能再活一百年，他还会做和现在一样的事吗？" | 终极问题 |

# 二、六域引路人

## 03 · 老赵（赵不惑）

> 他是宁秩在灵墟的第一个朋友。

| 项目 | 内容 |
|------|------|
| **全名** | 赵不惑 |
| **年龄** | 五十余岁 |
| **修为** | 筑基中期（散修） |
| **外貌** | 面容沧桑，手掌粗糙，穿一身洗得发白的旧道袍。看起来就是一个普通的中年散修——丢进人群里找不出来的那种 |
| **性格** | 表面粗犷、说话直来直去，实际上心思细腻。他活了半辈子，见过太多人和事。他不是一个厉害的修士——但他的看人眼光比很多金丹期都准 |
| **怎么认识宁秩的** | 宁秩摆摊第一天，他是第一个顾客。他拿起一株赤炎草说："小伙子，新来的吧？这株赤炎草成色还行，但你这个价定高了。"——他说"实价"的时候，手指在灵草边缘轻轻摩挲了一下。他是真的懂货 |
| **和老赵的关系** | 老赵不是随从，不是雇员——他就是不定期出现的一个朋友。他可能一周来一次，也可能一个月都没影——他有自己的生活。但他每次来都会和宁秩聊几句。老赵是宁秩在中央荒原最熟悉的人 |
| **在剧情中的作用** | 1. 新手引导中的"第一个顾客"<br>2. 中期透露灵墟"老话"——线索的潜在来源<br>3. 后期在商会竞争事件中帮宁秩打听消息<br>4. 他是宁秩在灵墟的第一个朋友——真正的朋友，不是商业上的 |

### 专属剧情

- 第6个月左右，老赵会消失大约两周。再次出现时胳膊上缠着绷带——他帮人押了一趟货，出了意外。如果玩家追问（人心≥20），他会透露那批货是从苍木域运出来的——"有人在大量收购灵木心。量很大。不像是正常生意。"——这是一条暗线线索的入口。

## 04 · 冰崖

> 寒渊宗里最好打交道的人——虽然也就是相对而言。

| 项目 | 内容 |
|------|------|
| **全名** | 冰崖（道号，本名已无人叫过） |
| **年龄** | 一百六十余岁 |
| **修为** | 金丹后期 |
| **身份** | 寒渊宗外事长老——负责与外界的一切商业往来 |
| **外貌** | 清瘦，白发白眉，面容冷峻。穿寒渊宗的白色法袍，但法袍袖口总是沾着墨迹——他每天都在写报价单 |
| **性格** | 说话简洁直接、不拖泥带水。他对灵石有实实在在的尊重——不是贪财，是理解"没有灵石宗门运转不了"。他不会和任何人称兄道弟，但也不会给人脸色看——在寒渊宗，这已经算"热情"了 |
| **怎么认识宁秩的** | 宁秩第一次与寒渊宗交易时，负责接洽的就是冰崖。他看了一眼宁秩的报价单，说："价格合理。以后有货直接送来。"——没有第二句废话 |
| **和宁秩的关系** | 每次宁秩去玄冰域做交易，冰崖都会多看一眼他的货单。有一次宁秩送来的玄冰髓样品成色比合同上的略好，冰崖主动提了价——"好货就是好货。不会让你吃亏。" |
| **在剧情中的作用** | 1. 寒渊宗的商业接口人<br>2. 线索三"报价单背面的灵气密度数据"——冰崖故意写的<br>3. 如果玩家走修复路线——冰崖会是第一个注意到宁秩不对劲的人 |

### 专属剧情

- 第10个月左右，完成一单大宗交易后，冰崖会多说一句："你最近问的问题——关于灵气密度的那些——不要再问第二个人。"他不解释为什么。

## 05 · 赤炼

> 她可能不是灵墟最好的炼器师——但她一定是最疯的那一个。

| 项目 | 内容 |
|------|------|
| **全名** | 赤炼（道号，本名已无人知晓） |
| **年龄** | 约一百二十岁 |
| **修为** | 金丹巅峰 |
| **身份** | 焚天阁左护法、首席炼器师 |
| **外貌** | 精瘦，手指修长但布满烫伤疤痕。常年穿着被火星烧出无数小洞的短打。头发随意扎着，有几缕被燎焦了也不在乎 |
| **性格** | 技术狂人。她对"人"没什么兴趣，但对"材料"有着近乎偏执的热情。可以三天三夜不睡就为了锻一件法器。社交能力基本为零——但至少能在谈正事的时候不骂人 |
| **怎么认识宁秩的** | 宁秩在炎狱域拍卖会上拍到一块看不出用途的金属，拿去焚天阁鉴定。赤炼看了那块金属一眼——"你在哪弄到的？这不是灵墟的东西。"然后她就不肯多说了 |
| **和宁秩的关系** | 赤炼对宁秩的态度很矛盾——她欣赏他的眼力，但不喜欢和商人打交道。不过，如果宁秩带来了她没见过的材料，她会放下手头的工作和他聊很久。他们的关系建立在"你带好货来，我给你鉴定"的基础上——但后来渐渐变成了"你来啦？最近又弄到什么奇怪的东西了？" |
| **在剧情中的作用** | 1. 焚天阁技术接口人<br>2. "不是灵墟的东西"——暗示域外材料<br>3. 对天道熔炼异变产物的鉴定者<br>4. 在灵墟归途路线的终局阶段——唯一有能力帮宁秩分析"那扇门后面有什么"的人 |

### 专属剧情

- 第14个月左右，如果交易次数≥5，赤炼会发来一条传讯——通过一个烧得发烫的小铁片："你那块金属我查到了。不是灵墟的东西——但这不代表灵墟没有。三百年前，有人见过一模一样的东西。那人是谁？焚天阁上一任阁主——天裂之战战死的那位。他生前一直在研究这个。"

## 06 · 云叶

> 她从来不笑。不是不高兴——是忘了怎么笑。

| 项目 | 内容 |
|------|------|
| **全名** | 云叶 |
| **年龄** | 约八十岁 |
| **修为** | 金丹后期 |
| **身份** | 万木灵宗灵植长老 |
| **外貌** | 面容清瘦、肤色苍白，像一株长期不见阳光的植物。穿淡绿色的法袍，袖口总是沾着泥土。她的手指很细——但每一根都很有力，像是常年握锄头的人 |
| **性格** | 温柔、善良、对灵植有着近乎偏执的热爱。她可能是灵墟最好打交道的高阶修士——没有架子、不端身份、不摆脸色。但她从来不笑。不是不高兴——是她忘记了怎么笑 |
| **怎么认识宁秩的** | 宁秩在苍木域进货时，在集市上遇到一个蹲在地上看灵草的老妇人——他当时不知道她就是万木灵宗的灵植长老。她抬头看了宁秩一眼："你这株赤炎草的成色不对。"叶片边缘确实有一圈不正常的暗纹。她说："下次进货看叶背。好货叶背是绿的。" |
| **和宁秩的关系** | 她对他没有任何企图。不买他的货、不卖他东西、不跟他做生意。只是偶尔出现在摊位前看看货，说一句"这批不错"或"这棵快枯了"，然后就走。宁秩有一次忍不住问她为什么帮他，她想了一会儿，说："因为你叫我'前辈'的时候，和那些叫我'长老'的人不一样。" |
| **在剧情中的作用** | 1. 苍木域引路人<br>2. 世界树之殇事件中的关键NPC<br>3. 线索四"世界树的呻吟"的深入触发者<br>4. 宁秩唯一可以"什么都不谈"的朋友 |

### 专属剧情

- 第8个月左右（世界树之殇期间），云叶会消失一段时间。再次出现时脸色苍白，递给宁秩一袋种子——"这是世界树今年最后一批种子。你拿着。"如果玩家追问（人心≥40），她低声说："树可能要死了。我不是说可能。我是在等它死。"——这是整个灵墟旅商中最悲伤的一句话。

## 07 · 金锋

> 他一天说不了十句话。但他用作品说话。

| 项目 | 内容 |
|------|------|
| **全名** | 金锋 |
| **年龄** | 约两百岁 |
| **修为** | 金丹巅峰 |

她等来了"可能"——但"可能"的时间窗口只有一百年。

她不会告诉宁秩这些。不是因为不信任，而是因为她不想让宁秩背负"只有一百年了"这个压力。宁秩知道了也不会改变什么——他该怎么走还是怎么走。

### 潮音的专属剧情
