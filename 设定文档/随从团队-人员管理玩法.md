# 随从团队 · 人员管理玩法

> 雇一个随从，很简单——花灵石就行。
> 但让一个随从愿意跟你干下去，没那么简单。
>
> 他们有脾气、有喜好、有过去。
> 他们之间合得来或合不来。
> 他们会在你遇到麻烦的时候替你出头——也有可能在你最需要他们的时候甩手走人。
>
> 你不是在"管理资源"——你在管理人。

---

## 一、设计目标

1. **把随从从"属性插件"变成"有独立人格的同伴"**——每个随从都是有故事、有性格的个体
2. **制造人员管理带来的策略深度**——谁和谁搭班、派谁去哪、怎么对待他们——这些决策影响经营效率
3. **让随从成为情感投资的对象**——玩家不只是"花钱买效率"，而是"培养一个愿意跟着自己的人"

---

## 二、随从的核心属性

每个随从拥有以下维度：

### 基础属性

| 属性 | 范围 | 说明 |
|------|------|------|
| **特长** | 1主 + 1-2辅 | 算账/押镖/探路/情报/炼药/鉴定/谈判/护卫…… |
| **特长等级** | 1-5级 | 初始1-3级，长期做同类任务可升级 |
| **性格** | 见下方表格 | 影响适合的任务类型和与其他人的相处 |
| **忠诚度** | 0-100 | 决定随从是否会在关键时刻站出来（或跑路） |
| **疲劳度** | 0-100 | 连续任务太久会累，效率下降；≥80时需要休息 |
| **好感度（对玩家）** | 0-100 | 影响忠诚度上限和交流意愿 |
| **人际关系（对其他随从）** | -50~+50 | 影响团队任务效率和冲突概率 |

### 性格类型

| 性格 | 适合的任务 | 不适合的任务 | 和谁合得来 | 和谁合不来 |
|------|-----------|------------|-----------|-----------|
| **勤奋踏实** | 守店、算账、重复性工作 | 探索、随机应变的任务 | 谁都行 | 懒散的 |
| **冒险进取** | 押镖、探路、开拓新商路 | 守店、看仓库 | 同样冒险的 | 过于谨慎的 |
| **谨慎保守** | 记账、保管、风险控制 | 高风险押镖、暗市交易 | 同样谨慎的 | 冒进的 |
| **社交能手** | 谈判、情报、客户维护 | 独自长途押镖 | 谁都行 | 孤僻的 |
| **独来独往** | 单独行动的任务 | 团队协作 | 社交能手除外 | 社交能手 |
| **忠诚耿直** | 护卫、押镖、随行 | 需要变通的任务 | 谁都行 | 阴险的（玩家行为如果太暗面会降低好感） |

## 三、任务分配

### 可用任务类型

| 任务 | 适合的特长 | 最适合的性格 | 基础时长 |
|------|-----------|------------|---------|
| **守店/管理店铺** | 算账 | 勤奋踏实 | 持续 |
| **采购进货** | 鉴定、谈判 | 社交能手 | 半天-1天 |
| **押镖护送** | 护卫 | 冒险进取/忠诚耿直 | 2-7天 |
| **探路开拓** | 探路 | 冒险进取 | 3-10天 |
| **暗市接头** | 情报 | 社交能手/独来独往 | 半天 |
| **宗门联络** | 谈判 | 社交能手 | 1-2天 |
| **仓库管理** | 算账 | 谨慎保守 | 持续 |
| **随行护卫**（玩家出门时） | 护卫 | 忠诚耿直 | 随行时间 |

### 任务效率公式

```
任务效率 = 特长等级 × 1.0 + (性格匹配? +0.5 : -0.3) + (疲劳<30? +0.2 : >70? -0.5 : 0) + (人际关系平均>20? +0.2 : <-20? -0.3 : 0)
```

**不展示具体公式给玩家**——但玩家可以通过任务结果感知到"状态好了效率高""吵架了效率低"。

## 四、随从互动事件

随从不是静态的资源——他们会**主动发生事情**，要求玩家做出回应。

### 触发频率

- 每个随从大约每**7-14个游戏日**触发一次互动事件
- 如果玩家长期不处理随从（忽略他们的需求），触发频率会加速
- 从不触发——每个随从至少有一件"专属事件"

### 事件类型

| 类型 | 示例 | 玩家需要做的 |
|------|------|------------|
| **随从之间的矛盾** | 小林和赵铁柱又吵了一架——小林说赵铁柱总是不经同意就拿他整理的账本 | 调解/惩罚一方/各打五十大板/不管 |
| **随从的个人请求** | 小林："掌柜的，我想学熔炼。你能教我吗？" | 教（消耗时间但提升忠诚+可能解锁新能力）/婉拒（忠诚下降） |
| **随从带来的情报/机会** | 赵铁柱押镖回来："掌柜的，我在路上听说——金戈域那边有个新矿脉被人发现了。" | 追问细节/记下但不管/奖励赵铁柱 |
| **随从遇到麻烦** | 阿萤从暗市回来脸色不太好："有人盯上我了……可能是天道商会的眼线。" | 帮她解决/让她避避风头/告诉她"自己小心" |
| **随从想辞职** | 小林犹豫了很久："掌柜的……我想回老家了。爹娘年纪大了。" | 挽留（加薪/承诺未来）/祝福送别/挽留失败 |
| **随从被挖墙脚** | 有竞争对手派人来接触你的随从——你会不会发现？ | 通过高人心值的管家预警发现/没发现→随从被挖走 |
| **随从的忠诚考验** | 某个关键时刻（如宁家之难事件），随从主动表示"掌柜的，我跟你一起扛" / 或"我……我想先避避" | —（事件本身展示随从的忠诚） |

### 事件选择的影响

| 玩家行为 | 忠诚影响 | 其他影响 |
|---------|---------|---------|
| 关心随从（询问近况、满足合理请求） | +5~15 | 好感度上升 |
| 忽视随从（长期不交流、拒绝合理请求） | -5~10/次 | 好感度下降，离职风险增加 |
| 偏袒一方（随从冲突中明显站队） | 被偏袒方+5~10，另一方-10~20 | 可能加深矛盾 |
| 公平处理 | 双方各+2~5 | 团队氛围改善 |
| 靠高人心值"感化" | 特殊对话选项，忠诚提升效果翻倍 | — |

## 五、随从的成长

| 成长维度 | 成长条件 | 效果 |
|---------|---------|------|
| **特长升级** | 长期从事同一类任务（累计成功执行次数） | 1级→2级：10次；2→3：25次；3→4：50次；4→5：100次 |
| **性格微调** | 长期被派去做不适合的任务 → 性格会向"适应"方向偏移 | 例如：冒险派的随从被长期派去守店→会变得更耐心 |
| **与新随从的关系建立** | 与新随从共同执行任务 | 每次共同任务+5~15关系值 |
| **忠诚度自然增长** | 玩家持续善待、公平对待 | 每月+2~5（上限取决于好感度） |
| **忠诚度因事件变动的上限** | 特定事件（救过随从的命/为随从出头）可突破上限 | 正常情况下忠诚上限=好感度；特殊事件后可突破至120（死忠） |

## 六、随从与现有系统的联动

| 系统 | 联动方式 |
|------|---------|
| **商路物流** | 派护卫型随从押镖→降低运输风险；派探路型随从探路→发现新捷径/隐藏商机 |
| **议价** | 带社交型随从一起去谈判→议价时获得额外"察言观色"信号 |
| **暗市** | 派情报型随从去暗市→每周自动获取一条暗市情报；派错人（正道宗门出身）→可能被发现 |
| **品阶鉴微** | 派鉴定特长随从去采购→自动应用"低成本鉴微"（随从帮你看一眼，不保证百分百准） |
| **灵材实验室** | 随从从各地带回的灵材自带"已观察"标记——省去玩家鉴微的步骤 |
| **管家系统** | 管家会和随从交流——管家可能会提醒你"少爷，小林最近好像有心事"（触发互动事件的前兆预警） |
| **天道熔炼** | 随从不能熔炼（只有宁秩能），但忠诚度高的随从会在熔炼时主动送灵材——"掌柜的，这个给你试试" |

## 七、随从团队管理的"新东西"总结

| 和传统随从系统的区别 | 我们的设计 |
|--------------------|-----------|
| 传统：招到人=属性加成 | 我们：招到人=开始一段关系管理 |
| 传统：随从之间无互动 | 我们：有矛盾、有合作、有化学反应 |
| 传统：随从不成长 | 我们：特长升级、性格可微调、忠诚可突破上限 |
| 传统：没有情感连接 | 我们：随从有自己的故事和请求，玩家的选择会塑造他们 |
| 传统：随从不会走 | 我们：真的会辞职、会被挖走、会在关键时刻选择留下或离开 |
| 传统：随从只是背景板 | 我们：随从是"这个商会的血肉"——玩家经营的"人"和经营的"货"同样重要 |
