# 交互系统设计

> 玩家不是"在看一个故事"。玩家是宁秩——他站在中央荒原的集市里，面前有人、有货、有路。交互方式决定了世界是不是"活的"。

---

## 一、核心交互原则

| 原则 | 说明 |
|------|------|
| **点击即达** | 看到的东西就能点，点了就有反馈。不隐藏可交互元素 |
| **少菜单，多场景** | 尽可能在场景中完成交互，不要频繁打开全屏菜单打断沉浸感 |
| **宁秩替玩家说话** | 玩家不需要打字。宁秩会替玩家说出选项，玩家只需要选择方向 |
| **反馈要"重"** | 每一次交易、每一次熔炼、每一次重要选择，UI反馈要足够清晰——灵石哗啦声、熔炉火光、玉简震动 |

---

## 二、场景与视角

### 主视角：俯视2.5D

游戏采用**俯视2.5D像素视角**，类似《星露谷物语》的视角度——不是正俯视，是微斜的视角，能看到摊位上的货物和人脸。

### 场景切换

灵墟旅商不是开放世界。世界由多个**场景节点**组成，玩家通过点击场景边缘或交互点切换到下一个场景：

| 场景类型 | 举例 | 切换方式 |
|---------|------|---------|
| 集市场景 | 中央荒原集市、各板块集市 | 点击场景边缘的路径标志（"→苍木域商路"） |
| 室内场景 | 玩家铺面、商会总堂、拍卖行、暗市 | 点击门口或入口（"→进入铺面"） |
| 特殊场景 | 拍卖会现场、熔炼室、黑门前 | 事件触发自动切换 |

每个场景大约一屏大小。不需要大地图滚动，聚焦于当前可交互的内容。

## 三、核心交互方式

### 3.1 点击交互

| 交互对象 | 点击效果 | 说明 |
|---------|---------|------|
| NPC | 打开对话/交易界面 | 不同NPC反应不同——顾客直接进入议价，熟客先寒暄再交易 |
| 货架/摊位上的货物 | 查看详情、定价、上架/下架 | 点击货物弹出小窗口：名称/品阶/五行/当前定价/市场参考价 |
| 熔炉 | 打开熔炼界面 | 夜间可交互，白天不可用（显示"火还没生"） |
| 玉简图标 | 打开管家面板 | 查看消息、提问、月度简报 |
| 随从 | 查看状态、分配任务、对话 | 点击随从打开个人面板 |
| 场景边缘路径标志 | 切换场景 | 需要确认是否出发（如果有在途货物会提醒） |
| 地图上的特殊标记 | 触发事件/进入特殊场景 | 闪烁的特殊标记表示"这里有东西" |

### 3.2 议价交互（核心循环）

议价是玩家最频繁的操作。设计必须简洁、反馈清晰：

**议价界面布局（占据屏幕下半部分）：**

```
┌──────────────────────────────────────────────┐
│  顾客：老赵 · 需求：赤炎草（灵品）×3        │
│                                              │
│  市场参考价：100  │  你的进货价：60           │
│                                              │
│  老赵出价：70  [还价]  [接受]  [拒绝]         │
│                                              │
│  你的还价：———[自定义输入，滑块/数字键盘]     │
│                                              │
│  老赵表情：[耐心地等待]                       │
│  （根据性格显示对话气泡）                      │
└──────────────────────────────────────────────┘
```

**交互流程**：

1. 顾客报出价格（对话气泡显示）
2. 玩家看到市场参考价和自己的进货成本
3. 玩家决定：直接接受 / 拒绝 / 还价
4. 如果还价，输入一个数字（滑块+数字键盘双模式）
5. 顾客反应——接受 / 再次还价 / 不耐烦 / 离开

**关键设计**：玩家永远能看到"市场参考价"和"自己的成本价"。不需要心算利润率。

### 3.3 对话交互

灵墟旅商没有自由文本输入。所有对话通过**选择分支**完成：

```
老赵："掌柜的，最近有什么好货？"

[1] "这批赤炎草成色不错，你看看。"（推荐商品）
[2] "最近生意不太好……"（闲聊，提升好感度）
[3] "你上次说那条商路不安全，详细说说？"（打听情报）
```

选择后，宁秩会"说出"对应的话（显示为对话气泡），NPC根据选项做出反应。

**数量控制**：每次对话最多提供3-4个选项。超过4个会让人疲劳。

**特殊选项**：部分选项只有在满足条件时才会出现——比如"打听情报"只在人心值足够时才显示。

## 四、信息呈现方式

### 4.1 宁秩的内心独白

玩家不是看到一个"系统提示框"。游戏中的所有系统级信息都以宁秩的内心独白形式呈现：

| 场景 | 系统提示 | 宁秩独白 |
|------|---------|---------|
| 灵石不足 | "余额不足"（红色文字） | "口袋比脸还干净……" |
| 新系统解锁 | "天道熔炼系统已解锁" | "也不知道能熔出个什么东西来……" |
| 要素提醒 | "今日熔炼次数：2/5" | "今天就炼到这里吧。炉火有点太大了。" |
| 危险预警 | "前方区域危险" | "这条路人不太多……要不要换条路？" |

**好处**：玩家不是在读说明书，是在听一个有血有肉的人说话。

### 4.2 管家的玉简消息

管家通过玉简传递消息，呈现方式为**屏幕右侧滑入一个玉简气泡**：

```
┌────────────────────┐
│ 💎 管家             │
│                     │
│ "少爷，今日苍木域   │
│ 的灵木心价格涨了    │
│ 三成。如果您手头    │
│ 有货，现在出手是    │
│ 好时机。"           │
│                     │
│         [关闭] [回复] │
└────────────────────┘
```

玉简消息不打断当前操作。玩家可以稍后阅读。未读消息时玉简图标闪烁。

### 4.3 过夜结算

每一天结束时（玩家选择"过夜"），以**半屏滚动报告**的形式呈现：

```
━━━ 丙午年·三月·十二日 ━━━

  收入：350 灵石（卖出 7 件商品）
  支出：-60 灵石（摊位费）
  支出：-120 灵石（进货）
  ─────────────────
  本日利润：170 灵石
  累计存款：1,280 灵石

  今日大事：老赵介绍了新顾客 / 世界树之液价格涨了

  ━━━━━━━━━━━━━━━━━━━━
        [进入明天]
```

结算界面简洁，数据清晰。玩家扫一眼就知道今天怎么样。

## 五、熔炼交互（特殊交互）

天道熔炼是灵墟旅商最特殊的交互，需要和普通经营操作有明显区分：

**进入熔炼界面**：夜间在熔炉前点击熔炉，画面变暗，屏幕中心出现熔炉特写。背景音变为炉火的噼啪声和低沉的共鸣音。

**放入灵材**：从右侧物品栏将灵材拖拽到熔炉上方。最多5个槽位。放入时灵材在炉火上方悬浮旋转，显示名称和五行属性。

**五行相性提示**：
- 天道值<20：无提示
- 天道值20-40：偶尔出现模糊文字（"感觉不太对"）
- 天道值41-60：显示五行箭头（"火→木→相生↑"）
- 天道值61+：显示完整相性分析

**点燃熔炉**：所有灵材放好后，点击"点燃"按钮。画面短暂闪烁，然后显示结果：

```
成功升品！✨
  赤炎草×3（凡品）→ 赤炎草·精（灵品）

  [查看属性]  [放入仓库]
```

**失败时**：
```
炉火暗淡……💔
  灵材化为灰烬。什么都没剩下。

  [关闭]
```

## 六、UI布局总览

```
┌─────────────────────────────────────────────────┐
│  时间：丙午年·春·三月·十二·申时   │ 灵石：1,280 │
│                                                   │
│                                                   │
│                                                   │
│              【主游戏场景】                          │
│                                                   │
│             顾客/摊位/熔炉/随从                      │
│                                                   │
│                                                   │
├─────────────────────────────────────────────────┤
│  [左下角：迷你地图]    │ [右下角：玉简📨]          │
│  [快捷键操作提示栏]    │ [当前场景名]              │
└─────────────────────────────────────────────────┘
```

**右上角**：时间和灵石余额。不变的核心信息。
**中央**：游戏场景。所有交互发生在这里。
**右下角**：玉简图标（管家入口）。未读消息时闪烁。
**左下角**：迷你地图（显示当前板块和附近的交互点）。

没有常驻的菜单栏。所有功能通过场景中的交互对象和玉简进入。

## 七、特殊场景交互

### 拍卖会交互

拍卖会不是全屏动画。它是在一个**场景**中发生的——玩家坐在拍卖席上，前方是拍卖台。

- 每件拍品展示时，拍品详情显示在屏幕上方
- 玩家点击"举牌"按钮出价
- 当前最高价和出价人实时显示
- NPC竞拍者会发出对话气泡（"我出2500！"）
- 成交时显示最终价格和买家

### 暗市交互

暗市场景比普通集市暗一个色调，保持神秘感。

- 摊位上的商品不显示价格——需要点击询问
- 暗市掮客会不定时出现在场景中，点击搭话
- 黑门在暗市场景最深处——早期不可达，暗市声望达标后解锁通路
- 守夜人站在暗市各处，不可交互（触摸无反应）

### 商路交互

玩家不是在抽象菜单里选路线。在仓库或商会场景中，有一张**灵墟地图**：

```
        【玄冰域】 ←→ 【中央荒原】 ←→ 【苍木域】
           ↕                    ↕
        【金戈域】 ←→ 【中央荒原】 ←→ 【深海域】
           ↕
        【炎狱域】
```

玩家点击出发地和目的地地图，选择运输方式（商队/传送阵/自己跑），然后确认发货。在途货物可以在玉简的"物流"面板中查看实时状态。
