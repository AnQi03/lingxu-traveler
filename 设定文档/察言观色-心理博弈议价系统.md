# 察言观色 · 心理博弈议价系统

> 讨价还价，从来不是算数。
> 是他在试探你，你在试探他。
> 谁先露怯，谁就输了。

---

## 一、设计目标

1. **把议价从数学博弈变成心理博弈**——玩家不是在调价格滑块，而是在"读人"
2. **让人心值真正有意义**——人心不是抽象的数值，它决定了你能"看穿"顾客多少底牌
3. **创造可传播的"我在经营游戏里玩读心术"的记忆点**

---

## 二、什么时候触发

察言观色不是每次交易都触发——只在**值得关注**的交易中才会出现：

| 触发条件 | 场景举例 | 是否开启察言观色 |
|---------|---------|----------------|
| 交易金额 ≤ 100灵石 | 散修买一株凡品灵草 | ❌ 跳过——买把葱不需要读心 |
| 交易金额 100-1000灵石 | 普通交易、老顾客常规采购 | 概率开启（30%）——金额到了值得注意的级别 |
| 交易金额 > 1000灵石 | 宗门采购、大宗订单 | ✅ 必开启 |
| 特殊NPC（第一次交易/剧情关键人物） | 五域引路人、宗门使者 | ✅ 必开启 |
| 暗市交易 | 违禁品买卖、情报交易 | ✅ 必开启（暗市的人更会演戏） |
| 玩家选择"主动压价/抬价"时 | 玩家主动发起高难度议价 | ✅ 手动触发 |

**核心原则**：让察言观色成为「关键时刻的工具」，而不是每次买瓶水都要看微表情。

## 三、议价界面布局

### 三层信息结构

```
┌──────────────────────────────────────────┐
│  议价 · 赤炎草×5                        │
│                                          │
│  ┌─ 第一层：基础信息（谁都能看到）────┐ │
│  │  顾客：老赵 · 散修                 │ │
│  │  他的出价：80灵石                  │ │
│  │  你的进价：50灵石                  │ │
│  │  市场参考价：100灵石               │ │
│  │  差额：+30灵石（利润）             │ │
│  └────────────────────────────────────┘ │
│                                          │
│  ┌─ 第二层：察言观色（需要观察）────┐  │
│  │  [🔍 仔细观察] → 展开第三层      │  │
│  └────────────────────────────────────┘  │
│                                          │
│  ┌─ 第三层：观察结果（点击后展开）───┐  │
│  │  眼神：快速扫了旁边摊位 ← 在比价  │  │
│  │  手指：敲了三下桌面 ← 不耐烦？    │  │
│  │  声音：(若有)                       │  │
│  │  表情：(需要人心≥40)               │  │
│  │  气场：(需要人心≥60)               │  │
│  │                                     │  │
│  │  综合推断：他的底线可能在85-90之间 │  │
│  └────────────────────────────────────┘  │
│                                          │
│  你的回应：                               │
│  [接受] [还价:___] [试探] [拒绝]        │
│                                          │
│  特殊选项（人心≥30解锁）：               │
│  [问] "老赵，你最近手头紧？"            │
└──────────────────────────────────────────┘
```

### "观察"按钮

- 非必须操作——玩家可以不点观察直接还价
- 点了观察→画面切入**顾客上半身特写**（像素画），持续约2-3秒
- 特写中会有动态细节：
  - 眼神在左右飘移（在比较）
  - 手指在桌面敲击（不耐烦/紧张）
  - 嘴角微微抽动（在压价）
  - 额角有汗珠（心虚/天气热——玩家需要自己判断是哪种）
- 特写结束后返回议价界面，第三层显示观察结果

## 四、察言观色的维度与解锁

每个维度是一个独立的"感知层"。玩家的人心值决定了能看到多少层：

| 人心值 | 可感知维度 | 表现形式 | 准确率 |
|-------|-----------|---------|--------|
| 0-19 | 无 | — | — |
| 20-39 | **第一层：动作** | 眼神动向、手部动作、身体朝向 | 70%（明显动作可信度高） |
| 40-59 | **第二层：表情** | 嘴角、眉毛、瞳孔变化 | 60%（微表情容易被伪装） |
| 60-79 | **第三层：声音** | 语调变化、语速、呼吸节奏 | 75%（声音比表情更难控制） |
| 80-100 | **第四层：综合气场** | "他今天状态不对"的整体直觉 | 85%（经验累积的综合判断） |

### 各维度具体信号库

#### 第一层·动作（人心≥20）

| 信号 | 可能的意思 | 不能排除的另一种可能 |
|------|-----------|---------------------|
| 眼神快速扫向旁边 | 在比较别家的价格 | 旁边有人叫他 |
| 眼神向下/向左 | 在算账/考虑 | 只是在发呆 |
| 手指敲桌面 | 不耐烦："快点决定" | 习惯性动作，无关紧要 |
| 搓手指/捏衣角 | 紧张——他的底线可能快到了 | 天冷/穿得不舒服 |
| 身体前倾 | 感兴趣，想成交 | 只是年纪大了听不清 |
| 身体后仰/抱臂 | 防御姿态——不打算让步 | 坐累了换个姿势 |
| 频繁看门口/窗外 | 赶时间——可以适当压价 | 外面有朋友在等 |

#### 第二层·表情（人心≥40）

| 信号 | 可能的意思 | 不能排除的另一种可能 |
|------|-----------|---------------------|
| 嘴角不对称抽动 | 在压价/说谎 | 牙疼 |
| 眉毛微抬 | 对你的还价感到意外 | 只是调整视角 |
| 瞳孔微微放大 | 对你的货很感兴趣——有提价空间 | 光线变化 |
| 鼻翼快速扩张 | 深呼吸——在克制情绪 | 感冒了 |
| 嘴唇抿紧 | 犹豫——你的价格在他的临界点上 | 在思考别的事 |
| 眨眼频率变快 | 紧张——他的报价可能是虚的 | 眼睛干 |

#### 第三层·声音（人心≥60）

| 信号 | 可能的意思 | 不能排除的另一种可能 |
|------|-----------|---------------------|
| 语调微微升高 | 不自信——报了个虚价 | 天生高音 |
| 语速突然变慢 | 在编造理由 | 在回忆（可能真有事） |
| 说到关键数字时停顿 | 那个数字是临时想出来的 | 计算中 |
| 呼吸变浅变快 | 紧张——快露馅了 | 刚爬了楼梯 |
| 叹气 | 无奈——差不多了 | 今天累了 |

#### 第四层·气场（人心≥80）

| 信号 | 意思 |
|------|------|
| "他今天不太对劲——和上次不一样。" | 综合判断——老板今天遇到了什么事 |
| "他虽然嘴上说不要，但他眼睛一直在看那件货。" | 想要，在压价 |
| "他说不要的时候，身体没有转开。" | 还有回旋余地 |
| "他整个人是松的——不紧张。" | 他报的价格就是他的真实底线，很难再压 |

## 五、玩家判断的赌注

察言观色不是"看穿了就赢了"——它只是一个**辅助工具**。最终的决策还是玩家来做：

### 成功场景举例

```
你观察到：老赵说"不能再低了"时，手指不自觉地敲了三下
你的判断：他不耐烦了——但也不一定到了底线
你的选择：还价85（比他的出价高了5，但比你的底价低15）
结果：老赵犹豫了一下——"……行吧，就85。"
你赚了：比预期多赚5灵石
你的感受：😏 "果然，他没到底线。"
```

### 失败场景举例

```
你观察到：老赵的眼神快速扫了旁边摊位
你的判断：他在比价——这边不卖他可能就去隔壁了
你的选择：还价90（抬高了10）
结果：老赵站起来就走——"太贵了，我去隔壁看看。"
你亏了：失去了这笔交易
你的感受：😅 "我看走眼了……他只是随便看了一眼。"
```

### 各种结果的情绪反馈

| 结果 | 发生了什么 | 情绪 |
|------|-----------|------|
| 看穿压价成功 | 你发现他在虚张声势，压到了你的理想价 | 🎉 "小样，跟我玩这套" |
| 看走眼失单 | 你判断失误，把他逼走了 | 😅 "……下次不能这么狠" |
| 看穿好心让利 | 你发现他确实手头紧，主动让了5灵石 | 😊 人心+5 "做生意不能只看钱" |
| 被对方看穿 | 他反过来说"你眼睛一直在眨，你也紧张了吧？" | 😳 "……被你发现了" |
| 高水平心理战 | 双方都看穿了对方但都装作没看穿，最后在一个双方都满意的价格成交 | 🤝 "这买卖做得舒服" |

## 六、与人心值的深度绑定

| 人心值 | 察言观色能力 | 附加效果 |
|-------|------------|---------|
| 0-19 | 无——你只能凭直觉议价 | — |
| 20-39 | 看到动作信号（敲手指、眼神、身体朝向） | 特殊选项解锁：议价中可以"闲聊"一句（"今天生意怎么样？"），不影响价格但累积好感 |
| 40-59 | 看到表情信号（嘴角、眉毛、瞳孔） | 议价失败时（谈崩了），你有一次机会"挽留"——"等等，我们再聊聊"——50%概率顾客回头 |
| 60-79 | 听到声音信号（语调、语速、呼吸） | 可以发起"高难度议价"——大幅压价/抬价，成功则大赚，失败则直接谈崩 |
| 80-100 | 综合气场感知 | 「直觉」——议价前自动跳出一行字："你的直觉告诉你，今天这笔交易……"（暗示玩家的成功率判断，不精确但有用） |

## 七、察言观色的"新东西"总结

| 和传统议价的区别 | 我们的设计 |
|----------------|-----------|
| 传统：看数字调滑块 | 我们：读人、看表情、听语气 |
| 传统：人人都能完美议价 | 我们：人心值决定你能看穿多少——人心低的玩家更容易被坑 |
| 传统：议价是算数最优解 | 我们：信号有模糊性——没有"必胜策略" |
| 传统：每笔交易都要操作 | 我们：小额自动，大额才触发——不疲劳 |
| 传统：NPC是行走的钱包 | 我们：NPC有自己的状态和心情——今天不高兴可能比平时更难议价 |

> 察言观色的本质——让玩家在每一笔大额交易中，都有一种"我在和真人讨价还价"的感觉。
>
> 对方可能骗你，可能心虚，可能真的手头紧，可能是个老江湖。
> 你是那个"读得懂他们"的人——还是被他们"读"的那个人？
