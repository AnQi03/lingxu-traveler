# NPC 性格与生成系统设定

> 灵墟的顾客不是"刷出来的交易对象"。他们有性格、有需求、有故事。每一次交易都是一次微型人际互动。

---

## 一、NPC 生成逻辑

### 谁来玩家摊位？

每天会有不同类型的 NPC 出现在摊位前。不是靠随机数决定"今天来几个人"，而是由以下因素共同决定：

| 因素 | 影响 | 说明 |
|------|------|------|
| **灵潮阶段** | 数量×类型分布 | 高峰期人多且大宗采购多，谷期人少且散修多 |
| **玩家商道值** | 客户质量 | 商道越高，高级顾客出现的概率越大 |
| **店铺位置** | 客流量基础 | 中央荒原 vs 偏远区域 |
| **店铺升级** | 客流量上限 | 铺面越大，能同时接待的客人越多 |
| **时间** | 时段影响 | 上午散修多，下午宗门采购多，傍晚老顾客多 |
| **特殊事件** | 触发特定NPC | 被某个宗门盯上了→他们的人会来打探 |

### NPC 生成模板

每个 NPC 由以下模板组合生成：

```
性格模板 + 身份模板 + 需求模板 + 额外属性
```

## 二、性格模板

### 四大基础性格维度

每个 NPC 的性格由四个维度构成，每个维度±1到±3：

| 维度 | -3 | -2 | -1 | 0 | +1 | +2 | +3 |
|------|----|----|----|---|----|----|----|
| **爽直↔精明** | 粗犷直爽 | 不绕弯子 | 比较直接 | 中立 | 有点算计 | 精明 | 老谋深算 |
| **慷慨↔吝啬** | 大方 | 不计较 | 比较慷慨 | 中立 | 有点抠 | 小气 | 铁公鸡 |
| **急躁↔耐心** | 急不可耐 | 没耐心 | 比较急 | 中立 | 比较稳 | 有耐心 | 极其耐心 |
| **多疑↔轻信** | 什么都不信 | 疑心重 | 有点怀疑 | 中立 | 比较信任 | 好说话 | 你说啥信啥 |

### 性格对交易的影响

| 性格组合 | 议价风格 | 典型反应 |
|---------|---------|---------|
| **爽直+急躁** | 两轮定胜负，谈不拢就走 | "痛快点，这个价能卖不能卖？" |
| **精明+吝啬** | 磨到底，每一块灵石都要压 | "你这成色一般啊，再降降？" |
| **慷慨+耐心** | 好说话，不太计较 | "掌柜的看着给吧，我不挑。" |
| **多疑+精明** | 反复检查货品，问你进货渠道 | "你这灵草哪采的？我怎么看着不像正品？" |
| **爽直+轻信** | 最容易成交的类型 | "你说灵品就灵品，我信你！" |

### 性格在对话中的体现

性格不只是一串数字——它在NPC的**说话方式**中体现：

| 性格特征 | 对话示例 |
|---------|---------|
| 爽直 | "少废话，这个价行不行？" |
| 精明 | "别家可比你便宜，你再想想？" |
| 急躁 | "快点快点，我还有事。" |
| 耐心 | "不着急，你慢慢算。" |
| 吝啬 | "太贵了太贵了，你这是抢钱啊。" |
| 慷慨 | "行，就这个价，不用找了。" |
| 多疑 | "你这货……来路没问题吧？" |
| 轻信 | "掌柜的看着就是个实在人！" |

## 三、身份模板

### 顾客身份类型

| 身份 | 购买力 | 需求倾向 | 出现条件 |
|------|--------|---------|---------|
| **散修** | 低-中 | 低阶灵草、基础丹药 | 始终出现 |
| **宗门弟子** | 中 | 修炼材料、任务所需物品 | 商道>20 |
| **宗门采购** | 高 | 大批量采购指定灵材 | 商道>40+特定事件 |
| **炼药师** | 中-高 | 灵草、灵植材料 | 商道>20 |
| **炼器师** | 中-高 | 矿石、金属材料 | 商道>20 |
| **游商** | 中 | 什么都看，主要是探行情 | 始终出现 |
| **急需客** | 中-高（愿意出高价） | 特定物品，急用 | 随机事件 |
| **老顾客** | 中 | 什么都买，信任优先 | 多次交易后生成 |
| **神秘人** | 极高（但不可预测） | 特殊物品/情报 | 极低概率 |
| **探子** | — | 不买东西，打探消息 | 宗门关系事件 |
| **委托者** | 视委托内容 | 不是来买东西的，是来委托任务的 | 随机事件 |

### 特殊顾客类型

| 类型 | 机制 | 触发条件 |
|------|------|---------|
| **老顾客** | 多次交易后NPC会被标记为"熟面孔"→后续优先出现，好感度传承 | 累计交易≥3次 |
| **粉丝顾客** | 听说玩家眼力毒/天道熔炼厉害，慕名而来 | 天道值>20或口碑高 |
| **来踢馆的** | 同行派来故意挑刺、压价、找茬 | 竞品事件触发 |
| **神秘大能** | 元婴期老怪伪装成普通修士，不买则已，一买就是大单 | 极低概率+商道>60 |

## 四、需求模板

### 需求生成逻辑

每个NPC到来时，系统为其生成当前需求：

1. **由身份决定需求大类**（散修→灵草，炼药师→灵植材料……）
2. **由需求紧迫度决定是否愿意出高价**
3. **由玩家库存决定能否当场成交**

### 需求类型

| 需求类型 | 说明 | 价格敏感度 |
|---------|------|-----------|
| **日常消耗** | 修炼必备，不急不缓 | 正常，可等 |
| **任务所需** | 接了任务，需要特定物品 | 中等，有时间限制 |
| **急用** | 修炼突破/炼丹到关键一步了 | 低，愿意出高价 |
| **批量采购** | 宗门/组织统一采购 | 高，要量大价优 |
| **碰运气** | 随便看看，有合适的就买 | 高，可买可不买 |
| **慕名而来** | 听说你有好东西，专门来的 | 中，期望很高 |
| **打听行情** | 不是真买，是探价的 | 不买 |

### 需求紧迫度与心理底价

| 紧迫度 | 心理底价系数 | 议价轮次 |
|--------|------------|---------|
| 不着急 | 0.7-0.9×参考价 | 3-4轮 |
| 正常 | 0.9-1.1×参考价 | 2-3轮 |
| 急需 | 1.3-2.0×参考价 | 1-2轮 |
| 十万火急 | 2.0-5.0×参考价 | 1轮，不议价 |

## 五、NPC 记忆

NPC 不是一次性的——**他们会记住你**。

| NPC 记忆 | 影响 |
|---------|------|
| **上次交易价格** | 如果这次你涨价太多，他会不满 |
| **你给过优惠吗** | 给过→好感度+，下次也找你 |
| **你坑过他吗** | 坑过→好感度-，可能再也不来了 |
| **预约订单完成度** | 守信→优先来找你；失约→再也不信你 |

### NPC 好感度（个人层面）

与势力好感度不同，这是**每个NPC个体对玩家的好感**：

| 好感度 | 效果 |
|--------|------|
| -10以下 | 拒绝交易，甚至可能散布坏话 |
| -5~0 | 冷淡，除非急需否则不买 |
| 0-5 | 中立，正常交易 |
| 5-10 | 友好，愿意多聊几句，给你情报 |
| 10-20 | 信任，交易时不怎么压价 |
| 20+ | 忠诚，会成为你的"回头客中的回头客" |

## 六、NPC 外观与名字

### 命名池

NPC 的名字不是随机字符串。每个域有自己的命名风格：

| 板块 | 姓氏风格 | 名字风格 |
|------|---------|---------|
| 玄冰域 | 寒、霜、雪、冰 | 单字为主：凌、彻、凝、肃 |
| 炎狱域 | 炎、烈、焚、炽 | 名字热烈：阳、灼、焱、煌 |
| 苍木域 | 林、青、木、叶 | 名字温润：柔、溪、岚、笙 |
| 金戈域 | 金、铁、铜、石 | 名字刚硬：锋、锐、坚、砺 |
| 深海域 | 海、潮、渊、沧 | 名字神秘：溟、澜、汐、隐 |
| 中央荒原 | 姓氏混杂 | 什么风格都有 |

### 像素外观

- 每个 NPC 生成时从预设的 **像素头像模板** 中选择
- 身份不同外观不同：散修穿布衣，宗门弟子有制服色，炼药师挂药葫芦
- 后期如果有余力，可以根据性格增加微小的表情差异（笑眯眯的/一脸严肃的）

## 七、生成流程总结

```
每天开始时：
  1. 根据灵潮阶段、商道值、店铺等级、时间段
     计算今日"客流量"和"客源类型分布"
  
  2. 按比例生成NPC：
     - 从性格模板库取4个维度的值
     - 从身份模板取身份（受商道值限制）
     - 从需求模板生成当前需求
  
  3. 检查是否为老顾客：
     - 是 → 调取历史好感度和记忆
     - 否 → 新NPC，初始好感度0
  
  4. 分配外观（名字+像素头像）
  
  5. NPC进入"等待队列"，按顺序出现在摊位前
```

> 玩家不会意识到"这是系统生成的"——每个NPC看起来都像是一个有血有肉的人。因为从你的视角看，你记住的是那个"每次都来磨价的散修"和"爽快的炼药师"，而不是一串随机生成的数字。
