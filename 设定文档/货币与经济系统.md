# 货币与经济系统设定

---

## 一、货币体系

### 灵石三阶制

| 货币单位 | 兑换比例 | 主要流通场景 | 持有者 |
|---------|---------|-------------|--------|
| 下品灵石 | 基础单位 | 凡人交易、低级散修日常 | 凡人、练气期修士 |
| 中品灵石 | 1中品=100下品 | 修士日常交易、集市采购 | 筑基期及以上 |
| 上品灵石 | 1上品=100中品 | 大宗交易、拍卖会、宗门采购 | 金丹期及以上、大商会 |

> 高阶修士几乎不随身带下品灵石——太沉，掉价。但玩家不用管重量问题，数字管理，只管看余额涨就行了。

### 货币兑换

三种灵石之间的兑换比例固定：**1上品=100中品=10000下品**。

玩家在主要城市的**钱庄**（天道商会运营）进行兑换：

| 兑换方向 | 手续费 |
|---------|--------|
| 下品→中品 | 1% |
| 中品→上品 | 1% |
| 上品→中品 | 0% |
| 中品→下品 | 0% |

**实际效果**：
- 日常交易收入以下品灵石为主
- 拍卖会和高阶交易用中品/上品结算——直接收到中品/上品灵石，而不是系统自动换算
- 收到中品灵石时，有明确的视觉/音效反馈（灵石颜色不同、图标不同、入账音效有区别）
- 系统自动处理兑换：当玩家进行一笔需要中品灵石的高阶交易时，如果中品余额不足，自动用下品按比例兑换并扣除1%手续费。玩家不需要手动跑钱庄
- 灵石余额显示如："3,280 + 12中品 + 3上品"——每一档都是真实存在的余额，不是换算单位

### 高阶灵石的获取途径

玩家通过以下方式**直接获得**中品/上品灵石（而非从下品兑换）：

| 获取方式 | 获得灵石类型 | 典型数额 | 说明 |
|---------|------------|---------|------|
| 宗门采购订单 | 中品灵石 | 20-200中品 | 铸魂殿、万木灵宗等的大宗采购直接以中品结算 |
| 拍卖会成交 | 中品/上品 | 视拍品价值 | 玩家卖出高价值物品时，拍卖行直接以中品或上品支付 |
| 完成宗门委托 | 中品灵石 | 30-100中品 | 特殊任务直接奖励中品 |
| 天道熔炼异变品交易 | 中品/上品 | 视异变品品质 | 异变品是高端商品，直接吸引中品/上品买家 |
| 暗市大额交易 | 中品 | 20-80中品 | 暗市中的大宗违禁品交易以中品结算 |
| 特殊事件奖励 | 上品灵石 | 1-5上品 | 完成关键剧情事件（如协助宗门度过危机）可能直接奖励上品 |
| 随从外出惊喜 | 上品灵石 | 1上品（极低概率） | 随从外出时，极小概率带回一块上品——触发特殊对话 |

**第一次"收到"中品灵石时的反馈**：

玩家完成第一笔宗门订单后，结算界面显示的不是"收入5000下品"，而是——"收入50中品"。灵石图标是绿色的，不是灰色的。入账音效不同。宁秩会说一句：

> "中品灵石啊……以前在宁家见过不少，自己赚到倒是第一次。"

这个瞬间让玩家感受到自己进入了一个新的层次——不是数字变大了，是货币本身升了一级。

**第一次"收到"上品灵石时的反馈**：

玩家在完成某个重要剧情事件（如协助万木灵宗度过世界树危机）后，结算界面显示"收入3上品"。灵石图标是金色的。宁秩沉默了一会儿：

> "上品灵石。以前只在账本上见过这个数。"

**设计意图**：高阶灵石不只是"换算单位"，它们是玩家经营层次提升的真实标志。第一次赚到中品、第一次赚到上品——这些瞬间应该和玩家第一次租铺面、第一次招随从一样，是游戏中的重要里程碑。

### 经济规则：灵石价值稳定，物价分层

**核心原则**：灵石的价值在整个游戏中保持稳定。不会因为玩家后期有钱了就通胀。

但**物价本身有天然层次**：
- 低级货（凡品、基础灵材）一直便宜 —— 但玩家后期也不太需要这些了
- 高级货（宝品、仙品、稀有灵材）本来就贵 —— 玩家去的地方决定了消费层次
- 玩家从中期开始，交易的对象变了：不再是散修，而是宗门采购、拍卖会——这些场景的金额天然就高

> 玩家不是"灵石贬值了"，而是"你开始玩更高端的局了"。凡人觉得100灵石很多，金丹期修士觉得100灵石掉地上都懒得弯腰——同一个世界，不同层次的人，不同的物价感知。

## 二、物价基础

### 基准物价表（灵品级，中央荒原市场参考价）

| 品类 | 基准价（下品灵石） | 说明 |
|------|------------------|------|
| 低阶灵草（赤炎草/寒露草） | 50-100 | 最基础交易品 |
| 中阶灵草 | 200-500 | 练气期刚需 |
| 低阶矿石 | 80-150 | 炼器基础材料 |
| 灵兽材料 | 150-400 | 看部位和兽种 |
| 基础丹药 | 200-800 | 看品级和功效 |
| 低阶法器 | 1000-5000 | 消耗品 |
| 灵品玄冰髓 | 2000 | 寒渊宗垄断货 |
| 灵品灰灵壤 | 1500 | 炎狱域特产 |
| 灵品金灵砂 | 800 | 用量最大的通用材料 |
| 灵品渊灵珠 | 5000 | 深海域硬通货 |

### 品阶价格倍率

| 品阶跨度 | 价格倍率 | 举例 |
|---------|---------|------|
| 凡品→灵品 | ×5 | 100→500 |
| 灵品→宝品 | ×10 | 500→5000 |
| 宝品→仙品 | ×50 | 5000→250000 |

> 仙品价格跳得厉害，因为仙品根本不是"日常用品"，每一件都是传说，定价没有参考标准。

### 价格波动因素

| 因素 | 影响幅度 | 说明 |
|------|---------|------|
| 产地价差 | -20%~+50% | 产地便宜，外地贵 |
| 灵潮期 | -30%~+50% | 丰收降价，紧缺涨价，看具体品类 |
| 供需关系 | -20%~+100% | 有宗门大量收购时价格暴涨 |
| 板块距离 | +10%~+100% | 越远越贵，深海域最极端 |
| 商道值 | -10%~+10% | 商道高→进价低一点 |
| 特定事件 | 不定 | 火山喷发后灰灵壤暴跌、寒渊宗庆典玄冰髓涨价 |

## 三、经济运行底层逻辑

> 灵墟的经济为什么不会崩盘？不是因为"设定如此"，而是因为**有几个天然的稳定机制在起作用**。

### 3.1 灵石总量控制（防通胀）

**灵石不是凭空产生的。** 修士用的灵石来自灵石矿脉，而矿脉的产量是有限的。

| 灵石来源 | 说明 | 对玩家的影响 |
|---------|------|------------|
| **灵石矿脉开采** | 五大板块都有矿脉，但产量稳定，不会突然暴增 | 你不会看到灵石突然贬值 |
| **修士猎杀灵兽/采集灵材出售** | 这是修士获取灵石的主要方式 | 顾客的钱来自他们自己的劳动，不是系统刷的 |
| **宗门发放俸禄** | 宗门弟子定期领俸禄 | 宗门采购有预算上限 |
| **任务奖励** | 散修完成委托获得报酬 | 同样来自其他修士的腰包 |

**灵石总量不变，只是在不同人手里流转**——玩家赚的每一块灵石，都是别人花出去的。没有"系统凭空刷钱"的环节。

### 3.2 灵石回收机制（防通缩）

如果灵石只在玩家之间流转，总量不变，那理论上玩家会越来越有钱。但灵墟有几个**天然灵石回收渠道**：

| 回收方式 | 说明 | 谁在收 |
|---------|------|--------|
| **传送阵使用费** | 每次使用消耗大量灵石，灵石真的被消耗掉了 | 传送阵维护方 |
| **宗门供奉/税收** | 宗门和城主府收的灵石不再流通 | 宗门、城主府 |
| **炼丹/炼器消耗** | 炼丹炼器失败的损耗 | 材料化为乌有 |
| **天道熔炼报废** | 熔炼失败，灵材和投入的"感觉"一起消散 | 天道本身 |
| **修士修炼消耗** | 修士修炼要吸收灵石中的灵气，吸完就变成废石 | 每一位修炼者 |
| **跨域传送货物损耗** | 长途运输中的自然损耗 | 运输过程本身 |
| **灵兽/妖兽吞噬** | 有些妖兽会吞食灵石 | 野生灵兽 |

> **灵墟的经济是一个闭环**：矿脉产出 → 修士赚取 → 玩家交易 → 各方消耗 → 灵石回归天地。总量动态平衡，不会无限膨胀。

### 3.3 顾客的钱从哪里来？（微观层面）

玩家卖货的顾客不是"刷出来"的NPC，他们的购买力有来源：

| 顾客类型 | 灵石来源 | 购买力上限 |
|---------|---------|-----------|
| 散修 | 猎杀灵兽、采集灵材出售、完成委托 | 有限，花完要去赚 |
| 宗门采购 | 宗门仓库拨款，有预算上限 | 一个采购周期内花完就没了 |
| 炼药师/炼器师 | 卖成品丹药法器的收入 | 取决于他们的生意好不好 |
| 急需客 | 可能有积蓄，也可能是借的 | 愿意多花但总量也有限 |
| 老顾客 | 稳定的收入来源 | 反复光顾但每次金额不大 |

**核心机制**：顾客的灵石花完了不会立即刷新。他们会离开一段时间（去赚灵石），然后带着新灵石回来。这也形成了**客流的自然节奏**——不会出现无限购买的情况。

### 3.4 大宗交易的资金上限

拍卖会、宗门采购等场景不会出现"买家无限加价"的情况：

| 场景 | 资金上限规则 |
|------|------------|
| 宗门采购 | 每次采购有预算上限，花完了要等下个季度拨款 |
| 拍卖会竞拍 | 每位宾客的灵石携带量有限，超出需当场以物抵价 |
| 暗市大额交易 | 同样受限于对方随身携带的灵石量 |
| 散修买高品阶物品 | 散修买不起宝品——他们的客户群天然过滤了超出消费能力的需求 |

> 顾客不是行走的钱包——他们有自己的经济状况。**玩家的定价权从来不是无限的**。

### 3.5 灵石的宏观流转图

```
       灵石矿脉（有限产出）
            │
            ▼
     ┌──────────────┐
     │  修士群体     │  ← 散修、宗门弟子、各方势力
     │  (赚取灵石)   │
     └──────┬───────┘
            │
            ▼
     ┌──────────────┐
     │  玩家店铺     │  ← 玩家在这里赚差价
     │  (灵石流转)   │
     └──────┬───────┘
            │
            ├──→ 进货成本 → 上游供应商/采集者
            ├──→ 商路运费 → 运输方消耗
            ├──→ 摊位/租金 → 城主府
            ├──→ 拍卖会/暗市 → 各方抽成
            ├──→ 装修/雇人 → 建筑/人工
            ├──→ 宗门供奉 → 宗门仓库
            ├──→ 熔炼报废 → 天道回收
            └──→ 玩家积蓄 → 买房/升级/投资
                    │
                    ▼
            最终流向：修炼消耗 + 传送阵 + 税收
            （灵石回归天地/被消耗）
```

> 没有无限刷钱、没有无限顾客、没有无限预算。灵墟的经济是**可持续的**。
