# 随从/雇员系统设定

> 从一个人扛到一支队伍，从"什么都要自己做"到"有人帮你分担"。雇员的成长就是玩家的成长。

---

## 一、设计目标

1. **缓解玩家的操作压力**：随着店铺扩大，玩家不可能一个人搞定所有事——雇员来分担
2. **创造新的决策维度**：招谁？培养谁？派去做什么？——每一个选择都有代价
3. **情感联结**：雇员不只是工具人，他们有性格、有成长、可能跟玩家产生羁绊
4. **经营升级的标志**：从光杆掌柜到带着一帮人，本身就是成就感的来源

---

## 二、雇员来源

| 来源 | 解锁阶段 | 说明 |
|------|---------|------|
| **招募公告** | 中期（商道>20） | 在中央荒原贴告示招人，基础来源，各色人都有 |
| **散修自荐** | 随机事件 | 某个散修主动上门求收留，可能捡到宝也可能招到麻烦 |
| **宗门推荐** | 与宗门关系友好后 | 宗门推荐的人更可靠，但人情债要还 |
| **暗市"买人"** | 去过暗市后 | 暗市有人口交易，能买到能力特殊的随从，但影响商道值 |
| **剧情获得** | 特定剧情节点 | 剧情中遇到的人可能加入 |
| **老顾客转化** | 多次交易后 | 有些老顾客相处久了，愿意来帮你干 |

---

## 三、雇员基础属性

### 属性面板

| 属性 | 范围 | 说明 |
|------|------|------|
| **修为** | 凡人~金丹 | 影响能执行的任务类型（去危险区域需要修为够） |
| **商道** | 1-100 | 影响独立经营的效率、议价能力 |
| **忠诚** | 1-100 | 影响是否会背叛、偷拿货物、被挖走 |
| **体力** | 1-100 | 每天能做的事有限，累了效率下降 |

### 特长标签（每个随从携带1-2个）

| 特长 | 效果 |
|------|------|
| **眼力毒** | 进货时更容易挑到好货（品阶鉴微加成） |
| **口才好** | 派去卖货时成交价更高 |
| **账目清** | 管理仓库时盘点更精准、损耗更低 |
| **路路通** | 跑商路时运费折扣、安全度提升 |
| **人缘好** | 和NPC打交道时好感度容易提升 |
| **手巧** | 协助熔炼时有微小的概率加成 |
| **能打** | 修为高于面板显示（隐藏属性，遇到劫修时有用） |
| **识货** | 能识别出特殊/隐藏价值的物品 |

## 四、雇员可执行的任务

| 任务类型 | 说明 | 需要什么特长 |
|---------|------|------------|
| **看店卖货** | 玩家不在时雇员可以独立接待顾客，成交额按比例算 | 口才好 |
| **外出进货** | 派去其他板块采购，可能拿到比玩家更便宜的价 | 眼力毒、路路通 |
| **管理仓库** | 自动整理库存、提醒补货、减少自然损耗 | 账目清 |
| **押送商路** | 随商队押货，降低被劫概率 | 能打 |
| **打探消息** | 去特定区域收集情报（拍卖会信息、价格波动等） | 人缘好 |
| **协助熔炼** | 帮忙准备材料、记录配方 | 手巧 |
| **拓展人脉** | 代玩家去拜访宗门/势力，维护关系 | 人缘好 |
| **独立经营分店** | 后期把雇员派去其他板块开分店（坐收利润） | 商道高+任意特长 |

## 五、忠诚与风险

### 忠诚度变化

| 行为 | 忠诚变化 |
|------|---------|
| 按时发工资 | +1/月 |
| 发奖金 | +3~10 |
| 派危险任务 | -3~10 |
| 长时间忽视（不安排任务不交流） | -2~5/月 |
| 被别的商会挖角 | 触发事件，可能降忠诚 |
| 发现你坑他 | -10~30 |

### 忠诚度带来的风险

| 忠诚度 | 可能发生的事 |
|--------|------------|
| >80 | 可靠，偶尔自发做事 |
| 60-80 | 正常干活，不出错也不主动 |
| 40-60 | 效率下降，可能出现小失误 |
| 20-40 | 可能偷拿货物、消极怠工 |
| <20 | 可能背叛——带着货物跑路、或把商业机密卖给竞争对手 |

### 雇员背叛事件

当忠诚度降至20以下，有一定概率触发背叛事件：
- 情节轻的：偷了几件灵材跑了
- 严重的：带着一批货跑了，甚至投靠竞争对手
- 极端的：出卖玩家的商业机密（进货渠道、暗市身份等）

> 忠诚度是玩家需要持续投入的管理成本。光发工资不够，还需要偶尔关心一下。

## 六、雇员培养

### 培养方式

| 方式 | 效果 |
|------|------|
| **分配任务** | 做得多→对应能力提升（派去卖货→口才涨） |
| **送礼物** | 提升忠诚度+可能解锁隐藏特长 |
| **传授经验** | 玩家可以花时间亲自教（消耗玩家行动次数） |
| **提供修炼资源** | 提升修为属性（需要花费灵石） |
| **共同冒险** | 带雇员一起出远门做任务→全面提升 |

### 成长上限

每个随从的成长有上限（天赋决定），但通过培养可以突破部分限制。少数随从有极高的成长天花板，属于"值得培养的核心班底"。

## 七、雇员数量与团队管理

### 可雇佣上限

| 阶段 | 最大雇员数 | 说明 |
|------|-----------|------|
| 前期（小摊） | 0~1 | 养不起也管不过来 |
| 中期（铺面） | 2~4 | 主力雇员 |
| 后期（商楼） | 5~8 | 团队化运营 |
| 鼎盛（连锁） | 10+ | 各板块分店都需要人 |

### 团队管理界面

- 雇员列表：头像+名字+当前状态（看店中/外出中/休息/空闲）
- 拖拽分配任务
- 忠诚度/体力条可视化
- 雇员对话：点击雇员可以聊天，有时会触发特殊对话或事件

---

## 八、与现有系统的联动

| 现有系统 | 联动方式 |
|---------|---------|
| **看店卖货** | 玩家不在时雇员可以替代——扩大单日经营时长 |
| **商路系统** | 派雇员押送货物可降低风险 |
| **暗市** | 有些暗市任务可以派雇员代去（但要承担被抓住的风险） |
| **拍卖会** | 可以派雇员去打探拍卖会内幕消息 |
| **时间系统** | 雇员的体力和任务耗时构成了新的资源管理维度 |
| **管家** | 管家会帮忙管理雇员的日常安排、提醒你谁忠诚度低了 |
| **好感度与声望** | 善待雇员会微微提升"人心"值；虐待雇员则会降低 |
