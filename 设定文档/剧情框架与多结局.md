# 剧情框架与多结局设计

> 核心：结局不是选出来的，是活出来的。你每一天的经营行为，都在悄悄改变世界的走向。

---

## 一、剧情设计理念

### 核心设定：灵墟的终局

灵墟世界是有寿命的。

天道之核破碎后，五块碎片被冲击波推离了彼此。那股力量并没有消散——它像一种看不见的斥力，持续地、缓慢地将碎片推离远离。这个速度原本极慢，以万年为单位——对于任何个体生命来说，都漫长到可以忽略不计。

但三百年前的天裂之战改变了这个进程。

天裂——那条横贯天际的空间裂缝——本质上是天道碎片互相推离时在灵墟世界表面撕开的一道伤口。天裂之战的封印延缓了裂缝的扩张，但它没有阻止碎片的漂移。封印只是让裂缝不再扩大——而碎片依然在远离。

**更关键的是：每一次灵潮大周期，斥力都会增强一分。**

灵潮本质上是五块碎片试图同步、却因为距离太远而失败时产生的"共振回响"。每一次失败的回响都在加剧碎片之间的不稳定性。

按照这个速度，灵墟的灵气将在**大约一百年内**——而不是一万年内——消散殆尽。

宁秩的寿命，恰好覆盖了这个过程的全周期。

**在宁秩出现之前，没有人能真正感知到碎片的"尽数"——因为要感知五块碎片的状态，需要五种灵根同时共振。单一灵根的修士只能感觉到自己那块碎片的波动，无法拼凑出全貌。**

宁秩是第一个能感知到全貌的人。

他的杂灵根就像一台五频道的收音机。别人只能收一个台，他可以收五个。当他天道熔炼的能力越来越强、感知越来越清晰时，他会逐渐意识到一个让他脊背发凉的事实——

**五块碎片的频率正在缓慢地、不可逆地加速偏移。它们正在加速远离彼此。**

按照他现在感知到的偏移速度——大约还有一百年。一百年后，灵墟将不再有任何灵气。

**一个凡人一生的长度，恰好是灵墟剩下的时间。**

这不是巧合。碎片选择了他——因为只有他能在一百年内做完需要做的事。

### 三条暗线与湮灭进度的关联

三条暗线不是独立于世界线之外的装饰性数值。它们直接影响玩家探索灵墟真相的能力：

| 暗线 | 对探索的作用 | 越高越容易…… |
|------|------------|-------------|
| **商道** | 信息网络 | 触发线索（与大商会/宗门的交易越多，接触到秘密的概率越大） |
| **天道** | 感知能力 | 理解线索（更高的天道值意味着宁秩能"读懂"碎片传递的信息） |
| **人心** | 信任资本 | 降低线索门槛（NPC更愿意向一个值得信任的人吐露真话） |

**具体机制**：

- **商道≥40**：线索"寒渊宗的报价单"触发概率从30%提升到60%
- **商道≥60**：线索"铸魂殿的未完成品"触发概率从20%提升到50%
- **天道≥30**：触发线索"商路尽头的不安"时，宁秩的感知时间从1秒延长到3秒——他能感受到更多细节
- **天道≥50**：触发线索"世界树的呻吟"时，宁秩能听出世界树的"叹息声"来自哪个方向（指向苍木域碎片的位置）
- **人心≥30**：老管家"欲言又止"线索触发后，宁秩追问时管家会多说一句——"那位游方修士还说了一句话……他说'碎片在找一个人'。但老奴不确定他说的'找'是什么意思。"
- **人心≥50**：暗市掮客在提及"那条通道"时，会多透露一句——"守夜人的首领说过——那扇门后面的东西，比整个暗市加起来都重。"

**三条线合一的影响**：

当三条暗线同时达到一定水平时（商道≥50 且 天道≥40 且 人心≥40），宁秩会在某个夜晚——在天道熔炼后的余温中——自动触发一次"顿悟"：他不需要任何线索就知道了一件事——**碎片在试图联络他**。不是通过语言，不是通过图像，而是一种凌驾于五感之上的"知道"。

这个"顿悟"会将其余所有线索的触发条件降低一个等级（比如原本需要大宗交易的线索，现在普通交易也能触发了）。也会在灵墟归途结局的最终抉择中，让宁秩更清楚地知道自己在做什么。

> 商道铺路，天道读懂，人心开口。三条线合在一起，才是一个完整的故事。

### 玩家的选择权

基于这个核心设定，玩家在游戏中始终有两条路可选：

| 路径 | 主动探索世界真相 | 只管经营 |
|------|---------------|---------|
| **行为方式** | 深入调查暗市、接触各宗门秘辛、寻找天道碎片的线索 | 经营商会、赚钱、过自己的日子 |
| **需要做什么** | 主动走商路去各板块、花灵石买情报、触发特定剧情事件 | 正常经营即可 |
| **最终结局** | 多元结局（商道/天道/人心/复合/隐藏） | 固定走向灵墟湮灭结局 |
| **通关时长** | 约60-80小时（一周目标准时长） | 可以持续游玩到宁秩寿终正寝 |

**最关键的设计：这是一条隐藏的"倒计时"。**

如果玩家只经营、不探索——商道可能很高、灵石可能很多——那么宁秩会像一个普通的凡人商人一样，活到七八十岁，寿终正寝。

在他闭眼的那个瞬间，灵墟——五块彻底失去最后一丝联系的天道碎片——将无法继续维持板块的稳定。灵墟世界在宁秩死后不久崩塌。

**玩家可能经营了一辈子，都不知道灵墟曾经有一个可以救赎的机会。**

> 这不是"惩罚"不探索的玩家。这是一个世界观层面的设定——世界不是围绕玩家转的。如果没有人去修复它，它就会终结。玩家可以选择成为那个"不关心世界命运的人"，而世界也会相应地给出它的结局。

### 关于真相的获得方式

玩家不需要"寻找真相"。真相会**主动接近**玩家——前提是玩家走对了路。

| 触发方式 | 说明 |
|---------|------|
| 天道熔炼达到一定层级 | 宁秩自己能感知到碎片的异常 |
| 与大事件中的关键人物对话 | NPC会透露秘密（如果你值得信任） |
| 阅读特定书籍/物品 | 初代宗主留下的遗物 |
| 探索特定区域 | 寒渊宗的冰窟、暗市最深处、沧溟宫的海渊 |
| 主动向管家提问 | 管家知道一些事——但他不会主动说，除非宁秩问 |

> 真相**不是通关奖励**。它是游戏世界自身的秘密——你如果想知道，就得自己花时间去挖。你可以不挖，照样能玩得很开心。只是世界会走向湮灭。

## 二、剧情节点（按时间线）

> 以下事件按照**游戏内时间**排列。部分事件有触发门槛，部分事件为固定触发。事件之间的"静默期"留给玩家自由经营。

---

### 第一章：荒野求生（游戏第1-3个月，现实≈15小时）

> 关键词：陌生、摸索、第一次

#### 事件1：逃离宁家 · 开幕

| 项目 | 内容 |
|------|------|
| **触发时间** | 游戏第1天 · 辰时（上午） |
| **触发条件** | 游戏开始即触发 |
| **具体内容** | 宁秩背着一个小包袱走出了宁家洞府所在的山谷。包袱里只有两样东西：一袋灵石（30块下品）和一本《灵墟商事录》（老管家塞的）。走到谷口时，他回头看了一眼——没有人追出来，也没有人送。他深吸一口气，走向了中央荒原的方向。<br><br>老管家没有给他传讯玉简，因为老管家手上也没有不需要灵力就能用的玉简。老管家只是说了一句："少爷，老奴不便与您同行。但您若有什么想知道的，随时问老奴——虽然老奴也不知道这传讯能不能通。"他递给宁秩一枚普通的传讯玉简，但那东西需要灵力激活。宁秩试了试，果然不行。<br><br>宁秩把那枚没用的玉简收进包袱里，没有扔掉。他说不清为什么——可能是老管家给的东西，舍不得丢。 |
| **管家第一句话** | （此时还没有玉简通信。管家的第一句话是在事件6——第一次天道熔炼之后——才传来的。） |
| **玩家获得** | 灵石×30、《灵墟商事录》 |
| **后续影响** | 第1天傍晚玩家收摊时，会在摊位附近发现几块废弃的耐火砖和一块破铁板。宁秩独白后自动搭起一个简陋小熔炉——这是玩家第一个熔炉，也是第一次天道熔炼的舞台。无特殊交互，熔炉在夜间才可使用。 |

#### 事件2：第一笔交易

| 项目 | 内容 |
|------|------|
| **触发时间** | 第1天 · 玩家第一次摆摊后 |
| **触发条件** | 摆好摊位，有一件商品可卖 |
| **具体内容** | 第一位顾客是一位衣着朴素的中年散修。他在摊位前站了一会儿，拿起一株灵草看了看，又放下。"小伙子，新来的吧？"他笑了笑，"这株赤炎草成色还行，但你这个价定高了。我给你个实价——爱卖不卖。"（无论成交与否，他都会留下这句话） |
| **NPC登场** | 散修·老赵（第一位顾客，后续会作为老顾客不定期出现） |
| **玩家学到** | 讨价还价的基本操作 |
| **后续影响** | 老赵在后续第7天左右会再次出现，成为第一个"熟面孔" |

#### 事件3：第一个预约订单

| 项目 | 内容 |
|------|------|
| **触发时间** | 第2-3天 |
| **触发条件** | 玩家遇见一个需要自己没有的货的顾客 |
| **具体内容** | 一位炼药师的徒弟来买"寒露草"，你没有货。他说："我家师父急需这个练一炉清心丹，你要是能三天内弄到，我按市场价加两成收。"（如果玩家接受，触发预约取货流程；如果拒绝，他会失望离开，后续换个顾客再来触发） |
| **玩家学到** | 预约取货系统、承诺与信用的重要性 |
| **后续影响** | 按时交货→这位炼药师的徒弟会成为回头客<br>逾期/失约→失去一个潜在客户，但不会致命 |

#### 事件4：暗市掮客

| 项目 | 内容 |
|------|------|
| **触发时间** | 第5-10天（最早第5天，最晚第10天） |
| **触发条件** | 玩家当天收摊时触发的随机事件 |
| **具体内容** | 傍晚收摊时，一个穿着斗篷、看不清面容的人无声无息地出现在摊位旁。"你在找好货。"他说。不是疑问句，是陈述句。"中央荒原地下有个地方，那儿卖的东西你这摊位上永远不会出现。想看看的话，明晚酉时，城西枯井旁见。来不来随你。"说完他转身消失在暮色中。 |
| **NPC登场** | 暗市掮客（无名，后续暗市相关事件的引路人） |
| **玩家解锁** | 暗市入口线索 |
| **后续影响** | 去→触发事件5、解锁暗市<br>不去→第二天晚上掮客不会再出现，但后续（第20天左右）会通过另一个方式接触到暗市——总归要去的 |

#### 事件5：暗市初体验

| 项目 | 内容 |
|------|------|
| **触发时间** | 事件4的第二天晚上 |
| **触发条件** | 接受了掮客的邀请，酉时到城西枯井 |
| **具体内容** | 枯井下面是一条隐秘的地道。走到底，眼前豁然开朗——一个灯火通明的地下集市。掮客递过来一个面具："戴上还是直接进去，你自己选。戴了没人认出你，但不戴更容易交到朋友——也更容易结仇。" |
| **玩家解锁** | 暗市（进入方式、戴面具/不戴面具的机制） |
| **后续影响** | 戴面具→暗市掮客好感+0，商道不受影响<br>不戴面具→暗市掮客好感+5（"有胆色"），商道-2 |

#### 事件6：第一次天道熔炼——传讯玉简

| 项目 | 内容 |
|------|------|
| **触发时间** | 玩家收集到至少3件凡品灵材后，夜晚在摊位/住处 |
| **触发条件** | 持有≥3件凡品灵材 |
| **具体内容** | 宁秩坐在摊位后面的小油灯前，面前摆着三件凡品灵材——一株赤炎草、一块铁精矿、一把寒露草。这些是他在中央荒原能买到的最便宜的东西了。鬼使神差地，他想起了《灵墟商事录》里老管家随手写的那句话——"有时候同品阶的灵材放在一起，会有种奇怪的感觉。"<br><br>他把三件灵材一起投进了临时搭起的小熔炉。炉火猛地一亮，却没有爆炸，没有烧毁——三件凡品灵材在火焰中融化成了一团流动的光。光团缓缓凝聚，固化，最后落在宁秩掌心——一枚通体温润、泛着淡蓝色微光的玉简。<br><br>宁秩愣住了。他认得这东西——这是传讯玉简。修士用来远程通信的法器。但它和普通的玉简不一样，它没有灵气回路，没有阵法刻印，没有需要灵力激活的符文。但它确实在发光，确实散发着"宝品"的气息。<br><br>宁秩试探着碰了碰它，一个念头浮现在他脑海中——他不知道这个想法从哪来的，但他知道这是真的：**这枚玉简不需要灵力来激活。它自己会记住谁碰过它，然后让碰过它的人之间能互相传讯。**<br><br>他小心翼翼地对着玉简说了一句话，然后把它放在桌上。过了很久——久到宁秩以为它坏了——玉简里传来一个颤抖的声音。<br><br>"……少爷？"<br><br>是老管家。 |
| **物品设定** | **无名玉简（玩家后来自行命名）**<br>品阶：宝品<br>五行：无（三件不同属性凡品熔炼出的异变产物，五行属性中和了）<br>特性：无需灵力激活，触碰即可绑定。触碰过的两个人之间可以通过玉简传讯。没有距离限制——至少在灵墟范围内没有。<br>来历：宁秩第一次天道熔炼的产物。三件凡品灵材在熔炼中发生了异变，融合成了一枚不符合任何法器分类的传讯玉简。没有人能解释它为什么不需要灵力。正如没有人能解释天道熔炼为什么存在。<br>**剧情意义**：这是宁秩与老管家之间唯一的通信渠道，也是宁秩在这个世界上极少数不需要提防的联系。 |
| **老管家的第一反应** | 玉简那边沉默了很久。老管家的声音带着宁秩从未听过的情绪——不是震惊，不是担忧，是一种很复杂的东西。"少爷……您刚才说，这是您自己熔出来的？"又沉默了一会儿。"老奴活了这么多年，从未听说过凡品灵材能熔出宝品的东西。从未听说过。"<br><br>他没有追问宁秩是怎么做到的。他只是说："少爷，这东西您收好。别让任何人知道它的来历。" |
| **玩家解锁** | 天道熔炼系统 + 管家通信系统 |
| **后续影响** | 1. 玉简的存在解释了为什么宁秩（零修为）可以和老管家远程通信——不是靠灵力，是玉简自己记住了他们<br>2. 玉简是唯一的，不能复制。如果丢了/坏了，宁秩就失去了和老管家的联系<br>3. 随着剧情发展，宁秩可能会发现这枚玉简还有更多未解锁的功能（比如绑定第三个人、储存信息等）

#### 事件7：月底结算 · 第一次

| 项目 | 内容 |
|------|------|
| **触发时间** | 第30天 · 过夜时 |
| **触发条件** | 满一个月 |

### 第二章：站稳脚跟（游戏第3-9个月，现实≈30小时）

> 关键词：扩张、关系、抉择

#### 事件8：第一个老顾客

| 项目 | 内容 |
|------|------|
| **触发时间** | 第3个月左右 |
| **触发条件** | 与同一个NPC累计交易≥3次 |
| **具体内容** | 老赵（开幕时的第一个顾客）又来了。这次他没有议价，直接按标价买了三株灵草。临走前他说："宁掌柜，我在你这儿买了小半年的东西了。说句实话——你比天道商会那些家伙靠谱。他们连正眼都不看我这种散修，你至少会问一句'最近怎么样'。"他顿了顿，"以后有好货，先给我留一份。" |
| **系统解锁** | 老顾客系统——特定NPC会重复出现，好感度开始积累 |
| **后续影响** | 解锁"回头客"机制。老顾客越多→每日客流量越稳定 |

#### 事件9：第一个随从

| 项目 | 内容 |
|------|------|
| **触发时间** | 第3-4个月 |
| **触发条件** | 商道>20 或 触发过老顾客事件 |
| **具体内容** | 三种可能的触发方式（按玩家的行为选择触发其一）：<br><br>**A. 散修自荐**（最常见）：一个年轻散修在收摊时犹豫地走过来："掌柜的……我看你这里生意越来越好，一个人忙不过来吧？我会算账，还认识几种灵草。管吃住就成。"<br><br>**B. 老顾客推荐**（如果玩家人心值较高）：老赵带来一个年轻人："这是我侄子，在老家待不下去了。你给他口饭吃，他帮你干活，行不？"<br><br>**C. 暗市买人**（如果玩家去过暗市）：暗市掮客带来一个沉默寡言的人："这人修为不错，能打。你要不要？价钱好说。"（价格比前两种贵，但能力更强） |
| **NPC登场** | 取决于触发方式——要么是小林（年轻散修）、要么是小赵（老赵侄子）、要么是某个无名随从 |
| **玩家解锁** | 随从/雇员系统 |
| **后续影响** | 第一个随从会在很长一段时间里是你的主要帮手。善待他→他会成长为核心成员；虐待他→他可能走人 |

#### 事件10：第一次拍卖会

| 项目 | 内容 |
|------|------|
| **触发时间** | 第3-5个月 |
| **触发条件** | 商道>20 或 获得拍卖会请柬 |
| **具体内容** | 管家发来消息："少爷，天道商会三日后在万宝楼有一场拍卖会。老奴打听到有几件罕见的灵品灵材要出手——如果少爷有闲钱，不妨去看看。入场需缴500灵石押金。"<br><br>（如果玩家押金不够，管家会补充："老奴可以先行垫付，但下月要从您的利润里扣。"） |
| **NPC登场** | 拍卖师（万宝楼特约）、各路买家 |
| **特殊可能** | 有一定概率在拍卖会上遇到**宁家的人**——不是父亲，是商会的一个老采购。他看到宁秩但装作没看到。离场时，宁秩发现自己桌上的竞拍牌被人留了一张纸条："你长大了。——刘叔" |
| **玩家解锁** | 拍卖会参与系统 |
| **后续影响** | 参加拍卖会→商道+2，获得潜在人脉<br>不参加→管家不会说什么，但下次拍卖会可能要等一个月 |

#### 事件11：宁家来人

| 项目 | 内容 |
|------|------|
| **触发时间** | 第4-5个月（固定触发，不依赖任何数值） |
| **触发条件** | 时间到达第4个月后，某天收摊时 |
| **具体内容** | 一个头发花白的老者站在摊位不远处。宁秩认出了他——宁家的老仆人，刘伯。刘伯走过来，没有行礼，只是站在那里看了宁秩一会儿。"少爷……你瘦了。"他的声音有些沙哑。"老爷让我来看看你过得好不好。他什么都没说，就说'去看看那小子还活着没'。"<br><br>刘伯递过来一个钱袋："这是老爷给的？不是。这是我自己的私房钱。少爷，你在外面做什么都行，但别碰暗市。别碰违禁的东西。宁家的名声……你大哥在撑着，不容易。"<br><br>刘伯不等宁秩回答，转身走了。走出几步，又回头："少爷，你要是真想家……随时可以回来。" |

| **后续影响** | 这是宁家第一次正式知道宁秩的动向。不管玩家态度如何，这个事件会在宁秩心里埋下一个钩子——家和家族的重量。 |

| **后续影响** | 取决于玩家的应对——可能大赚一笔、可能血亏、可能发现隐藏商机。这次事件的表现会影响管家对你的评价（"少爷有胆识"或"少爷谨慎些也好"） |

#### 事件13：宗门第一次接触

### 第二章收束

第二章结束时，玩家应该已经：
- 有了稳定的客源和多条收入渠道
- 至少与一个宗门建立了合作关系
- 接触过暗市并做出了自己的选择（深入或疏远）
- 经历了第一次灵潮大事件
- 拥有了第一个随从
- 开始跨域贸易

> **第二章的核心矛盾**：你已经不再是那个"第一天摆摊的新人"了。但这也意味着——有人开始注意你了。

### 第三章：风口浪尖（游戏第9-18个月，现实≈40小时）

> 关键词：博弈、阵营、代价

#### 事件16：天道熔炼的真相

| 项目 | 内容 |
|------|------|
| **触发时间** | 第9-12个月 |
| **触发条件** | 天道值≥45 或 累计熔炼次数≥20 |
| **具体内容** | 在一次成功的升品熔炼中，宁秩在炉火燃起的那一刻看到了幻象——不是灵材的结构，而是五行本源的流动。他看到了木生火、火生土、土生金、金生水、水生木——完整的相生循环在他眼前一闪而过。<br><br>他愣了很久。然后他意识到了一件他从未想过的事：他的杂灵根不是五种灵根乱七八糟地混在一起。它们**齐全**。别人只有一种灵根，所以只能感知一种灵材的属性。他有五种。所以他才能"听到"灵材之间的共鸣。<br><br>老管家的玉简亮了。但这一次，宁秩先开口了："管家……熔炼不是我在操作灵材。是灵材在引导我。"<br><br>玉简那头沉默了很久。"……少爷，您终于感觉到了。" |
| **玩家解锁** | 熔炼感知升级——从此可以看到五行相性提示 |
| **后续影响** | 天道值达到该里程碑后，后续熔炼的体验完全不同——不再盲赌了 |

#### 事件17：世界树之殇

| 项目 | 内容 |
|------|------|
| **触发时间** | 第6-10个月 |
| **触发条件** | 时间触发，与玩家行为无关 |
| **事件背景** | 万木灵宗的上古世界树开始枯萎。世界树之液产量暴跌，价格暴涨10倍。苍木域所有灵材价格同步上涨。万木灵宗封锁了消息，但暗市上早已传遍 |
| **玩家可做的事** | - 囤货/倒卖世界树之液（利润极高，但万木灵宗好感大降）<br>- 接万木灵宗的委托——寻找救治世界树的方法<br>- 调查世界树枯萎的真正原因（可能涉及暗市情报、潜入苍木域）<br>- 什么都不做（不影响游戏进程，但苍木域经济格局永久改变） |
| **结局** | 世界树的最终命运不由玩家决定，但玩家在事件中的选择会影响：<br>- 与万木灵宗的关系<br>- 是否获得稀有物品<br>- 是否发现某些隐藏秘密 |

#### 事件18：商会竞争

| 项目 | 内容 |
|------|------|
| **触发时间** | 第10-14个月 |
| **触发条件** | 商道≥50 |
| **具体内容** | 你的生意已经大到引起注意了。某一天，一个自称"铁算盘商会"的人来到你的摊位——不是来买东西的，是来"谈合作"的。<br><br>"宁掌柜，你在这片混得不错啊。我们东家说了，要么你每月交两成利润当'联合经营费'，要么……我们会在你进货的路上'碰巧'遇到几批货。"<br><br>这是第一次有人明目张胆地威胁你。<br><br>（如果玩家选择了求助：管家可以提供建议、老顾客中有人认识铁算盘的人、暗市掮客愿意"帮忙处理"——但要代价） |
| **玩家面临的选择** | 屈服、对抗、找人调解、借刀杀人……方式很多，但后果各不同 |
| **后续影响** | - 屈服→商道-5，但短期内生意不受影响<br>- 对抗→可能升级为商路劫掠战<br>- 找人调解→人心高的话可以和平解决<br>- 借暗市的手→暗市好感+，但商道- |

#### 事件19：天机子的隐退

|------|------|

| **触发条件** | 商道≥55 或 与天道商会交易累计达到一定额度 |

| **玩家面临的选择** | 支持大义子/二义子/三义子/谁也不支持 |
| **结局** | 不是玩家选谁就是谁赢。最终继承人由多方博弈决定。但如果你支持的人赢了，你会获得长期利益；如果你支持的人输了……小心被清算 |

#### 事件20：五方盟的重聚

### 第三章收束

第三章结束时，玩家已经参与过至少2-3个大事件（取决于你的路线选择）。商道、天道、人心三条线中的至少一条开始明显领先。灵墟的未来格局在你面前展开——你的每一个选择都在缩小可能的结局范围。

> **第三章的核心矛盾**：你已经有能力影响灵墟的走向了。但每一次影响，都有代价。

### 终章：结局（游戏第18-24个月）

结局由三项数值的综合走向决定——不是单一维度够高就行，而是**三个维度的相对关系**。

## 三、结局一览

### 结局类型：按主导维度分

#### 商道结局：商业帝国

> "宁秩不是灵墟最大的修士，他是灵墟最大的商人。"

**触发条件**：商道≥80，且商道显著高于其他两项

**剧情走向**：
- 宁秩的商会成长为灵墟不可忽视的力量
- 天道商会和万宝楼开始认真把你当竞争对手
- 最终——你或许没有颠覆灵墟的商界格局，但你让所有人都记住了你的名字

**终幕**：
宁秩站在自己商会总堂的顶层，看着楼下络绎不绝的客人。老管家的玉简亮起："少爷，今日进账又破记录了。老奴记得您刚来中央荒原时，一天能卖出一株灵草就算大日子了。"

---

#### 天道结局：熔炼之巅

> "他们说我灵根驳杂修炼无望。后来他们发现，是我在触碰他们碰不到的东西。"

**触发条件**：天道≥70，且天道显著高于其他两项

**剧情走向**：
- 宁秩逐渐发现了天道熔炼背后的秘密——它不仅改变灵材，也在改变他自己
- 熔炼到极致时，宁秩的杂灵根产生了某种异变——这不是修炼，但比修炼更接近天道的本质
- 最终——天道的真相是：五行本是一体，杂灵根反而是最完整的灵根。宁秩不是不能修炼，只是修炼的方式和别人不一样

**终幕**：
宁秩将最后一件灵材投入熔炉。这一次没有火花，没有爆炸——灵材在炉中化为一道光，融入他的体内。老管家的玉简沉默了许久，才传来一句话："少爷……您终于找到了自己的路。"

---

#### 人心结局：众望所归

> "他不是一个修为高深的修士。但他在灵墟最黑暗的时候，是所有人愿意相信的人。"

**触发条件**：人心≥80，且人心显著高于其他两项

**剧情走向**：
- 宁秩在各个板块积累了许多朋友和盟友
- 当某个大危机来临时（灵潮大灾/势力冲突/外敌入侵），各方势力不是去找宗门求援，而是来找宁秩
- 最终——宁秩以一介商人之身，调解了宗门之间、正道与暗市之间的冲突

**终幕**：
中央荒原的集市上，有人摆了块匾，上面写着"宁公道"。宁秩摆摆手说撤掉。老管家难得地笑了："少爷，这匾不是老奴让人摆的。是街坊们自己做的。"

---

### 结局类型：维度叠加（复合结局）

当两个维度同时达到较高水平时，会触发**复合结局**：

#### 商道+天道：熔铸商途

> "他炼出来的东西没人见过。他卖出的价格没人能比。"

**触发条件**：商道≥70 且 天道≥60

**剧情走向**：
- 宁秩的商会以"天道熔炼出品"为招牌，成为灵墟最独特的高端灵材供应商
- 其他商会能卖的东西你们也能卖，但你们能卖的东西别人卖不了——这就是护城河

**终幕**：
拍卖会上，一件"宁记熔炼·异变品"拍出了天价。买家是寒渊宗的宗主。她说："我活了八百年，没见过这种成色的东西。宁小子，你是怎么做到的？"

#### 商道+人心：义利天下

> "他不是最会赚钱的商人。但他是所有商人里，最让人放心的。"

**触发条件**：商道≥70 且 人心≥60

**剧情走向**：
- 宁秩的商会不以利润最大化为导向，但在商户和顾客中口碑最好
- 当大商会试图垄断某个市场时，宁秩会选择用"公平贸易"策略对抗——可能利润更薄，但赢得了人心

**终幕**：
灵潮大年来临，物价飞涨。大商会囤货居奇，宁秩却选择平价出售。其他小商户也跟着不涨价。老管家问："少爷，这一季少赚了不少。"宁秩说："下次灵潮来的时候，他们会站在我们这边。"

#### 天道+人心：点石成金

> "他帮过的每一个人，后来都成了他的朋友。而他熔炼时，这些朋友送来的灵材，总能出好东西。"

**触发条件**：天道≥60 且 人心≥70

**剧情走向**：
- 宁秩的"熔炼+人脉"组合带来了一种独特的商业模式——帮人熔炼，不收灵石，只交朋友
- 朋友多了，送来的灵材也就多了；灵材多了，熔炼的经验也就涨了

**终幕**：
宁秩在深夜的熔炉前。老管家的玉简亮起："少爷，老奴今天算了算您帮过的人——散修327位，宗门弟子45位，炼药师18位，还有3位是……元婴期的前辈。您这个朋友交得值。"

---

### 结局类型：全满结局

#### 三道合一：天道归墟

> "他修的不是仙，他修的是灵墟本身。"

**触发条件**：商道≥85 且 天道≥80 且 人心≥85（极难达成）

**剧情走向**：
- 这是游戏中唯一的"隐藏结局"。绝大多数玩家一周目无法触发，需要深入了解系统、精心规划
- 宁秩的三条道路同时达到巅峰——他是最成功的商人、最高明的熔炼师、最受爱戴的朋友
- 灵墟的天道因他而改变——天道熔炼不再是一种赌博，而是被真正理解的艺术

**终幕**：
宁秩站在中央荒原的集市中——他当初支起第一个小摊的地方。他已经不需要再摆摊了，但他还是来了。老管家的玉简亮了最后一条消息："少爷，老奴陪您走了这么多年，今天想跟您说一句——老爷要是看到您现在这个样子，他一定……后悔当年说您'修炼无望'。"

宁秩没有回答。他只是把一件凡品灵草丢进熔炉——这是他第一次熔炼时用的那种最便宜的灵草。炉火亮起，仙品的光辉照亮了整个集市。

> **天道归墟，万物归一。**

---

### 暗面结局：暗市之主

> "他既是商人，也是暗市的影子。"

**触发条件**：暗市交易累计值极高，商道较低或人心较低

**剧情走向**：
- 宁秩逐渐从正规市场转向暗市，成为地下世界的重要人物
- 正道宗门与之决裂，但暗市势力全力支持
- 最终——宁秩接手了暗市的某一部分管理权，成为守夜人之上的"影子商人"

**终幕**：
暗市的地下大殿里，守夜人的首领——一个从未露过面的人——把一枚黑色的令牌放在宁秩面前。"从今天起，这暗市有一半是你的。"宁秩接过令牌，面具之下的表情看不清楚。老管家的玉简没有亮起。这一次，管家没有话要说。

---

### 隐藏结局·序：湮灭的倒计时

> 这个结局不是"你做了一个错误的选择所以得到了坏结局"。它是灵墟世界最深的秘密——藏在每一块灵石、每一次灵潮、每一株灵材的根里。如果你不知道它存在，你永远不会触发它。如果你知道它存在，你要花一整局游戏才能触碰到它的边缘。

#### 贯穿全程的线索链

灵墟湮灭结局的线索不是集中在一个地点或一个事件中的，而是**散落在游戏的每一个角落**。玩家需要将它们拼凑起来，才能理解灵墟真正的命运。

以下八条线索，分布在游戏的各个阶段。玩家即使在一周目触发了灵墟湮灭结局，也只有把线索集齐了，才能在二周目走向拯救路线。

---

**线索一：商路尽头的不安（第3-6个月，解锁条件：第一次跨域贸易）**

宁秩在第一次跨域贸易的途中，经过一条连接两个板块的商路时，在某个瞬间感到一阵莫名的心悸——不是危险，更像是一种"空"的感觉。仿佛有什么东西本应该在这里，但不存在了。

持续时间不到一秒。宁秩以为是错觉。

**触发方式**：第一次跨域贸易时自动触发，无法错过。但玩家此时不会理解这意味着什么。

---

**线索二：老管家的欲言又止（第6-12个月，解锁条件：天道值>30或触发过3次大事件）**

在某次月度简报的末尾，管家发来一条比其他消息都长的玉简讯息：

> "少爷，老奴有一句话憋了很久。以前在宁家的时候，老奴伺候过一位游方修士——他在宁家借住了几天。有一天他喝多了，说了一句很奇怪的话。他说——'这世界的灵气，终有一日会燃尽。'第二天老奴问他，他说他不记得自己说过这话。但老奴记得。"

然后管家不再提这件事。

**触发方式**：玩家在月度简报中正常收到。如果玩家追问（回复玉简），管家只说："老奴也不知道那人是谁。只是突然想起来了。"

---

**线索三：寒渊宗的报价单（第8-14个月，解锁条件：商道>40且与寒渊宗有过至少一次交易）**

在与寒渊宗的交易中，玩家收到的报价单背面有一行手写的小字：

> "玄冰髓的灵气密度比三百年前降低了约百分之七。不影响使用。但……——冰崖"

好像是寒渊宗的外事长老冰崖随手写在草稿上的笔记，被当作废纸装进了报价单里。宁秩注意到了这句话。百分之七，三百年——他算了一下，如果这个趋势不变，大约四千年后玄冰髓将彻底失去灵气。

但宁秩又想：四千年，关他什么事？

**触发方式**：与寒渊宗交易时小概率获得。如果玩家第一次没拿到，后续交易中还会出现。

---

**线索四：世界树的呻吟（第6-10个月，解锁条件：触发世界树之殇事件）**

在世界树之殇事件期间，如果玩家前往苍木域并靠近世界树（不需要进入万木灵宗核心区域，远观即可），宁秩会听到一种声音——不是耳朵听到的，是身体感知到的。像是一棵巨大的树在缓慢地、不可逆转地弯曲。

他旁边的人什么都没听到。

宁秩没有告诉任何人。因为他说不清自己听到了什么。

**触发方式**：在世界树之殇事件期间前往苍木域，自动触发。如果玩家在选择"什么都不做"，仍然会触发——因为这个事件不是玩家能避开的感知。

---

**线索五：暗市最深处的一扇门（第12-18个月，解锁条件：暗市累计交易≥10次且暗市声望达标）**

在暗市最深处，有一条不起眼的通道——大多数暗市常客都不知道它的存在。通道尽头是一扇黑色的门。门上没有锁，没有把手，只有一行刻字：

> "进来的每一个人都问我里面有什么。我告诉他们——里面是灵墟的尽头。没有人相信我。你信吗？——守夜人·无名"

门是锁着的。玩家现在打不开。但门的存在本身就是一条线索——暗市之下，还有更深的东西。

**触发方式**：在暗市声望达到一定程度后，暗市掮客会无意中提及"那条通道"。"别去那边，那边什么都没有。"——他说这话时的表情让宁秩觉得他在撒谎。

---

**线索六：铸魂殿的未完成品（第14-20个月，解锁条件：与铸魂殿关系达到友好）**

如果玩家与铸魂殿的关系足够好（友好以上），钱通在一次闲聊中会提到一件怪事：

> "咱们殿里秘库有块铁板，听说是祖师爷留下的。上面刻满了符号，没人看得懂。有个小崽子盯着看了三十天，疯了。疯之前他一直念叨——'它们在动，它们在动'。"

钱通耸耸肩："谁知道呢，祖师的遗物嘛，总有些神神叨叨的。"

**触发方式**：与铸魂殿关系≥友好后，与钱通谈话概率触发。如果一次没触发，后续还可以触发。

---

**线索七：沧溟宫的潮汐不对（第16-22个月，解锁条件：与沧溟宫有过贸易往来）**

如果玩家与沧溟宫进行过至少一次大宗交易，海瑶会在交易完成后说一句：

> "潮宫主让我问您一个问题——您觉得，最近几年的潮汐，是不是和以前不太一样了？"

宁秩说他不觉得——他是凡人，又不靠潮汐吃饭。

海瑶笑了笑："潮宫主说，如果您觉得不一样了，可以来找她。"

**触发方式**：与沧溟宫完成大宗交易后自动触发。海瑶不会解释更多。

---

**线索八：老管家的最后一封玉简（第22-24个月，解锁条件：游戏时间接近第2年末）**

在游戏接近第2年末、尚未走向任何明确结局路线时，管家会发来一条前所未有的长消息：

> "少爷，老奴活了这么多年，有一件事从未对任何人说过。
>
> 老奴当年侍奉的那位游方修士——他不只说了灵气会燃尽。他还说了一句。
>
> 他说——'碎片在找一个人。五块碎片，都在找同一个人。'
>
> 老奴当时只当他在说醉话。但这些年看着少爷一路走过来……老奴觉得，那个人可能真的存在。
>
> 只是老奴不知道，找到了那个人之后，会发生什么。
>
> 少爷，您觉得呢？"

这是最后一条线索。也是唯一一条玩家可以**直接回应**的线索——但宁秩答不上来。

---

#### 线索集齐的判定

以上八条线索不需要全部触发才算"集齐"。玩家只需要触发其中的**五条以上**，系统就会在后台记录"玩家已接触到灵墟终局的真相"。

当玩家在一周目走向灵墟湮灭结局时（宁秩寿终正寝），终幕的文本会多出一段——在宁秩闭眼之后、灵墟崩塌之前：

> "但在灵气消散的最后一刻，宁秩忽然明白了那些碎片想要什么。
>
> 它们不是想回去。
>
> 它们是想让人知道——它们还在。"

这个"明白"本身不会改变结局——宁秩已经死了。但这个"明白"会记录在存档中，成为二周目解锁拯救路线的关键钥匙。

---

### 隐藏结局·壹：灵墟湮灭

| 项目 | 内容 |
|------|------|
| **结局名称** | 灵墟湮灭 |
| **触发条件** | 宁秩寿终正寝时，三条暗线均未达到激活"修复"路线的门槛 |
| **解锁前提** | 在一周目或当前周目中，集齐至少5条湮灭线索 |
| **判定时机** | 宁秩在凡人的寿命终点（游戏内约60-80年）自然去世时 |
| **核心设计** | 这是一个**不会被警告的结局**。没有任何系统提示告诉你"你正在走向湮灭结局"。玩家可能经营了一辈子，都不知道灵墟曾经有一个可以救赎的机会。 |

**触发时的终幕演出**：

宁秩度过了一个完整的商人一生。他去世的那天，是一个普通的傍晚。他坐在自己商会的庭院里，看着天边的晚霞。老管家的玉简——那枚他自己熔出来的宝品玉简——静静地躺在他的膝盖上。

宁秩闭上了眼睛。

在他呼吸停止的那一瞬间，他终于感知到了他一生中从未真正理解的东西——五块天道碎片的频率在同一刻断裂了。它们最后互相呼唤了一次，然后彻底失去了联系。

灵墟的灵气开始不可逆地消散。

> 宁秩去世后第三年，灵潮完全停止。
>
> 第五年，凡品灵材不再生长。
>
> 第十年，灵品灵材全部退化。
>
> 第三十年，五大板块开始出现大面积灵气荒漠。
>
> 第一百年，灵墟回到了天道之核破碎前的状态——但不是完整的，是空的。

世界没有毁灭。它只是不再有灵气了。

**如果玩家已集齐5条以上线索**，在终幕的最后，会多出以下一段：

> 不。
>
> 宁秩不应该知道这些。他已经走了。
>
> 但碎片不这么认为。
>
> 它们在宁秩的感知消失前的最后一瞬，把一段信息——不是语言，不是图像，而是一种比任何表达都更直接的"知道"——注入了他正在消散的意识中。
>
> 他不知道这是什么意思。他也不会再有时间去弄懂了。
>
> 但他记住了。
>
> 在灵魂彻底消散之前，他记住了。

**多出这一段的意义**：这个"记住"是一个跨周目的存档标记。它让二周目的玩家在开局时，就会在某个不经意的瞬间感到"不对"——从而有了主动探索的动力。

---

### 隐藏结局·贰：灵墟归途

| 项目 | 内容 |
|------|------|
| **结局名称** | 灵墟归途 |
| **触发条件** | 至少完成过一次灵墟湮灭结局（获得"记住"标记），且在后续周目中集齐全部8条线索，并在游戏第18-24个月内触发"修复"剧情线 |
| **难度** | 极高。这是灵墟旅商最难的结局，预计只有不到5%的玩家能在一周目内达成 |

**触发流程简述**：

1. **前置条件**：至少在一周目达成了灵墟湮灭结局，存档中保留了"记住"标记

2. **线索重聚**：在一个新周目中，玩家需要再次集齐全部8条湮灭线索。但这一次，由于宁秩"记住了"上一世的东西，每条线索的触发方式发生了变化：

   - 线索一（商路不安）：宁秩在第一趟跨域贸易时，直接认出了那种感觉——"和上次一样。"
   - 线索二（管家的话）：管家的玉简还没发来，宁秩主动问："那个游方修士，还说了什么？"
   - 线索三（寒渊宗的报价单）：宁秩看到报价单上的数字时，直接问冰崖："三百年来降低了百分之七，对吗？"——冰崖愣住了。
   - 以此类推，每条线索的触发从"被动发现"变为"主动回忆"

3. **修复之路**：当全部8条线索集齐后，宁秩会在某个夜晚——独自面对熔炉时——完全理解了他一直在感知的东西：

   五块天道碎片不是"分离"了。它们是被某种力量**推开**的。那股力量——也许就是当年天道之核破碎时的冲击——至今仍然存在，像一种看不见的斥力，持续地、不可逆地将五块碎片推离彼此。

   要阻止灵墟的湮灭，不是要"修复"碎片——而是需要有人用自己的五行杂灵根作为桥梁，让五块碎片的频率**重新建立连接**。

   不需要把它们物理上合在一起。只需要让它们知道——彼此还在。

4. **最终抉择**：在游戏第22-24个月，玩家会触发一个不同于所有其他结局的抉择时刻：

> 宁秩站在自己搭建的第一个熔炉前——那个用废弃耐火砖搭起来的简陋野灶。他已经很久没用它了。他现在用的是一座真正的熔炉，花了大价钱请铸魂殿打造的。
>
> 但他今晚用的是第一个。
>
> 他把五件灵材——分别来自五大板块、分别对应五行——放进了熔炉。这不是天道熔炼。没有任何配方的天道熔炼能容纳五件不同出处的灵材。
>
> 这是他自己想出来的。
>
> 老管家的玉简亮了起来。
>
> "少爷，您要做什么？"
>
> 宁秩没有回答。他点燃了炉火。
>
> ——这意味着什么？
>
> A. 他尝试用自己的杂灵根同时共振五块碎片，将五件灵材熔炼成一个完整的信标。如果成功，五块碎片会重新感知到彼此的存在。如果失败——炉火会吞噬一切，包括他自己。
>
> B. 他停止了这个疯狂的念头。他还有很多事要做，还有很多生意要谈。灵墟的湮灭——那是几千年后的事。关他什么事？
>
> C. 他熔炼了五件灵材，但不是为了连接碎片。他把它们熔成了自己的本命法器——一件只有他能用的、代表"见证"的法器。他没有改变灵墟的命运，但他留下了自己存在过的证据。

5. **结局分支**：

   **A. 成功 → 灵墟归途（真结局）**

   > 炉火没有熄灭。五件灵材在火焰中融化成了一道光——不是宝品、不是仙品，是宁秩从未见过的一种品阶。光柱冲天而起，穿透了中央荒原的天空，穿透了灵墟上空的结界，消失在了无尽的虚空中。
   >
   > 然后——一切安静了。
   >
   > 五块碎片的频率同步了。
   >
   > 不是恢复了完整，而是建立了一种新的平衡。它们不会再远离彼此了。灵墟剩下的灵气不会再消散了。
   >
   > 宁秩瘫坐在地上，浑身被汗水湿透。老管家的玉简再次亮起。
   >
   > "少爷……您做了什么？"
   >
   > 宁秩看着自己的双手。他的手在发抖。
   >
   > "我什么都没做。我只是——告诉了它们，它们不是一个人。"

   终幕：灵墟的灵气浓度停止了下滑。灵潮周期恢复正常。世界树的枯萎速度放缓了。没有人知道发生了什么——除了老管家，和宁秩自己。

   **B. 放弃 → 回到灵墟湮灭路线**

   宁秩熄灭了炉火。他选择了不改变什么。灵墟的终局不会因为这个选择而加速或延缓——它本来就一直在那里。宁秩只是没有成为那个改变它的人。

   **C. 见证 → 解锁新结局/新物品**

   宁秩熔出了一件独一无二的法器——"归墟之证"。它的品阶不在凡灵宝仙的任何一档中。它的作用不是战斗、不是防御、不是辅助修炼。它只是记录——记录灵墟曾经有一个人，知道了真相。

   这个物品没有实际用途。但它会出现在玩家的物品栏里——即使在新周目也会保留——作为"我曾经来过这里"的证明。

---

### 设计总结：两个隐藏结局的关系

```
一周目（或任意周目，未集齐线索）
  └→ 主线结局（商道/天道/人心/复合等）
  └→ 灵墟湮灭（触发"记住"标记）
       └→ 二周目及以后
            ├→（不集齐线索）→再次湮灭
            └→（集齐全部8条线索）→ 灵墟归途（真结局）
                 ├→ 成功修复 → 灵墟归途
                 ├→ 放弃 → 回到其他主线
                 └→ 见证 → 获得归墟之证
```

> 玩家不是非得走隐藏路线不可。灵墟旅商的主食是模拟经营，隐藏剧情是留给那些"觉得这个世界不只是表面上这样"的玩家的甜品。
>
> 你可以在不知道灵墟终将湮灭的情况下，快快乐乐地当一个富商过一辈子。
>
> 也可以选择挖下去——直到挖出这个世界最深的秘密。


> "他来过，他走了，没有人记得他。"

**触发条件**：两年内三项数值均未达到40，且商道≤30

**剧情走向**：
- 这不是一个"游戏失败"的结局，而是一种平庸的结局
- 宁秩没有获得巨大的成功，也没有遭遇彻底的失败——他只是平平淡淡地做了两年小生意，然后回了宁家

**终幕**：
宁秩回到宁家。父亲什么都没说，只是拍了拍他的肩膀。大哥说："回来就好，家里不缺你一口饭。"宁秩没有反驳。那天晚上，老管家的玉简收到最后一条消息——不是管家发的，是宁秩自己发的："管家，那本商事录，我带走了。"

# 灵墟大型事件年表

> 这些不是玩家所能左右的"日常任务"。它们是灵墟世界自己的历史——有些发生在玩家到来之前，有些在玩家经营期间爆发。玩家能做的，是在这些大事件中生存下来，并找到自己的位置。

---

## 一、史前事件（玩家出生前已发生）

灵墟世界中所有角色都知晓这些历史，它们奠定了目前的势力格局。

### 事件A：天裂之战（300年前）

| 项目 | 内容 |
|------|------|
| **时间** | 约300年前 |
| **起因** | 灵墟上空出现了一道横贯天际的空间裂缝——"天裂"。无数域外异兽从裂缝中涌入，灵墟五域同时遭到入侵 |
| **经过** | 五大正道宗门被迫联手，成立临时联盟"五方盟"。战斗持续了整整七年。凡人王朝几乎覆灭，散修死伤过半。最惨烈的一役在炎狱域——焚天阁前任阁主引爆了整座火山，与异兽大军同归于尽。铸魂殿倾尽所有法器库存，寒渊宗冰封了三座城池作为临时堡垒 |
| **结果** | 五方盟付出惨重代价后封印了天裂。但封印并不完美——每过数十年会出现一次"裂缝渗漏"，有小股异兽或域外灵气渗入 |
| **对当前世界的影响** | - 铸魂殿积累了最多的战争法器，战后成为最富裕的宗门<br>- 焚天阁元气大伤，至今未完全恢复<br>- 沧溟宫在天裂之战中几乎未受影响，因此被其他宗门隐约忌惮<br>- 天裂留下的空间不稳定区域成为探险者和亡命徒的目的地 |
| **玩家相关** | 天裂遗迹中仍能挖到当年遗落的法器残片和异兽骸骨——暗市上很受欢迎 |

### 事件B：暗市建立（约200年前）

| 项目 | 内容 |
|------|------|
| **时间** | 约200年前 |
| **经过** | 天裂之战后，灵墟百废待兴。战后大量违禁物资（异兽材料、禁术残卷、战场遗物）没有正规流通渠道。一群不愿透露身份的人——据说是当年五方盟的后勤官员——在中央荒原地下开辟了第一个暗市。守夜人从暗市建立的第一天就存在了 |
| **结果** | 暗市迅速扩张，成为灵墟地下经济的核心。正道宗门虽然公开谴责，但私下都有人员在暗市活动 |
| **玩家相关** | 这就是玩家今天看到的暗市。它的历史赋予了它"不是法外之地，而是另一套法"的特殊地位 |

### 事件C：天道商会崛起（约80年前）

| 项目 | 内容 |
|------|------|
| **时间** | 约80年前 |
| **经过** | 一个不知名的商人从金戈域起家，在短短二十年内建立了一个横跨五域的商业网络。他自称"天机子"，没人知道他的真名。天机子用独特的经营手段——统一价格、信用体系、物流网络——迅速挤垮了各地的小商会 |
| **结果** | 天道商会成为灵墟最大的商业组织。凡人王朝的税收都经他们之手流转。五大宗门也不得不与天道商会合作——因为他们掌握了太多的流通渠道 |
| **对当前世界的影响** | - 天道商会垄断了正规市场的高端流通<br>- 小商户生存空间被极度压缩——这也是玩家的机会（大商会照顾不到的缝隙市场）<br>- 天机子近百岁高龄，仍未指定继承人。他的隐退或去世可能引发商界大地震 |
| **玩家相关** | 玩家经营的每一个决策，都在或明或暗地与天道商会竞争。中期以后，天道商会可能会注意到你——可能是拉拢，可能是打压 |

## 二、当代大事件（玩家经营期间可能触发）

这些事件可能在玩家一周目的过程中发生。部分为固定时间触发，部分为玩家行为触发。

### 事件1：世界树之殇

> 灵墟世界最古老的生命——苍木域万木灵宗的上古世界树——开始枯萎了。

| 项目 | 内容 |
|------|------|
| **触发时间** | 游戏第6-10个月（玩家中期） |
| **触发条件** | 时间到达后触发，与玩家行为无关（这是世界自身的进程） |
| **事件背景** | 万木灵宗赖以生存的上古世界树——传说中在灵墟诞生之前就已存在的古老存在——开始出现枯萎迹象。最初只是几片叶子发黄，没有人当回事。但三个月内，枯黄蔓延到了三分之一树冠。世界树之液的产量断崖式下跌，从每月百瓶骤降至不足十瓶。万木灵宗封锁了消息，但暗市上早已传遍 |
| **事件经过** | 1. **消息走漏**（第6-8个月）：玩家可能会从三种渠道得知——管家（"老奴听说苍木域那边不太平，世界树好像出了点事"）、暗市（有人在兜售"可能是最后一批"的世界树之液）、或者直接看到世界树之液在拍卖会上的价格涨了三倍<br><br>2. **价格连锁反应**：世界树之液价格暴涨10倍（从2000灵石/瓶→20000灵石/瓶）。苍木域出产的所有灵材价格同步上涨（世界树的灵气滋养着整片森林）。万木灵宗开始高价收购各种传说中的"灵树养护灵材"——有些连听都没听过<br><br>3. **暗流涌动**（第8-10个月）：有人提出世界树的枯萎不是自然原因——是有人在世界树根部做了手脚。怀疑对象包括：金戈域铸魂殿（需要千年灵木心做一件传说级法器，但万木灵宗一直不卖）、某个不知名的域外势力、甚至万木灵宗内部也有人嫌疑 |
| **玩家可做的事** | - **囤货/倒卖**：世界树之液价格高涨期间，如果能从其他渠道拿到货，利润极高<br>- **接委托**：万木灵宗开出高价悬赏——谁能找到救治世界树的方法，重重有赏<br>- **调查真相**：如果你选择了"调查世界树枯萎真相"的路径，会触发一系列调查事件，可能涉及暗市情报交易、潜入苍木域、甚至与守夜人打交道<br>- **置身事外**：也可以不管，这不会影响你的游戏进程，但世界树之殇的后续影响会改变苍木域的经济格局 |
| **事件结局（并非由玩家决定）** | 世界树最终会怎样，**不取决于玩家**。这是世界自身的历史——玩家只是见证了它。<br><br>但玩家在事件中的选择会影响：<br>- 与万木灵宗的关系（如果帮过他们→友好；如果发灾难财→好感大降）<br>- 是否获得了某些稀有的、与世界树相关的物品<br>- 是否发现了某些秘密（比如世界树枯萎的真正原因） |
| **对游戏世界的影响** | - 世界树之液从常驻商品变为稀缺品，价格永久性上涨（即使事件结束也不会恢复原价）<br>- 万木灵宗的实力受到削弱，灵墟的势力平衡发生变化<br>- 苍木域的凡人和低阶修士受到最大冲击——失去了世界树的灵气庇护，森林边缘开始退化 |

---

### 事件2：天机子的隐退

> 天道商会的创始人、灵墟百年最传奇的商人——天机子——终于老了。

| 项目 | 内容 |
|------|------|
| **触发时间** | 游戏第12-15个月（玩家后期） |
| **触发条件** | 商道≥50 或 与天道商会交易累计达到一定额度 |
| **事件背景** | 天机子九十八岁了。对于不会修炼的凡人来说，这已经是极限。坊间流传他大限将至的传闻已经好几年了，但这一次——天道商会内部开始出现了不寻常的动静。<br><br>三名继承人（天机子的三个义子）开始明争暗斗。天道商会的统一价格体系出现了裂痕——北域的商会分会和南域的分会开始用不同的价格收购同一种灵材 |
| **事件经过** | 1. **价格松动**（第12个月左右）：玩家可能会注意到天道商会的报价不再像以前那样死板了。某些灵材他们开始愿意议价——这在以前是不可能的<br><br>2. **三方拉拢**（第13-14个月）：三名继承人分别派人接触玩家——他们都想争取独立商人的支持。大义子许诺稳定的供货渠道、二义子许诺更低的抽成、三义子（最小的）什么都没有许诺，只说了句"天道商会需要一个不属于任何宗门的盟友"<br><br>3. **天机子召见**（第14-15个月）：如果你在商界已经有一定地位，天机子本人会亲自召见你一次——不是为了拉拢，只是想看看"这些年从夹缝里长出来的年轻人"长什么样。这次会面没有实质性的交易，但天机子说的话可能会影响你对整个商界的判断 |
| **玩家面临的选择** | 选择支持哪一位继承人？或者选择不支持任何人？这个选择将决定天道商会未来的走向——以及你在商界的盟友与敌人。<br><br>**什么都不选**：天道商会照常运营，但你失去了一个影响未来格局的机会<br>**支持大义子**：他掌权后天道商会会更保守，小商户生存更艰难，但你会获得稳定的供货<br>**支持二义子**：他掌权后天会商会会更激进、更具侵略性，但你能拿到更低的成本价<br>**支持三义子**：风险最高——他是最不被看好的继承人，但如果他赢了，他会是三个里面对独立商人最友好的 |
| **结局（取决于玩家选择+系统判定）** | 不是玩家选谁就是谁赢。你的支持只是一个筹码之一。最终的继承人由多方势力博弈决定——玩家只是其中的一个变量 |
| **对游戏世界的影响** | - 天道商会的新掌门决定了未来几十年的商业格局<br>- 继承人之争期间的市场混乱是投机者的黄金窗口<br>- 如果你支持的人输了，你可能面临新掌门的打压 |

### 事件3：五方盟的重聚

> 天裂之战三百年后，有人提议重建五方盟。

| 项目 | 内容 |
|------|------|
| **触发时间** | 游戏第14-18个月 |
| **触发条件** | 灵潮大周期异动触发 或 天裂遗迹出现异常 |
| **事件背景** | 天裂封印经过三百年，开始出现不稳定的征兆。沧溟宫的占卜师发现裂缝周围的灵气波动频率在逐年加快。如果他们是对的，下一次大规模渗漏——甚至第二次天裂——可能在十年内发生。<br><br>沧溟宫秘密联络了其他四宗，提议重启五方盟。但三百年过去了，当年的五宗早已不是当年的五宗——有衰落的、有崛起的、有面和心不和的 |
| **事件经过** | 1. **密会**：五大宗门的代表在中央荒原秘密会面——这是三百年来第一次。消息还是走漏了，整个灵墟都在猜测发生了什么<br>2. **分歧**：铸魂殿主张重建五方盟并由他们主导（因为他们有最多的战争物资）；焚天阁表示无所谓（"你们定就好"）；寒渊宗要求所有决策必须五宗一致同意；万木灵宗因世界树之殇实力大减，话语权变弱；沧溟宫态度暧昧，似乎在观望<br>3. **外部压力**：暗市势力对五方盟的重建极为警惕——一个统一的宗门联盟意味着地下经济的生存空间会被压缩。暗市掮客可能会找上玩家，希望玩家"在商人圈子里制造一些反对声音" |
| **玩家面临的选择** | - **支持联盟**：如果你和正道宗门关系好，可以选择公开支持——会提升宗门好感度<br>- **反对联盟**：如果你和暗市关系密切，可以选择制造反对意见——会提升暗市好感度<br>- **保持中立**：两不得罪，也两面不是人<br>- **从中牟利**：不管联盟成不成，战争物资的筹备本身就是巨大的商机——如果你提前囤积相关灵材 |
| **结局** | 五方盟的重建进程不会在玩家的一周目内完成（这需要数年时间）。但玩家在事件中的立场和选择会影响——如果真有第二次天裂之战，你在灵墟的势力格局中站在哪一边 |
| **对游戏世界的影响** | - 短期内：战争物资价格全面上涨<br>- 长期影响：取决于联盟最终是否建立，以及谁主导 |

### 事件4：宁家之难

> 宁秩的家族商会——那个他逃离的地方——遭遇了灭顶之灾。

| 项目 | 内容 |
|------|------|
| **触发时间** | 游戏第14-18个月 |
| **触发条件** | 玩家已完成"宁家来人"事件（刘伯出现），与宁家的关系网已建立 |
| **事件背景** | 宁家商会在一次大宗跨域贸易中被设局——一批价值连城的货物在运输途中被劫，押送人员全部失踪。这不是普通的劫修，是有预谋的打压。宁家的现金流瞬间断裂，多处供货商同时催款，宁家商会摇摇欲坠。<br><br>宁秩的父亲——那个说过"让他安生过日子"的父亲——没有来找宁秩。但刘伯来了。<br><br>刘伯站在摊位前，比上次见面时老了十岁。"少爷……家里出事了。" |
| **玩家面临的选择** | **A. 出手相救**：将你的灵石和商路资源投入宁家——可能救回宁家商会，也可能把自己也搭进去。如果成功，宁秩与家族和解，人心+15，商道+10。如果失败，你的资金链可能和宁家一起断裂。<br><br>**B. 有限帮助**：提供一部分资金支援，但不全面介入。宁家商会可能缩水但不会覆灭。宁秩的父亲不会说什么，但刘伯会感激。人心+5，商道+3。<br><br>**C. 袖手旁观**：不是不帮，是帮不了——你的实力还不够。宁家商会覆灭，父亲和大哥下落不明。宁秩永远失去了与家族和解的机会。人心-10，商道不受影响。<br><br>**D. 趁机收购**（如果你走暗面路线）：以低价收购宁家的剩余资产和商路网络。商道+5（资产扩张），人心-20，暗市好感大增。 |
| **结局** | 宁家的命运掌握在玩家手中。这不是天道商会的兴衰——这是宁秩的家事。无论结果如何，宁秩的"家"已经永远改变了。 |
| **对游戏世界的影响** | - 宁家商会这个存在了六十年的老字号，要么在危机中重生，要么就此消失<br>- 玩家对家族的态度会直接影响"人心"数值和后续剧情走向 |

### 事件5：暗市风暴

> 守夜人内部出现了裂痕。暗市——那个看似永恒的地下世界——开始震荡。

| 项目 | 内容 |
|------|------|
| **触发时间** | 游戏第15-20个月 |
| **触发条件** | 玩家在暗市的累计交易达到一定额度，或与暗市势力关系密切 |
| **事件背景** | 暗市的幕后主人——那个从未露面的存在——失踪了。有人说他死了，有人说他离开了灵墟。守夜人失去了最高指令的来源。一部分守夜人主张维持现状，另一部分守夜人开始自行其是。<br><br>暗市第一次出现了"在暗市内动手"的违规事件——而且违规者没有被惩罚。这个消息比任何灵材价格波动都更令人不安 |
| **事件经过** | 1. **秩序松动**：暗市内出现了斗殴、抢货、黑吃黑——以前不可能发生的事情，现在开始发生了。暗市的入场保证金也开始混乱——有人收有人不收<br>2. **分裂**：暗市分成两派——"守旧派"（维持原来的规则，但不一定有执行能力）和"革新派"（主张暗市应该更开放、更自由——也更混乱）<br>3. **玩家被卷入**：无论你站在哪一边，暗市的混乱都会影响你的生意——你在暗市的存货可能被抢、你的暗市交易对手可能跑路、暗市掮客可能会向你求助 |
| **玩家面临的选择** | - **支持守旧派**：帮助恢复暗市秩序。暗市恢复稳定，但你在革新派中树敌<br>- **支持革新派**：暗市变得更加混乱但也更加自由——更多违禁品流通、更低的手续费。但风险更高<br>- **中立自保**：收缩暗市业务，等尘埃落定再说。安全第一，但也失去了趁乱牟利的机会<br>- **渔翁得利**：趁着暗市混乱，低价收购某些平时买不到的好货，然后退场 |
| **结局** | 暗市的未来取决于多方博弈的结果。玩家的选择会影响暗市在接下来数年内的走向——变得更加规范还是更加狂野。 |
| **对游戏世界的影响** | - 暗市可能变成两个不同的样子——取决于谁赢了<br>- 如果你在暗市风暴中站对了队，你在暗市的地位可能大幅提升<br>- 如果你站错了队……你可能被暗市列入黑名单 |

### 事件6：拍卖行的垄断战争

> 当万宝楼遇见天道商会——两大商业巨头的正面碰撞。

| 项目 | 内容 |
|------|------|
| **触发时间** | 游戏第14-18个月 |
| **触发条件** | 玩家商道≥50，且至少主办过一次拍卖会 |
| **事件背景** | 万宝楼——长期中立的超级拍卖行——因为天道商会继承人之争的牵连，开始与天道商会产生摩擦。问题出在：万宝楼的许多拍品依赖于天道商会的供货渠道。如果天道商会换了一个不友好的掌门，万宝楼的货源会被掐断。<br><br>万宝楼决定先发制人——开始扶持独立商人（包括玩家），摆脱对天道商会的依赖。天道商会的回应是：对所有向万宝楼供货的独立商人加收"渠道费"。<br><br>玩家被夹在了中间。 |
| **玩家面临的选择** | - **站在万宝楼一边**：失去天道商会的低价货源，但获得万宝楼的拍卖优先权和更高的拍卖抽成<br>- **站天道商会一边**：失去万宝楼的拍卖渠道，但保住低价货源<br>- **左右逢源**：两边的货都供，但两边的价格都比别人差（不站队的结果是两边都不把你当自己人） |
| **结局** | - 万宝楼与天道商会的竞争不会在一周目内结束<br>- 但玩家的选择会影响：未来谁的拍卖行有更好的货、价格更透明 |
| **对游戏世界的影响** | - 拍卖行业的格局发生变化<br>- 独立商人在两大巨头之间的博弈空间更大——或更小，取决于你怎么玩 |

## 三、大事件时间总表

```
玩家出生前：
  ──300年 天裂之战（灵墟被入侵，五方盟建立）
  ──200年 暗市建立
  ── 80年 天道商会崛起

玩家一周目内：
  第1-3个月  第一章：荒野求生（新手期，无大事件）
  第3-9个月  第二章：站稳脚跟
    第6-10月  → 世界树之殇（受世界进程影响）
  第9-18个月 第三章：风口浪尖
    第12-15月 → 天机子的隐退（受商道值影响）
    第14-18月 → 五方盟的重聚（受灵潮大周期影响）
    第14-18月 → 宁家之难（固定触发）
    第14-18月 → 拍卖行的垄断战争（受拍卖会参与度影响）
    第15-20月 → 暗市风暴（受暗市参与度影响）
  第18-24个月 第四章：终局（结局触发）
```

> 不是所有事件都会在一周目内全部触发。玩家的行为会"激活"与自己路线相关的事件。一个从不碰暗市的玩家不会遇到"暗市风暴"，一个商道不够的玩家也触发不了"拍卖行的垄断战争"。**世界因你而不同——你关注什么，什么就会出现在你面前。**
