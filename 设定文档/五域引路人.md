# 五域引路人

> 宁秩是孤身一人走出宁家的。但在每一个板块，他都会遇到一个人——不是随从，不是商业伙伴，而是一个会让他记住很久的人。

---

## 设计思路

| 板块 | 引路人 | 角色定位 | 与宁秩的关系 |
|------|--------|---------|------------|
| 中央荒原 | 老赵 | 第一个顾客、第一个朋友 | 忘年交 |
| 玄冰域 | 冰崖 | 表面冷淡但暗中关照的长辈 | 亦师亦友 |
| 炎狱域 | 赤炼 | 技术狂人、同行 | 互相欣赏的技术搭档 |
| 苍木域 | 云叶 | 温柔善良的灵植师 | 可以倾诉的朋友 |
| 金戈域 | 金锋 | 沉默寡言的大铸师 | 不需要言语的默契 |
| 深海域 | 海瑶 | 神秘但可靠的外务使 | 信任但保持距离 |

## 中央荒原 · 老赵

| 项目 | 内容 |
|------|------|
| **全名** | 赵不惑 |
| **年龄** | 五十余岁 |
| **修为** | 筑基中期（散修） |
| **外貌** | 面容沧桑，手掌粗糙，穿一身洗得发白的旧道袍。看起来就是一个普通的中年散修 |
| **性格** | 表面粗犷、说话直来直去，实际上心思细腻。他活了半辈子，见过太多人和事，看人的本事一流 |
| **怎么认识宁秩的** | 宁秩摆摊第一天，他是第一个顾客。他拿起一株赤炎草说："小伙子，新来的吧？"——从那之后，他是宁秩最忠实的顾客 |
| **和老赵的关系** | 老赵不是随从，不是雇员，就是一个不定期出现的朋友。他可能一周来一次，也可能一个月都没影——他有自己的生活。但他每次来都会和宁秩聊几句：今天生意怎么样、最近灵墟有什么新鲜事、听说哪个板块出了什么好东西。老赵是宁秩在中央荒原最熟悉的人 |
| **在剧情中的作用** | 1. 新手引导中担任"第一个顾客"角色<br>2. 中期会透露一些灵墟的"老话"——"我年轻时听过一个说法，说这世界的灵气不是无穷无尽的"（线索的潜在来源）<br>3. 后期如果宁秩遇到麻烦（商会竞争事件），老赵会用自己的关系网帮忙打听消息<br>4. 他是宁秩在这个世界上交到的**第一个朋友**——不是商业上的，是真正的朋友 |

**专属剧情**：
- 第6个月左右，老赵会消失大约两周。再次出现时，他胳膊上缠着绷带。宁秩问他怎么了，他只说："帮人押了趟货，出了点小意外。没事。"
- 如果玩家追问（人心≥20），老赵会透露：那趟货是从苍木域运出来的——"有人在大量收购灵木心。量很大。不像是正常生意。"——这是一条暗线线索的入口。
- 如果玩家不追问，老赵不会主动说。

## 玄冰域 · 冰崖

| 项目 | 内容 |
|------|------|
| **全名** | 冰崖 |
| **年龄** | 一百六十余岁 |
| **修为** | 金丹后期 |
| **身份** | 寒渊宗外事长老 |
| **性格** | 寒渊宗里最好打交道的人——虽然也就是相对而言。他说话简洁直接、不拖泥带水，但至少不会给人脸色看。他对灵石有实实在在的尊重——不是贪财，是理解"没有灵石宗门运转不了" |
| **怎么认识宁秩的** | 宁秩第一次与寒渊宗交易时，负责接洽的就是冰崖。他看了一眼宁秩的报价单，说："价格合理。以后有货直接送来。"——没有第二句废话 |
| **和冰崖的关系** | 冰崖不会和宁秩称兄道弟。寒渊宗的人不这样。但每次宁秩去玄冰域做交易，冰崖都会多看一眼他的货单。有一次宁秩送来的玄冰髓样品成色比合同上的略好，冰崖主动提了价——"好货就是好货。不会让你吃亏。"在寒渊宗，这已经是很高的评价了 |
| **在剧情中的作用** | 1. 寒渊宗的商业接口人<br>2. 那句写在报价单背面的"灵气密度降低了百分之七"——是冰崖故意写的。他知道宁秩会看到，他想看看宁秩的反应<br>3. 线索"寒渊宗的报价单"的核心人物<br>4. 如果玩家选择走"修复"路线，冰崖会是第一个注意到宁秩异常的人——因为他认识宁秩太久了，宁秩最近问的问题不对 |

**专属剧情**：
- 第10个月左右，宁秩在完成一单大交易后，冰崖会多说一句："你最近问的问题——关于灵气密度的那些——不要再问第二个人。"
- 他不解释为什么。说完就去处理下一份报价单了。
- 如果宁秩追问，冰崖只会说："寒渊宗有些事，连我这个外事长老都不该知道。但我活了一百多年，至少学会了什么东西该问、什么东西不该问。"——他在警告宁秩，也在提醒宁秩。

## 炎狱域 · 赤炼

| 项目 | 内容 |
|------|------|
| **全名** | 赤炼（赤炼是道号，本名已无人知晓） |
| **年龄** | 约一百二十岁 |
| **修为** | 金丹巅峰 |
| **身份** | 焚天阁左护法、首席炼器师 |
| **性格** | 技术狂人。她可以三天三夜不睡觉就为了锻一件法器。她对"人"没什么兴趣，但对"材料"有着近乎偏执的热情。她是焚天阁少数还保留了一些"正常社交能力"的人——但也就是"能在谈正事的时候不骂人"的水平 |
| **怎么认识宁秩的** | 宁秩在炎狱域参加一次小型拍卖会时，拍到了一块他看不出用途的金属。他把那块金属带到焚天阁想找人鉴定，正好遇到了赤炼。赤炼看了那块金属一眼，又看了宁秩一眼——"你在哪弄到的？"宁秩说在拍卖会上。赤炼沉默了一会儿："这不是灵墟的东西。"然后她就不肯再多说了 |
| **和赤炼的关系** | 赤炼对宁秩的态度很矛盾：一方面，她欣赏宁秩的眼力——一个凡人能认出她不认识的金属，这本身就说明他不是普通人；另一方面，她不喜欢和商人打交道。她不会主动找宁秩，但如果宁秩带来了她没见过的材料，她会放下手头的工作和他聊很久。他们的关系建立在"你带好货来，我给你鉴定"的基础上——但后来渐渐变成了"你来啦？最近又弄到什么奇怪的东西了？" |
| **在剧情中的作用** | 1. 焚天阁的技术接口人<br>2. "不是灵墟的东西"——赤炼这句话暗示了域外材料的存在，与天裂之战的背景遥相呼应<br>3. 如果玩家收集到异变产物（天道熔炼产出），赤炼是最识货的人——她会给宁秩的异变产物定价，并且可能出价收购<br>4. 在灵墟归途路线的最终阶段，赤炼可能是唯一有能力帮宁秩分析"那扇门后面有什么"的人——因为她见过不是灵墟的东西 |

**专属剧情**：
- 第14个月左右，如果玩家已经与赤炼建立了足够的关系（交易次数≥5），赤炼会主动发来一条传讯——不是通过玉简，是通过一个烧得发烫的小铁片：
> "你那块金属我查到了。不是灵墟的东西——但这不代表灵墟没有。三百年前，有人见过一模一样的东西。你猜那人在哪？"
>
> 宁秩等着下一句。铁片不再发烫了。她没有写完。
>
> 如果玩家带着铁片去找赤炼追问，她只说："别问了。写那句话的人是焚天阁上一任阁主——天裂之战战死的那位。他生前一直在研究这个。我找到的只是他研究笔记的残页。"

## 苍木域 · 云叶

| 项目 | 内容 |
|------|------|
| **全名** | 云叶 |
| **年龄** | 约八十岁 |
| **修为** | 金丹后期 |
| **身份** | 万木灵宗灵植长老 |
| **性格** | 温柔、善良、对灵植有着近乎偏执的热爱。她可能是灵墟最好打交道的高阶修士——没有架子、不端身份、不摆脸色。但她有一个奇怪的特质：她从来不笑。不是不高兴，而是她好像忘记了怎么笑 |
| **怎么认识宁秩的** | 宁秩在苍木域进货时，在集市上遇到一个蹲在地上看灵草的老妇人——他当时不知道她就是万木灵宗的灵植长老。她抬头看了宁秩一眼："你这株赤炎草的成色不对。"宁秩愣了一下，低头看自己刚进的货——叶片边缘确实有一圈不正常的暗纹。他谢过她。她说："下次进货看叶背。好货叶背是绿的。"后来宁秩才知道她是谁 |
| **和云叶的关系** | 云叶是宁秩在灵墟遇到的最特别的人——她对他没有任何企图。她不买他的货，不卖他东西，不跟他做生意，也不要求任何回报。她只是偶尔会出现在宁秩的摊位前，看看他的货，说一句"这批不错"或者"这棵快枯了"，然后就走了。宁秩有一次忍不住问她："前辈为什么要帮我？"云叶想了一会儿——她似乎真的在思考——然后说："因为你叫我'前辈'的时候，和那些叫我'长老'的人不一样。" |
| **在剧情中的作用** | 1. 苍木域引路人——云叶对灵材的了解无人能及<br>2. 世界树之殇事件中的关键NPC——她比任何人都更清楚世界树发生了什么，但她不愿意说<br>3. 线索"世界树的呻吟"的深入触发者——如果人心够高，云叶会告诉宁秩她为什么不笑："世界树在三百年前天裂之战后就再也没有'开心'过了。我和它共生了一百多年，我能感觉到。它不笑，我也笑不出来。"<br>4. 她是宁秩唯一可以"什么都不谈"的朋友——没有交易、没有合作、没有利益关系 |

**专属剧情**：
- 第8个月左右（世界树之殇期间），云叶会消失一段时间。再次出现时，她的脸色比平时更苍白。宁秩问她去了哪里，她没回答。递给他一袋种子——"这是世界树今年最后一批种子。你拿着。"
- 如果玩家追问（人心≥40），她会低声说："树可能要死了。我不是说可能。我是在等它死。"
- 这是整个灵墟旅商中最悲伤的一句话。说出这句话的云叶，和第一次教宁秩看叶背的云叶，是同一个人。

## 金戈域 · 金锋

| 项目 | 内容 |
|------|------|
| **全名** | 金锋 |
| **年龄** | 约两百岁 |
| **修为** | 金丹巅峰 |
| **身份** | 铸魂殿大铸师 |
| **性格** | 沉默寡言，一天说不了十句话。但他的眼睛会说话——他看到好材料时眼睛会亮，看到坏材料时会皱眉，看到徒弟打废了一块铁时会叹气。他几乎不开口，但你永远知道他在想什么 |
| **怎么认识宁秩的** | 宁秩送了一批金灵砂去铸魂殿。交货的时候是金锋出来接的——这很少见，大铸师一般不亲自验收原材料。但金锋听说了"那个凡人商人"的名声，想看看他的货。他拿起一块金灵砂，看了三秒钟，放下——"行。"然后转身走了。就一个字。宁秩后来才知道，金锋对大多数供货商的评价是两个字——"一般。"
| **和金锋的关系** | 金锋和宁秩的关系可能是灵墟旅商中最怪的一段——他们几乎没有对话。但金锋开始注意到宁秩带来的货品越来越好，有时候宁秩还会带来一些他自己都叫不出名字的金属块（天道熔炼的异变产物）。金锋看了那些金属块后，会默默收起来——过几天，宁秩会收到一件精致的小法器，没有任何说明，没有任何收费。那是金锋用异变材料随手做的。也是他表达"你是个有意思的人"的方式 |
| **在剧情中的作用** | 1. 金戈域引路人——一个不需要言语的朋友<br>2. 线索"铸魂殿未完成品"的知情者——钱通提到的那块铁板，金锋知道得比钱通多得多，但他不会主动说<br>3. 如果玩家在灵墟归途路线中需要锻造某种特殊的法器（比如用来连接碎片信标的容器），金锋是唯一有能力做到的人——但他要求一个交换条件："把那块铁板上的符号，给我看看你看到了什么。" |

**专属剧情**：
- 如果玩家与金锋的关系达到"信任"级别（累计交易次数≥8或收到过金锋的"回礼"≥3次），金锋会在一次交货时递过来一块巴掌大的金属板——不是铸魂殿秘库里的那块，是一块新的。
- 金属板上刻着几个符号——和那块未完成品上的符号一模一样。金锋用指关节敲了敲金属板，然后看着宁秩。
- 他在问宁秩——"你看得懂吗？"
- 宁秩看不懂。但宁秩发现自己**能感觉到**——他的手碰到金属板的那一刻，那些符号在他的感知中"活"了过来。符号在移动，在重组，在尝试告诉他什么。
- 金锋看到了宁秩的表情。他点了点头。然后把金属板塞给了宁秩。"拿着。"——这是他主动送给别人的第一件东西。

## 深海域 · 海瑶

| 项目 | 内容 |
|------|------|
| **全名** | 海瑶 |
| **年龄** | 不确定——沧溟宫的弟子看起来都很年轻，但实际年龄可能远超外表 |
| **修为** | 金丹中期 |
| **身份** | 沧溟宫外务使 |
| **性格** | 沧溟宫中最"正常"的人——说话清晰、有逻辑、不绕弯子。但她有一个习惯：她会突然沉默几秒钟，然后说一句看似无关的话。后来宁秩发现，她不是在走神——她是在**听**什么。她可能在听深海中的某种声音 |
| **怎么认识宁秩的** | 宁秩通过万宝楼的介绍第一次联系沧溟宫谈业务。接洽人就是海瑶。她在见面的第一句话是："潮宫主让我问您一个问题——您最近是不是经常耳鸣？"宁秩愣住了。他确实最近经常耳鸣——就像有什么高频的声音被隔绝在他的听力边缘。他不知道潮音是怎么知道的。海瑶笑了笑："那不是什么大问题。只是您的灵根正在觉醒。" |
| **和海瑶的关系** | 海瑶是宁秩在深海域唯一一个能正常交流的人。但宁秩始终觉得——海瑶对他说的每一句话，可能都不是她自己的意思。"潮宫主说……"这三个字几乎出现在她每一句话的开头。宁秩不确定海瑶有自己的想法，还是她只是潮音的传声筒 |
| **在剧情中的作用** | 1. 深海域引路人——唯一能联系沧溟宫的渠道<br>2. 线索"沧溟宫的潮汐不对"的触发者<br>3. 是海瑶转达了潮音的第一个问题——"您最近是不是经常耳鸣？"这个问题暗示了潮音从一开始就知道宁秩是谁<br>4. 在灵墟归途路线的最后阶段，海瑶会成为宁秩和潮音之间的唯一桥梁——"潮宫主说，您可以来。她等您很久了。" |

**专属剧情**：
- 第18个月左右，如果玩家已经与沧溟宫建立了稳定的贸易关系，海瑶会在一次交易结束时留下一句话——不是转达潮音的，是她自己的话：
> "宁掌柜，我在沧溟宫做事一百多年了。我从来不问为什么。但我想问你一个问题——你相信这个世界上有人活了三百年，只是为了等一个她没见过的人吗？"
>
> 她说完就走了。宁秩当天晚上做了一个梦——他站在深海中，面前是一扇发光的门。门没有锁。他推开了。
>
> 他醒了。窗外是中央荒原的月亮。他发现自己不知道什么时候流了眼泪。
>
> （如果玩家已触发至少3条湮灭线索，这个梦会更清晰——门的后面，是五道光。）
