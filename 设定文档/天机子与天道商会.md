# 天机子与天道商会

---

## 一、天机子

| 项目 | 内容 |
|------|------|
| **身份** | 天道商会创始人，灵墟百年最传奇的商人 |
| **年龄** | 九十八岁——凡人极限 |
| **修为** | 无。他是凡人 |
| **真实姓名** | 已无人知晓。"天机子"是道号，意为"天机不可泄露之人" |

### 他是谁

天机子是一个凡人。在灵墟这个修为至上的世界里，一个人凡人用了七十年时间，建立了一个横跨五大板块的商业帝国。他是怎么做到的？

答案是——**他用信息弥补了灵气的缺失。**

天机子不会修炼，但他会**计算**。他早年游历灵墟时，每到一个地方就做三件事：记录物价、记录商路、记录人事。他用了十年时间，在脑子里构建了一张灵墟的完整经济地图——哪里的货便宜、哪里的路好走、哪个宗门需要什么。

天道商会不是靠"垄断资源"起来的。是靠"我知道你不知道的信息"起来的。

### 天机子知道多少

天机子是灵墟少数几个（可能只有三个人）**完全知道天道碎片真相的非宗门人士**。

他不是通过灵根感知到的——他是通过**数据**推断出来的。

七十年间，天道商会经手的每一笔交易都记录在案。天机子从这些数据中发现了一个他无法解释的模式：同一种灵材，在灵墟不同板块的灵气含量在**缓慢地分化**——同一个品阶的赤炎草，玄冰域产的比三百年前含灵气少了，炎狱域产的却多了。不是均匀的，是分裂的。

他花了十年时间确认这个模式。又花了十年时间寻找解释。最终他通过一些古老的文献（可能是从暗市高价收购的）拼凑出了天道之核的真相。

但他没有公开。因为他知道——公开了也没有用。他一个凡人，能做什么？他选择了一个更实际的做法：**利用这个真相赚钱。**

他知道哪些板块的灵材在变质、哪些板块还维持着原状。他提前布局、提前囤货、提前调整商路。天道商会后来能碾压所有竞争对手，不是偶然——是天机子读懂了灵墟的"身体报告"。

### 天机子对宁秩的态度

天机子听说过宁秩。他从宁秩在中央荒原摆摊的第一天就知道了——不是因为宁秩有什么特别的，而是因为天道商会的眼线遍布灵墟每一个角落。

他一开始没有在意宁秩——一个连修为都没有的小商贩，不值得关注。但当宁秩的天道熔炼名声开始传开后，天机子注意到了。他开始收集宁秩的情报。从他卖过什么货、和谁做过交易、去过哪些板块——天道商会都有记录。

天机子看了宁秩的资料后，做了一件所有人都不理解的事：他下令天道商会**不在中央荒原打压宁秩的生意**。

"那个小子的摊子——不要碰。让他自己长。"

手下人不理解。天机子没有解释。

他知道宁秩是什么。他可能比宁秩自己更早知道宁秩是什么——**一个能听见碎片频率的人。**

他自己是个凡人，他用数据看到了真相。宁秩也是个凡人，但宁秩用另一种方式感受到了同样的东西。天机子在宁秩身上看到了自己的影子——一种跨越了修炼体系的、属于凡人的天赋。

### 天机子的召见

如果玩家在游戏中达到以下条件——商道≥55、且与天道商会的累计交易额达到一定水平——天机子会亲自召见玩家一次。

这不是交易会、不是商业谈判。就是在天道商会总堂顶层的书房里——一个老人坐在窗边，面前摆着一壶茶和两本账本。

> "坐。"
>
> "你知道我是谁。我也知道你。"
>
> "我没有太多时间了——不是指这场谈话，是指我的寿命。所以我就直说了。"
>
> "你不是普通的商人。你手里有一件我花了一辈子才得到的东西。你不知道你手里有什么。但你会知道的。"
>
> "等你知道了——你可以来找我。如果我还活着的话。"

他不会解释更多。但宁秩走出房间时，发现那两本账本被塞进了他的包袱里。上面记录着天道商会创立头十年的一些原始数据——包括灵材价格、商路距离、不同板块的灵气密度变化。

这是天机子送给宁秩的礼物——**他花了一辈子收集的数据的开头。**

## 二、三名义子

天机子一生未婚，没有子嗣。他收养了三个义子——不是因为他想要继承人，而是因为他知道天道商会需要一个能在他死后掌舵的人。但他始终下不了决心选谁。

### 大义子：商鹤

| 项目 | 内容 |
|------|------|
| **年龄** | 四十五岁 |
| **修为** | 筑基后期 |
| **职务** | 天道商会北域总管 |
| **性格** | 稳重、保守、守规矩。他是三个人中最像"合格继承人"的人——做事稳妥、不出错、让人放心 |
| **经营风格** | 维持现状。他不喜欢冒险，不喜欢开拓新市场，不喜欢尝试新模式。按老规矩办事，把现有的生意守好 |
| **对宁秩的态度** | 警惕但不敌对。他觉得宁秩是一个"不安定因素"，但还不值得动手打压 |
| **为什么天机子犹豫** | 商鹤太保守了。天道商会能发展到今天，靠的是天机子的冒险精神。商鹤只能守成，无法开拓 |

### 二义子：商雀

| 项目 | 内容 |
|------|------|
| **年龄** | 三十八岁 |
| **修为** | 筑基中期 |
| **职务** | 天道商会南域总管 |
| **性格** | 精明、圆滑、有野心。他是三个人中最像"商人"的人——会算计、会谈判、会抓住机会 |
| **经营风格** | 激进扩张。他主管的南域是天河道商会在五大板块中增长率最高的区域。但他的手段有时候不太干净——压榨小商贩、与暗市做交易 |
| **对宁秩的态度** | 轻视。"一个没修为的小摊贩——不值得我出手" |
| **为什么天机子犹豫** | 商雀有手段，但没有底线。天道商会交给他，可能会变得更强大，但也会失去天机子积累百年的声誉 |

### 三义子：商鱼

| 项目 | 内容 |
|------|------|
| **年龄** | 三十岁 |
| **修为** | 练气后期 |
| **职务** | 天道商会总堂文书——名义上，实际上他没有实权 |
| **性格** | 安静、观察力强、不争不抢。他是三个人中最不像商人的——他不喜欢应酬、不喜欢谈判、不喜欢出席任何公开场合。他喜欢一个人待在藏书阁里看旧账本 |
| **经营风格** | 没有自己的地盘。他名义上负责总堂的文书工作，但实际上天机子让他做的事情只有一件——**整理和分析天机子七十年来积累的所有数据** |
| **对宁秩的态度** | 好奇。"义父提起过他。说他是个有意思的人。" |
| **为什么天机子犹豫** | 商鱼的能力可能是在三人中最强的——他是唯一一个真正理解了天机子"用信息做生意"方法的人。但他没有任何经营管理经验。天机子不知道他能不能镇住天道商会那些老油条 |

### 继承人之争的影响

| 继承人 | 如果上位 | 对玩家的影响 |
|--------|---------|------------|
| 商鹤 | 天道商会趋于保守，新市场开拓停滞 | 玩家所在的独立商人群体受到的打压减少——但他也不会和玩家合作 |
| 商雀 | 天道商会变得更具侵略性 | 玩家可能被吞并或打压——但如果和商雀合作，能获得更多资源 |
| 商鱼 | 天道商会内部改革，转向"信息驱动"经营 | 玩家可能成为商鱼最重要的外部合作伙伴——但老牌势力会趁机反扑 |
| 无继承人（天机子死后无人继位） | 天道商会分裂，各域总管自立门户 | 市场大洗牌，玩家有机会从中渔利——但灵墟经济也将陷入混乱 |

## 三、天道商会的秘密

### 天机子的书房

天机子的书房——那次召见发生的地方——看起来只是一个老商人的书房：书架、账本、地图、茶具。但在书桌的暗格里，藏着天机子七十年来最机密的东西：

- **一份亲手绘制的灵墟灵气浓度变化图**——标注了从年轻到现在每年各板块的灵气波动
- **一封未寄出的信**——收信人空白，上面只写了一句话："对不起。我应该早点说的。"
- **一颗已经熄灭的灵石**——看起来和普通废灵石没有区别，但天机子把它当作最珍贵的物品保存着

那颗熄灭的灵石，是天道之核碎片的细屑。

天机子不知道它是从哪来的——他在一次拍卖会上偶然拍到的，当时没人知道这是什么。他研究了十年，才确认了它的来历。他把它留在身边，因为他觉得——如果有一天有人能修好碎片，这颗细屑可能会有用。

他一直在等那个人出现。

### 天机子百年数据中看到的真相

天机子用七十年时间记录的数据可以总结为三条曲线：

1. **各板块灵材灵气密度变化曲线**：同一品阶的灵材，各板块的灵气含量在逐年分化——不是均匀下降，而是分裂
2. **灵潮周期频率曲线**：灵潮的发生频率在逐年加快——三百年前平均8-10天一次，现在平均5-7天一次
3. **跨域贸易的长期利润曲线**：同样是跨域倒卖，三百年前的利润率远高于现在——因为板块间的价差在缩小，不是价格趋同，而是货物本身在"变质"

天机子从这三条曲线中读出了一个结论：**灵墟正在慢慢地、不可逆地走向某种终点。** 他不知道终点是什么，但从曲线的斜率来看——大约在他死后的五十年内，会有一个临界点。

他不知道临界点是什么。但他知道——宁秩可能知道。

所以他把账本给了宁秩。
