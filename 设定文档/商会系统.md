# 商会系统设定

> 从一块布到一座商楼，从一个名字到一段传说。

---

## 一、商会的创立

### 商会命名

玩家在游戏早期（大约第3-7天），会触发一个事件——老赵在一次闲聊中问起：

> "宁掌柜，你这摊子也摆了些日子了，总得有个名号吧？人家问起来，我好说'我在XX商会买东西'。"

此时玩家可以为自己的商会取一个名字。这个名字会影响后续游戏中NPC对商会的第一印象，以及部分剧情走向：

| 命名风格 | NPC第一印象 | 可能的影响 |
|---------|------------|----------|
| 务实型（如"宁记商行"） | 正经商人，靠谱 | 天道商会初期不把你当威胁 |
| 霸气型（如"凌霄商会"） | 有野心，值得关注 | 某些宗门更愿意和你合作，但天道商会更早注意到你 |
| 古怪型（如"三块灵石"） | 有趣的人，想认识你 | 暗市势力更愿意接触你 |
| 诗意型（如"归云商号"） | 有来头，可能背景不简单 | 万木灵宗的好感度初始+5 |

> 商会名字确定后不可更改。建议玩家慎重取名。

### 商会等级

商会等级不靠"经验值"提升，而是靠**满足具体条件后手动升级**。每次升级需要花费灵石，并解锁新功能。

| 等级 | 名称 | 升级条件 | 升级费用 | 解锁功能 |
|------|------|---------|---------|---------|
| 1 | 无名小摊 | 开局默认 | — | 基础摆摊、议价 |
| 2 | 有名字的摊位 | 完成命名 + 累计利润≥500灵石 | 100灵石 | 商会招牌（可吸引路过NPC）、老赵会帮你口头宣传 |
| 3 | 固定铺面 | 商道≥20 + 累计利润≥3000灵石 | 800灵石 | 租下一个小铺面（面积×2，客流量+30%）、可存放更多库存 |
| 4 | 小有名气 | 商道≥35 + 与至少一个宗门有交易记录 | 2000灵石 | 可以参加拍卖会、商队开始主动接你的单、管家解锁"坊间传闻"功能 |
| 5 | 商号挂牌 | 商道≥50 + 拥有至少2个板块的进货渠道 | 5000灵石 | 商会正式挂牌，拥有自己的商号印章、可以向其他NPC发放"商会令牌"、解锁分店功能 |
| 6 | 一方商贾 | 商道≥65 + 至少主办过一次拍卖会 | 15000灵石 | 可在其他板块开设分店、解锁"商会声望"细分系统、获得铸魂殿定制商会招牌 |
| 7 | 跨域商会 | 商道≥75 + 在至少3个板块有业务 | 50000灵石 | 商会名字会在各板块传开、可承接宗门级大宗订单、解锁"商会联盟"功能 |
| 8 | 灵墟名号 | 商道≥85 + 参与过至少2个大事件 | 150000灵石 | 商会成为灵墟知名品牌、天道商会正式将你视为值得注意的对象、可发起跨域联合拍卖会 |
| 9 | 商道传奇 | 商道≥95 + 触发过至少一个结局线 | 不可用金钱升级 | 商会进入传说级别。解锁最终商会能力：商会信标——你的商会名字将被写入灵墟商业史 |

## 二、商会声望细分

商道值是玩家的"硬实力"。但除了商道之外，商会还有一个**声望系统**——它决定了NPC对商会的看法：

| 声望指标 | 如何提升 | 如何下降 |
|---------|---------|---------|
| **信誉度** | 按时交货、公平定价、不卖假货 | 欺诈顾客、预约失约、以次充好 |
| **知名度** | 扩大经营范围、参加拍卖会、举办活动 | 不经营、长时间不露面 |
| **宗门关系** | 完成宗门委托、提供优质货源 | 暗市交易被曝光、拒绝合作 |
| **民心** | 善待散修顾客、给老顾客优惠 | 恶意抬价、欺压小贩 |

### 信誉度——最重要的指标

信誉度独立于商道值。一个商道100但信誉度0的玩家，没人愿意和他做生意——即使他货再好。

| 信誉度 | 效果 |
|--------|------|
| 80-100 | 顾客主动加价（"宁掌柜的货，值这个价"） |
| 60-80 | 正常交易，顾客不压价 |
| 40-60 | 顾客压价幅度增加 |
| 20-40 | 部分顾客拒绝交易 |
| 0-20 | 门可罗雀，几乎无顾客上门 |

## 三、分店系统

### 开设分店的条件

当商会等级达到5级（商号挂牌）后，玩家可以在其他板块开设分店。

| 板块 | 开分店费用 | 特殊条件 |
|------|----------|---------|
| 中央荒原（第二分店） | 3000灵石 | 已有第一间铺面 |
| 玄冰域 | 5000灵石 | 与寒渊宗交易次数≥5 |
| 炎狱域 | 5000灵石 | 与焚天阁交易次数≥5 |
| 苍木域 | 5000灵石 | 与万木灵宗交易次数≥5 |
| 金戈域 | 5000灵石 | 与铸魂殿交易次数≥5 |
| 深海域 | 8000灵石 | 与沧溟宫交易次数≥3 |

### 分店的经营模式

玩家不能亲自在所有分店坐镇。分店需要**派驻随从**经营管理：

- 每个分店需要指派一名掌柜（随从）
- 掌柜的商道属性决定分店的经营效率（影响利润百分比）
- 掌柜的忠诚度决定分店的风险（低忠诚度可能卷货跑路）
- 玩家可以定期去分店巡查（检查账目、补充货源、和掌柜谈话提升忠诚度）

### 分店的收益

| 掌柜商道 | 分店利润比例 | 是否需要玩家干预 |
|---------|------------|----------------|
| 1-20 | 总利润的30% | 频繁干预（天天亏本） |
| 21-40 | 总利润的50% | 每周查看 |
| 41-60 | 总利润的70% | 每月查看 |
| 61-80 | 总利润的85% | 季度查看 |
| 81-100 | 总利润的95% | 基本不需要管 |

## 四、商会联盟

当商会等级达到7级（跨域商会）后，玩家可以与其他NPC商会建立联盟关系。

| 联盟类型 | 条件 | 效果 |
|---------|------|------|
| **供货联盟** | 与某个宗门的友好度≥50 | 获得该宗门的独家供货渠道，进货价-15% |
| **商路联盟** | 与另一个独立商会友好度≥40 | 共享商路信息，双方商路运费-10% |
| **防御联盟** | 与某个实力派势力（铸魂殿/天道商会）关系≥60 | 被竞争对手打压时，盟友会出面调解 |
| **信息联盟** | 与沧溟宫或暗市势力关系≥50 | 定期获得对手动向和市场情报 |

## 五、商会的日常开销

商会不是越大越好的。商会等级越高，固定开销也越大，需要玩家持续经营来维持：

| 商会等级 | 每日固定开销 | 主要支出项目 |
|---------|------------|------------|
| 1-2（小摊） | 10灵石 | 摊位费（按天交） |
| 3（铺面） | 50灵石 | 铺面租金+杂费 |
| 4-5（小有名气） | 120灵石 | 铺面租金+随从工资+仓库费 |
| 6-7（一方商贾） | 500灵石 | 分店租金+多名随从工资+保护费 |
| 8（名号） | 1500灵石 | 各分店运营成本+宗门供奉+品牌维护 |
| 9（传奇） | 可变（维护费随经营规模浮动） | 全链条运营成本 |

> 如果玩家不赚钱了，商会等级越高死得越快。一个月不开张，8级商会就得倒闭。

## 六、商会令牌系统

当商会达到5级后，玩家可以向特定NPC发放**商会令牌**：

| 令牌等级 | 可发放给 | 效果 | 数量上限 |
|---------|---------|------|---------|
| 铜令 | 普通顾客/散修 | 持令者享受9.5折优惠 | 不限 |
| 银令 | 老顾客/合作伙伴 | 持令者享受9折优惠+优先供货 | 10枚 |
| 金令 | 重要盟友/引路人 | 持令者享受8折优惠+优先供货+情报共享 | 3枚 |
| 黑令 | 特殊关系 | 持令者可在所有分店调货（相当于玩家的代理人） | 1枚 |

玩家可以随时收回令牌——但收回银令以上级别的令牌，会严重损害与该NPC的关系。

## 七、与现有系统的联动

| 现有系统 | 联动方式 |
|---------|---------|
| **主角成长路线** | 商会的升级节奏与主角成长阶段一一对应 |
| **随从系统** | 分店需要派驻随从管理，培养随从就是在培养分店掌柜 |
| **商路系统** | 分店之间的物流依赖商路，商会等级越高运输需求越大 |
| **拍卖会** | 商会等级达到一定级别后才能主办拍卖会 |
| **管家** | 管家会自动汇报各分店的经营状况、预警风险 |
| **天道熔炼** | 高阶天道熔炼产出的异变物可以作为商会的独家商品 |
| **天机子隐退** | 商会等级影响你在天机子隐退事件中的话语权 |
