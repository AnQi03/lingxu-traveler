# 灵光一现 · 微节奏熔炼交互

> 大多数时候，你投入灵材，闭眼等结果。
>
> 但有些瞬间——炉火之中的五行之力突然变得清晰可见。
> 宁秩的感知被拉入了灵材的内部世界。
> 在那里，你能看到能量在流动、在冲突、在寻找出口。
> 你有机会——用手去"调"它。
>
> 不是每次都有这个机会。但当你看到它的时候——别错过。

---

## 一、设计目标

1. **在随机的熔炼结果中加入可控的玩家操作**——不改变"随机"的核心，但给玩家一个影响命运的窗口
2. **创造"我和炉子有连接"的沉浸感**——不只是点一下按钮等结果，偶尔你需要"亲手稳住它"
3. **保持简洁**——操作简单、不频繁、不打断节奏，但每次出现都让人心跳加速

---

## 二、触发条件

灵光一现不是每次熔炼都触发——它是**特殊条件下的偶发事件**：

| 条件 | 触发概率 | 设计意图 |
|------|---------|---------|
| **基础概率**（无任何加成） | 10% | 偶尔给个惊喜 |
| **投入相生组合**（2件相生） | 20% | 相生的灵材更容易"说话" |
| **投入完整相生链**（3件以上） | 30% | 完整的链条更容易产生共振 |
| **投入高亲密度灵材**（玩家频繁经手的种类） | 30% | 熟悉的灵材在炉火中格外活跃 |
| **赌注超过流动资金50%** | 40% | 压力越大，直觉越敏锐 |
| **连续3次无质变** | 50% | 保底——给连续失败的玩家一个翻盘窗口 |
| **熔炼剧情关键物品** | **100%必触发** | 重要时刻不允许玩家干等随机数 |
| **天道值≥40** | 基础概率+10% | 天道感悟越高，越容易看见能量的流动 |
| **玩家当前疲劳值低**（当日熔炼≤2次） | 概率×1.2 | 精力充沛时感知更敏锐 |
| **玩家当前疲劳值高**（当日熔炼≥4次） | 概率×0.5 | 累了，看不见了 |

**核心原则**：触发是可预期的（条件引导），但不是可控制的（依然有随机成分）。

---

## 三、交互模式

灵光一现触发的瞬间，游戏画面从熔炉外部切换到**灵材内部的感知空间**。

### 感知空间画面风格

- 背景：纯黑，只有五行能量光丝在流动
- 视角：第一人称——玩家"看到"的是宁秩感知到的东西
- 光丝颜色：金/绿/蓝/红/棕，对应五行
- 音效：低沉的环境轰鸣 + 灵材振动的细微嗡鸣
- **没有UI干扰**——没有血条、没有计时条、没有分数——只有能量和你的反应

### 五种模式

每次灵光一现的模式取决于**投入灵材的组合状况**。系统根据以下维度自动匹配：

| 模式 | 触发条件 | 玩家操作 | 成功效果 | 失败后果 |
|------|---------|---------|---------|---------|
| **① 调和冲突** | 投入的灵材中存在相克属性 | 两条不同颜色的光丝正在互相排斥，在它们碰撞的瞬间点击交汇点——"切断"冲突 | 消除相克debuff——降品/报废概率恢复正常 | 相克debuff保留——风险照旧 |
| **② 注入活力** | 灵材整体能量偏弱（品阶低/灵气不活跃） | 一条金色的光丝断断续续地闪烁，节奏提示浮现——玩家跟着节奏点击，像"打拍子"一样给炉火加力 | 升品概率+15%，异变概率+8% | 按基础概率结算，无加成 |
| **③ 锁定方向** | 升品判定已通过，但品质方向不确定 | 五色光丝开始汇聚成一道旋转的光束——光束对准一个刻度盘，玩家在它对准最优刻度时按下"锁定" | 锁定最优品质方向（例如"防御型异变"而不是"普通升品"） | 随机方向——可能不理想但不会更差 |
| **④ 稳定炉压** | 投入品阶不一致 | 能量流紊乱地在炉内横冲直撞——玩家需要在能量流冲到临界点前拖拽到"泄压口"位置 | 消除品阶不一致惩罚——升品概率恢复 | 品阶不一致惩罚保留 |
| **⑤ 决定命运** | 熔炼剧情关键物品（必触发） | 炉火中出现两个方向的光路——一条平稳明亮（"稳住火候"），一条剧烈燃烧（"加一把火"） | 选"稳住"→大概率升品；选"加一把火"→小概率直升仙品但大概率报废 | — |

### 特殊：炉火失控（极低概率）

**触发条件**：投入了极不稳定的组合（如3件以上相克+跨品阶）且同时在熔炼中触发了灵光一现。

**表现**：
- 感知空间不再是安静的黑色——而是红色滤镜，能量光丝疯狂翻涌
- 画面边缘出现裂纹特效——"炉子要撑不住了"
- 宁秩的独白（文字）："——不对，这不对——"

**玩家需要做的**：在2秒内完成**连续操作**：

```
第一步（0-0.8秒）：在翻涌的能量中找到"最亮"的那条光丝——点击它
  ↓ 正确 → 画面裂纹减少一半 → 进入第二步
  ↓ 错误/超时 → 直接报废

第二步（0.8-1.5秒）：引导剩余能量沿着正确的五行相生方向流动——拖拽光丝到对应颜色的出口
  ↓ 正确 → 🔥 炉火重新稳定 → 保底原样，完美操作可逆转为升品
  ↓ 错误/超时 → 报废
```

**设计意图**：
- 炉火失控是**极稀有事件**——普通玩家一周目可能只遇到1-2次
- 操作难度**明显高于普通灵光一现**——让成功稳住的玩家有巨大的成就感
- 失败惩罚和成功回报都很重——高风险高回报
- 直播效果极好——"等等等等等！炉子要炸了！快按！！"

## 四、操作反馈

| 操作状态 | 视觉反馈 | 音效反馈 |
|---------|---------|---------|
| 开始灵光一现 | 画面从熔炉外景->感知空间（渐变，0.3秒） | 嗡——低沉的能量共鸣声 |
| 操作正确 | 光丝平复、颜色变得柔和 | 一声清脆的"叮" |
| 操作错误 | 光丝猛地闪烁一下、变暗 | 一声短促的"呲" |
| 操作超时 | 光丝迅速消散、感知空间变暗 | 嗡鸣声减弱直至消失 |
| 炉火失控·成功稳住 | 红色褪去、光丝回归正常的五彩 | 长舒一口气似的气流声 |
| 炉火失控·失败 | 画面碎裂、变白 | 破碎声+突然静音 |

### 操作后

退出感知空间，回到熔炉外景。无论操作结果如何，玩家都会看到宁秩的双手从炉壁上松开——仿佛刚从专注中回过神来。

然后进入正常的结果揭晓流程。

---

## 五、与天道值的联动

| 天道值 | 效果 |
|-------|------|
| <20 | 灵光一现触发率低；感知空间中的光丝比较模糊，难以判断走向 |
| 20-39 | 触发率提升；光丝开始变得清晰；可勉强分辨颜色 |
| 40-59 | 触发率再提升；光丝清晰可见；"调和冲突"模式中能提前半秒看到碰撞点 |
| 60-79 | 光丝出现"流动方向"提示（微光闪烁指向最优操作位置） |
| 80+ | 灵光一现触发时，宁秩会多出一句独白（"我感觉到它在往那个方向走……"）——暗示操作方向 |

## 六、一个完整的灵光一现回合

```
1. 玩家投入5件宝品灵材 → 点击熔炼
2. 炉火燃起 → 正常等待中……
3. （判定触发灵光一现） → 画面渐变 → 感知空间展开
4. 系统选择模式（根据投入组合）
   → 这次是「调和冲突」——水属性和火属性的光丝在互相排斥
5. 玩家需要在它们碰撞的瞬间点击交汇点
6. 成功 → 光丝平复 → 感知空间淡出 → 回到熔炉外景
7. 结果揭晓 → 「宝品·玄冰髓 × 5 → 宝品·极寒晶核（升品成功）」
8. 玩家感受：😌 "还好我看到了……不然这炉可能就炸了。"
```

> **灵光一现的底层逻辑**：它不是在惩罚玩家——"你没点对，所以炸了。"
> 它是在给玩家一个机会——"本来要炸的，但因为你的操作，稳住了。"
> 区别在于：前者让玩家觉得"我不该碰"，后者让玩家觉得"我救了它"。

---

## 七、微节奏熔炼的"新东西"总结

| 和传统抽卡式炼器的区别 | 我们的设计 |
|----------------------|-----------|
| 传统：放入材料→等随机数→出结果 | 我们：大部分时间也是这样，但偶尔会进入可交互的感知空间 |
| 传统：玩家完全没有操作空间 | 我们：灵光一现时玩家可以影响概率走向 |
| 传统：失败就是"运气不好" | 我们：失败可以归结为"没抓住那个瞬间"——有归因，不纯粹甩锅给随机 |
| 传统：枯燥的重复操作 | 我们：每次熔炼都有可能"来点不一样的"——不确定性本身就是乐趣 |
| 传统：没有操作深度 | 我们：五种模式+炉火失控，每次灵光一现的体验都可能不同 |
