# 游戏边界条件补充

---

## 一、失败条件

灵墟旅商没有"游戏结束"的概念，但有**几种会让玩家陷入困境的状态**：

### 1. 灵石归零

| 情况 | 结果 |
|------|------|
| 身上灵石为0，无库存可卖 | 无法进货、无法交摊位费 |
| 持续3天灵石为0 | 摊位被收回，玩家失去固定经营场所 |
| 持续7天灵石为0 | 管家会发来一条消息："少爷……要不要先回宁家待一阵子？不丢人。" |

**不会发生的事**：宁秩不会饿死、不会被追杀、不会游戏结束。他只是会陷入"先回去躲躲"的状态。

**如何脱困**：
- 找到老赵，他会借给玩家50灵石（一次性的，人情债）
- 触发"散修求助"小事件——帮一个散修个小忙，拿一点报酬
- 向管家求助——管家会用自己的积蓄帮玩家渡过难关（也会触发一段对话：管家不会责备，但宁秩自己会觉得愧疚）

**设计意图**：游戏不会惩罚失败，但会让玩家感受到"穷了很难受"。这种难受足以驱动玩家不想再穷一次。

### 2. 信誉度归零

| 情况 | 结果 |
|------|------|
| 信誉度≤20 | 顾客基本不上门 |
| 信誉度≤10 | 老赵都不来买你的东西了 |
| 信誉度=0 | 天道商会派出调查员——如果你的信誉度长期为0，你的商会执照可能被吊销 |

**如何恢复**：
- 通过完成小额诚信交易缓慢恢复（每天最多+2）
- 完成某个宗门的委托（一次性+10）
- 老赵愿意帮你在熟人圈子里说句话（人心≥30时可触发）

### 3. 所有随从全部离开

最糟糕的管理失败。商会失去所有人力，玩家退回到第一阶段——一个人守着一个空铺面。

**不会发生的事**：不会有"孤家寡人"的强制结局。随从走光了，玩家可以从头再来——重新招人。

### 总结

灵墟旅商没有**硬性失败条件**。最坏的情况就是"回到起点"，不会"游戏结束"。这是一款允许玩家犯错、允许玩家重来的游戏。

## 二、随从工资标准

| 随从类型 | 工资（每月） | 说明 |
|---------|------------|------|
| 无特长随从 | 100灵石 | 刚入行的，只能做基础杂务 |
| 单特长随从 | 250灵石 | 有一技之长的（口才好/眼力毒等） |
| 双特长随从 | 500灵石 | 稀缺人才 |
| 特殊随从（暗市买来的） | 无需工资 | 但需要不定期"投喂"（提供修炼资源或灵石），否则忠诚度每月-5 |
| 老顾客转化来的随从 | 150灵石 | 友情价——因为他们本来就和宁秩有交情 |

**工资与忠诚度**：
- 按时发工资→忠诚度每月+1
- 拖欠工资1个月→忠诚度-5，随从会抱怨
- 拖欠工资2个月→忠诚度-15，随从可能提出辞职
- 拖欠工资3个月→随从自动离开

> 管家会在每月初提醒玩家："少爷，该发工钱了。" 如果玩家灵石不足，管家会建议先发工资再进货——"人比货重要。"
