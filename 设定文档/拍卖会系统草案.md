# 拍卖会系统设计草案

> 定位：中期解锁参与权，后期解锁主办权。既是资金流转的出口，也是社交博弈的舞台。

---

## 一、设计目标

1. **中期资金出口**：玩家积累了一定灵石后，需要高阶灵材/稀有物品来突破经营瓶颈，拍卖会提供获取渠道
2. **社交博弈舞台**：拍卖会上会遇到各势力的人——宗门采购、其他商会、散修大能，每一次举牌都是关系的博弈
3. **后期权力象征**：能自己开拍卖会了，说明你从一个摆摊的变成了灵墟有头有脸的人物

---

## 二、参与拍卖会（中期解锁）

### 解锁条件
- 商会达到一定声望等级（比如「小有名气」）
- 或者持有某张「拍卖会请柬」（触发事件获得）

### 拍卖会来源
- **天道商会**举办的大型拍卖会：规模最大，东西最全，但竞争激烈
- **万宝楼**的中型拍卖会：物品质量稳定，规矩公平
- **暗市拍卖**（需特殊渠道）：来路不明的货，价格波动大，可能被查
- **宗门专场**：某个宗门清仓/募资举办的定向拍卖

### 参与流程
```
收到请柬/打听到拍卖会信息
  → 缴纳入场押金（或凭声望免费入场）
  → 预览拍卖品目录（部分公开部分隐藏）
  → 决定预算上限，进场
  → 拍卖开始，逐件竞拍
  → 举牌/加价/放弃
  → 成交/流拍
```

### 竞拍机制
- **明拍**：公开举牌，价高者得——但要小心被人盯上（\"这人灵石不少\"）
- **暗拍**：密封投标，价高者得但不知道别人出多少——考验心理博弈
- **一口价**：部分拍品设有立即成交价，不想竞价可以直接拿下

### 竞品风格（给玩家制造决策压力）

| 竞拍者类型 | 风格 | 提示信号 |
|-----------|------|---------|
| 宗门采购 | 理性，有预算上限 | 某价格后突然停手 |
| 其他商会 | 试探性，会判断你的底线 | 小幅加价拖节奏 |
| 土豪散修 | 情绪化，看上了就不放手 | 大幅跳价 |
| 托儿（暗市） | 故意抬价 | 只在有人出价时跟 |

### 风险与收益
- **拍亏了**：一时上头花了大价钱买了不值的东西，资金链断裂
- **被盯上**：当众露富，之后商路可能被劫
- **捡漏**：没人识货的宝贝被你低价拿下
- **结缘**：和某位竞拍者因为礼让/竞价结下善缘或梁子

## 三、主办拍卖会（后期解锁）

### 解锁条件
- 声望达到「名动一方」以上
- 拥有或租用拍卖场地
- 能凑齐至少5件有分量的拍品

### 主办方的准备工作

#### 1. 征集拍品
- 自己的库存：天道熔炼出的稀罕物、积压的高阶灵材
- 委托代拍：其他修士/小商会托你卖（抽成）
- 宗门合作：大宗门给面子放几件好东西撑场子

#### 2. 宣传与邀约
- 根据宣传力度决定到场人数和宾客质量
- 可以定向邀请特定势力（比如请寒渊宗的人来，他们对冰系灵材最感兴趣）
- 宣传成本 vs 到场质量的权衡

#### 3. 场地与安保
- 租用万宝楼的场地（贵但安全）
- 自己在商会大厅办（省钱但要做好安保）
- 暗市露天拍（不用场地费但随时可能被查）

#### 4. 定价与排期
- 起拍价定多少？定高了流拍，定低了亏本
- 拍品顺序：暖场货放前面，压轴货放最后
- 可以安排托儿防止冷场

### 主办方的收益

| 收益来源 | 说明 |
|---------|------|
| 佣金抽成 | 每件成交品抽5-15% |
| 入场费 | 宾客缴纳的入场灵石 |
| 声望收益 | 成功举办拍卖会大幅提升声望 |
| 信息收益 | 知道谁对什么东西感兴趣，后续可以精准推销 |

### 主办风险

| 风险 | 后果 |
|-----|------|
| 流拍太多 | 声望下降，下次没人来了 |
| 安保不力 | 拍品被抢/被偷 |
| 得罪人 | 拒绝了某个势力的入场请求，结仇 |
| 亏本 | 场地费+宣传费花了一大笔，成交额不够cover成本 |

## 四、与现有系统的联动

| 系统 | 联动方式 |
|-----|---------|
| **天道熔炼** | 熔炼出的高品阶/异变物品是拍卖会的绝佳拍品来源 |
| **好感度** | 老顾客/好友会来捧场；敌对势力可能来捣乱 |
| **声望/口碑** | 声望决定你能参加/举办什么级别的拍卖会 |
| **灵潮周期** | 灵潮期大家手头宽裕，拍卖成交价更高 |
| **商路/物流** | 拍到大件货物需要运回去，路途可能被劫 |
| **暗市系统** | 有些拍品只能走暗市拍卖，正道拍卖会上不了 |
