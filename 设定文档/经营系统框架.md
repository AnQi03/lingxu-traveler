# 灵墟商途 — 经营系统框架

## 一、设计哲学

**核心体验：从"自己讨价还价"到"运筹帷幄"，成长感来自经营方式的升级，不只是数字的膨胀。**

玩家在前期亲力亲为，感受每一次交易的紧张和利润的来之不易；后期通过招募随从、扩建店铺，逐步从"掌柜"变成"东家"，不再事事亲力亲为，但要面对更大的决策压力。

---

## 序章：核心资源定义——「灵材」是灵魂，「灵石」是血液

> **关键认知**：灵墟旅商有两个层次的资源，它们角色不同，不能混为一谈。
>
> **灵材才是核心资源**——它是玩家一切操作的出发点，是天道熔炼的载体，是差异化竞争的唯一护城河。
> **灵石是中间介质**——它衡量价值、驱动交易，但它可以被任何其他货币取代而不改变游戏的内核。
>
> 就像石油大亨：石油可以被金子或韭黄取代，核心玩法不变。灵墟旅商的灵材也是如此——如果把它换成"修真界的食材"或"魔法草药"，核心循环依然成立。
>
> 但如果把灵材拿走——没有了品阶鉴微、没有了天道熔炼、没有了灵材图鉴——游戏就只剩一个普通的买卖模拟器。
>
> **灵材就是灵墟旅商的灵魂。灵石只是血液。**

### 为什么灵材是核心资源

| 维度 | 灵材 | 灵石 |
|------|------|------|
| **玩家操作的对象** | 买卖灵材、鉴别灵材、熔炼灵材 | 收钱、付钱、存钱 |
| **差异化优势的来源** | 天道熔炼 + 品阶鉴微——大商会做不了 | 大家都用灵石，没有区别 |
| **剧情驱动力** | 灵材的来源/品阶/异变关联世界真相 | 灵石只是交易的中间结果 |
| **玩家知识的积累** | 认识灵材→辨识品阶→掌握相性→创造异变 | 数字变大/变小，没有深度 |
| **不可替代性** | 玩家是唯一能做这件事的人 | 谁都能赚灵石 |

**一句话结论**：玩家不是在"赚灵石"，玩家是在"经营灵材——灵石只是这个过程的价值标尺。"

### 两个资源的关系图

```
          品阶鉴微（识别价值）
                 │
  采集/采购 ──→ 灵材 ──→ 天道熔炼（创造新价值）
    （灵石流出）    │          │
                    │          └──→ 异变品（独一无二，无法对标价）
                    │
              直接销售 ──→ 灵石（价值标尺）
                    │
              灵石三个去向：
               ├→ 采购新灵材（扩大经营）
               ├→ 升级装备/店铺（提升效率）
               └→ 被系统回收（传送阵/税收/修炼消耗）
```

玩家**真正在做的事**是：获取灵材 → 识别它的真实价值 → 决定直接卖还是熔炼 → 用赚到的灵石获取更多/更好的灵材。

灵石只是这个循环的**润滑剂**——它让交易发生，但它不是玩家操作的核心。

### 这对设计意味着什么

| 设计决策 | 灵材作为核心 | 灵石作为核心（改前） |
|---------|------------|-----------------|
| 新手引导 | 先教玩家认识灵材、学会鉴别 | 先教玩家怎么讨价还价赚灵石 |
| 玩家成长感的来源 | "我能辨认的灵材种类变多了" / "我能熔出宝品了" | "我的灵石余额变大了" |
| 成就感峰值 | 第一次熔出宝品 / 第一次发现相生组合 / 第一次辨认出被低估的灵材 | 第一次赚到1000灵石 / 第一次收到中品灵石 |
| 游戏深度的体现 | 灵材图鉴的学习曲线、品阶鉴微的经验积累、天道熔炼的创造力 | 金钱管理（谁都能做） |
| 差异化 | 全灵墟只有玩家能做 | 大商会的灵石比玩家多得多 |

### 落实到经营框架的改动

基于以上认知，整个经营系统框架围绕**灵材**展开：

1. **品阶鉴微**不是"一个额外技能"——它是玩家认识世界的方式。每次接触一件灵材，玩家都在积累"知识"。这个知识不是数值，而是**品味**——眼光越毒，容错空间越大
2. **天道熔炼**不是"一个特色功能"——它是玩家创造力的出口。它的价值不在"升品的概率"，而在"玩家对灵材属性的理解深度决定成功率的隐形加成"
3. **灵材图鉴**不是"一个数据库"——它是玩家的成长记录。填满图鉴本身就是一种收集乐趣，和赚灵石并列的成就感来源

### 循环的闭合性校验

| 环节 | 是否闭合 | 证明 |
|------|---------|------|
| 灵材→灵石 | ✅ | 出售灵材直接获得灵石，价格由品阶+议价决定 |
| 灵石→灵材 | ✅ | 采购/跨域贸易/暗市买入都用灵石支付 |
| 次级资源→灵材效率 | ✅ | 好感度→灵材成本↓（详见好感度声望系统.md §7） |
| 次级资源→灵石效率 | ✅ | 商路物流→资金周转率↑（详见商路系统设定.md §7） |
| 灵石→系统回收 | ✅ | 传送阵/税收/修炼消耗/熔炼报废（详见货币与经济系统.md §3.2） |
| 灵石总量控制 | ✅ | 矿脉有限产出，顾客有购买力上限（详见货币与经济系统.md §3.1） |

**结论**：灵墟旅商的资源循环满足视频方法论的全部要求——核心资源有清晰流动规则、次级资源全部回流到核心资源、玩家的每一步操作都围绕着"获取灵材→加工灵材→出售灵材→获取更多/更好的灵材"这个循环展开。

## 〇、核心问题：小摊凭什么活得下去？

> 灵墟有大型商会垄断，散修和修士凭什么来玩家的小摊买东西？

### 答案：大商会吃不下、看不上、管不到的市场缝隙，就是玩家的生存空间。

**第一层原因：天道熔炼——大商会做不到的事**

这是最核心的差异化。宁秩的五行杂灵根让他拥有两种大商会完全不具备的能力：

1. **品阶鉴微**：杂灵根让他对各种灵材的品阶判断极度敏锐，别人看不出的品阶差异他能一眼辨出。大商会的伙计只能按常规标准分级，经常出现"标价凡品实为灵品"或"灵品中藏有微瑕"的情况。宁秩能挑出被大商会误分类的宝贝，也能发现大商会以次充好的货——**这让他在散修圈子里很快建立了"这人眼力毒"的口碑。**

2. **天道熔炼**：大商会的商人灵根纯粹，根本无法触发熔炼。整个灵墟只有宁秩这种杂灵根才能感知灵材间的共鸣关系。这意味着**只有玩家的小摊能提供"可能升品"的灵材**——虽然概率低，但对赌徒和急需高阶灵材的修士来说，这就是唯一的渠道。

> "大商会卖的是确定性，我卖的是可能性。"

**第二层原因：大商会的傲慢与盲区**

| 大商会的问题 | 玩家的机会 |
|-------------|-----------|
| **不接小单**：散修买三株灵草？排队等叫号，态度冷淡 | **亲切灵活**：你亲自招呼，愿意花时间聊需求 |
| **不议价**：标价多少就是多少，灵石不够请出门 | **可以谈**：人情冷暖，价格好商量 |
| **品类固定**：只卖量大好管的常销货，冷门灵材一律不进 | **什么都能找**：接预约订单，帮顾客专门去淘 |
| **不看人**：有钱就是爷，没钱靠边站，不记得你是谁 | **认人**：老顾客有交情，急事可以赊账通融 |
| **不冒险**：天道熔炼？听都没听过，不可能碰 | **敢赌**：熔炼出来的稀罕物，大商会根本没有 |

**第三层原因：灵墟的经济生态本身就有缝隙**

灵墟不是一个完全垄断的市场，原因如下：

- **灵潮周期**：灵潮涌动时需求暴增，大商会的库存根本供不上，散修只能到处找小摊
- **地理分散**：五大板块各有特色灵材，大商会的分号不可能覆盖每一个角落
- **暗市需求**：有些东西上不了大商会的台面（违禁灵材、来路不明的遗物），但小摊可以偷偷转手
- **宗门壁垒**：大宗门垄断了自己的产出，但不经允许大商会也拿不到，反而独立商人有时能通过私人关系搞到

### 总结：三个"凭什么"

| 凭什么 | 解释 |
|--------|------|
| **凭本事** | 天道熔炼+品阶鉴微，大商会没有的能力 |
| **凭态度** | 愿意亲自招呼、愿意谈价、愿意帮找货 |
| **凭缝隙** | 灵潮波动、地理分散、暗市需求，垄断者覆盖不到的地方 |

### 口碑传播逻辑（前期自然获客）

玩家不需要"广告"，口碑是自然传播的：

```
第一个顾客 → 发现"这人眼力很毒，挑的货比大商会靠谱"
  → 告诉同门/朋友
  → 散修圈子里传开："中央荒原新开了个小摊，老板识货"
  → 客流量自然增长
  → 有客人来问"听说你能把灵材熔了升品？"
  → 天道熔炼的名声开始扩散 → 更多赌徒型/急需型顾客上门
```

这个逻辑也解释了为什么后期大商会开始视玩家为威胁——不是你抢了他们的客户，是你在他们看不到的地方长出了一整个他们无法复制的生态。

## 二、阶段划分

### 第一阶段：亲力亲为（游戏前1/3）

> 关键词：面对面、讨价还价、缺货焦虑、口碑积累

**玩家状态**：小摊位，一个人撑全场，既是采购员也是售货员。

#### 顾客交互流程

```
顾客上门
  │
  ├→ 顾客表明需求（要什么灵材/几品/多少量）
  │
  ├→ 【判断】玩家有现货？
  │   │
  │   ├─ 有现货 → 进入【讨价还价】
  │   │           │
  │   │           ├→ 成交 → 灵石入账 + 好感度 ±
  │   │           └→ 谈崩 → 顾客离开，可能损失口碑
  │   │
  │   └─ 无现货 → 进入【预约取货】
  │               │
  │               ├→ 玩家承诺取货时间
  │               │   │
  │               │   ├→ 时间合理 → 顾客接受，等待
  │               │   └→ 时间过长 → 顾客拒绝离开
  │               │
  │               └→ 顾客等待期间 → 可能被竞争对手截走
  │
  └→ 顾客离开（满意度影响口碑）
```

#### 讨价还价系统

**核心机制**：以市场参考价为锚，双方在此基准上博弈。成交价落在双方可接受区间的交集中即为成功。

##### 市场参考价

每种灵材都有一个**市场参考价**，玩家在议价界面可以直观看到。

| 要素 | 说明 |
|------|------|
| 来源 | 基于近期该灵材在灵墟各集市的成交均价计算 |
| 波动 | 受灵潮周期、供需关系、突发事件影响，不是固定值 |
| 更新频率 | 每个灵潮小周期（约游戏内1天）刷新一次 |
| 作用 | 给玩家一个议价锚点，但**不等于顾客的心理底价** |

**市场参考价的局限**：
- 参考价是均价，不代表当前这个顾客愿意出多少
- 某些灵材交易量小，参考价可能失真（被个别大单拉高或拉低）
- 灵潮期间价格剧烈波动，参考价滞后于实际行情
- 玩家的品阶鉴微能力可以判断"这批货实际品阶比市面标的高"，等于暗示你**可以加价卖**

##### 顾客心理底价

每位顾客心中有一个**最高成交价**，由市场参考价乘以一个类型系数得出。这个数值玩家**不可直接看到**，需要通过顾客的言行和议价过程推测。

| 顾客类型 | 心理底价系数 | 议价风格 | 提示线索 |
|----------|-------------|----------|----------|
| 散修 | 0.8-0.9×参考价 | 粗犷，两轮定胜负 | 说话直接，会暗示"别磨蹭" |
| 宗门采购 | 1.0-1.1×参考价 | 精明，会货比三家 | 会提到"别家什么价" |
| 炼药师 | 0.9-1.0×参考价 | 专业，懂行情 | 会指出货品瑕疵压价 |
| 急需客 | 1.3-2.0×参考价 | 几乎不议价 | 明确说"急用，价好说" |
| 老顾客 | 1.0-1.15×参考价 | 温和，有信任底 | 会说"老交情了" |

> 例：灵品赤炎草市场参考价100灵石，散修心理底价约80-90，急需客可能愿意出130-200。

**额外影响因素**：
- 好感度：与玩家好感高的顾客，系数微增（更愿意让你赚）
- 供需紧张度：灵潮期间该灵材紧缺，所有类型系数上浮
- 玩家口碑：口碑高→顾客信任你的品阶判断→系数微增

##### 议价交互设计

| 步骤 | 玩家看到的 | 发生了什么 |
|------|-----------|-----------|
| 1. 顾客出价 | 顾客报出一个价格 | 通常低于心理底价（试探性出价） |
| 2. 玩家决策 | 看到市场参考价+进货成本，选择还价 | 还价幅度越大风险越高 |
| 3. 顾客反应 | 顾客态度变化（接受/还价/不耐烦） | 靠近心理底价时顾客会松口 |
| 4. 最终结果 | 成交/谈崩 | 成交价落在双方交集内即成功 |

**议价轮次**：通常2-3轮，超出后顾客不耐烦概率大增。急需客1轮定胜负，老顾客可多聊几轮。

**关键决策点**：
- 看到参考价100，顾客出价70——这是真心只值70，还是在试探？
- 你的进货成本60，参考价100，该还价到多少？
- 顾客第二轮还到85，你猜他底价在90左右——接受85落袋为安，还是再压一下到88？

> 议价的乐趣不是算数学题，是**读人**——参考价给你方向，但每一单都是和具体的人打交道。

#### 预约取货系统

**核心机制**：没有现货时，玩家可以和顾客约定取货时间。时间越长，顾客接受度越低；延期则受惩罚。

| 要素 | 说明 |
|------|------|
| 基础等待容忍 | 不同顾客类型有不同的最大等待时间 |
| 灵潮影响 | 灵潮期间顾客更着急，容忍度降低 |
| 竞争威胁 | 等待期间竞争对手可能截走顾客（概率事件） |
| 定金机制 | 高价值订单可收定金，锁定顾客但不保证对方一定来取 |

**预约时间与顾客接受度**：

| 顾客类型 | 最大容忍等待 | 说明 |
|----------|-------------|------|
| 急需客 | 1个时辰 | 几乎不接受预约，除非加急费 |
| 散修 | 半天 | 勉强能等 |
| 炼药师 | 1天 | 懂行，知道好货需要时间 |
| 宗门采购 | 2天 | 有计划性采购 |
| 老顾客 | 3天 | 信任度加成 |

**延期惩罚**：

| 延期程度 | 惩罚 |
|----------|------|
| 轻微延期（1个时辰内） | 好感度-1，顾客抱怨但取货 |
| 中度延期（半天内） | 好感度-3，顾客可能拒绝取货要求打折 |
| 严重延期（超过半天） | 好感度-5，顾客取消订单，口碑-1 |
| 完全失约 | 好感度清零，口碑-3，该顾客不再上门 |

**守信奖励**：提前交货可获得好感度+2，有概率触发"回头客"事件。

### 第二阶段：小有规模（游戏中1/3）

> 关键词：雇佣帮手、宗门合作、商路开拓、资源博弈

**玩家状态**：有了店铺，雇了1-2个伙计，开始有资格主动找宗门谈合作，从"等人上门"变成"主动出击"。

#### 店铺经营（承接前期）

| 机制 | 说明 |
|------|------|
| 伙计售货 | 常规交易伙计可以处理，但利润不如玩家亲自谈（议价能力低） |
| 大单上报 | 高价值/特殊顾客需求会上报给玩家决策 |
| 采购委托 | 可以派伙计去进货，但眼光不如自己，可能买贵或买错品阶 |
| 口碑系统生效 | 口碑影响客流量，口碑高=客人多，口碑低=门可罗雀 |

#### 宗门合作系统（中期核心新玩法）

**设计意图**：前期玩家只跟散客打交道，中期开始接触"机构客户"——宗门。跟宗门谈合作是全新的体验：不是讨价还价赚差价，而是建立长期关系、争取特权、管理信誉。

**合作触发**：
- 玩家口碑达到一定阈值后，会有宗门采购主动接触（被动）
- 玩家也可以主动前往宗门拜访，提出合作意向（主动）
- 主动拜访需要满足前置条件（如持有推荐信、通过入门考验、或由NPC引荐）

**合作谈判流程**：

```
玩家前往宗门 / 宗门派人来接触
  │
  ├→ 表明合作意向
  │
  ├→ 宗门提出条件（可能有多轮）
  │   ├ 供货品类与数量要求
  │   ├ 价格区间（通常低于零售价，但量大稳定）
  │   ├ 交货周期要求
  │   └ 独家条款（要求玩家不卖给竞争对手/其他宗门）
  │
  ├→ 玩家回应
  │   ├ 接受全部条件
  │   ├ 谈判（可就某项条件讨价还价）
  │   └ 拒绝（可能影响关系，也可能下次再来）
  │
  └→ 达成合作 → 签订契约
```

**合作类型**：

| 合作类型 | 说明 | 风险 | 收益 |
|----------|------|------|------|
| 稳定供货 | 按周期给宗门供指定灵材，价格固定 | 周期压力大，缺货要赔 | 收入稳定，宗门好感提升 |
| 优先采购权 | 宗门产出的特定灵材优先卖给你 | 需支付定金/预付款 | 拿到稀缺货源，可加价转卖 |
| 独家代理 | 某类灵材只通过你流通 | 不能卖给其他宗门（违约重罚） | 垄断利润极高 |
| 以物易物 | 不用灵石，用灵材互换 | 需要判断对方灵材的实际价值 | 可能捡漏，也可能被坑 |
| 联合探矿 | 共同出资探索新灵脉，产出按比例分 | 探矿可能失败血本无归 | 成功则获得长期稳定货源 |

**宗门好感与信任**：

| 好感等级 | 解锁内容 | 说明 |
|----------|---------|------|
| 陌生 | 只能谈基础供货 | 宗门对你不了解，条件苛刻 |
| 熟悉 | 优先采购权、以物易物 | 履约几次后解锁 |
| 信任 | 独家代理、联合探矿 | 长期合作+关键事件选择后解锁 |
| 盟友 | 宗门庇护、特殊资源渠道 | 信任满+完成宗门专属任务线 |

**违约与后果**：
- 交货延迟：按天数扣好感，超限则合作暂停
- 质量不符（品阶弄虚作假）：好感骤降，可能被拉黑
- 违反独家条款：重罚灵石+好感清零+可能被宗门追责
- 单方面毁约：退还定金+赔偿+长期声誉受损（其他宗门也会知道）

**合作带来的叙事可能性**：
- 两个对立宗门同时找你合作，你只能选一边（或冒险两边瞒）
- 宗门内部有人想让你当棋子，给的条件好但暗藏陷阱
- 长期合作后，宗门遇到危机找你帮忙（分支剧情触发点）

#### 商路开拓

| 机制 | 说明 |
|------|------|
| 跨域采购 | 前期只在中央荒原进货，中期可前往其他域采购特色灵材 |
| 商路风险 | 跨域运输有劫匪、灵潮异变等随机事件 |
| 护卫需求 | 商路需要雇佣护卫（与随从系统联动） |
| 路线优化 | 不同路线距离/风险/成本不同，玩家选择最优解 |

**这一阶段的核心体验**：

1. **从被动到主动**：不再只是等人上门，而是主动出击找宗门、谈条件、拓商路
2. **从短期到长期**：单笔交易变成契约关系，要考虑的不是"这单赚多少"而是"这个合作值不值得投入"
3. **从自由到约束**：签了独家就不能卖给别家，接了大单就必须按时交货——每一次选择都在关闭一些门、打开一些门
4. **叙事与经营的交织**：宗门合作不只是数值交换，每次谈判都可能触发故事分支

---

### 第三阶段：商道大能（游戏后1/3）

> 关键词：管人不管事、供应链、势力博弈

**玩家状态**：多个分号，掌管商队，成为一方商道势力。

**经营重心转移**：

| 从 | 到 |
|----|-----|
| 自己讨价还价 | 定价策略、让管事执行 |
| 自己进货 | 管理供应链和商路 |
| 面对单个顾客 | 面对宗门大客户、竞争对手势力 |
| 口碑 | 品牌与势力声望 |

**这一阶段的核心体验**：决策从"这笔赚多少"变成"这个方向要不要投入"，经营从微观操作变成宏观布局。但关键谈判（与大宗门、天骄等）仍需亲自出马，这些场景提供叙事高潮。

## 三、顾客需求生成规则

### 需求构成

每个顾客的需求由以下要素组成：

```
需求 = 物品类型 + 品阶 + 数量 + 急迫度 + 预算上限
```

### 生成权重（受灵潮影响）

| 灵潮阶段 | 需求特征 | 常见顾客类型 |
|----------|---------|-------------|
| 灵潮退去 | 基础灵材为主，量少价低 | 散修居多 |
| 灵潮平稳 | 各类均衡 | 混合 |
| 灵潮涌动 | 高阶灵材需求暴增，急需客增多 | 炼药师、宗门采购激增 |
| 灵潮巅峰 | 稀有灵材、大宗订单 | 宗门采购为主，急需客频繁 |

### 特殊需求（叙事驱动）

- 特定NPC的专属需求（与NPC故事线挂钩）
- 限时大宗订单（高利润但高风险）
- "不明物品"需求（顾客描述模糊，需要玩家判断是什么，猜错可能亏本）

## 四、经济平衡要点

### 利润结构

| 交易类型 | 利润率 | 风险 | 说明 |
|----------|--------|------|------|
| 现货现卖 | 10-30% | 低 | 基础收入来源 |
| 预约订单 | 20-50% | 中 | 利润更高，但有延期风险 |
| 议价成交 | 视能力 | 中 | 议价能力决定上限 |
| 大宗订单 | 30-80% | 高 | 高利润但资金占用大 |

### 通货设定

- 基础货币：灵石
- 高阶货币：灵晶（1灵晶 = 100灵石）
- 天道熔炼产出：天材地宝（不可直接标价，需通过熔炼获得）
