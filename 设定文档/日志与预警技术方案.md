## 一、日志系统

### 1.1 日志数据结构

```
res://scripts/systems/log_system.gd
```

```gdscript
# 日志条目
class_name LogEntry
var timestamp: Dictionary  # {year, month, day, hour}
var category: String       # "trade" | "auction" | "refine" | "relationship" | "milestone"
var title: String          # 日志标题
var detail: String         # 日志正文
var importance: int        # 0=普通 1=重要 2=里程碑
var related: Array[String] # 关联的实体ID（灵材ID/势力ID等）

# 日志系统（全局单例）
# 自动记录玩家关键行为，可查看和检索
```

### 1.2 记录触发点

| 触发事件 | 日志内容 | 分类 | 重要性 |
|---------|---------|------|-------|
| 完成一笔交易 | "以XX价格卖出X件XX，净赚XX灵石" | trade | 0 |
| 参加拍卖会 | "参加了XX拍卖会，拍得XX，花费XX" | auction | 1 |
| 天道熔炼成功升品 | "成功将X件XX熔炼为XX！" | refine | 2 |
| 天道熔炼报废 | "熔炼失败，X件XX化为灰烬" | refine | 1 |
| 宗门关系变化 | "与XX宗的关系提升至XX" | relationship | 1 |
| 解锁新地域 | "首次抵达XX域" | milestone | 2 |
| 商会升级 | "商会声望达到XX，解锁新功能" | milestone | 2 |
| 管家特定提醒 | "管家报告：XX" | system | 0 |

### 1.3 存储方案
- 每个存档保存一个 JSON 格式的日志数组（随着游戏整体存档读写）
- 游戏内按分类/时间筛选浏览
- 可以一键跳转到日志所记录的事件发生地点

## 二、事件预警系统

### 2.1 预警数据结构

```gdscript
class_name GameAlert
var alert_id: String        # 唯一ID
var type: String            # "deadline" | "disaster" | "opportunity" | "visitor" | "price_surge"
var priority: int           # 0=信息 1=提醒 2=紧急
var title: String           # 标题
var body: String            # 管家说的原话
var trigger_time: Dictionary # 触发条件（游戏内时间或事件）
var action_hint: String     # 建议玩家做什么
var is_read: bool           # 玩家是否已查看
var dismissed: bool         # 玩家是否已忽略
```

### 2.2 预警种类与触发逻辑

| 类型 | 触发条件 | 优先级 | 提前量 |
|-----|---------|--------|-------|
| 订单到期 | 距预约截止还有半天 | 1 | 半天 |
| 订单超时 | 已过截止时间 | 2 | 立即 |
| 灵潮预报 | 距灵潮来临1-2天 | 1 | 1-2天 |
| 拍卖会通知 | 拍卖会前1天 | 1 | 1天 |
| 宗门来访 | 使者已出发（约2日后到） | 1 | 2天 |
| 商路危险 | 某商路出现劫匪（概率事件） | 2 | 立即 |
| 价格异动 | 某灵材单日涨幅超30% | 0 | 立即 |
| 竞品行动 | 概率事件检测 | 1 | 立即 |

### 2.3 预警调度器

```
res://scripts/systems/alert_scheduler.gd
```

核心逻辑——**每游戏时辰（或每次过夜时）检查一次**：
1. 遍历所有活跃的预约订单，检查是否接近截止
2. 检查灵潮计时器，看是否在预报窗口内
3. 检查拍卖会日程表，看是否有即将开始的拍卖会
4. 随机事件骰子（商路安全、竞品行动等）
5. 将新触发的预警加入待推送队列
6. 如玩家在线，立即弹出玉简闪动通知；如玩家离线（读档时），积攒到下次上线时一次性显示

### 2.4 UI 交互

- 主界面右下角常驻一个**玉简图标**，有未读预警时闪动
- 点击展开**预警列表**，按时间倒序排列，未读的高亮
- 点击某条预警展开详情（管家的原话+建议操作）
- 部分预警提供**快捷跳转**：比如订单到期的预警跳转到该顾客的信息、拍卖会通知跳转到拍卖会界面
- 可以在设置里开关各类预警

## 三、与管家系统的关系

```
              ┌─────────────┐
              │  管家玉简    │  ← 统一入口
              └──────┬──────┘
                     │
          ┌──────────┴──────────┐
          │                     │
    ┌─────▼─────┐        ┌─────▼─────┐
    │  商途日志   │        │  事件预警   │
    │  (历史记录) │        │  (实时推送) │
    └───────────┘        └───────────┘
          │                     │
          │ 玩家主动翻阅         │ 管家主动推送
          │ 分类/搜索/回顾       │ 玉简闪动提醒
```

- 日志是**玩家主动去翻**的——经营一段时间后坐下来看看自己的成长
- 预警是**管家主动推**的——有事情要处理了，玉简就亮了
