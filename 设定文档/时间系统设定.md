# 时间系统设定

> 核心：时间要让人有"过日子"的感觉，又不能拖得太慢让玩家犯困。

---

## 一、基础时间单位

### 游戏内时间流速

| 现实时间 | 游戏内时间 | 说明 |
|---------|-----------|------|
| 1秒 | 约10分钟 | 日常活动快速流转 |
| 1分钟 | 约2.5小时 | 处理几笔交易的时间 |
| 约10分钟 | 1天 | 一个完整的经营周期 |
| 约70分钟 | 1周 | 灵潮小周期 |
| 约5小时 | 1个月 | 可触发中型事件 |
| 约60小时 | 1年 | 灵潮大周期+年度事件 |

> 正常玩一个小时，大概过了一周。节奏感参考《星露谷物语》——一天过得够快，但每一件事你都能记住。

### 一天的时间划分

| 时段 | 游戏内时间 | 玩家可做的事 |
|------|-----------|------------|
| 上午 | 辰时~午时（7:00-12:00） | 摆摊、进货、老顾客上门 |
| 下午 | 午时~酉时（12:00-18:00） | 摆摊、处理订单、商队抵达 |
| 傍晚 | 酉时~戌时（18:00-20:00） | 收摊、整理库存、熔炼 |
| 夜间 | 戌时~次日辰时（20:00-7:00） | 不可摆摊，可走暗市、整理账目、阅读 |

> 夜间不能摆摊但可以做别的事——倒逼玩家规划每天的时间分配。

---

## 二、时间推进机制

### 操作推进 vs 自动推进

灵墟旅商的时间推进采用**半操作驱动**模式：

- **玩家主动操作时时间不流动**——议价、整理库存、看百科等，时间暂停
- **切换场景/确认行动时时间推进**——发货、收摊、切换板块等
- **过夜是明显的节奏节点**——每天结束时有一个"过夜"过渡，结算当日收支、触发晚间事件

### 每个"游戏日"的典型流程

```
上午（7:00-12:00）
  开摊 → 迎接顾客 → 讨价还价 → 成交几单

下午（12:00-18:00）
  继续卖货 or 去进货 → 处理预约订单 → 商队到达

傍晚（18:00-20:00）
  收摊 → 盘点库存 → 进行天道熔炼

夜间（20:00-次日）
  整理账目/日志 → 去暗市（可选） → 过夜结算
```

> 一个完整的游戏日大约对应**10分钟现实时间**——玩家在这10分钟里做了不少事，但不会觉得时间在飞。

## 三、与系统的时间交互

### 各系统的时间单位

| 系统 | 时间粒度 | 说明 |
|------|---------|------|
| 摆摊/交易 | 以时辰计 | 顾客在一天内会陆续上门 |
| 预约订单 | 以天计 | "三日后交货" |
| 商路运输 | 以天计 | "玄冰域→炎狱域，预计12天" |
| 灵潮周期 | 以周/月计 | 小周期7天，大周期数月 |
| 拍卖会 | 以周计 | 每月几次大型拍卖会 |
| 天道熔炼 | 以天计 | 每天限5次 |
| 好感度变化 | 以天/周计 | 一次大交易可能立即见效 |
| 宗门事件 | 以月/季计 | "每季度宗门采购预算刷新" |
| 剧情推进 | 以月/年计 | 大事件数月到一年一次 |

### 时间提示

玩家随时可以看到当前时间：
- 界面左上/右上角：显示"丙午年·三月·十二日·申时"
- 也可以切换到简洁模式："春三月·十二·申"
- 重要事件发生前，管家会提醒时间

## 四、为什么这个节奏合理

### 不会太快（每天10分钟现实时间）

10分钟里玩家要做：
1. 开摊（1-2分钟）
2. 接待3-5批顾客（3-5分钟）
3. 处理预约/发货（1-2分钟）
4. 熔炼（1分钟）
5. 过夜结算（30秒）

每一件事都是**有意识的操作**，不会"唰一下一天就过完了"。

### 不会太慢（一周≈70分钟）

- 灵潮小周期7天 → 约70分钟现实时间刷新一次，节奏感强
- 拍卖会每周一次 → 玩家有足够时间备货，不会觉得等太久
- 预约订单3天 → 约30分钟现实时间，紧迫感刚好
- 商路12天 → 约2小时，差不多一次游戏的时长

### 长期事件的节奏

| 事件 | 游戏内时间 | 现实时间 | 感受 |
|------|-----------|---------|------|
| 灵潮小周期 | 7天 | ~70分钟 | 每次游戏都能经历1-2次 |
| 拍卖会 | 每周/月 | ~70分/5小时 | 每次游戏基本都能参与 |
| 宗门季度采购 | 3个月 | ~15小时 | 几天玩下来能赶上一次 |
| 年度事件 | 1年 | ~60小时 | 正常玩家通关前能遇到 |
| 剧情大事件 | 数月到数年 | 几十小时 | 贯穿始终 |

> 设计原则：**大多数时间敏感的内容，玩家每次游戏都能遇到至少一次**。不会出现"玩了一天什么都没发生"或者"一天之内什么都发生了"的情况。

## 五、一周目通关时间

### 时间换算

| 现实时间 | 游戏内时间 |
|---------|-----------|
| ~10分钟 | 1天 |
| ~70分钟（1小时+） | 1周 |
| ~5小时 | 1个月 |
| ~60小时 | 1年 |

### 一周目预计时长

模拟经营游戏一周目通关大约需要**2-3个游戏年**，按星露谷的节奏换算：

| 阶段 | 游戏内时间 | 现实时间 | 内容 |
|------|-----------|---------|------|
| 前期（摸索期） | 第1-3个月 | ~15小时 | 熟悉系统、摆摊积累第一桶金、首次天道熔炼、接触暗市 |
| 中期（发展期） | 第4-12个月 | ~45小时 | 扩张店铺、商路打通、参与拍卖会、宗门关系建立、管家系统深度使用 |
| 后期（鼎盛期） | 第13-24个月 | ~60小时 | 主办拍卖会、触发剧情大事件、三道走到一个方向上、结局触发 |

**总计：现实时间约60-80小时，游戏内约2年**

### 阶段性体验参考

| 时间点 | 玩家应该体验到的内容 |
|-------|-------------------|
| 第1周（~70分钟） | 学会摆摊和议价，完成第一次预约订单 |
| 第1个月（~5小时） | 第一次天道熔炼，第一次去暗市，现金流稳定 |
| 第3个月（~15小时） | 有固定客源，开始考虑扩张，参与了一次拍卖会 |
| 第6个月（~30小时） | 商路打通，在多板块有仓库，小有规模 |
| 第1年（~60小时） | 商会小有名气，宗门合作启动，管家深度绑定 |
| 第1.5年（~90小时） | 举办第一次自己的拍卖会，分支剧情开始收束 |
| 第2年（~120小时） | 结局触发节点 |

> 和星露谷一样，**通关不是终点**。玩家通关后可以继续经营下去（沙盒模式），也可以选择进入二周目继承部分内容（如天道经验、部分配方记录等）。

### 通关后的选择

| 选项 | 说明 |
|------|------|
| **继续经营（沙盒模式）** | 世界继续运行，所有系统正常运作，但不再有主线推进。适合想把自己商会做到极致的玩家 |
| **进入二周目** | 重置大部分进度，但继承部分内容（见下方继承表），可走不同的剧情路线 |
| **封档** | 保存成就数据，结束游戏 |

### 二周目继承内容

| 继承 | 不继承 |
|------|--------|
| 天道熔炼的配方记录（已发现的相生组合） | 灵石、库存、店铺 |
| 管家的部分知识（世界观百科会保持） | 所有好感度、声望值 |
| 暗市的入场资格（不用再找人引荐） | 暗市保证金和信誉 |
| — | 商路进度、在途货物 |
| — | 所有剧情相关状态 |

> 二周目的核心卖点是：**你带着上辈子的经验和认知，重新走一条不同的路**。你知道了玄冰髓值多少钱、知道暗市怎么走、知道哪些宗门好说话——但你要从头再赚一遍灵石。
