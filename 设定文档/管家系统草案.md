# 管家系统设计草案

> 定位：玩家的私人助理，也是灵墟旅商的"引导精灵"。既是百科全书，也是预警系统。

---

## 一、设计目标

1. **新手引导**：玩家不了解世界观/物品/势力的信息时，随问随答
2. **信息聚合**：把散落在各处的游戏信息汇聚到一个入口——不需要翻菜单找
3. **主动预警**：重要事件快过期/发生了，管家主动跳出来提醒
4. **沉浸感**：不是冷冰冰的系统界面，而是一个有性格的 NPC 在帮你打理事务

---

## 二、管家的身份设定

### 背景
- 宁秩从宁家逃出来时，老管家偷偷塞给了他一本 **《灵墟商事录》** 和一枚传讯玉简
- 老管家说：\"少爷，这本书记载了老奴这些年攒下的商道经验，你遇到不懂的就去翻翻。传讯玉简我已经炼好了，有什么要紧事我会告诉你。\"
- 后来这本书记录的内容越来越多，渐渐成了一个**活的灵墟百科全书**

### 性格
- **忠诚可靠**：老派管家作风，对宁秩忠心耿耿
- **话多但不啰嗦**：你问他就会详细讲，但平时不会打扰你
- **见多识广**：在宁家做了几十年，对各宗门、各势力、各种灵材都如数家珍
- **偶尔毒舌**：你买亏了或者做了蠢事，他会委婉地吐槽一句

### 形象
- 像素风——一位穿着朴素、头发花白但精神矍铄的老者
- 没有实体跟随，**以书信/传讯玉简的方式在游戏里出现**
- 玩家看玉简时，画面角落会出现一个管家的像素小头像

## 三、功能详细设计

### 功能一：百科全书（玩家主动查询）

玩家可随时打开玉简，向管家询问各种信息。查询方式有两种：

**方式A：关键词查询（UI界面）**
- 打开管家面板，顶部有搜索框
- 按分类浏览：灵材图鉴 | 势力介绍 | 境界说明 | 灵潮知识 | 品阶体系 | 商道技巧

**方式B：自然语言提问（对话式）**
- 玩家可以在玉简界面输入文字提问
- 管家用文字回复——不是对话树，而是根据游戏内的数据库检索回答

#### 百科内容范围

| 分类 | 内容举例 |
|-----|---------|
| **灵材** | 赤炎草是什么？玄冰髓哪里产？火心石有什么用？ |
| **势力** | 寒渊宗是什么来头？天道商会和万宝楼有什么关系？ |
| **境界** | 金丹期的修士一般需要什么？元婴期老怪出手阔绰吗？ |
| **玩法** | 天道熔炼怎么提升成功率？好感度有什么影响？ |
| **商道** | 怎么和宗门搞好关系？暗市怎么进？ |
| **地图** | 玄冰域和炎狱域之间怎么走最快？灵潮期走哪条路安全？ |
| **事件** | 最近有什么拍卖会？哪个宗门在收购什么灵材？ |

### 功能二：主动预警（管家推送）

管家会在以下场景**主动弹出玉简讯息**，在画面中以气泡/弹窗形式出现：

#### 提醒类
| 事件 | 触发时机 | 管家的说法 |
|-----|---------|-----------|
| 预约订单即将到期 | 距离截止还剩半天 | "少爷，您答应了翠屏城李道友的灵木心明日就要交货了，货备好了吗？" |
| 预约订单已超时 | 过了截止时间 | "少爷，菌落镇张道友的货已经过了一个时辰了……老奴建议您赶紧备货，免得折了口碑。" |
| 灵潮即将来临 | 灵潮前1-2天 | "老奴观天象，三日内恐有灵潮涌动。少爷可提前备货，灵潮期间灵材价格波动不小。" |
| 拍卖会即将开始 | 拍卖会前1天 | "天道商会三日后在万宝楼有一场大型拍卖会，据说有宝品级的灵药出场。少爷可要老奴去打点入场的事？" |
| 宗门使者将至 | 使者出发后 | "铸魂殿那边传来消息，说是想派人来拜访少爷，约莫两日后到。老奴已备好茶水。" |

#### 预警类
| 事件 | 触发时机 | 管家的说法 |
|-----|---------|-----------|
| 商路危险 | 某条商路出现劫匪/凶兽 | "老奴听闻西行商路近来不太平，风沙帮的人说沙口镇外有劫修出没。少爷若是要走那条路，得多带几个人。" |
| 价格异常 | 某灵材价格剧烈波动 | "少爷留意，今日金灵砂的价格较昨日涨了三成。听说铸魂殿那边有大订单，怕是要缺货了。" |
| 竞争对手行动 | 其他商会开始针对玩家 | "老奴收到风声，铁算盘商会的人在打听少爷的进货渠道。他们那帮人无利不起早，少爷小心些。" |
| 税务/政策变化 | 城主府出了新规 | "中央荒原城主府发了新的摊位税则，比上月涨了两成。少爷若是觉得摊位费吃不消，老奴去打听打听有没有减免的门路。" |

#### 随机互动
- 节日问候（游戏内节日/节气）
- 生意太差的安慰（"少爷别急，万事开头难。"）
- 生意极好的祝贺（"少爷今日进账不少，老奴看着也高兴。"）
- 当你买了奇怪的东西时吐槽（"少爷……这个真的卖得出去吗？"）

### 功能三：信息存档与管理

管家会自动记录玩家经历过的关键事件和查过的信息，形成一本 **"商途日志"**：

- 每次拍卖会的参与记录（去了哪里、拍了什么、花了多少）
- 重要交易记录（大单成交）
- 宗门的拜访/合作记录
- 玩家的经营数据汇总（总流水、利润率变化趋势）
- 天道熔炼的历史记录（成功/失败各多少次）

玩家可以随时翻日志，看到自己的成长轨迹。

## 四、交互方式

### 玉简界面设计
- 像素风书卷/玉简样式，翻开后左侧是分类菜单，右侧是内容
- 管家的头像出现在右上角或左下角
- 文字以手写体/古朴字体呈现

### 主动提醒的呈现
- 游戏主界面右下角出现玉简闪动 icon
- 点击展开管家的消息气泡
- 可以在设置里调整提醒频率（全部提醒/仅重要事件/关闭）

### 与游戏时间的关联
- 利用游戏内的时间系统触发提醒
- 管家也需要"时间"来获取信息——突发事件不是秒知，而是有延迟的


## 五、与现有系统的联动

| 系统 | 联动方式 |
|-----|---------|
| **预约订单** | 管家提醒玩家订单即将到期/已超时 |
| **拍卖会** | 管家预报拍卖会信息，玩家可委托管家提前打点入场 |
| **好感度/声望** | 管家会根据声望变化调整说话语气；声望高了会主动汇报更多信息 |
| **商路系统** | 管家通过"情报网络"获知商路安全状况 |
| **灵潮周期** | 管家能预测灵潮并提前警告 |
| **天道熔炼** | 管家会记录熔炼历史并给出概率参考（非数值，用文字描述） |
| **宗门关系** | 管家汇报宗门动向，推荐与谁合作 |
