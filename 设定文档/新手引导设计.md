# 新手引导设计

> 灵墟旅商的新手引导不是"强制教学关"，而是让玩家在不知不觉中学会怎么玩。

---

## 一、引导原则

### 核心理念：让玩家"做中学"，不要"读教程"

| 原则 | 说明 |
|------|------|
| **不弹窗** | 尽可能避免大段文字弹窗打断操作 |
| **不强制** | 大多数引导可以通过"发现"触发，而不是"必须完成" |
| **有回报** | 完成引导步骤后给予微小的奖励（灵石/灵材/经验） |
| **可跳过** | 资深模拟经营玩家可以直接跳过文字提示 |
| **管家的存在就是引导** | 老管家是天然的引导员——他告诉宁秩怎么做事是合理的，比系统提示自然得多 |

---

## 二、开场（游戏开始前）

### 开场画面

黑暗的画面中，一行字缓缓浮现：

> "灵墟没有神。灵墟只有价格。"

画面渐亮，一个年轻人的背影站在山谷口。山风吹动他的衣角，他回头看了一眼身后的山谷——那里什么也没有。

> "宁秩，十八岁，灵根驳杂，修炼无望。"

他转过身，走向前方的荒原。画面渐亮，色彩浮现。

> "但品阶不会骗人。"

——这是玩家看到的第一个画面。没有旁白，没有大段世界观说明。三句话，一片荒原，一个人。

### 开场后的状态

玩家直接进入游戏，宁秩站在中央荒原的集市边缘。面前是一个空空荡荡的摊位——一块布铺在地上，什么都没有。

**屏幕上只有几个UI元素：**
- 左上角：时间（丙午年·春·初一·辰时）
- 右上角：灵石余额（30）
- 右下角：一个黯淡的玉简图标（管家系统未激活，此时不可用）
- 中间：一个闪烁的箭头指向中央荒原的集市方向

## 三、第一天引导流程

> 第一天的目标是：让玩家完成第一笔交易。不需要任何文字教程。

### 引导第1步：你去哪？

玩家一开始面对中央荒原，可以看到集市方向有 NPC 走动。闪烁的箭头提示"去集市看看"。

如果玩家超过30秒没有移动，屏幕中间出现一行小字——不是弹窗，是像电影字幕一样缓缓浮现：

> "听说中央荒原的集市，每天早上都有好货。"

然后消失。如果再过30秒还没动，宁秩自己说一句："站着也不是办法……先去看看行情吧。"

**用角色自己的话代替系统提示，比任何教程框都自然。**

### 引导第2步：进货

玩家到达集市后，看到几个摊位。其中一个摊位上有闪烁的光点——那是一株凡品赤炎草，售价10灵石，旁边站着一个NPC摊主。

此时**没有任何弹窗提示**。玩家需要自己走到摊位前，点击赤炎草，触发购买界面。如果购买了，摊主说一句："眼光不错，这是今天早上刚摘的。"

如果玩家尝试和摊主聊天（点击NPC），摊主会说："买货就买货，别套近乎。"——暗示他现在应该先买货。

**如果玩家买了赤炎草，获得成就/提示："第一笔进货。" 🎉**

### 引导第3步：摆摊

玩家买了货之后，回到自己的摊位前。此时摊位上出现一个"摆摊"的按钮提示（微弱发光）。点击后，将赤炎草放在摊位上。

自动触发——**不是弹窗，是宁秩的内心独白**：

> "也不知道能卖多少……先试试看吧。"

### 引导第4步：第一笔交易

一位中年散修（老赵）走过来，这就是事件2——第一笔交易。他拿起赤炎草看了看说："小伙子，新来的吧？这株赤炎草成色还行，但你这个价定高了。我给你个实价——爱卖不卖。"

此时议价界面出现。玩家可以看到：
- 标价：10灵石
- 老赵出价：7灵石
- 进货成本：10灵石（这里玩家会意识到——他7块卖就亏了）

**这是游戏教会玩家的第一课：做生意不能低于成本。**

如果玩家拒绝了老赵的出价，老赵会耸耸肩走开。大约10秒后，另一位顾客走过来，以9灵石的价格买走了——这不是设计好的事件，而是系统检测到玩家拒绝后触发的"补偿机制"：让玩家知道"不卖给他，也会有人来买，只是价格不同"。

如果玩家以7灵石卖了，老赵会满意地点头："谢了，小伙子。以后有好货记得给我留着。"——不亏，至少认识了第一个老顾客。

### 引导第5步：天道熔炼的种子

完成第一笔交易后，当天傍晚玩家收摊时，系统不会直接触发熔炼引导。但会在玩家的物品栏中埋下一个伏笔。

玩家在翻看《灵墟商事录》时（此时管家不可用，可以设计成游戏初期的一个翻书交互），翻到某一页，上面是老管家歪歪扭扭的字迹：

> "老奴在宁家干了四十年，见过的好货坏货不计其数。有一件事一直想不明白——有时候，两件同品阶的灵材放在一起，老奴会觉得它们在互相呼唤。不是灵气共鸣的那种感觉，更像是一种……亲近。好像它们本来就应该在一起。
>
> 老爷说老奴想多了。也许吧。
>
> 但万一不是呢？"

这段文字**没有任何高亮、没有闪烁、没有提示**。它就在那里，像一个普通的书页。玩家读到了就记住了，没读到也不影响后面的触发——因为天道熔炼的真正引导是由事件6（第一次熔炼）本身带动的。商事录里的这段话只是在玩家的潜意识里种下一个念头："好像可以试试？"

> 天道熔炼不像议价或摆摊——它不是一个需要教学的操作技能。它是一个需要玩家**自己决定去尝试**的东西。强行引导会破坏"发现"的乐趣。最好的引导就是什么都不引导——让玩家在某天晚上，看着手里三件卖不出去的灵材，想起书里那句话，然后试一试。

完成第一笔交易后，屏幕上的闪烁箭头和发光按钮全部消失。屏幕出现一行字：

> "欢迎来到灵墟。"

这是玩家看到的最后一句"系统提示"。此后所有信息都将通过以下方式传递：
1. 管家的玉简（激活后）
2. NPC的对话
3. 场景中的视觉线索
4. 宁秩自己的内心独白

## 四、前3天的引导节奏

| 时间 | 引导内容 | 呈现方式 | 设计意图 |
|------|---------|---------|---------|
| 第1天·上午 | 去集市→进货→摆摊→第一笔交易 | 视觉引导+宁秩独白 | 让玩家完成第一次完整经营循环 |
| 第1天·下午 | 如果还有时间，可以继续交易或收摊 | 无引导，自由探索 | 让玩家自己发现"可以收摊了" |
| 第1天·傍晚 | 收摊后宁秩独白："今天赚了……还行。" | 过夜自动结算 | 让玩家看到第一天的成果 |
| **第1天·傍晚** | **收摊时，宁秩看到几块废弃耐火砖和一块破铁板："这几块砖扔在这儿也是占地方……搭个炉子吧，至少冬天能暖和点。"→摊位角落出现一个简陋的小熔炉** | **宁秩独白+场景变化** | **给玩家一个自己搭的熔炉，为第一次天道熔炼铺路** |
| 第2天·上午 | 老赵再次出现（NPC记得你） | NPC对话 | 让玩家感受到"NPC有记忆" |
| 第2天~第3天 | 遇到需要预约的顾客 | NPC对话引导 | 自然引出预约系统 |
| 第2天~第3天·傍晚 | 持有3件以上同品阶灵材后，夜间靠近熔炉→宁秩感到灵材在发出微弱的共振，浮现念头："它们在呼唤你。" | 画面+文字演出 | 暗示天道熔炼的入口，由玩家自主决定是否尝试 |
| 第3天~第5天 | 暗市掮客出现 | 特殊事件触发 | 引出暗市系统 |
| 收集到3件灵材后 | 触发第一次天道熔炼（产出传讯玉简） | 剧情事件 | 引出天道熔炼系统+管家通信

## 五、引导信息的分层呈现

| 信息类型 | 呈现方式 | 示例 |
|---------|---------|------|
| **操作提示** | 宁秩的内心独白 | "这个应该放摊位上。" |
| **玩法提示** | 管家的玉简消息 | "少爷，老奴听说——不同品阶的灵材价格差很大。" |
| **世界信息** | NPC对话/场景细节 | "这灰灵壤是炎狱域来的，听说那边火山最近可不太平。" |
| **经济信息** | 市场价格变化 | 直接体现在价格标签的波动上 |
| **剧情信息** | 特殊事件触发 | 大事件以演出形式出现 |

> 没有"帮助菜单"。管家就是帮助菜单。

---

## 六、可跳过的设计

| 玩家类型 | 引导方式 |
|---------|---------|
| 第一次玩模拟经营游戏 | 按部就班，每个步骤都有提示 |
| 玩过同类游戏 | 操作过的步骤不再提示 |
| 速通/老手 | 开局直接跳过所有引导，从第1天下午开始 |

识别方式：如果玩家在第一次交易后立刻连续进行后续操作（进货→摆摊→交易一气呵成），系统判定为"有经验玩家"，从第2天开始减少提示频率。

以下是玩家在前3天通过管家/独白/NPC可以学到的全部基础信息：

| 知识点 | 何时学到 | 通过谁 |

| 怎么进货 | 第1天·上午 | 视觉引导 |
| 怎么摆摊 | 第1天·上午 | 宁秩独白 |
| 议价怎么玩 | 第1天·上午 | 老赵 |
| 不能低于成本卖 | 第1天·上午 | 议价界面（显示成本） |
| 可以收摊了 | 第1天·傍晚 | 宁秩独白 |
| 每天的费用 | 第1天·过夜结算 | 结算界面（摊位费） |
| NPC会记住你 | 第2天 | 老赵再次出现 |
| 没有的货可以预约 | 第2-3天 | NPC对话 |
| 熔炼是存在的 | 收集3件灵材后 | 宁秩独白+剧情事件 |
| 暗市的存在 | 第3-5天 | 暗市掮客 |
| 管家的存在 | 第一次熔炼后 | 玉简激活 |
