# 暗市系统设定

---

## 一、定位与核心感觉

> 中央荒原地下，一个没有白天的地方。所有人都戴着面具，也都没有戴——因为在这里，面具本身就是一种诚实。

暗市不是"偷偷摸摸的小角落"，而是一个**自成体系的平行市场**。它公开地存在于地下，所有人都知道它的存在，只是没有人会公开承认自己去过。

---

## 二、位置与进入

### 位置
中央荒原地下，入口散布在各处——可能是某个酒馆的后门、一口枯井、一座废弃传送阵。第一次进入需要通过某个NPC指引（触发事件），之后玩家可以自行前往。

### 进入方式
- **门槛很低**：不需要熟人引荐，不用对暗号
- **缴纳保证金**：一笔入场押金，保证你不会在暗市闹事
- **身份选择**：
  - 戴面具进入（默认提供，遮掩气息，NPC不会认出你）→ 不降商道值
  - 不戴面具（以真实身份进入）→ 交易会小幅降低商道值
- 保证金在离开时可退还，但如果违反暗市规则则没收

---

## 三、暗市规则

> 暗市有自己的规矩，这里不是无法之地，而是**有另一套法**。

### 暗市的背后势力

暗市的真正主人从未公开露面。有人说是一个活了不知道多少年的老怪物，有人说是一个横跨五域的隐秘组织，也有人说根本没有主人——暗市的规则本身就是一种上古禁制，被刻在了这片土地下。

**不管真相如何，有一点所有人都知道**：在暗市违反规矩的人，下场会很惨。

维护暗市秩序的是一群被称为 **"守夜人"** 的存在——没人知道他们是谁、从哪里来、修为多高。他们不出现在白天，只在暗市范围内出现。你敢在暗市动手，守夜人就会出现在你身后。

### 暗市守则

| 规则 | 说明 |
|------|------|
| **禁止强取豪夺** | 在暗市范围内动手者——无论修为多高——守夜人会出现，**当场处决或废除修为** |

### 惩罚体系

| 违规行为 | 首次惩罚 | 再犯惩罚 | 严重违规 |
|---------|---------|---------|---------|
| 在暗市范围内动手/斗法 | 没收保证金×3 + 逐出暗市30天 | 没收保证金×5 + 逐出一年 | 守夜人直接出手，轻则废修为，重则当场斩杀 |
| 欺诈/以次充好（被查实） | 赔偿买家损失 + 警告一次 | 没收保证金 + 逐出暗市 | 下发**暗市通缉令** |
| 泄露暗市交易信息（出卖买家/卖家身份） | 没收保证金×2 + 封口警告 | 下发暗市通缉令 | — |
| 勾结外人围剿暗市 | 永久逐出 + 暗市通缉令 | — | — |

### 暗市通缉令

> 暗市通缉令不是暗杀令——暗杀令是顾客花钱买的，通缉令是暗市自己发的。

被通缉的人会被守夜人追踪，**所有暗市商人都会拒绝与其交易**。更严重的是，暗市会把通缉令**有偿分享给暗杀公会**——也就是说，被通缉的人会成为其他杀手的目标。

要撤销通缉令，只有两种方式：
1. 缴纳巨额罚金（通常是违规所得的10倍以上）
2. 完成一个暗市指定的"赎罪任务"（通常极其危险）

### 保证金的双重意义
保证金不仅仅是入场费——它也是你在暗市的**信用抵押**。保证金金额和你的交易上限挂钩：
- 基础保证金：1000灵石（允许每日交易上限5000灵石）
- 更高档位：缴纳更多保证金可解锁更高交易额度
- 违规时保证金会被没收，需要重新缴纳才能再次入场

## 四、可交易内容

### 常规品类

| 类别 | 举例 |
|------|------|
| **违禁灵材** | 凶兽内丹、禁制类毒草、需要特殊功法才能驾驭的材料 |
| **来历不明之物** | 古修士遗迹出土品、来路不明的法器、无主洞府的遗物 |
| **情报** | 宗门灵脉薄弱点、商路运输时刻表、某位大能的弱点 |
| **禁术丹方** | 被正道联盟封禁的炼丹配方、禁忌功法残卷 |
| **奴仆/人口** | 战俘、被灭门宗门的幸存弟子、自愿卖身的散修 |
| **暗杀令** | 花灵石买命——挂单和接单都在暗市进行 |

### 特殊服务

| 服务 | 说明 |
|------|------|
| **暗杀令发布** | 挂出悬赏，指定目标，暗市抽取两成佣金。暗杀令分等级（对应目标修为），价格天差地别 |
| **暗杀令接单** | 玩家也可以接暗杀令赚钱（如果你觉得自己打得过的话） |
| **销赃** | 抢来的/偷来的货物，暗市有专门的收购渠道，但价格会被压得很低（三折起步） |
| **改头换面** | 花灵石改变气息特征，躲避仇家追杀 |
| **伪造身份** | 搞到一张假的商会执照/通行令 |

## 五、价格体系

| 对比项 | 正规市场 | 暗市 |
|--------|---------|------|
| 价格水平 | 参考价±浮动 | **远高于市场价**（通常1.5-3倍） |
| 货品质量 | 有保障，品阶明确 | 可能有假货、以次充好 |
| 退换货 | 可以 | 离柜不认 |
| 稀缺品 | 基本没有 | 正规市场买不到的东西，这里可能有 |
| 风险 | 低 | 高（被盯上、买到假货、出了暗市被劫） |

**定价逻辑**：暗市没有市场参考价，价格完全由卖方定。能不能买到好东西，基本看三个东西：
1. 你的眼力（品阶鉴微技能是否有用？——有用的，暗市上太多来路不明的货）
2. 你的砍价能力（暗市的讨价还价更激烈）
3. 你的运气（恰好遇到好东西还没被别人买走）

## 六、风险与代价

| 风险 | 后果 |
|------|------|
| **商道值下降** | 每次在暗市交易（无论买还是卖）都会降低商道值。戴面具降得少，不戴面具降得多 |
| **被盯上** | 离市后可能被跟踪、抢劫、甚至被悬赏 |
| **买到假货** | 暗市不保真，买到假货只能自认倒霉 |
| **暗杀令反噬** | 如果你挂了暗杀令被查出来，暗杀目标可能会反过来找你 |
| **正道关系恶化** | 如果被正道宗门发现你频繁出入暗市，好感度会下降 |

### 商道值影响

| 行为 | 商道值变化 |
|------|-----------|
| 戴面具进入暗市 | -0（但交易商品时仍会降商道） |
| 不戴面具进入暗市，只逛不买 | -0 |
| 暗市购买物品（戴面具） | 小幅下降 |
| 暗市购买物品（不戴面具） | 中幅下降 |
| 暗市出售物品（普通） | 小幅下降 |
| 发布暗杀令 | 大幅下降 |
| 交易违禁品（奴仆/禁术） | 大幅下降 |

> 商道值影响什么？参考之前的设定——商道维度影响名声、客户类型、能否进入某些市场。如果商道值太低，正派宗门可能拒绝与你合作，正道修士不愿光顾你的店铺。但相应的，暗市势力会更青睐你。

## 七、与现有关联

| 系统 | 联动方式 |
|------|---------|
| **管家** | 管家会委婉提醒你少去暗市（"少爷，老奴听说那地方去多了，容易沾上晦气"） |
| **天道熔炼** | 暗市是获取罕见熔炼材料的重要渠道，有些灵材正规市场根本没有 |
| **拍卖会** | 暗市的货物不能上正规拍卖会，但暗市自己也有"地下拍卖"（更野的路子） |
| **好感度/声望** | 正道势力发现你去暗市会降好感，暗市势力会提升好感 |
| **商路** | 从暗市买的好东西要安全运回去，也得走商路——被劫了就血本无归 |
| **宗门关系** | 有些宗门暗地里在暗市有眼线，甚至派驻了采购人员 |
| **多结局** | 暗市行为积累到一定程度，可能触发"堕落商道"结局分支 |
