# 体验优化清单

> 基于玩家视角走完一周目后，针对三个核心问题的修改方案。

---

## 问题一：平原期过长，玩家在前中期"什么都买不起"

### 现状

玩家第1个月净赚约100灵石。暗市入门商品500灵石起、拍卖会入场费500灵石、跨域贸易运费100灵石+最低货量成本200灵石。中间有大约2-3个游戏周（现实约2-3小时）的"我什么都做不了"的空窗期。

### 修改方案

**1. 在暗市设置"穷人专柜"**

暗市不是只有高级货。掮客带玩家第一次进入暗市后，在入口附近设置一个"旧货摊"——都是些不值钱但有意思的东西：

| 商品 | 价格 | 用途 |
|------|------|------|
| 一张褪色的旧地图 | 30灵石 | 标注了一条不太安全的近道（解锁一条小商路线索） |
| 一本残破的日记 | 20灵石 | 某个已故散修留下的笔记，记录了一些灵材采集点 |
| 一块不明材质的金属片 | 40灵石 | 交给赤炼或金锋鉴定后，可以换一笔小钱或好感度 |
| 一条坊间传闻 | 50灵石 | "最近有人在大量收购赤炎草，价格比市场价高三成"——一条即时的套利信息 |

**效果**：暗市不再是一个"我进去啥都买不起只好逛逛"的地方。即使只有50灵石，也能买到"有用"的东西——信息、线索、可交易物。

**2. 降低拍卖会的早期门槛**

第一次拍卖会（事件10）的入场费500灵石对新手太贵。改为：

- 入场费100灵石（基础档）
- 500灵石是"含竞拍资格"的档位
- 100灵石入场只能看、不能举牌——但能看到别人在拍什么、什么价格成交
- 管家会建议："少爷，第一次去先看看行情也好。知道什么东西值多少钱，比什么都重要。"

**效果**：玩家在第1个月就能参加第一次拍卖会——即使买不起，也能积累"市场认知"。下次再有时，他知道什么价是合理的。

**3. 跨域贸易的"零担"模式**

目前的跨域贸易逻辑是"整批发货"，运费和货量挂钩，小批量不划算。增加"零担"选项：

- 每次跨域可以夹带少量货物（不超过10件）
- 运费按件计算，单价更高（整批的1.5倍）
- 但不需要凑够整批，随时可以发

**效果**：玩家在第2个月就可以小规模尝试跨域贸易——可能利润很低，但能提前解锁商路系统和跨域感知。

## 问题二：目标感不够强

### 现状

游戏告诉玩家"摆摊、赚钱、扩张"，但没有给出具体的阶段性目标。玩家常常不知道"我现在应该做什么"或者"赚多少钱才算够"。

### 修改方案

**1. 管家导入目标体系**

老管家不是只提供信息和预警。他会在适当时机给宁秩建议方向。这些建议以玉简消息的形式出现，不是系统任务：

| 时间节点 | 管家说的话 | 隐含目标 |
|---------|-----------|---------|
| 第3天 | "少爷，您现在算是站住脚了。老奴建议您攒够100灵石——有了本钱，才好做下一笔生意。" | 目标：存款达到100灵石 |
| 第10天 | "您的手头应该宽裕些了。如果方便的话，不妨先买一块耐火砖——哦，老奴听说搭个正经炉子比野灶安全。" | 目标：升级熔炉 |
| 第20天 | "老奴打听到中央荒原北街有个空铺面在招租，月租60灵石。虽然贵了些，但有个固定地方总比风吹日晒强。" | 目标：攒够租金，租铺面 |
| 第2个月 | "您现在的身家，已经可以去拍卖会看看了——入场费100灵石，去看看不亏。" | 目标：参加一次拍卖会 |
| 第3个月 | "您最近有没有注意到——同样的灵材，不同板块的价格差得很多？" | 目标：尝试第一次跨域贸易 |

**效果**：每个目标都不大——100灵石、租个铺面、参加一次拍卖会。玩家不需要做"主线任务"，只需要顺着管家的话往下走，自然会有事做。

**2. 里程碑提示系统**

当玩家达成某个里程碑时，不是弹窗，而是在过夜结算时加一行小字：

> "累计利润突破1000灵石——在灵墟，你已经不能算'穷'了。"

这种"世界对你状态的反馈"比任何任务奖励都更有"我在成长"的感觉。

里程碑列表：

| 里程碑 | 反馈文案 |
|--------|---------|
| 累计利润≥100灵石 | "够买一株像样的灵草了。" |
| 累计利润≥500灵石 | "中央荒原的大多数散修，一年也就赚这个数。" |
| 累计利润≥1000灵石 | "在灵墟，你已经不能算'穷'了。" |
| 累计利润≥5000灵石 | "这个数目，值得你在天道商会开一个账户了。" |
| 累计利润≥10000灵石 | "你现在的身家，已经超过了一个筑基期散修一辈子的积蓄。" |
| 累计利润≥50000灵石 | "你不再是'小商贩'了。你是商人。" |
| 累计利润≥100000灵石 | "这笔钱，已经足以让某些宗门正眼看你了。" |
| 累计利润≥500000灵石 | "灵墟能赚到这个数的人，一只手数得过来。" |

**3. 商会等级作为可视化目标**

商会系统（1-9级）本身就是最好的目标体系。玩家的核心目标变成了"如何让我的商会在灵墟立足/小有名气/名动一方"——每次升级都有明确的条件和奖励，比抽象的"赚更多钱"更有指引性。

**建议**：在UI中常驻一个商会等级的显示位（不需要数字，用称谓即可："小摊"→"铺面"→"商号"→"商会"）。玩家每次看到自己的称谓变化，都知道自己走到哪一步了。

## 问题三：前中期和中期之间的事件节奏过密

### 现状

在第6-9个月之间，玩家可能同时触发：世界树之殇、暗市掮客提醒暗市的代价、第一次灵潮大事件、随从忠诚度事件、宁家来人。这些事件如果在一个月内全部触发，玩家会感到"被事件推着走，没时间经营"。

### 修改方案

**1. 设置事件缓冲期**

每个大事件触发后，至少间隔7天（游戏内）才会触发下一个大事件。这7天是"静默期"——没有任何事件推进，玩家可以专心经营。

管家会在静默期的第一天说："少爷，最近应该没什么大事了，您好好做生意吧。"

**效果**：玩家不会觉得"整个世界都在催我"。经营是主食，事件是配菜。

**2. 玩家可以选择"推迟"事件**

部分事件（非固定时间触发类）允许玩家选择"过段时间再说"：

- 暗市掮客来邀请时 → 可以选择"今晚没空，改天"
- 宗门采购首次接触时 → 可以选择"这批货我先考虑考虑"
- 商会被威胁时 → 不能推迟（这是固定事件）

推迟后的事件不会消失，会在30天内重新触发。但如果玩家连续推迟同一事件三次，该事件被视为"玩家主动放弃"，对应的NPC态度会下降。

**效果**：玩家可以自主控制游戏节奏。想深入探索这个事件？现在就去。现在没空？以后再说。

**3. 时间流速的"放松"模式**

夜间和跨域运输期间的时间流速调整：

- 夜间：时间流速是白天的0.5倍。玩家可以在夜间慢慢看库存、整理账本、和随从聊天——不用赶着过夜
- 跨域运输中：发完货后，时间不是快进的。玩家可以做其他事（去其他板块、处理其他业务），货在路上跑，玩家继续玩

**效果**：玩家不会觉得"一天过得太快啥都没干"或者"发了货就只能干等"。
