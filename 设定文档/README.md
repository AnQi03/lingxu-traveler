## 🎯 核心卖点速查

```
天道熔炼（核心玩法）← 灵材（核心资源）
  ├─ 品阶鉴微（眼力考验）→ 判断灵材真实价值
  ├─ 灵材实验室（探索发现）→ 发现灵材隐藏属性
  ├─ 灵光一现（微节奏调律）→ 关键时刻影响熔炼结果
  └─ 察言观色（心理博弈）→ 读懂顾客心理底线
  
经营系统 ← 灵石（中间介质）
  ├─ 讨价还价（融入察言观色）
  ├─ 商路物流（融入突发事件调度）
  └─ 随从团队（融入人员管理）

剧情系统 ← 三条暗线（商道/天道/人心）
  ├─ 23个事件 + 9种结局
  ├─ 三阶立场站队（不可回头、有得有失）
  └─ 8条湮灭线索 → 灵墟湮灭/灵墟归途
```

## 📐 开发依赖关系（从设计到代码）

```
第一阶段（基础系统）
  灵材系统 ← 品阶鉴微
  交易系统 ← 讨价还价 + 察言观色
  经营循环 ← 进货→卖出→灵石循环

第二阶段（核心玩法）
  天道熔炼 ← 概率系统 + 灵光一现交互
  灵材实验室 ← 感应石板 + 研究笔记
  随从系统 ← 任务分配 + 互动事件

第三阶段（内容整合）
  剧情框架 ← 23个事件 + 9种结局
  立场站队 ← 三阶抉择 + 存档标记
  湮灭线索链 ← 8条线索 + 跨周目继承

第四阶段（优化+DLC）
  体验优化 ← 手感 + 节奏 + 引导
  DLC ← 当前体量分层文档中的候选内容
```
