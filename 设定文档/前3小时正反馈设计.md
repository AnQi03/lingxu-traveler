# 前3小时正反馈设计

> 玩家买下游戏后的前3个小时决定了他会不会退款、会不会继续玩、会不会向朋友推荐。这段时间内，每一件"让他觉得值了"的事情都很重要。

---

## 一、核心原则

| 原则 | 说明 |
|------|------|
| **每15分钟给一次正反馈** | 玩家不会因为"游戏很好"而留下，会因为"刚刚那件事让我爽了一下"而留下 |
| **反馈要具体，不要抽象** | "你的商道提升了"不如"老赵说：'你小子最近行啊，货越来越好了'" |
| **第一次体验不可复制** | 第一次成交、第一次预约、第一次熔炼、第一次去暗市——这些瞬间只有一次，必须做足 |
| **正反馈不是奖励** | 不是送东西。是让玩家觉得自己做了个正确的决定 |

---

## 二、前3小时反馈时间线

### 第0-5分钟：开场

| 时间点 | 发生的事情 | 玩家感受 |
|--------|-----------|---------|
| 0:00 | 黑屏文案→宁秩离开山谷→落地中央荒原 | 氛围不错，想知道接下来会发生什么 |
| 1:00 | 箭头指向集市，买下第一株赤炎草 | 操作直观，点了就有反馈 |
| 3:00 | 摆摊，第一个顾客老赵上门 | 有NPC了，不是单机 |
| 4:00 | 第一笔成交——灵石入账声效 | 💰 **第一次赚钱的快感** |

**关键正反馈**：第一笔成交的灵石入账音效。声音要清脆、满足、让人想再听一次。

### 第5-15分钟：第一天下午~傍晚

| 时间点 | 发生的事情 | 玩家感受 |
|--------|-----------|---------|
| 8:00 | 第二笔或第三笔生意 | 节奏感来了——"我好像会玩这个游戏了" |
| 12:00 | 收摊时看到废砖，搭起熔炉 | 场景变化——摊位角落多了个东西，世界因我而变 |
| 14:00 | 第一天的过夜结算（可能小亏） | 数据清晰，知道亏在哪，想翻盘 |

**关键正反馈**：熔炉搭起来的那一刻。不是为了"解锁系统"，是纯粹的世界变化感——"我早上来的时候这里还没有这个炉子"。

### 第15-45分钟：第2-3天

| 时间点 | 发生的事情 | 玩家感受 |
|--------|-----------|---------|
| 20:00 | 老赵再次出现——"又来了，掌柜的" | **NPC记得我**——这个世界不是一次性的 |
| 30:00 | 预约订单触发、完成、多赚了两成 | 无中生有赚了一笔——"原来没货也能做生意" |
| 40:00 | 第二天结算——开始赚钱了 | 从第一天亏11灵石到第二天赚40+灵石——成长曲线可见 |

**关键正反馈**：老赵第二次出现说"又来了"。这一点点的记忆感，比任何系统提示都更能让玩家觉得这个世界是活的。

### 第45-90分钟：暗市 + 第一次熔炼

| 时间点 | 发生的事情 | 玩家感受 |
|--------|-----------|---------|
| 50:00 | 暗市掮客在傍晚出现——"你在找好货" | 神秘感拉满——"这个游戏还有地下世界" |
| 55:00 | 进入暗市，选择戴面具/不戴 | 选择权——"我的选择有后果" |
| 60:00 | 在暗市买到一张旧地图（30灵石） | 👑 **前1小时内的第一个"赚到了"的瞬间**——30灵石买的旧地图标了一条近道，下次跨域贸易省了一笔运费 |
| 75:00 | 夜间靠近熔炉——"它们在呼唤你" | 神秘感拉满——世界在主动和我互动 |
| 80:00 | 第一次天道熔炼——玉简诞生 | ⭐ **前1.5小时内的最高光瞬间**——灵石声效、火光画面、然后管家的声音从玉简中传来 |

**关键正反馈**：玉简亮起，管家的声音出现。这是前1.5小时设计中最重要的一刻——灰色图标亮了，玩家不再是一个人了。这个情绪的释放度决定了玩家会不会继续玩下去。

### 第90-120分钟：管家时代

| 时间点 | 发生的事情 | 玩家感受 |
|--------|-----------|---------|
| 90:00 | 管家第一条建议："攒够100灵石" | 终于有人告诉我该做什么了——不是系统任务，是人说的 |
| 95:00 | 跑腿任务——帮老赵取东西赚了15灵石 | 不用只靠摆摊了，有其他事可做 |
| 105:00 | 赚到了第一笔100灵石——管家说"您现在算站住脚了" | 阶段性成就——有人认可我的进度 |
| 115:00 | 管家的第一条月度简报 | 回顾+总结——"我这一个月干了什么"一览无余 |

**关键正反馈**：管家说"您现在算站住脚了"。这不是系统弹出"恭喜达成成就"，是故事里的一个角色在肯定玩家的进展。

### 第120-180分钟：稳定期+第一个小高潮

| 时间点 | 发生的事情 | 玩家感受 |
|--------|-----------|---------|
| 130:00 | 租下第一个铺面——不再是一块布了 | **场地升级**——从小摊到铺面，视觉上的成长 |
| 150:00 | 第一次参加拍卖会（100灵石入场参观） | 看到高级货的世界——激发"我也要买到那个"的欲望 |
| 170:00 | 随从加入 | 不再是一个人——有了第一个助手 |
| 180:00 | 第一笔宗门订单 | 客户升级——从散修到宗门，商道在涨 |

**关键正反馈**：从小摊到铺面的那一刻。场地变化是最直观的成长——"我确实不一样了"。

---

## 三、设计检查清单

每15分钟，给玩家一个"值得继续玩下去"的理由：

| 时间段 | 正反馈事件 | 检查 |
|--------|-----------|------|
| 0-5min | 第一笔成交的灵石声效 | ✅ |
| 5-15min | 搭熔炉、世界因我而变 | ✅ |
| 15-45min | 老赵再次出现、预约赚钱 | ✅ |
| 45-90min | 暗市探险、第一次熔炼、管家激活 | ✅ |
| 90-120min | 管家第一个建议、里程碑认可 | ✅ |
| 120-180min | 铺面升级、拍卖会、随从、宗门订单 | ✅ |

---

## 四、第一次熔炼——最重要的一个节点

前3小时内最重要的正反馈是高光是玉简激活瞬间。为了保证这个效果，需要确认以下几点：

| 要素 | 要求 |
|------|------|
| 玉简亮起的动画 | 不能太快——慢一点，让玩家看到灰色图标在闪烁→光芒扩散→彻底亮起的全过程 |
| 老管家的第一句话 | 音色温和、略带颤抖、有辨识度。"……少爷？"这几个字的间隔要拉长一点，体现出难以置信 |
| 对话后的短暂沉默 | 老管家说完第一句话后，有2-3秒的沉默——让玩家消化这个时刻 |
| 后续引导 | 管家激活后不要立刻推出大量信息。他只说了一句话，然后沉默了。玩家自己会主动尝试"和管家说话"——这比任何弹窗引导都自然 |

> 第一次熔炼的本质不是"解锁系统"。是"确认这个世界里，你不是一个人。"
