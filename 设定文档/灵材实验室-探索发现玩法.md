# 灵材实验室 · 探索发现玩法

> 你买了一件灵材，然后呢？
> 直接卖掉——可以，但你永远不会知道它还有什么可能。
> 拿到实验台上试试——也许是浪费，也许是改变你整条商路的发现。

---

## 一、设计目标

1. **把"灵材图鉴"从被动收集变成主动探索**——玩家不是"解锁条目"，而是"做实验发现新知识"
2. **给灵材一个"卖掉之外的去处"**——每件灵材都可能有隐藏的相性/属性/用途，值得"研究一下"
3. **满足玩家的"试试看"冲动**——看到两件灵材放在一起，就忍不住想知道"它们之间会怎么样"

---

## 二、获得实验台

### 前期：简陋工具（第10-20天左右）

宁秩在第一次天道熔炼后注意到了一件事——他在熔炉前感受过灵材之间的"共鸣"，但在熔炼之前，有没有办法先"试探"一下？

某天（第10-20天），管家发来消息：

> "少爷，老奴记得您在宁家的时候，后院的炼药房有一块『灵性感应石板』——就是那种把灵材放上去会显示它们之间有没有灵气共振的东西。老奴托人找了一块旧的，给您捎过去了。不是什么值钱货，但兴许有用。"

玩家收到一块**旧感应石板**，可以放在店铺角落或仓库里。这是最简陋的实验台——只能同时放**2件**灵材，反馈也很基础（冒烟/发光/变色）。

### 中期：正式实验台（第3个月后，可升级）

玩家可以花灵石升级实验台：
- 花费800灵石 → 升级为**三槽实验台**（可同时放3件）
- 花费3000灵石 → 升级为**五槽精密实验台**（可放5件，能看到更精细的反应数据）
- 特殊条件（铸魂殿关系友好）→ 解锁**天道感应实验台**（能看到灵气流动的轨迹）

### 位置

实验台不是独立的"屏幕"——它是玩家场景中的一个**可交互物体**。就像熔炉一样，玩家在经营场景中走到实验台前，点击进入实验界面。

---

## 三、实验操作流程

```
【第一步：选择灵材】
从库存中拖拽灵材到实验台的槽位上。
· 2槽台：只能放2件
· 3槽台：可放2-3件
· 5槽台：可放2-5件

【第二步：观察基线】
灵材放上去后，感应石板会显示基础读数：
  · 各自的五行属性
  · 各自的品阶
  · 各自的灵气活跃度（新鲜程度）

【第三步：启动感应】
点击"感应"按钮——石板开始振动，灵材之间的互动开始显现。

【第四步：观察结果】
根据灵材组合的不同，会出现不同级别的反应——
```

## 四、实验结果分级

| 级别 | 表现形式 | 信息量 | 触发条件 |
|------|---------|-------|---------|
| **无反应** | 石板没有任何变化，灵材各自安好 | — | 两件灵材之间没有特殊关联——最常见的情况 |
| **微反应** | 石板微微发亮，灵材表面有极淡的光晕 | "这两件灵材之间似乎有一些联系……但很微弱。" | 灵材产地相近/属性相近但非相生组合 |
| **明显反应** | 石板亮起，灵材之间的空气中出现光丝连接 | 「发现基础相生关系：火→木——赤炎草和翠灵木之间有微弱的相生反应」 | 五行相生组合 |
| **强烈反应** | 石板剧烈发光，光丝变粗，灵材微微颤动 | 「发现强相生关系：火→木→土——这三件灵材的相生链是完整的！」 | 3件以上相生链 |
| **异常反应** | 颜色/动静和预期不符，灵材表面出现从未见过的纹路 | 「你的赤炎草和冰晶髓产生了你从未见过的反应——紫色的烟雾从接触面升起。这在任何图鉴中都没有记载。」 | 发现了隐藏的相性/变异组合 |
| **危险反应** | 石板发烫，灵材开始冒烟——赶紧分开！ | 「水火相克——如果再晚一息分开，这两件灵材可能会互相损伤。」 | 相克组合——如果持续太久可能导致灵材品质下降 |
| **共鸣反应（极稀有）** | 实验台所有的灵材同时发光，脉动频率完全一致——宁秩能感觉到它们"在唱同一首歌" | 「三件来自不同板块的灵材，在实验台上产生了频率共振。这不是巧合——它们的源头……可能是同一个东西。」 | 和天道碎片关联的灵材组合——触发隐藏线索 |

## 五、玩家的"研究笔记"

每次实验的结果不会自动写入图鉴——**需要玩家自己决定"记下来"**：

### 记录方式

实验结束后，系统会显示：
```
┌─────────────────────────────────┐
│  实验结果记录                  │
│                                 │
│  赤炎草（火·凡品）×            │
│  翠灵木（木·凡品）              │
│  → 发现：基础相生（火→木）     │
│                                 │
│  [💾 记入研究笔记]             │
│  [🗑️ 不记录——这只是个巧合]    │
│                                 │
│  研究笔记中已有 3/∞ 条记录      │
└─────────────────────────────────┘
```

- 不记录→实验结果被丢弃，不会影响任何系统
- 记录→写入图鉴的"研究笔记"分页，并且：
  - 如果是**未发现的新组合** → 天道值+1~2
  - 如果是**异常反应** → 天道值+3~5
  - 如果是**共鸣反应** → 天道值+10，并且自动标记为"值得深入调查"

### 研究笔记的用途

| 用途 | 效果 |
|------|------|
| **熔炼时的参考** | 当你的研究笔记中记录了某组合"有强相生反应"，熔炼时你投入同样组合会获得更高的升品概率 |
| **卖给情报贩子** | 暗市掮客愿意收购某些特殊反应的记录——"这个现象我没见过，给你100灵石，让我抄一份" |
| **和NPC交流** | 某些NPC会对特定反应感兴趣——展示你的研究笔记可以获得好感度或触发对话 |
| **解锁成就/称号** | 累计记录50条→「实验狂人」称号；发现10种异常反应→「异象观察者」称号 |

## 六、引导发现——线索 vs 自由探索

### 自由探索（任何时候都可用）

玩家可以随时把包里的灵材拖到实验台上"试试看"。这是游戏的**主要发现方式**——没有任何任务在催你，纯粹出于"想知道会发生什么"的好奇心。

**自由探索的乐趣来源**：
- 你永远不会知道哪两件灵材会产生有趣的反应——所以每次尝试都有"抽奖"的兴奋感
- 有时候你以为没反应，但微光一闪——"等等，刚才是不是亮了一下？"
- 有时候你发现了连系统都没预料到的组合——"天……我是不是发现了什么不得了的东西"

### 线索引导（加速发现）

NPC对话/书籍/事件会给出"配方片段"，让玩家有方向地去实验台验证：

| 线索来源 | 内容 | 验证后的奖励 |
|---------|------|------------|
| 老管家随口一句 | "老奴记得炎狱域的赤炎草和苍木域的翠灵木，好像合不来……但也有人说它们其实是互补的。" | 发现"火木看似相克实则相生"的特殊组合→天道+3 |
| 暗市掮客兜售的情报 | "有人在暗市卖一种配方残页——灰灵壤+极光晶→会在接触面产生黑色结晶。我帮你留了一份，80灵石。" | 花80灵石买线索→实验发现"黑色结晶"→解锁一种新型防具灵材的熔炼配方 |
| 拍卖会上的古籍 | 一本残破的《灵材百话》——记载了300年前有人发现"五件同品阶不同产地的灵材同时放在一起会唱歌" | 验证→发现共鸣反应→天道+10，触发隐藏线索加速 |
| 万木灵宗的研究员 | 云叶在一次交易中说："我们有一种推测——世界树的叶子，和任何一种灵材放在一起都会有反应。但我们不敢试——只剩三片了。" | 拿世界树之叶+不同灵材实验→每次都有不同反应→发现世界树和所有灵材都有"血缘关系"→推进世界树之谜剧情线 |

### 线索获取的节奏

| 游戏阶段 | 可获得线索数 | 来源 |
|---------|------------|------|
| 前期（1-3月） | 2-3条 | 管家闲聊、老赵的随口提点、暗市掮客 |
| 中期（3-9月） | 5-8条 | 宗门合作中获得的书籍、拍卖会上的残页、随从从各地带回来的见闻 |
| 后期（9月+） | 10+条 | 天道商会的情报网络、暗市守夜人的秘闻、五大宗门的秘典 |

> **核心设计**：线索是"加速器"不是"必经之路"。即使玩家一条线索都没拿到，也可以靠自由探索发现所有组合——只是需要更多时间和灵石（摊手）。

## 七、与现有系统的联动

| 系统 | 联动方式 | 实验台的位置 |
|------|---------|------------|
| **品阶鉴微** | 鉴微发现"异常特征"→买下来→拿到实验台验证→发现隐藏属性 | 鉴微是"入口"，实验台是"验证工具" |
| **天道熔炼** | 实验台发现的相生组合→直接应用到熔炼中→成功率提升 | 实验台是"知识库"，熔炼是"实践场" |
| **灵材图鉴** | 实验发现的新组合→手动记录→图鉴研究笔记分页更新 | 实验台是"发现工具"，图鉴是"记录载体" |
| **管家系统** | 管家偶尔给线索→玩家去实验台验证→验证后管家会说"少爷果然聪明" | 管家是"线索源"之一 |
| **暗市系统** | 暗市掮客买研究笔记、卖配方线索、对共鸣反应极度感兴趣 | 暗市是"情报市场" |
| **随从系统** | 派随从去特定板块采集灵材→他们可能会带回"这块地方的灵材和别处的好像不太一样"的见闻→引导玩家实验 | 随从是"远程线索采集器" |
| **商路物流** | 运货途中灵材在包裹里相互接触→到达后玩家发现"这批货的状态好像不太一样"→引发实验 | 物流是"偶遇式线索源" |

## 八、灵材实验室的"新东西"总结

| 和传统图鉴的区别 | 我们的设计 |
|----------------|-----------|
| 传统：被动解锁条目 | 我们：主动做实验发现新知识 |
| 传统：图鉴是死的 | 我们：研究笔记是活的——可以卖、可以分享、可以解锁新能力 |
| 传统：知道一切信息 | 我们：不知道的远比知道的多——探索永无止境 |
| 传统：所有玩家看到的图鉴都一样 | 我们：每个玩家的研究笔记都可能不同——"你是怎么发现这个组合的？" |
| 传统：和游戏玩法脱节 | 我们：实验发现的组合直接影响熔炼成功率——知识就是力量 |

> **灵材实验室的存在意义**：不是"又一个系统"——它是让玩家从"被动的灵材买卖者"变成"主动的灵材研究者"的通道。
>
> 你卖了一百株赤炎草，你还是个商人。
> 你发现了赤炎草+翠灵木+极光晶会产生从未见过的紫色结晶——你就从一个商人，变成了"那个发现紫色结晶的人"。
