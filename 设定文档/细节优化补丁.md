# 细节优化补丁

> 从高优先级到低优先级，逐项补充设定中的遗漏。

---

## 🔴 高优先级

### 1. 税收与经济成本细化

玩家在经营过程中除了摊位费和进货成本，还需要面对以下经济成本（从低到高逐步解锁）：

| 成本项目 | 出现阶段 | 金额 | 说明 |
|---------|---------|------|------|
| 摊位费 | 第1天起 | 10灵石/天 | 中央荒原露天摊位的基本费用 |
| 铺面租金 | 租用铺面后 | 60灵石/天 | 比摊位费高，但客流量和库存容量大幅提升 |
| 经营许可税 | 商道≥20或注册商号后 | 月利润的5% | 天道商会代城主府收取。按月自动扣除，玩家在月度简报中看到 |
| 跨域关税 | 第一次跨域贸易时 | 货值的3% | 进入其他板块时收取，由当地城主府征收。自动计入运费中 |
| 暗市交易抽成 | 进入暗市后 | 每笔交易的5% | 暗市官方抽成——用于维持守夜人和暗市运转。自动扣除 |
| 宗门供奉（可选） | 与宗门关系友好后 | 每月100-500灵石 | 自愿缴纳，不缴不会受罚，但缴了能提升宗门好感度 |
| 商会运营税 | 商会等级≥5 | 月利润的8% | 商会规模大了以后要交的税。比小摊时期高，但商会等级5的利润也远高于小摊 |

**设计意图**：
- 前期只有摊位费一种成本，让玩家轻松起步
- 中期随着经营规模扩大，税收项目逐渐增加——但每一笔都有对应的服务和价值
- 税率固定透明，玩家可以在月度简报中看到"本月税费合计"的汇总
- 玩家不会感觉"被系统压榨"，因为每项税费都有明确的用途描述

**税收的正面作用**：当玩家看到"您的跨域关税支撑了金戈域的商路维护"之类的管家消息时，纳税就不只是一种支出，而是"世界在运转"的一部分。

### 2. 议价失败的后续反馈

当玩家把顾客气走时，以下反馈机制确保玩家知道自己做了什么事：

**轻度谈崩**（还价太狠导致顾客拒绝）：
- 顾客留下一句话："算了，我去别家看看。"
- 宁秩内心独白："……开太高了么。"
- 没有惩罚。顾客会去其他摊位转一圈，当天不再回来

**中度谈崩**（态度恶劣或连续拒绝两次以上）：
- 顾客不满："你这什么态度？"
- 宁秩内心独白："好像把人得罪了。"
- 如果该顾客是熟客/老顾客，好感度-3
- 如果是新顾客，无好感度影响

**重度谈崩**（欺诈被识破：以次充好/虚报品阶）：
- 顾客大怒："你敢拿这种货来糊弄我？！"
- 周围NPC侧目——信誉度-5
- 该顾客成为"愤怒的顾客"，一定时间内不会再来
- 管家会发来消息："少爷，老奴听说您今天和一位客人有些不愉快……做生意，信誉比利润重要。"

**补救机制**：
- 如果随从在店，且随从有"口才好"特长 → 随从可以追上去打个圆场，有概率挽回
- 如果玩家有人心值≥30 → 第二天该顾客可能回来，但态度冷淡——玩家可以通过更优惠的价格挽回关系
- 如果以上都没有 → 时间会冲淡一切。大约7天后顾客会恢复正常态度

## 🟡 中优先级

### 3. 动态物价机制（大事件后的永久性变动）

灵墟的物价不是"事件结束后恢复原状"的。每一次大事件都会对经济产生**永久性影响**：

| 事件 | 短期波动 | 长期（永久）变化 |
|------|---------|----------------|
| 世界树之殇 | 世界树之液价格暴涨10倍 | 世界树之液永久性减产，价格稳定在事件前的5-7倍。苍木域部分灵材价格+20%。不会回落到事件前水平 |
| 天机子隐退 | 天道商会部分商品价格混乱±15% | 取决于继承人。资源型商品（金灵砂等）价格稳定，服务型商品（物流等）价格波动 |
| 灵潮大盛 | 灵材价格暴跌30-50% | 无永久影响。潮退后恢复正常 |
| 灵潮大枯 | 灵材价格暴涨50-100% | 无永久影响。潮退后恢复正常 |
| 灵潮异动 | 特定板块灵材价格剧变 | 异动板块的部分灵材可能永久性改变五行属性，形成新品种 |
| 宁家之难 | 宁家商路中断→玄冰域部分商品价格上涨 | 如果宁家覆灭，玄冰域商路永久性减少一条，物流成本+10% |
| 暗市风暴 | 暗市交易价格波动±30% | 取决于哪个派系获胜。守旧派赢→暗市规范但手续费上涨。革新派赢→暗市混乱但手续费下降风险上升 |

**设计意图**：
- 让大事件的影响真正"有分量"——世界树之殇结束后，苍木域的灵材确实永远变了，不会回到老样子
- 玩家在事件中做的选择（囤货/清仓/不参与）会长期影响后续经营
- 管家会在事件结束后提醒："少爷，世界树虽然保住了，但苍木域的灵材价格怕是回不去了。"

### 4. 存档系统预设

| 项目 | 设定 |
|------|------|
| 存档位数量 | 3个手动存档位 + 1个自动存档位（每日过夜时自动保存） |
| 手动存档 | 玩家随时可以保存（非战斗状态、非对话状态），在菜单中操作 |
| 自动存档 | 每天过夜结算完成后自动保存，覆盖上一个自动存档 |
| 存档内容 | 所有事件触发状态、三条暗线数值、NPC好感度、库存、灵石、在途货物、分店数据、已读/未读的管家消息 |
| 载入存档 | 可以选择载入手动存档或自动存档。注意：自动存档是"昨天过夜时"的状态，不是"当前时刻"的状态 |
| 关于灵墟湮灭结局 | 这个结局不会触发读档提示。玩家正常走到宁秩寿终正寝时，结算画面播放完，回到主菜单。此时玩家可以选择"开启新游戏+"（继承该存档的二周目标记）或"读取存档"（回到结局前的状态继续经营）|

### 5. 二周目开启细节

**如何开启二周目**：
- 玩家触发任意结局后，回到主菜单
- 主菜单出现"新游戏+"选项（替代原来的"新游戏"）
- 选择"新游戏+"后，弹出继承选择界面

**继承选择界面**：

```
是否使用存档 [存档1 - 商道81·天道45·人心60·主线结局：商业帝国] 的数据开启新游戏+？

继承内容：
  ✅ 天道熔炼的配方记录（已发现的相生组合保留）
  ✅ 灵墟百科知识（管家解锁的知识条目保留）
  ✅ 暗市的入场资格（不用再找人引荐）
  ✅ 灵墟湮灭的"记住"标记（如果上一周目触发过）
  
不继承的内容：
  ❌ 所有灵石、库存、店铺
  ❌ 所有好感度、声望值
  ❌ 商路进度、在途货物
  ❌ 所有剧情相关的状态（事件触发标记全部重置）
  ❌ 宁秩的年龄和时间进度

[开始新游戏+]  [取消]
```

**二周目初始状态**：
- 宁秩依然是18岁，站在中央荒原的入口
- 剧情从头开始——所有事件都会重新触发
- 但二周目的NPC对话中，会出现一些细微变化：
  - 老赵第一次交易时可能会说："我怎么觉得以前见过你？"
  - 管家的第一句玉简消息可能会有不同措辞
  - 暗市掮客的邀请方式可能会略有不同

**设计意图**：
- 二周目让玩家带着知识和经验重新体验剧情——知道什么值钱、暗市怎么走、哪个宗门值得合作
- NPC的细微变化给老玩家一种"好像有些地方不一样了"的新鲜感，而不是完全的重复
- 配方记录的保留让天道熔炼不再从零开始——玩家可以直接尝试高价值的熔炼组合

## 🟢 低优先级

### 6. 宁秩的母亲

在主角成长路线中补充一句：

- **如果母亲已去世**："宁秩的母亲在他六岁那年因一次修炼意外去世。他对她的记忆已经很模糊了——只记得她身上有一种淡淡的草药味。"

- **如果母亲还在世但不出场**："宁秩的母亲是凡人——没有修为。她在宁家所处的修士世界中一直活得很安静。宁秩离家时最放心不下的人其实是她，但他知道——母亲不会拦他，因为她一辈子没有拦过任何人。"

（选择哪种取决于你对这个角色的定位。我个人觉得凡人母亲这个设定更有意思——她是宁秩在宁家唯一一个真正的凡人亲属，这可以让宁秩的"凡人身份"更有根基。）

### 7. 教程回顾机制

玩家可以随时按 **H键** 或点击右上角的 **"?"图标** 打开轻量操作手册。

- 不是大段的教程说明
- 每个功能只有1-2句话的说明
- 按功能模块分组：经营 / 熔炼 / 商路 / 暗市 / 随从 / 管家

**示例**：
```
[经营]
- 进货：前往集市，点击摊位上的货物购买
- 摆摊：在自家摊位将库存中的货物拖拽到货架上
- 议价：点击顾客，根据市场参考价和成本决定出价
- 预约：如果顾客要的货你没有，可以承诺期限内进货交货

[熔炼]
- 放入灵材：夜间在熔炉前，将库存中的灵材拖拽到熔炉
- 每日熔炼上限：5次（显示在熔炉界面上方）
- 五行相性的提示会在天道值达到对应水平后自动出现
```

每个条目在第一次阅读时会标记为"已读"。如果玩家从未打开过操作手册，在前3小时内不会收到任何提示——不会弹窗问"要不要查看操作指南"。

### 8. 关于移动端适配的备注

当前交互系统设计基于PC端的鼠标+键盘操作。如果未来考虑移植到移动端/掌机，需重新评估以下交互：

| 交互方式 | PC端 | 移动端改动需求 |
|---------|------|--------------|
| 场景切换 | 点击边缘路径标志 | 改为触屏点击，可能需要放大热区 |
| 议价 | 滑块+数字键盘 | 滑块在触屏上体验良好，数字键盘需适配 |
| 拖拽（熔炼放灵材） | 鼠标拖拽 | 触屏拖拽可以保留，但需要增加"点击选择"的备选方案 |
| 管家玉简 | 点击右下角图标 | 触屏同样可以，热区需放大 |

在开发早期不需要考虑这个问题，但设计UI布局时建议保留"字号可调""热区可调"的灵活性。

### 10. 玩家主动报价

在议价界面新增一个 **"报价"模式**：

通常议价是"顾客出价→玩家回应"，但某些情况下玩家可以**主动报一口价**——比如遇到一个看起来不太懂行的顾客时，可以报一个高于市场参考价的价格。

**触发方式**：在顾客还没开口前，玩家可以点击"报价"按钮，输入一个数字。顾客的反应取决于：

| 报价相对参考价 | 顾客反应 | 概率 |
|--------------|---------|------|
| 低于或等于参考价 | 正常接受 | 80% |
| 高10-20% | 精明型顾客会还价；爽直型直接买 | 60%/90% |
| 高30-50% | 大部分顾客拒绝（"你当我傻？"） | 10% |
| 高100%以上 | 所有顾客拒绝，好感度-1 | 0% |

**设计意图**：
- 给玩家一种"我可以占个便宜"的机会——但风险自担
- 让议价不再只是"等NPC开价"的被动行为
- 一口价报高了被拒绝的惩罚很轻（好感度-1），鼓励玩家多尝试
