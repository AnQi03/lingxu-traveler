# 灵墟旅商 — 世界观框架

> 核心：修仙世界中，灵石为通用货币，万物皆可交易，而经商本身就是另一种修行。

---

## 一、世界基底

### 天地灵气
- 世界由灵气驱动，灵气浓度因地域而异
- 灵气浓郁处：名山大川、灵脉交汇之地 → 宗门盘踞
- 灵气稀薄处：凡人城池、荒漠戈壁 → 散修和商人活动
- 灵潮：每隔数年灵气会周期性潮涌/潮退，影响万物生长和物价波动

### 修炼体系（简略，服务于玩法）
| 境界 | 大致对应 | 消费特征 |
|------|----------|----------|
| 凡人 | 普通百姓 | 买米面油盐，偶尔求个护身符 |
| 练气期 | 入门修士 | 大量消耗低阶灵石、基础丹药 |
| 筑基期 | 中坚力量 | 需要筑基丹、法器、中级灵材 |
| 金丹期 | 宗门骨干 | 高阶丹药、灵兽、洞府材料 |
| 元婴期 | 宗门之主 | 天材地宝、仙品灵物，出价不计成本 |

> 游戏中不需要玩家修炼，但客户群分层决定了你的经营策略

## 二、世界地图：五大板块

> 世界由五方灵脉撑起，灵脉交汇之处形成五大板块，各自孕育出独特的生态环境与修炼文明。

### 总览

```
            【北·玄冰域】
               |
   【西·金戈域】— 中央荒原 —【东·苍木域】
               |
            【南·炎狱域】
               |
            【渊·深海域】
```

---

### 北·玄冰域

**生态**：永冻之地，千里冰原，极光游弋于天际。冰层之下暗藏灵脉温泉，偶有冰裂露出地热绿洲。

| 项目 | 内容 |
|------|------|
| **大宗门** | 寒渊宗 — 坐落于万年玄冰之上，宗门大殿由整座冰山雕成 |
| **宗门特质** | 修炼冰系功法，弟子心性清冷，重规矩，最难打交道 |
| **垄断资源** | 玄冰髓（炼器极品冷却材）、极光晶（阵法核心）、永冻灵泉 |
| **下属小宗门** | 霜剑门（剑修）、雪隐谷（情报组织）、冰蚕坊（织物） |
| **凡人城池** | 北望城（最大贸易枢纽）、暖炉镇（地热绿洲小镇） |
| **环境特色** | 极寒，运输途中可能冻损货物；但冰封保存灵材不腐，是天然仓库 |
| **贸易机会** | 玄冰髓外面根本买不到，只能通过寒渊宗渠道；倒卖暖炉镇的地热灵蔬到其他域是暴利 |

---

### 南·炎狱域

**生态**：火山群连绵，岩浆河纵横，空气灼热。火山灰孕育了最肥沃的灵土，越是危险之处灵材越珍贵。

| 项目 | 内容 |
|------|------|
| **大宗门** | 焚天阁 — 建于最大活火山口内，以岩浆为护城河 |
| **宗门特质** | 修炼火系功法，性格暴烈直爽，看重实力和诚意，不绕弯子 |
| **垄断资源** | 火心石（炼器核心燃料）、熔岩灵铁（顶级法器材料）、灰灵壤（灵植极品肥料） |
| **下属小宗门** | 赤炼堂（炼器宗）、焰丹谷（炼丹宗）、火蚁寨（驯兽） |
| **凡人城池** | 熔城（建在凝固岩浆上的大城）、灰落镇（火山灰平原上的农业镇） |
| **环境特色** | 随时可能火山喷发，喷发后短期内大量稀有灵材暴露地表，形成"火山淘宝潮" |
| **贸易机会** | 灰灵壤是全修仙界的刚需——谁都要种灵草；火山喷发后的抢货是高风险高回报事件 |

---

### 东·苍木域

**生态**：万古森林覆盖，灵木参天，有些古树自身就是生灵。林中雾气常年不散，深处有上古遗迹。

| 项目 | 内容 |
|------|------|
| **大宗门** | 万木灵宗 — 与一棵上古世界树共生，宗门即是森林本身 |
| **宗门特质** | 修炼木系/生灵功法，重视自然和谐，最讲因果，不善杀伐但最擅长持久 |
| **垄断资源** | 世界树之液（可续命延寿）、千年灵木心（顶级法器木质材料）、万灵孢子（炼丹辅料） |
| **下属小宗门** | 青药堂（灵药种植）、藤隐门（暗杀/情报）、木偶坊（傀儡术） |
| **凡人城池** | 翠屏城（树冠上的城市，梯桥相连）、菌落镇（森林地面的蘑菇聚落） |
| **环境特色** | 森林深处有迷阵，不识路者永远走不出来；灵木有灵性，砍伐过度会遭报复 |
| **贸易机会** | 世界树之液是延寿圣品，元婴期以上老怪物愿意倾家荡产买；灵木心是法器制作刚需 |

---

### 西·金戈域

**生态**：戈壁荒漠与金属矿脉交织，风沙漫天，地下矿洞密布如蛛网。地表荒凉，地下是另一个世界。

| 项目 | 内容 |
|------|------|
| **大宗门** | 铸魂殿 — 半在地上半在地下，地上是交易大殿，地下是矿场和锻造厂 |
| **宗门特质** | 修炼金系功法，务实重利，一切皆可交易，最开放的宗门 |
| **垄断资源** | 星陨铁（天外陨铁，最顶级的法器原材料）、金灵砂（通用炼器基础材料）、矿灵石（天然形成的矿脉灵石） |
| **下属小宗门** | 千锤门（锻造宗）、矿奴营（采矿组织，半强迫性质）、风沙帮（商路护送） |
| **凡人城池** | 铁壁城（堡垒城市，修仙界最安全的地方）、沙口镇（沙漠商路入口） |
| **环境特色** | 沙暴频发，商路随时中断；但沙暴过后矿脉裸露，可能发现新矿 |
| **贸易机会** | 金灵砂是全修仙界用量最大的材料，需求永远在；星陨铁是传说级材料，一片就能换一座城 |

---

### 渊·深海域

**生态**：无尽深水之下，阳光不可及之处。海渊底部有发光灵物照亮黑暗城池，海底热泉周围长满奇异灵藻。

| 项目 | 内容 |
|------|------|
| **大宗门** | 沧溟宫 — 悬浮于最深的海渊之上，以水压和阵法双重守护 |
| **宗门特质** | 修炼水系功法，神秘莫测，少与外界来往，但掌控海上一切通行 |
| **垄断资源** | 渊灵珠（天然形成于深海，可储存大量灵气）、海魂丝（顶级防具材料）、潮汐石（可操控水流） |
| **下属小宗门** | 潮音阁（占卜/预言）、珊瑚坊（装饰/建筑）、渊猎团（猎杀深海凶兽） |
| **凡人城池** | 浮城（漂浮在海面上的城市）、珍珠港（浅海贸易港） |
| **环境特色** | 无水下呼吸法无法深入；海底有巨型凶兽，商路最危险也最暴利 |
| **贸易机会** | 渊灵珠是硬通货中的硬通货，一颗顶百倍同重灵石；海上商路是连接其他四域的唯一通道，收过路费都能发财 |

### 板块间贸易逻辑

```
玄冰域 ──玄冰髓/极光晶──→ 炎狱域（冷却材料换灰灵壤）
炎狱域 ──灰灵壤/火心石──→ 苍木域（灵植肥料换灵木心）
苍木域 ──灵木心/灵药──→ 金戈域（法器材料换星陨铁）
金戈域 ──金灵砂/法器──→ 深海域（通用材料换渊灵珠）
深海域 ──渊灵珠/海魂丝──→ 玄冰域（硬通货换冰系材料）
```

> 每个板块都有自己的刚需和垄断，**差异就是商机**。玩家的核心玩法之一就是找到板块间的价差，低买高卖。

### 中央荒原

五大板块交汇之处，灵气最混乱也最稀薄，不属于任何宗门。

- **宁秩的起点**：他逃出宁家洞府后，第一个落脚点就在这里
- 无主之地，鱼龙混杂，什么人都有
- 五域商路在这里交汇，是全修仙界最大的自由交易市场
- 也是暗市最活跃的地方

### 货币
- **下品灵石**：基础货币，凡人交易用
- **中品灵石**：1中品 = 100下品，修士常用
- **上品灵石**：1上品 = 100中品，大宗交易

### 货物品阶
同一类物品分四个品阶，品阶越高越稀有：

| 品阶 | 标记 | 说明 |
|------|------|------|
| 凡品 | 灰色 | 普通品质，凡人可用 |
| 灵品 | 绿色 | 含灵气，修士可用 |
| 宝品 | 蓝色 | 灵气充沛，稀缺 |
| 仙品 | 金色 | 传说级，可遇不可求 |

> 例：一株凡品灵芝值10灵石，仙品灵芝值10000灵石——品阶决定一切

### 价格影响因素
1. 品阶（凡/灵/宝/仙）
2. 地域（产地便宜，远方贵）
3. 灵潮周期（灵潮期灵材丰收价跌，潮退期价涨）
4. 宗门关系（友好宗门给折扣，敌对宗门不交易甚至抢劫）
5. 稀有度（某些天材地宝全服限量）

## 三、势力格局

### 宗门
- **正道大宗**：控制灵脉，垄断高端资源，规矩多但稳定
- **魔道宗门**：不择手段，货物流通快但风险大，利润高
- **中立宗门**：炼丹宗、炼器宗、灵植宗，是重要的供应商和客户
- **散修联盟**：松散组织，消息灵通，是情报和倒货的重要渠道

### 商会
- **天道商会**：最大的商会，背后是正道联盟，规矩最严
- **暗市**：地下交易网络，什么都能买，包括禁术和毒丹
- **万宝楼**：中立商会，只认灵石不认人
- **玩家商会**：宁秩创立的商会，初始无名，逐步崛起

### 官方/凡人
- **凡人王朝**：不管修士的事，但控制凡人城市的税收和治安
- **城主府**：每个修士城池的管理者，收摊位费、发经营许可

## 四、核心玩法骨架

### 经营循环
```
进货 → 加工（可选）→ 定价 → 摆摊/开店 → 客人来买 → 赚灵石 → 进更好的货
```

### 进货渠道
1. **集市采购**：最基础，去各地低买高卖
2. **宗门供货**：跟宗门搞好关系后可以拿到独家货源
3. **自行采集**：派伙计去灵山灵谷采集（有风险）
4. **冒险者委托**：花钱雇人去秘境/遗迹取宝（高风险高回报）
5. **炼丹炼器**：买原材料自己加工，利润最高但需要配方和技术

### 核心决策点
- 这批货卖给谁？凡人量大价低，修士量少价高
- 要不要加工？原料便宜但利润低，成品贵但有风险（炼丹可能炸炉）
- 走正道还是暗市？正道安稳利润薄，暗市暴利但可能被查
- 扩张还是存钱？开分店赚更多但管理更难

## 五、核心特色系统：天道熔炼

### 设定
五行杂灵根让宁秩无法修炼，却赋予了他一种独有能力——他能感知不同灵材之间微妙的共鸣关系，将同品阶的物品投入"天道熔炉"中熔炼，试图激发更深层的灵性。

这不是炼丹，不是炼器，是赌命。

### 基本规则
- **输入**：2-5件同品阶物品
- **产出**：随机，由概率决定

### 熔炼结果

| 结果 | 概率 | 说明 |
|------|------|------|
| ✨ 升品 | 极低（约3-5%） | 产出一件高一品阶的物品，一飞冲天 |
| ⚡ 异变 | 低（约10-15%） | 产出意料之外的物品，好坏看运气（比如三株灵草熔出毒丹） |
| ➡️ 原样 | 中等（约30%） | 产出同品阶但不一定同类的物品 |
| 💔 降品 | 较高（约35-40%） | 品阶下降一档，灵性受损 |
| 💀 报废 | 低-中（约10-20%） | 什么都没了，灰飞烟灭 |

### 影响概率的因素
1. **投入物品数量**：投入越多，升品概率微增，但报废概率也增加
2. **物品相性**：五行相生的组合升品概率更高，相克的组合更容易报废
   - 宁秩的杂灵根优势：他能"感知"相性提示，普通商人完全盲熔
3. **灵潮周期**：灵潮期熔炼成功率略高，潮退期更危险
4. **熔炼经验**：成功熔炼次数越多，获得"熔炼感悟"，微幅提升成功率

### 玩家的核心抉择

```
                安全路线                    风险路线
            正常买卖赚差价    ←→    天道熔炼搏一搏
             稳定但慢                   暴富或归零
```

这个系统制造了游戏里最核心的心理张力：
- 你手里有5件灵品灵草，卖了稳赚500灵石，还是熔一下搏一件宝品？
- 熔成功了，你从路边摊变成名铺；熔失败了，一夜回到解放前
- **越穷越想赌，越赌越穷**——还是克制住慢慢来？这就是宁秩的修行

### 剧情呼应
- 父亲当年禁止他碰熔炼——"你灵根驳杂，熔炼必出事"
- 宁秩第一次成功升品时：原来驳杂的灵根不是缺陷，是天赋
- 后期解锁：天道熔炼的终极真相——**天道本就包罗万象，杂灵根反而是最接近天道本质的**

## 七、动态世界与多结局系统

### 设计理念
不是在关键节点弹出"你选择A还是B"，而是玩家**每一天的经营行为**都在悄悄改变世界的走向。结局不是选出来的，是活出来的。

### 三大隐性维度

玩家的行为会持续影响三个维度，游戏全程不显示数值，但世界会给出反馈：

| 维度 | 积累方式 | 世界反馈 |
|------|----------|----------|
| **商道** | 诚信经营/坑蒙拐骗的累计 | 名声好坏、客户类型、能否进入某些市场 |
| **天道** | 天道熔炼的频率和结果 | 熔炼成功率偏移、是否引起天道注意 |
| **人心** | 对待弱者/竞争者/朋友的方式 | NPC态度、盟友数量、关键时刻谁帮你 |

### 世界动态机制

**1. 宗门兴衰**
- 玩家的供货选择会影响宗门实力。长期给某宗门供丹药→该宗门壮大→改变区域格局
- 一个宗门被灭→原来受它压制的小宗门崛起→新客户新市场
- 玩家不是旁观者，是推手

**2. 灵潮周期**
- 灵潮期：灵材丰收，物价跌，但熔炼成功率上升→有人囤货有人狂熔
- 潮退期：物资紧缺，物价飞涨，散修劫掠增多→运输风险大但利润高
- 每次灵潮都是一次经济重洗

**3. 流动的NPC**
- 冒险者有自己的人生：出发→可能带回宝物/可能失踪/可能回来后成了竞争对手

---


### 重大事件：逼玩家站队的时刻

> **设计原则：大事从小处渗透。** 世界级变局不会直接找上门，而是先改变你身边的日常——你认识的NPC变了、常买的货断供了、老客户出了事。等你反应过来，你已经站在某个立场上了。

> 每个事件分为**渗透期**（影响日常，玩家可感知但不一定理解全貌）和**爆发期**（矛盾公开化，必须表态）。

---

#### 事件一：世界树之殇（万木灵宗危机）

**本质**：灵墟最重要的灵药产源正在死去，所有人的利益都会受牵连。

##### 渗透期：玩家还没听说过"世界树"，但日子已经开始不对劲了

| 你遇到的事 | 你以为的原因 | 真正的原因 |
|-----------|------------|-----------|
| 阿萤的灵植摊突然断货了，她愁眉苦脸说"最近苗子总养不活" | 天气不好？ | 苍木域灵气衰减，灵植成活率在降 |
| 常来买灵药的散修老周不来了，别人说他病了 | 个人运气差 | 灵药品级在普遍下降，散修买到的大多是次品 |
| 集市上灵药价格悄悄涨了20%，你去进货被加价 | 商人囤货？ | 产量确实在减少，供不应求 |
| 你帮老客户预约的灵药，对方来取时发现品阶不对——说好的灵品变成了凡品 | 供货商坑你？ | 整条供应链的品质都在下滑 |
| 苏荷的酒馆里，有人醉后说"听说苍木域那边出事了" | 醉话 | 消息开始泄露 |

**这个阶段玩家的感受**：生意越来越难做，进货变贵、品质变差、老客户抱怨。你以为是普通的市场波动，但其实整个灵药体系在从根部腐烂。

##### 爆发期：世界树将死的消息公开

| 阶段 | 世界变化 | 玩家面对的抉择 |
|------|---------|---------------|
| **真相公开** | 苍梧子承认世界树在枯萎，灵药产量骤降，市价暴涨 | 你手里的灵药库存是囤还是卖？老客户来找你救命呢 |
| **四宗角力** | 各宗门亮出态度（见下方），开始争夺资源 | 每一宗都来找你——不是找你站队，是找你做生意，但每笔生意都有立场 |
| **灵液争夺** | 世界树之液成了全修仙界的争夺对象 | 有人出天价，有人用势力压——你守得住秘密吗？ |
| **最终走向** | 世界树可能续命成功/失败/异变 | 你在危机中的每一步都在决定结局 |

**四宗的态度**：

| 宗门 | 表面立场 | 真实意图 | 怎么找上玩家 |
|------|---------|---------|-------------|
| 寒渊宗 | "愿助苍木域渡过难关" | 用援助换取灵药产区控制权 | 派人来谈"合作"：你帮我们运物资进苍木域，我们给你冰系灵材独家代理 |
| 焚天阁 | "灵植死了正好，灰灵壤需求暴涨" | 巴不得世界树早死 | 灰灵壤订单暴增，你接单就是加速世界树死亡——但这单利润够你活半年 |
| 铸魂殿 | "我们只做生意，不站队" | 两边都赚 | 给你开出优厚条件，只要你两头供货——表面中立，实际在维持混乱 |
| 沧溟宫 | "海的低语说……世界树不该死" | 真心想救 | 派沉渊来找你：深海秘境有续命之物，但你得亲自冒险 |

**立场光谱**：

```
全力救树 ←——————————————→ 坐视枯死
   │                          │
   │ 帮阿萤找灵植替代源       │ 囤积灵药等暴涨
   │ 拒绝焚天阁的灰灵壤大单   │ 接焚天阁的暴利订单
   │ 跟沉渊去深海秘境冒险     │ 把世界树之液高价卖给元婴老怪
   │ 给老客户平价供灵药       │ 管他呢，赚钱要紧
```

> **没有"正确答案"**。关键是——你在渗透期做的那些"正常经营决策"，已经不知不觉把你推到了某个位置上。

#### 事件二：天道之锤（被迫走向暗市）

**本质**：天道商会要吞并所有独立商人的生存空间，玩家被逼进暗市不是堕落，是求生。

##### 渗透期：天道商会还没有颁布统购令，但已经开始"温水煮青蛙"

| 你遇到的事 | 你以为的原因 | 真正的原因 |
|-----------|------------|-----------|
| 天道商会的人来"拜访"你，客气地建议你加入商会，享受"供货优先权" | 商会想招人？ | 在摸底你的货源和客户 |
| 你的某个供货商突然说不卖给你了，只走天道商会渠道 | 供货商自己选的？ | 天道商会在逐个收编上游 |
| 集市上多了几个天道商会的摊位，价格比你低10% | 正常竞争？ | 他们在用补贴价挤压独立商人 |
| 白鹿（天道商会少主）请你喝茶，聊得很愉快，走时说"以后多合作" | 交朋友？ | 在评估你——是拉拢还是打压 |
| 老莫突然变得沉默，不再教你商路技巧了 | 他心情不好？ | 他年轻时是天道商会的人，他知道要发生什么 |

**这个阶段玩家的感受**：生意越来越难，供货商在减少，竞争对手在增多，但你还能撑住——直到那道令下来。

##### 爆发期：统购令颁布

| 阶段 | 世界变化 | 玩家面对的抉择 |
|------|---------|---------------|
| **统购令颁布** | 所有灵材必须经天道商会统购统销，利润被大幅压缩 | 按官方价卖就亏本——你还能活吗？ |
| **第一根稻草** | 一个老客户深夜来找你："我师父的灵药断了，官方渠道排到下个月，你能想想办法吗？" | 帮还是不帮？这是第一笔"地下订单" |
| **暗市扩张** | 越来越多商人被逼入暗市，暗市规模暴涨 | 你在暗市越深，赚得越多，但追查也越紧 |
| **最终摊牌** | 天道商会清洗暗市 / 统购令被推翻 / 僵持 | 你站哪边决定了你是被清算还是被铭记 |

**暗市的层层深入**：

| 层级 | 触发方式 | 交易内容 | 你失去的 |
|------|---------|---------|---------|
| 第一层 | 老客户求助 | 帮老客户私下找货，价格公道 | 官方渠道的优先权 |
| 第二层 | 赤练找上门 | 在暗市摆摊，卖给陌生人 | 天道商会的合作资格 |
| 第三层 | 暗市内部推荐 | 经销禁品（违禁灵材、未注册丹方） | 正道宗门的信任 |
| 第四层 | 暗市主人现身 | 触碰暗市核心——发现暗市背后是谁 | 回不了头了 |

> **关键**：进入暗市不是一瞬间的选择，是你在渗透期被一步步挤压后，到了爆发期发现"不走暗市就得关门"。

#### 事件三：冰火之殇（炎冰世仇爆发）

**本质**：灵脉偏移引发两大宗门争夺，商路被战争裹挟，你不可能独善其身。

##### 渗透期：灵脉偏移的影响先到，战争还没打起来

| 你遇到的事 | 你以为的原因 | 真正的原因 |
|-----------|------------|-----------|
| 你常走的商路突然多了一群"巡逻队"，要收过路费 | 地方势力趁火打劫？ | 焚天阁和寒渊宗在交界处布控，还没公开 |
| 你在集市上收到了一种从没见过的灵材——同时有火和冰的灵性 | 捡到宝了？ | 新灵脉的产出开始流入市场 |
| 护卫铁柱突然警告你"最近别走北边那条路" | 他在小题大做？ | 他有军方直觉，感觉到了战争前兆 |
| 寒渊宗和焚天阁的弟子在酒馆吵起来，差点动手 | 年轻人冲动？ | 两宗的矛盾在基层已经压不住了 |

**这个阶段玩家的感受**：商路变贵了，但也出现了新货——那批双系灵材是你的品阶鉴微发现的，熔炼效果极好。你还在高兴，不知道这是战争的前兆。

##### 爆发期：冲突公开化

| 阶段 | 世界变化 | 玩家面对的抉择 |
|------|---------|---------------|
| **代理人战争** | 两宗不直接开战，但各拉拢小宗门和商人 | 焚天阁和寒渊宗同时找你签独家——你只能选一边 |
| **商路封锁** | 炎冰两域各自封闭，物资断流 | 你在另一域的库存怎么办？ |
| **全面对抗** | 两域各自封闭，贸易完全中断 | 你之前跟哪边做生意多，哪边就信任你一点——但另一边会记恨 |
| **停战谈判** | 某一方撑不住要谈和 | 你在战争期间的立场决定了你在谈判桌上的位置 |

**最刁钻的设计**：新灵脉的双系灵材——你是在渗透期就开始用的，那时候你不知道它会成为战争导火索。等战争爆发了，你手里已经有一批存货。熔炼？卖掉？上交？每一个选项都有立场。

#### 事件四：矿奴之怒（铸魂殿的黑暗面）

**本质**：铸魂殿的暴利建立在压榨之上，真相曝光后，你的供货链和良心同时受拷问。

##### 渗透期：矿奴还没跑出来，但痕迹已经在你身边了

| 你遇到的事 | 你以为的原因 | 真正的原因 |
|-----------|------------|-----------|
| 你进的金灵砂品质参差不齐，有时混着血迹 | 铸魂殿品控变差？ | 矿奴在极端条件下开采，品控根本顾不上 |
| 沙口镇来了几个面黄肌瘦的陌生人，在街上乞讨 | 普通流民？ | 从矿奴营逃出来的，但还没形成规模 |
| 姜糖（账房）看到铸魂殿的账目后脸色变了，但不说为什么 | 他算术职业病？ | 他看出了金灵砂产量和矿工数量的比例不对——有人在被压榨 |
| 铸魂殿突然大幅提高金灵砂产量，价格反而降了 | 产能提升？ | 加大了矿奴的开采强度 |

**这个阶段玩家的感受**：金灵砂便宜了，你的利润变好了——你不会主动去想为什么便宜。

##### 爆发期：矿奴暴动

| 阶段 | 世界变化 | 玩家面对的抉择 |
|------|---------|---------------|
| **矿奴出逃** | 数百名矿奴涌入中央荒原，身上带伤 | 他们就倒在你铺子门口——你给不给口水？ |
| **铸魂殿施压** | 发布悬赏：交还矿奴有赏，藏匿矿奴同罪 | 矿奴里有人懂矿脉，如果你雇佣他们…… |
| **真相扩散** | 矿奴的遭遇传遍修仙界 | 铸魂殿是你最大的金灵砂供应商——你还要跟他做生意吗？ |
| **清查** | 铸魂殿派人来"清点"你的商铺 | 你藏了矿奴吗？交还是不交？ |

**关键设计**：渗透期你享受了金灵砂降价的红利，爆发期才知道低价背后的代价——**你已经是共犯了吗？** 这个问题没有答案，但它会让你在后面的每一次进货都多想一层。

### 事件之间的连锁

这些事件不是孤立的，它们通过**日常经营**相互影响：

| 连锁 | 传导方式 |
|------|---------|
| 世界树枯萎 → 灵药断供 | 你进货时发现灵药价格涨了，天道商会借机宣传"统购令能稳定价格" |
| 统购令逼商人入暗市 | 暗市壮大后有能力帮矿奴逃跑——你如果已经在暗市，就会遇到逃出来的矿奴 |
| 冰火冲突 → 商路封锁 | 加速灵药紧缺，阿萤的灵植更运不出来了，加剧世界树危机的体感 |
| 矿奴暴动揭露铸魂殿 | 铸魂殿在冰火冲突中失去调停资格，战争更难停火 |

> 你不是在一个个事件里做选择，而是在一个**连锁反应的世界**里经营。你在渗透期做的每一笔正常生意，都在爆发期变成了你的立场。
- 竞争对手有AI：看到你卖什么赚钱就跟着卖，甚至挖你的伙计

**4. 事件链**
不是随机事件，而是有因果关系的：
- 你给某个穷散修打折 → 他后来成了筑基修士 → 成了你的忠实客户 → 关键时刻替你挡了一次暗市追杀
- 你卖了假货给某人 → 他到处传你坏话 → 城里客户减少 → 被迫走暗市 → 越陷越深

### 结局谱系

不是简单的3-5个结局，而是一个**谱系**，由三个维度的组合决定大方向，加上关键事件决定细节差异：

#### 商道结局分支
| 结局 | 触发条件 | 描述 |
|------|----------|------|
| 天下通商 | 商道极高，人心极高 | 建立修仙世界最大的商会网络，万国通商，父亲以平等身份来访 |
| 暗市之王 | 商道极低，掌控暗市 | 什么都能买卖，有钱能使鬼推磨，但身边没有真朋友 |
| 稳健商贾 | 商道中等，不冒大险 | 安安稳稳的小商会，日子过得去，但离"成为父亲的骄傲"始终差一点 |

#### 天道结局分支
| 结局 | 触发条件 | 描述 |
|------|----------|------|
| 以商证道 | 天道极高，成功升品次数多 | 杂灵根的本质被天道认可，开辟"商道"修炼体系，前无古人 |
| 天道弃子 | 天道熔炼失败过多 | 一次致命的熔炼炸炉，灵根尽毁，从此再也无法感知灵材品阶 |
| 敬而远之 | 天道中等，极少使用熔炼 | 知道自己有这个能力但选择克制，用稳扎稳打的方式走到终点 |

#### 人心结局分支
| 结局 | 触发条件 | 描述 |
|------|----------|------|
| 众望所归 | 人心极高 | 关键时刻所有人来帮你，不只是生意伙伴，是朋友 |
| 孤家寡人 | 人心极低 | 赚了很多灵石，但没有人真心待你，和父亲一样的孤独 |
| 江湖故人 | 人心中等 | 有几个真朋友，虽然不多，但够了 |

#### 组合示例
- 商道极高 + 天道极高 + 人心极高 → **商道始祖**：宁秩开创商修体系，与父亲并肩立于修仙世界之巅
- 商道极低 + 天道极高 + 人心极低 → **疯狂的赌徒**：靠熔炼一飞冲天又跌入谷底，最终在一次孤注一掷中消失于天道熔炉
- 商道中等 + 天道中等 + 人心中等 → **平凡的传奇**：没有惊天动地，但活出了自己想要的人生——不被怜悯地活着

> 大方向9种组合 × 关键事件细节差异 → 实际体验远超9个结局

### 关键原则
1. **永远不弹出"你选择A还是B"**——所有分支来自玩家自然的行为积累
2. **玩家可能不知道自己走向哪个结局**——直到结局揭晓的那一刻回顾，才发现一切早有伏笔
3. **没有"坏结局"**——每个结局都是宁秩的某种活法，只是不同的路
4. **可回溯**——结局画面展示关键行为节点，让玩家知道"我是在哪里走向这条路的"

## 八、NPC系统

### 设计理念
灵墟的每个人都在过自己的人生。他们不是待在原地等你交互的NPC，而是有自己的欲望、立场和秘密。你选择相信谁、培养谁、防备谁，决定了你的商会能走多远。

---

### 一、核心随从系统

玩家身边的核心随从，拥有**忠诚值**和**能力值**两项关键数值。

#### 忠诚值（0-100）

| 忠诚区间 | 状态 | 表现 |
|----------|------|------|
| 80-100 | 死心塌地 | 关键时刻主动卖命，偶尔送你礼物，战斗中优先保护你 |
| 60-79 | 忠心耿耿 | 正常执行命令，不会背叛 |
| 40-59 | 心生间隙 | 执行效率降低，偶尔偷懒，可能被对手收买 |
| 20-39 | 同床异梦 | 消极怠工，偷偷截留利润，可能泄露商业机密 |
| 0-19 | 背叛边缘 | 随时可能卷款跑路、投靠对手、甚至暗害你 |

**忠诚值影响因素**：
- ✅ 按时发薪、涨薪、过节送礼
- ✅ 在危险中保护他们
- ✅ 听取他们的建议
- ✅ 帮他们解决个人困难
- ❌ 长期克扣工资
- ❌ 让他们干违背良心的事
- ❌ 偏心其他随从
- ❌ 无视他们的困境

**背叛事件举例**：
- 管家忠诚过低 → 卷走仓库货物投奔竞争对手
- 护卫忠诚过低 → 遇到劫匪时袖手旁观甚至倒戈
- 账房忠诚过低 → 做假账私吞灵石
- 伙计忠诚过低 → 把你的客户名单卖给对手

#### 能力值（多维度）

不同职位看重不同能力：

| 随从类型 | 核心能力 | 辅助能力 |
|----------|----------|----------|
| 管家 | 统筹/人脉 | 讨价还价、情报收集 |
| 护卫 | 战斗/警觉 | 商路护卫、威慑 |
| 账房 | 算账/心算 | 识假货、估价 |
| 伙计 | 推销/亲和 | 货物搬运、店面维护 |
| 炼师 | 炼丹/炼器 | 识材、品阶鉴定 |
| 探子 | 潜行/情报 | 侦察、反侦察 |

**能力提升方式**：
- 实战积累（跑商路、应付劫匪）
- 送他们去进修（花钱，但期间不能用）
- 玩家亲自指导（消耗时间，但增加忠诚+能力）

### 二、可深交NPC（20+）

每个可深交NPC有独立的好感度系统、个人故事线和隐藏面。

#### 五大宗主

##### 1. 寒渊宗·宗主·冷霜凝
- **性格**：外冷内冷，看似无情实则极致理性。说话从不多一个字，但每个字都算数
- **喜好**：珍稀冰系灵材、逻辑严密的合作方案

### 三、道侣系统

#### 两种结缘方式

**灵墟中，人与人的结合有两种路：**

| | 情缘道侣 | 联姻道侣 |
|---|---|---|
| **触发方式** | 好感度达标后可提出请求 | 商会势力达标后宗门主动提出 |
| **核心条件** | 好感度 + 可能需要完成任务 | 物质条件（聘礼/嫁妆） |
| **基础** | 情感 | 利益 |
| **隐藏特质** | 有，需要慢慢发现 | 有，但宗门会提前告知部分（不一定是全部） |
| **优势** | 情感羁绊深，关键时刻更可靠 | 立刻获得商业优惠政策 |
| **风险** | 隐藏特质可能踩雷 | 关系建立在利益上，商会衰退时联姻可能破裂 |

---

#### 情缘道侣

从可深交NPC中发展，好感度达到一定程度后可以提出结为道侣的请求。

**可发展为情缘道侣的NPC及任务：**

| NPC | 结缘好感要求 | 结缘任务 |
|------|------------|----------|
| 阿萤（灵植小贩） | ★★★ | 帮她找到苍木域的某种绝世灵植种子，证明你愿意为她冒险 |
| 青萝（炼丹师） | ★★★★ | 为她找到一种失传丹方，证明你认可她的才华而非只看她的脸 |
| 苏荷（酒馆老板娘） | ★★★ | 在她的酒馆被地痞砸场子时出手撑腰，证明你靠得住 |
| 裴鹤（情报贩子） | ★★★★ | 完成他布置的三个情报考验，证明你配得上一个情报贩子的信任 |
| 沉渊（冒险者） | ★★★★ | 跟他一起深入一次深海秘境，证明你不是只会躲在后方的商人 |

#### 联姻系统

**触发条件**：商会势力达到"一方之主"（拥有3家以上店铺、跨域经营、声望达标）

**联姻流程**：
1. 宗门使者上门提亲，提出物质条件（聘礼清单）
2. 玩家选择接受/拒绝
3. 接受后举行联姻仪式，双方正式结盟
4. 联姻生效，获得商业优惠

**联姻风险**：
- 联姻是利益绑定，**商会势力衰退时联姻可能被单方面解除**
- 联姻对象可能有宗门安排的隐藏任务（如"定期向宗门汇报商会动向"）
- 与一个宗门联姻 → 其他宗门可能心生芥蒂
- 联姻对象的好感度仍然存在，**好感过低联姻名存实亡**——优惠打折、对外泄露信息

**情缘 vs 联姻的核心区别**：
- 情缘：赌的是人心，人心难测但真心无价
- 联姻：赌的是实力，实力在则盟约在，实力不在则树倒猢狲散
- **你可以先联姻后发展情缘，也可以先有情缘再被联姻插足——但一个人只能有一位道侣**

### 四、NPC选择的核心抉择

你不可能跟所有人搞好关系，资源有限、立场冲突：

- 跟寒渊宗走太近 → 焚天阁对你冷淡
- 用暗市渠道 → 正道宗门不信任你
- 对某个随从太好 → 其他随从可能嫉妒
- 道侣选了暗市背景的 → 正道客户减少

**每个选择都有代价，没有全通路线。这就是灵墟——你必须取舍。**

## 九、开发优先级分层

### 第一层：MVP（必须做，先跑通）

**目标**：一个能让人玩起来的最简版本，验证核心玩法是否有趣。

| 模块 | 范围 |
|------|------|
| 地图 | 仅中央荒原，1个集市+1个店铺 |
